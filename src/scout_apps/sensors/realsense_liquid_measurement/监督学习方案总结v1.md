# 监督学习方案总结 v1

## 1. 当前监督学习算法结构

当前主线是 **single-frame pure vision regression**：输入是 rectified ROI 灰度图，标签是人工标注的 `human_peak_mm`，输出是当前时刻液面峰值高度。  
当前使用的网络是轻量 CNN 回归器：`Conv(1->16, 3x3) + ReLU + MaxPool`，再接 `Conv(16->32, 3x3) + ReLU + MaxPool`，然后 `AdaptiveAvgPool(8x16) + Flatten + Linear(4096->64) + ReLU + Linear(64->1)`。  
当前 best family 仍然是这版单帧模型；`K=5` 的简单时序平均头没有超过它，而“上下各裁 1/4”的 `center-half ROI` 只带来了很小的增益，因此当前主线仍应理解为“单帧视觉主线 + 小范围 ROI ablation”。  

## 2. 当前阶段性结果

完整 `raw ROI` 单帧模型在 held-out test 上达到 `MAE = 0.1905 mm`、`RMSE = 0.2965 mm`、`Corr = 0.8932`，已经明显优于 `/slosh/height` 的 `MAE = 0.2852 mm`。  
在此基础上，我们又做了一个固定 crop ablation：保持完整宽度，只把 ROI 上下各裁掉 `1/4`，得到 `center-half ROI`；这版 test `MAE = 0.1894 mm`，比完整 `raw ROI` 的 `0.1905 mm` 只好了一点点。  
这说明“ROI太大”不是当前误差的主因，当前误差更可能还是来自高峰值样本稀缺、单帧任务本身缺时序信息，以及标签仍然是 `human_peak_mm` 而不是更底层的 `y_rect`。  

## 3. 当前功能能否判断 MPC 是否抑制液体晃动

可以，当前功能已经有能力用于判断 **MPC 是否对液体晃动有明显抑制作用**，因为当前 best `SL` 相对人工真值的 held-out test 误差已经在 `0.19 mm` 量级，明显优于 `/slosh/height` 的 `0.2852 mm`。  
这意味着它已经可以作为一条比 `/slosh/height` 更可信的离线评估链，用来比较两组控制器 bag 的峰值幅值、超阈值时间、峰值频次和衰减速度。  
但它目前更适合支持“中等及以上效应量”的结论，不适合只凭它单独宣称 `0.05 ~ 0.1 mm` 这种很小改善，因此若两组控制器差异很小，仍应抽人工真值做复核。  

## 4. 当前保留的核心代码文件

数据组织层主要包括：`scripts/SL_build_supervised_manifest.py`、`scripts/SL_make_splits.py`、`scripts/SL_supervised_common.py`，分别负责汇总 `debug_session/human_labels`、按 bag 切分 train/val/test，以及提供公共读表、指标和工具函数。  
当前主线训练层主要包括：`scripts/SL_export_raw_rectified_roi.py`、`scripts/SL_export_center_half_roi.py`、`scripts/SL_train_visual_human.py`、`scripts/SL_train_visual_temporal_human.py`；其中 `raw ROI` 和 `center-half ROI` 都属于单帧视觉主线，时序版目前只是对照实验。  
结果分析与 debug 层主要包括：`scripts/SL_plot_visual_human_curves.py`、`scripts/SL_plot_slosh_vs_visual_only.py`、`scripts/SL_render_visual_prediction_debug.py`、`scripts/SL_infer_on_debug_session.py`，分别用于画曲线、单独比较 `SL` 与 `/slosh/height`、生成逐帧图像级误差排查图，以及对整包 debug session 做推理。  

## 5. 当前阶段结论

当前监督学习链已经不是“概念验证”，而是已经训练出了一版能直接输出当前液面峰值高度的模型，并且在 `0401` held-out bags 上稳定优于 `/slosh/height`。  
当前最稳的工程结论是：**可以把它作为当前控制器抑制效果的主离线评估器，但不能把它包装成已经完成的高精度终版测量器。**  
下一步最值钱的方向不是再做无目的超参搜索，而是围绕高峰值样本、当前帧锚定时序头、以及更底层 `y_rect` 标签监督继续收敛误差。  

## 6. 当前保留主线与已清理垃圾

当前官方主线 best 仍然是 `sl_runs/SL_visual_human_0401_raw_roi_v1/`，也就是单帧 `raw ROI -> human_peak_mm` 这版；`center-half ROI` 只保留为小型 ablation，对主线不改口径。  
`sl_runs/SL_visual_human_0401_raw_roi_v2_after_train_candidates/` 保留为一次有价值的失败实验，它说明“只补极端难例”会把训练分布带偏，因此不能升级成新的 best。  
本轮只做了保守清理：删除了 `scripts/__pycache__/` 和 `/data/a/.../SL_candidate_frames_all_scored.csv` 这类中间垃圾，保留了 best、失败实验、小型 ablation 和时序对照，避免把仍有分析价值的实验结果误删。
