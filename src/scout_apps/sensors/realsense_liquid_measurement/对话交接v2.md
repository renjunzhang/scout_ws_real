## 3. 当前误差结构

当前 best 的误差特征不是“整体都差”，而是：

- 低幅值段已经明显收紧
- 中间幅值段可用
- 少数高峰帧仍存在压峰

按目标幅值分层：

- `low <= 0.2 mm`
  - `MAE = 0.0742 mm`
- `mid 0.2 ~ 0.5 mm`
  - `MAE = 0.1454 mm`
- `high > 0.5 mm`
  - `MAE = 0.3724 mm`

held-out test `554` 帧上：

- `|err| > 0.2 mm`：`118`
- `|err| > 0.3 mm`：`71`
- `|err| > 0.5 mm`：`35`

所以当前主矛盾已经不是 average case，而是高峰尾部。

## 7. 当前对方法的判断

- 不再继续回到单帧主线扫 `lr / batch / weight` 这类细碎超参
- 不再继续缩回 `K=5`
- 当前最稳的 temporal 主线是：
  - `K=7`
  - `GRU`
  - `current-frame anchor`
  - weighting `1.0 / 1.5 / 3.0`
- `TCN` 是值得保留的次优备选：
  - `RMSE` 和尾部稳定性更好
  - 但总体 `MAE` 没超过 current best

如果后续还要继续推进，优先方向应是：

- hardest segments / hardest frames 定向分析
- 评估口径固化
- 控制器对比实验

## 8. 推荐评估口径

后续对外或交接时，不建议只报 `MAE`。

推荐固定同时报告：

1. `overall MAE`
2. `overall RMSE`
3. `|err| > 0.3 mm` 的帧比例
4. `low / mid / high` 分层 MAE
5. `p95 abs error`
6. `max abs error`
7. `bag-wise MAE / p95 / max / >0.3mm count`
8. 仅在 `target > 0.5 mm` 上统计的相对误差

原因：

- 单看 `MAE` 会把不同幅值区间混在一起
- 当前主要残差集中在高峰尾部
- 是否满足工程阈值，更直接取决于超阈值帧比例
