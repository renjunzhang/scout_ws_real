## 4. 当前误差结构

当前 best 并不是“所有帧都已经很准”，而是已经进入：

- 大多数帧误差明显收紧
- 少数高峰帧仍存在系统性压峰

在 held-out test `554` 帧上：

- `|err| > 0.2 mm`：`118` 帧
- `|err| > 0.3 mm`：`71` 帧
- `|err| > 0.5 mm`：`35` 帧
- `p95 abs error = 0.5562 mm`
- `max abs error = 1.7300 mm`

按目标幅值分层：

- `low <= 0.2 mm`
  - `MAE = 0.0742 mm`
- `mid 0.2 ~ 0.5 mm`
  - `MAE = 0.1454 mm`
- `high > 0.5 mm`
  - `MAE = 0.3724 mm`

所以当前误差的核心结构是：

- 低幅值段已经明显收紧
- 中间幅值段可用
- 真正难点仍然是少数大峰值段的振幅压缩

## 5. 当前功能能否判断 MPC 是否抑制液体晃动

可以，而且现在比之前更稳。

当前 best 已经能够作为离线评估器，用来判断：

- 峰值幅值是否下降
- 超阈值时间是否缩短
- 振荡衰减是否更快
- 两组控制器在同类 motion bag 上是否存在中等及以上效应量差异

但仍应保持这个边界：

- 它适合支持“明显改善”的结论
- 不适合只凭当前模型就宣称极小量级改善，例如 `0.05 ~ 0.1 mm`

如果控制器差异很小，仍建议抽人工真值做复核。

## 6. 推荐评估口径

后续对外、汇报、交接时，**不要只报 MAE**。  
原因很直接：不同 bag、不同时间段的真实峰值高度分布不同，同样 `0.2 mm` 的绝对误差，在 `0.1 mm` 峰值段和 `2.0 mm` 峰值段含义完全不同。

推荐最少同时报告下面 6 组指标：

1. `overall MAE`
   - 继续保留，回答“平均每帧绝对偏差多少 mm”
2. `|err| > 0.3 mm` 的帧比例
   - 直接对应工程阈值是否满足
3. `low / mid / high` 分层 MAE
   - 建议固定分层：
   - `low <= 0.2 mm`
   - `mid 0.2 ~ 0.5 mm`
   - `high > 0.5 mm`
4. `p95 abs error` 和 `max abs error`
   - 用来刻画尾部风险，避免被平均值掩盖
5. `bag-wise metrics`
   - 每个 held-out test bag 至少报：
   - `MAE`
   - `p95 abs`
   - `max abs`
   - `|err| > 0.3 mm` 帧数
6. 相对误差口径
   - 推荐只在 `target > 0.5 mm` 上报
   - 避免 near-zero 样本让比例误差失真
   - 当前 best 的 `target > 0.5 mm` 平均相对误差约 `28.95%`

若只能给一页摘要，推荐指标组合是：

- `MAE`
- `RMSE`
- `|err| > 0.3 mm` 比例
- `high > 0.5 mm` 的 MAE
- `p95 abs error`

## 8. 当前阶段最终结论

截至当前，这条监督学习链已经可以收口为：

- **当前主线 best 是短时序视觉模型，不再是单帧模型**
- **当前阶段收敛版是 `raw ROI + K=7 + GRU + current-frame anchor + weighting(1.0/1.5/3.0) + seed=11`**
- **当前 held-out test 最好结果是 `MAE = 0.1567 mm`**

如果后续只是为了工程落地和控制器离线评估，这里已经足够作为阶段性收敛版本，不建议再做大范围无约束试验。  
若后续还要继续研究，真正值得投入的方向应是：

- hardest segments / high-peak cases 定向分析
- 标签一致性继续收紧
- 在固定主线配置下做少量重复训练验证稳定性
