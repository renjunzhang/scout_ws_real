## 1. 主线与契约

正式实现为 `continuous_mpcc_acados + explicit_actuator`。车体和液体由实际运动驱动，发布命令从独立 command 状态提取。`continuous_mpcc_direct_omega_legacy` 和 `primitive` 是历史诊断/采样路径，未纳入本轮 V2–V4 主线验收。

| 契约 | 当前代码 |
|---|---|
| OCP 网格 | 30 Hz，60 阶段，2 s；控制 `[a_cmd,alpha_cmd,v_s]` |
| B0 状态 | `[x,y,yaw,v_actual,s,omega_actual,v_cmd,omega_cmd]` + 5 拍线速度 FIFO + 10 拍角速度 FIFO + `a_cmd_memory`，共 24 维 |
| slosh 状态 | B0 后追加 `[eta_x,eta_x_dot,eta_y,eta_y_dot]`，共 28 维 |
| 参数 | B0 34、slosh 46；字段顺序以生成模型 `parameter_names` 为准 |
| 版本 | `liquid_model_version=1`、`cost_model_version=2`；CasADi 3.7.2、acados 0.5.4 |
| 记录 ABI | PreSolveSnapshot / PredictedHorizon schema 7；旧参数宽度不能直接传给新 solver |
| 执行器候选值 | 线/角延迟 5/10 拍，tau 为 0.112/0.119 s，gain 为 1.018/1.096；实际误差未验收 |

来源：[符号模型](scripts/acados/spmpc_acados_model.py)、[执行器契约](include/spmpc_local_planner/dynamics/actuator_model.h)、[公共配置](config/planner/common.yaml)。旧文档的 6/10 维状态、23/32 或 28/37 维参数不适用于本版。

运行链：传感器接纳与时间对齐 → 真实已发布命令历史 → 显式执行器初态前推 → OCP / 真实终点停车协调 → 原安全门与发布契约 → 最终命令入队并记录历史 → 诊断。历史保存最终发布值；它是 ROS publisher 入队记录，尚无底盘接收确认。

## 3. 四项改进的实际状态

### V1：统一液体模型——已实现，输入准确性待验证

容器中心按与 `base_link` 重合处理；IMU 外参沿用当前配置，没有重新标定。模态位移 `q=[eta_x,eta_y]` 在随车旋转的水平容器坐标系表示，小幅单模态、相对阻尼下使用：

```text
q_ddot = -2*zeta*omega_n*q_dot - omega_n²*q - a_C
         - 2*omega_actual*J*q_dot - alpha_actual*J*q + omega_actual²*q
h_modal = c_h * ||q||
```

OCP、观测器、前推、热启动和新版重放共用液体定义。IMU 按当前去重力/偏置/旋转和 IMU→容器作用点换算，不能再叠加 `v*omega`。预测端使用实际 `a_C=[v_actual_dot,v_actual*omega_actual]`、`alpha_actual`；`alpha_cmd` 只更新命令。容器偏移为零时旋转耦合仍存在。

OCP 每阶段 4 个 RK4 子步，观测/前推每段至少 4 子步且子步不超过 1/120 s。相同分段下数值传播一致，不同分段仍有截断误差。IMU 通过插值把加速度、omega、alpha 对齐到共同有效时刻；传感器延迟/滤波相位是当前估计，软件对齐不等于物理相位已标定。详见 [V1 实现与离线验证](../../../../docs/实物实验注意事项/对比试验/解决问题的思路/20260913_液体模型一致性V1实现与离线验证.md)。

### V2：核准代价与减速空间——统计已核准，anti-creep 保持 8

采用 `J=(1/N)*sum(L_k)+Phi_N`，acados scaling 显式为 `[1]*(N+1)`。修正旧生成物 running 已除以 N 后又乘 dt 的缩放。**未开开发覆盖层时，新版也不等价于旧实验二进制。**

分项包含跟踪、进度、实际/虚拟速度、anti-creep、控制、平滑、液体、松弛和停车；终端不重复统计。用 solver 返回的 x/u 和实际 stage p 重建，与 `ocp_nlp_eval_cost` 核对，误差超过 `1e-8*(1+|J_solver|)` 拒绝。

人工急弯快照 gain 8→0 后，1 s 预测实际速度从 0.19160 降至 0.16223 m/s，但峰值模态高度从 0.29890 升至 0.30718 mm。它说明减速空间变化，**不能证明关闭 anti-creep 有降晃收益**。保留默认 8，提供[离线对照工具](scripts/analysis/audit_ocp_cost_and_anticreep.py)，没有凭此更改实车权重。

### V3：液面上限与恢复——机制已实现，物理数值未定

`H_target` 是性能目标，恢复 cap 为 `H_target+budget`，已知静液面余量时再受 `freeboard-margin` 截断；`freeboard=0` 表示未知。松弛用平方模态超量解析消元，加线性/二次惩罚与独立 cap，不增加状态/控制维度。

真实 x0、延迟前缀和终端节点均检查；不缩初态、不改历史、不放宽运动边界。使用恢复的周期不报严格目标通过；预算耗尽、触及已知物理边界及 NoState 与约束混用明确失败。开发值 1 mm 目标、3 mm 预算未由容器余量和统一模型重放确定。节点约束不是连续时间或实物防溢出保证。

### V4：完整停车——可选实现已通过模型内流程测试

真实任务终点参考加入制动、延迟/惯性/jerk 裕度，速度、虚拟进度与 anti-creep 同步减速。交接后由停车模块执行制动及释放负加速度，传播 FIFO 和实际运动尾段；普通 2 s 窗口末端不强制停车。

命令/FIFO/加速度记忆清零且实际运动达到 quiet 阈值后，用 `H_res=c_h*sqrt(||q||²+||q_dot||²/omega_n²)` 评价残余晃动并要求持续稳定。尾段仍有激励时继续传播；quiet 阈值下这是能量指标，严格无激励幅值上界只适用于实际无激励条件。

计时只累计新的 robot 和 liquid 测量，重复测量不累计，倒退/断流重置。完成后外扰撤销 reached 并重新稳定；首次车体停止与液体稳定时间分别保留，超时锁存到新任务。B0 开完整停车也消费液体，必须通过 observer 接纳与 common epoch 门。

详细公式、复现和局限见 [V2–V4 实现及审查记录](../../../../docs/实物实验注意事项/对比试验/解决问题的思路/20260914_代价核准液面恢复与完整停车实现验证.md)。

## 6. 未关闭问题与下一步顺序

| 顺序 / ID | 当前证据和改进方向 |
|---|---|
| RUN-01：静止微负速度不可行 | B0/slosh 在真实 `v=-0.0001/-0.001 m/s`、零 FIFO 下均复现 `ACADOS_SOLVE_FAILED_4`；零及 +0.0001 成功。未来 actual-v 非负下界与不可控延迟前缀冲突。先测静止噪声/偏置/真回退，再定义实际运动允许域；不裁成零或盲目放宽全部约束 |
| RUN-02：发布时间与实际激励 | 名义 jerk 不保证非等周期下的物理 jerk；前推截止求解前，计算/传输延迟仍有残差。记录真实周期，同有效时刻比较预测/实测 a_C、omega、alpha；检查超时/故障零速，不能只看 solver 内部耗时 |
| RUN-03：低速执行器与静止判定 | 历史 0.05/0.15 m/s 阶跃起效约 369/139 ms；固定 FOPDT 未覆盖死区、摩擦、换向，quiet=0.001 未按噪声校准。先核验静止/低速数据，再决定模型扩展 |
| LIQ-01：性能目标和物理边界 | 测 freeboard/margin，固定液量与安装；统一模型重放 Smooth-only，选择可行固定目标/预算。考虑 IMU 去重力/姿态/滤波、地缝、滚俯、侧滑及单模态误差；当前 observer 不是液面传感器 |
| 集成与新 C03 | ROS1 全链重建、先不发布速度检查，再验证执行链；前置问题解决后冻结新代码/参数/监视器/窗口。Smooth-only 与完整 S-MPCC 配对，车体停止和液体稳定分别计时 |
| 后续参照与扩展 | 离线完整任务优化作参照；Fixed-profile、NoState 后续补充；无障碍降晃有重复收益后再扩展避障 |
