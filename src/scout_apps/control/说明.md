## 模块概述

`control` 文件夹包含 Scout 机器人的局部控制相关功能包，主要负责：
- 局部路径规划（MPC控制器）
- 液体晃动建模与抑制
- 速度指令生成

## 功能包说明

### 1. slosh_models（液体晃动建模库）

提供液体晃动的物理建模，基于 Mass-Spring-Damper 等效模型。

**核心类：**
- `LiquidSloshModel`：液体晃动动力学模型
  - 基于论文 "Sloshing Dynamics Estimation for Liquid-filled Containers under 2-Dimensional Excitation" (ECCOMAS 2021)
  - 输入：容器加速度 `[ax, ay]`
  - 输出：液面晃动高度 `η`
  - 支持旋转修正（Lp模型）

- `MPCVelTracker`：带液体晃动约束的MPC速度跟踪器
  - 使用 OSQP 求解器
  - 支持增广状态空间法（晃动状态作为优化变量）
  - 液体晃动抑制通过软约束实现

**依赖：**
- Eigen3
- OsqpEigen（可选，用于MPC求解）

### 2. scout_local_planner（局部规划器）

基于 MPC 的局部路径跟踪器，集成液体晃动抑制。

**功能：**
- 接收全局路径，生成局部速度指令
- 实时液体晃动状态估计
- 通过 MPC 软约束抑制液体晃动

**话题：**
- 订阅：
  - `/odom`：里程计
  - `/global_path`：全局路径
- 发布：
  - `/cmd_vel`：速度指令
  - `/slosh_height`：当前液面晃动高度

**参数配置：** 见 `config/local_planner.yaml`

## 使用方法

### 编译

```bash
cd ~/scout_ws
catkin_make
source devel/setup.bash
```

### 运行局部规划器

```bash
roslaunch scout_local_planner local_planner.launch
```

### 参数调优

1. 液体晃动模型参数（需根据实物测量）：
   - `container_radius`：容器半径
   - `liquid_height`：液面高度
   - `damping_ratio`：阻尼比（需实验辨识）

2. MPC参数：
   - `q_slosh`：晃动惩罚权重（越大越抑制晃动）
   - `s_delta`：速度增量权重（影响加速平滑度）
   - `max_speed`：最大速度限制
