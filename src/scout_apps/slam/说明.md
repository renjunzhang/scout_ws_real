尝试在 `/home/a/scout_ws/src/scout_apps/slam` 中安装 Cartographer SLAM 算法，但遇到编译失败问题。

#### 2. 安装依赖（已完成）
```bash

sudo apt-get install -y ninja-build libceres-dev libprotobuf-dev protobuf-compiler \
    libgoogle-glog-dev liblua5.2-dev libboost-all-dev libeigen3-dev libcairo2-dev
```

#### 3. 编译失败问题

**错误原因**：Cartographer 的源码使用了 `LOCKS_EXCLUDED`, `GUARDED_BY`, `EXCLUSIVE_LOCKS_REQUIRED` 等线程锁宏，这些宏在 GCC 9.4 + C++17 环境下无法正确展开，导致编译失败。

**失败命令**：
```bash
# 方式1：直接编译 cartographer
cd /home/a/scout_ws/src/scout_apps/slam/cartographer
mkdir -p build && cd build
cmake .. -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja  # 失败

# 方式2：使用 catkin 编译
cd /home/a/scout_ws
catkin_make_isolated --install --use-ninja  # 失败
```

**典型错误信息**：
```
error: expected ';' at end of member declaration
error: 'lock_' has not been declared
error: ISO C++ forbids declaration of 'LOCKS_EXCLUDED' with no type
```

### 解决方案建议

#### 方案 A：使用二进制包（推荐）
ROS Noetic 可能没有预编译的 Cartographer 包，需要手动安装或使用 Docker。

#### 方案 B：修复源码兼容性问题
需要修改 Cartographer 源码中的线程锁宏定义，工作量较大。

#### 方案 C：使用其他 SLAM 算法
- **Gmapping**：2D 激光 SLAM，安装简单
- **Hector SLAM**：适合无里程计的场景
- **ORB-SLAM3**：视觉 SLAM

#### 方案 D：使用 Cartographer 官方 Docker 镜像
