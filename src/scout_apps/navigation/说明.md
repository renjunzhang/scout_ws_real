## 模块概述

`navigation` 文件夹包含 Scout 机器人的全局导航相关功能包，主要负责：
- 全局路径规划
- 代价地图管理
- 目标点管理

## 功能包说明

### scout_global_planner（全局规划器）

提供全局路径规划功能，当前为框架结构，后续可扩展。

**规划方式（可选）：**
1. **使用 ROS 导航栈自带规划器**（推荐初期使用）
   - `navfn`：Dijkstra/A* 规划器
   - `global_planner`：更灵活的全局规划器

2. **自定义规划器**（后续扩展）
   - 实现 `nav_core::BaseGlobalPlanner` 接口
   - 可添加特定约束（如平滑路径、避免急转弯）

**配置文件：** `config/global_planner.yaml`

## 集成方式

### 方式一：使用 move_base（推荐）

```xml
<launch>
  <node pkg="move_base" type="move_base" name="move_base" output="screen">
    <rosparam file="$(find scout_global_planner)/config/global_planner.yaml" command="load"/>
    <!-- 其他参数... -->
  </node>
</launch>
```

### 方式二：独立全局规划节点

后续可开发独立的全局规划节点，与 `scout_local_planner` 配合使用。

---

## TF 依赖

全局规划器需要以下 TF 链路：
```
map -> odom -> base_link
```

其中：
- `map -> odom`：由 SLAM/定位节点发布（如 Cartographer, AMCL）
- `odom -> base_link`：由底盘驱动发布（scout_mini_robot_base.launch）
