### TF 转换关系
- 静态（fixed joint / static tf）：
  - `base_footprint -> base_link`
  - `base_link -> inertial_link`
  - `base_link -> front_mount`
  - `base_link -> rear_mount`
  - `base_link -> frame_link`
  - `base_link -> nano_nanoscan3_base_link`
  - `nano_nanoscan3_base_link -> nano_nanoscan3_sensor_link`
- 动态（随运动变化）：
  - `odom -> base_footprint`（差速插件里程计）
  - `base_link -> front_left_wheel_link / front_right_wheel_link / rear_left_wheel_link / rear_right_wheel_link`（轮子转动）
