# 红色液体视觉验证固定流程

## 1. 适用范围

本流程用于实物 bag 中 RealSense RGB 红色液体液面高度验证。目标是用外部视觉给出真实液面指标，并与 `/slosh/height` 做对齐比较。`/slosh/height` 是控制/模型侧辅助量，不能替代视觉真值。

禁止修改 MPC、GeoRef、OSCRS 或其它控制代码。所有标定、HSV、CSV、debug 图和报告应独立输出到分析目录。

## 2. 数据分组原则

必须按同一录制批次、同一路径、同一初始液位做组内比较。若不同 run 的初始液位或相机视角不同，必须分别标定、分别估计零点、分别比较，不能跨 run 混合原始高度。

推荐目录：

```text
docs/Claude/分析数据/<experiment>/
  calib/
  *_visual_metric_summary.csv
  *_runwise_effect_summary.csv
  *_report.md

/data/a/slosh_bags/.../<experiment>_red_visual_debug/
  <group>/<condition>/
  summary_plots/
```

`docs/Claude/分析数据` 只保留最终 CSV、报告和少量标定预览；大量 debug 图放到 bag 数据目录下。

## 5. 离线提取

使用红色液体三标尺脚本：

```bash
python3 src/scout_apps/sensors/realsense_liquid_measurement/scripts/red_liquid_infer_from_bag.py \
  --bag <BAG> \
  --calibration <RUN_SPECIFIC_CALIB.yaml> \
  --out-dir <DEBUG_OUT_DIR> \
  --topic /camera/color/image_raw \
  --zero-correction-frames 30 \
  --smooth-frames 5 \
  --debug-every 30 \
  <HSV_ARGS>
```

固定指标口径：

```text
h_final = median(h_left, h_center, h_right)
h_corr = h_final - h0
h_smooth_corr = rolling_median(h_corr, window=5)
h_max_lcr = max(h_left, h_center, h_right)
```

主指标：`h_smooth_corr` 的 peak、p95、RMS。`h_max_lcr` 是保守瞬时峰值，只做辅助判断。`h0` 必须由包内初始静止段估计，不跨 run 复用。

#### 7.1.2 主统计窗口

主效果窗口固定为：

```text
TRACKING start → 第一次 terminal/capture 相关状态之前
```

原因：

```text
terminal_slowdown / TERMINAL_MPC_STOP / REACHED 附近通常包含停车包络、输出限加速度、
capture stop 或其他安全收敛逻辑。该段不代表 slosh cost 在正常 tracking 中的主效果，
不能混入真实液面抑制结论。
```

`full_bag` 图必须保留，但只用于排查：

```text
起步延迟；
终点停车脉冲；
残余振荡；
录包截断；
检测异常。
```

#### 7.1.3 RGB 主指标

固定路径 cost 对比的 RGB 主指标为：

```text
H_vis(t) = abs(h_smooth_corr(t))
metric = p95(H_vis) over TRACKING_PRE_TERMINAL
```

同时输出辅助指标：

```text
RMS(abs(h_smooth_corr))
peak(abs(h_smooth_corr))
peak(h_max_lcr)
```

判读优先级：

```text
p95 是主指标；
RMS 用于看整体能量；
peak 和 h_max_lcr 更容易受单帧反光、HSV 局部误检和量化误差影响，只做 safety/异常检查。
```

若两组 RGB p95 差值远小于视觉检测误差，结论必须写成：

```text
RGB p95 基本持平，未观察到可分辨下降。
```

不能写成：

```text
策略无效
```

也不能用 `/slosh/height` 的下降替代 RGB 真值下降。

#### 7.1.4 速度、加速度与 cost 占比

固定路径 cost 对比必须同时报告：

```text
v_p95
ax_p95 / ax_rms
ay_p95 / ay_rms，其中 ay = v * yaw_rate
jerk_p95 / jerk_rms
tracking duration
path_len_m
```

如果 D 组或 slosh-priority 组出现：

```text
v_p95 下降；
ay_p95 下降；
/slosh/height 下降；
RGB p95 未下降；
```

结论应写为：

```text
slosh cost 已改变车辆行为并降低模型侧高度，但当前 RGB 真值没有显示真实液面同步降低。
```

如果 `jerk_p95` 或 `ax_p95` 没有下降，必须单独指出：

```text
真实液体可能仍被纵向 ax/jerk 脉冲或相位效应激励；
不能只用 ay 下降解释真实液面应当下降。
```

Cost Contribution Check 使用：

```bash
python3 src/scout_apps/control/scout_local_planner/scripts/analysis/extract_mpc_cost_breakdown.py \
  <BAG_LIST> \
  --out-dir <OUT_DIR> \
  --prefix <GROUP_NAME>
```

报告至少给出：

```text
pct_slosh_total mean / median / p95
pct_v
pct_control
pct_smooth
```

若 slosh cost 占比已经较高而 RGB 不降，说明问题不应简单归因为 `Q_slosh` 不够大，应优先检查模型保真度、ax/jerk 脉冲和时间相位。

#### 7.1.5 分辨率与可分辨差异

记录 RGB 分辨率是必须项：

```bash
rostopic echo -n 1 /camera/color/camera_info | grep -E "width|height"
```

经验判读：

```text
640x480:
  可做初步分析，但 1mm 级别差异容易被边界模糊、HSV、反光和人工标尺误差淹没。

1280x720:
  推荐作为实物验证的最低正式分辨率。

1920x1080:
  推荐用于论文级 RGB 真值，但 bag 体积、CPU 和磁盘压力明显增加。
```

报告中如果 RGB p95 差值只有 0.01~0.10 mm 量级，且当前分辨率为 640x480，应写成：

```text
当前分辨率下未观察到可分辨差异；需要更高分辨率复核。
```

不要把 640x480 的小差值解释成强结论。

## 8. 模型保真度与 /slosh/height 可信度判断

本节用于判断模型估计高度是否可信。可信度判断必须以视觉为外部观测基准，不能用 `/slosh/height` 自证正确。

参考 Ferrari 等 2026 的实验验证口径：模型曲线与实验液面曲线应做时间积分偏差评估，且积分窗口需要覆盖运动后的残余振荡。本项目在此基础上增加 OSCRS 选择保真度和安全 gate 保真度。

### 8.1 视觉真值定义

主视觉真值：

```text
H_vis(t) = abs(h_smooth_corr(t))
```

保守峰值检查：

```text
H_vis_max(t) = max(h_left, h_center, h_right) - h0
```

`H_vis_max` 只用于 peak safety check，不作为主趋势指标。run01/run02 或不同初始液位的数据必须先各自标定和零点校正，再做 run 内比较。

### 8.2 Ferrari-style 绝对保真度

令 `H_model(t)` 为 OSCRS rollout 预测值；若当前只有 bag 里的 `/slosh/height`，可暂用 `/slosh/height` 作为模型侧高度。

固定积分窗口：

```text
t0 = tracking_start
t1 = tracking_end + 2s
```

如果没有可靠 `tracking_end`，使用 tracking_start 后的有效 tracking window。

Ferrari-style 指标：

```text
gamma_model_pct =
  100 * integral_t0_t1 [H_model(t) - H_vis(t)] dt
      / (integral_t0_t1 H_model(t) dt + epsilon)
```

解释：

```text
gamma_model_pct > 0: 模型整体偏保守，预测高于视觉；
gamma_model_pct ≈ 0: 模型整体吻合；
gamma_model_pct < 0: 模型低估真实液面，安全上危险。
```

同时输出：

```text
RMSE = rms(H_model(t) - H_vis(t))
correlation = corr(H_model(t), H_vis(t))
```

### 8.3 Summary-level 保真度

对每个 bag 输出：

```text
e_p95  = model_p95  - visual_p95
e_peak = model_peak - visual_peak
e_rms  = model_rms  - visual_rms

U_p95  = max(0, visual_p95  - model_p95)
U_peak = max(0, visual_peak - model_peak)
```

解释：

```text
e_* > 0: 模型偏保守；
e_* < 0: 模型低估视觉液面；
U_* > 0: 存在低估风险。
```

如果当前模型侧只有 `/slosh/height` summary，至少必须报告：

```text
e_p95 = slosh_p95_mm - smooth_p95_mm
U_p95 = max(0, smooth_p95_mm - slosh_p95_mm)
```

### 8.4 OSCRS 选择保真度

OSCRS 不只需要模型曲线接近视觉曲线，还需要模型能正确指导候选选择。对同一 run/block 内所有条件两两比较：

```text
A_rank =
  mean over pairs(i,j) [
    sign(H_model_metric_i - H_model_metric_j)
    ==
    sign(H_vis_metric_i - H_vis_metric_j)
  ]
```

推荐使用 `p95` 作为主排序指标，也可补 `peak` 和 `RMS`。例如 RAW、FIXED_MILD、OSCRS 三个条件有 3 个 pair。

解释：

```text
A_rank >= 0.80: 模型排序较可信；
0.50 <= A_rank < 0.80: 只能作为辅助选择依据；
A_rank < 0.50: 不足以指导候选选择。
```

### 8.5 安全 gate 保真度

若 OSCRS 使用 hard gate，还必须评估模型是否漏判危险片段：

```text
U_max = max_t [H_vis(t) - H_model(t)]_+

r_under =
  count{t: H_model(t) < H_vis(t)}
  / count{t}
```

如果真实液面存在超过阈值 `eta_lim` 的片段，输出 violation recall：

```text
recall =
  count{t: H_vis(t) > eta_lim and H_model(t) > eta_lim}
  / count{t: H_vis(t) > eta_lim}
```

若当前视觉幅值远低于 `eta_lim`，固定阈值 recall 没有信息量，应做 threshold sweep：

```text
tau = 0.5, 1.0, 1.5, 2.0, 3.0, 4.0 mm
或 tau = P80, P90, P95 of H_vis
```

### 8.6 时间配对质量

所有时间序列保真度指标都必须先输出配对质量：

```text
paired_samples
pair_dt_median_ms
pair_dt_p95_ms
scale_fit_slosh_per_visual
visual_p95 / slosh_p95
visual_max / slosh_max
```

插值只允许在 `/slosh/height` 相邻样本间隔不超过 0.15 s 时使用；超过间隔的视觉帧记为 NaN，不参与 correlation 或 scale。

### 8.7 三层可信度结论

可信度分级：

```text
可信:
  paired_samples 充足，pair_dt_p95_ms <= 80 ms；
  correlation >= 0.60；
  gamma_model_pct 不显著为负；
  U_p95 和 U_max 小；
  A_rank >= 0.80；
  策略间 p95/peak 方向与视觉一致。

部分可信:
  时间配对质量合格；
  correlation 为 0.30~0.60，或 gamma_model / scale 稳定但排序只部分一致；
  0.50 <= A_rank < 0.80；
  可用于控制侧趋势辅证，但不能作为视觉 ground truth。

不可信:
  时间配对差，或 correlation < 0.30；
  gamma_model_pct 明显为负，且 U_p95 / U_max 较大；
  A_rank < 0.50；
  /slosh/height 的 p95/peak 方向与视觉主指标相反。
```

报告中必须分开写：

```text
视觉结论：真实液面是否降低。
Ferrari-style 绝对保真度：模型曲线是否接近视觉曲线。
OSCRS 选择保真度：模型排序是否能指导候选选择。
安全 gate 保真度：模型是否漏判高晃动/危险片段。
```

若视觉显示策略 A 高于参考条件，而 `/slosh/height` 显示策略 A 低于参考条件，应判定 `/slosh/height` 在该 run/block 上不可信或仅部分可信，不能用它支持真实液面降低。

## 9. 报告结论口径

报告必须先给视觉结论，再给 `/slosh/height` 辅证。推荐结构：

```text
1. 数据分组和标定说明
2. HSV 参数
3. 视觉指标表
4. 组内差值表
5. tracking_start 三图索引
6. trajectory_analysis 辅证
7. 视觉结论
8. 模型保真度与 /slosh/height 可信度判断
```

结论模板：

```text
按红色液体三标尺视觉口径，策略 A 相对参考条件：
- run/block 1: smooth_p95 差值 = ... mm，方向 = ...
- run/block 2: smooth_p95 差值 = ... mm，方向 = ...
- smooth_peak / smooth_rms 是否同方向 = ...

因此，视觉证据 [支持 / 不支持 / 暂不支持] 策略 A 降低真实液面晃动。

/slosh/height 可信度：
- 时间配对质量 = ...
- correlation = ...
- gamma_model_pct = ...
- U_p95 / U_max = ...
- A_rank = ...
- p95/peak 方向是否与视觉一致 = ...
- 可信度 = [可信 / 部分可信 / 不可信]
```
