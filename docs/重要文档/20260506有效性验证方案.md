# Online GeoRef / OSCRS 实物液体晃动抑制有效性验证方案

日期：2026-05-06
重写：2026-05-08

## 1. 目的

验证在相同起点、相同终点、相同地图、相同定位、相同 MPC 跟踪器的条件下，参考生成层是否能降低实物液体晃动。

本方案主比较四条线。根据 2026-05-09 实物 phase2 smoke，`strong/medium` 级别候选会引入终点过冲回头；实物正式验证采用 SAFE mild variant：

```text
RAW_REAL
  MBF global path -> normal MPC

GEOREF_FIXED_MILD_REAL
  MBF global path -> fixed mild GeoRef candidate -> normal MPC

GEOREF_TUNED_MILD_REAL
  MBF global path -> geometry-only GeoRef candidate selection, candidate set capped at mild -> normal MPC

GEOREF_OSCRS_ACTIVE_MILD_REAL
  MBF global path -> OSCRS slosh-constrained candidate selection, candidate set capped at mild -> normal MPC
```

OSCRS 是 RA-L/Ferrari 整合方案的实物落地线。它不使用实时液面高度闭环；它在执行前对候选参考路径做 slosh rollout，按 `eta_lim / residual / score` 选择路径，再由普通 MPC 跟踪。

## 2. 固定边界

四条线必须使用同一套 MPC 参数。MPC 内部防晃全部关闭：

```text
Q_slosh=0
Q_slosh_eta_dot=0
enable_slosh_box_constraint=false
risk_scheduler_enable=false
energy_profile_enable=false
input_shaping_enable=false
slosh_speed_governor_enable=false
```

唯一允许变化的是参考路径来源：

```text
RAW_REAL:                 不启动 post-processor
GEOREF_FIXED_MILD_REAL:   固定 mild 候选；mild 被 gate 拒绝时回退 original
GEOREF_TUNED_MILD_REAL:   geometry-only selector, candidate set capped at mild
GEOREF_OSCRS_ACTIVE_MILD_REAL: OSCRS hard gate + score selector, candidate set capped at mild
```

调参只允许发生在参考生成层：

```text
GeoRef 候选强度:
  max_candidate_level
  mild/mid/medium/strong 的 iters / gain / max_drift

OSCRS 模型与评分:
  config/oscrs_container.yaml
  oscrs.eta_lim_mm
  oscrs.residual_ratio
  oscrs.score/*

安全与可行性:
  enable_collision_check
  costmap_topic
  collision_threshold
  ay_ratio_limit
```

实物 phase1 smoke 注意：

```text
如果 candidate_report 显示所有 GeoRef 非 original 候选都因 ay ratio 被拒绝，
先把 ay_ratio_limit 从 1.0 临时放宽到 3.0 跑 1 包 smoke。
该包只验证 post-processor 是否真正接管非 original 参考路径，不进入正式有效性统计。
若 smoke 的 odom_ay_p95、tracking、碰撞检查可接受，再回收阈值到 2.0 / 1.5 做正式包。
```

实物 phase2 collision smoke 注意：

```text
如果 validate_georef_oscrs_bag.py 输出：
  mild:accepted=0,reason=collision:idx=0:cost=68

说明 fixed mild 没接管的直接原因不是 ay_ratio_limit，也不是 OSCRS score，
而是 costmap collision gate 在候选路径起点附近把 mild 判为高代价。

调参顺序：
  1. 保持 enable_collision_check:=true；
  2. 先加 collision_threshold:=90 跑 1 包 fixed mild smoke；
  3. 若仍然 collision:idx=0，再试 collision_threshold:=100；
  4. 若 100 仍失败，才在开阔场地临时使用 enable_collision_check:=false 做通路 smoke。

注意：
  enable_collision_check:=false 只能用于开阔场地通路 smoke，
  不能作为正式安全实验参数，也不能写进正式有效性结果。
```

具体调参顺序按：

```text
docs/重要文档/20260508_Online_GeoRef_OSCRS实物录包SOP.md
```

禁止把这些旧方案混入主表：

```text
Q_slosh / Q_eta_dot 主动消晃
OUTPUT_GUARD / PMG
PROFILE_ENERGY / PROFILE_REF_V2
GEOREF_CONSTRAINED
GEOREF_SLOSH_SCORE_TUNED
```

## 3. 成功标准

每个 condition 至少 3 包，正式结果优先看 5 包均值。

`GEOREF_TUNED_MILD_REAL` 相对 `RAW_REAL`：

```text
/slosh/height h_rms             下降
/slosh/height h_p95             下降，目标 >= 10%
modal_energy_rms                下降，目标 >= 10%
eta_dot_rms                     不上升，最好下降
tracking_time                   <= RAW * 1.15
ay_p95                          不上升
solve_success_ratio             >= 0.97
无碰撞、无人工接管、无明显定位丢失
```

`GEOREF_FIXED_MILD_REAL` 的作用是 naive fixed-smoothing baseline：

```text
如果 GEOREF_FIXED_MILD_REAL ≈ GEOREF_OSCRS_ACTIVE_MILD_REAL：
  说明主要收益可能来自固定 mild 平滑，OSCRS selector 增量弱。

如果 GEOREF_OSCRS_ACTIVE_MILD_REAL 优于 GEOREF_FIXED_MILD_REAL：
  说明 slosh model selector 有增量价值。

如果 GEOREF_FIXED_MILD_REAL 经常 fallback original、碰撞风险高或 tracking 变差：
  说明固定强平滑不够稳，OSCRS / geometry selector 的约束选择有必要。
```

`GEOREF_OSCRS_ACTIVE_MILD_REAL` 相对 `GEOREF_TUNED_MILD_REAL`：

```text
首选结果:
  takeover=1 的包中，h_p95 / h_rms / h_max 至少一项进一步下降，且 eta_dot 不显著上升。

可接受结果:
  h 指标与 GEOREF_TUNED_MILD 持平，但 residual / terminal 风险更低。

饱和结果:
  active=1 但 takeover=0 占多数，说明 OSCRS 与 geometry selector 选择同一路径；
  不能宣称 OSCRS 有额外物理贡献，只能写 candidate set saturated。

失败结果:
  takeover=1 但 h / eta_dot / energy 明显劣于 GEOREF_TUNED_MILD；
  或 active 频繁 fallback；
  或 candidate_report 解释不了 selected path。
```

如果使用 RealSense RGB 离线视觉真值：

```text
视觉 h_p95 / h_max 的改善方向必须与 /slosh/height 一致。
如果 /slosh/height 下降但 RGB 真液面不降，不能声明真实液体晃动被抑制。
```

## 4. 场地与目标

第一轮只在开阔场地做。

要求：

```text
开阔平整场地
无动态障碍
有足够转弯余量和制动距离
路径长度 >= 4 m
路径包含至少一个转弯或 S 型段
```

不建议第一轮使用：

```text
maze / 窄走廊
贴墙路径
定位容易漂移的区域
需要人频繁接管的环境
```

同一组 RAW / GEOREF / OSCRS 必须使用同一个 `x/y/yaw`。优先使用固定脚本发布目标，不用 RViz 手点。

`takeover_ratio` 定义：

```text
takeover_ratio = count(active=1 且 fallback=0 且 selected==oscrs 且 selected!=geo) / count(active=1)
```
