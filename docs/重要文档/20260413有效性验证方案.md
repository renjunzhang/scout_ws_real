## 1. 结论先行

当前方案总体有道理，可以作为论文实验的主框架，但需要把验证目标拆开：

- Phase A：验证 supervised 视觉液面证据链是否仍然可信
- Phase B：验证 `Q_slosh` 软代价是否真的降低液体晃动风险

核心原则是：

- 先验证“尺子”是否可信，再用这把尺子量控制器
- 第一轮只改 `Q_slosh`，不要同时改 speed governor、box constraint、IMU ay 口径
- 不只按时间比较，还要按路径进度比较
- 不只看彩色图，还要给数值指标、可比性指标和人工复核

## 5. 采集计划

### 5.1 正式运动 bag

最低配置：

- `Q_slosh = 0 / 5 / 10`
- 每组 `3` 次
- 总计 `9` 个 motion bag

论文更稳配置：

- `Q_slosh = 0 / 5 / 10`
- 每组 `5` 次
- 总计 `15` 个 motion bag

如果时间有限，先跑 `3` 次/组；若结果趋势存在但方差较大，再补到 `5` 次/组。

### 5.2 运行顺序随机化

不要按下面顺序采：

- 先采完所有 `Q0`
- 再采完所有 `Q5`
- 再采完所有 `Q10`

推荐按 randomized block 采，例如：

```text
Block 1: Q5, Q0, Q10
Block 2: Q0, Q10, Q5
Block 3: Q10, Q5, Q0
```

如果做 `5` 次/组，则继续扩展 block。

原因：

- 电池电量会漂移
- 轮胎/地面状态会漂移
- 光照/曝光会漂移
- 液体状态和少量损耗会漂移

随机化可以降低这些因素和 `Q_slosh` 的混淆。

### 5.3 static bag

每个 randomized block 前后各录一个 static bag：

- 机器人静止
- 容器静止
- RealSense 固定
- 时长 `10 ~ 15 s`

如果环境光、相机曝光或安装状态明显不稳定，则升级为每次 motion bag 前后各录一个 static bag。

static bag 用途：

- 估计视觉链静止抖动
- 检查 bias floor
- 检查光照/曝光漂移
- 检查实验前后是否出现系统性漂移

## 7. 人工复核方案

不要全帧人工标注。

每个 motion bag 人工复核建议 `30 ~ 40` 个 unique frames。

组成：

- 固定路径进度采样：`21` 帧
- 固定时间采样：`10 ~ 15` 帧
- 峰值事件采样：`20 ~ 30` 帧候选，去重后保留
- 可疑帧/视觉异常帧：按需补充

固定路径进度采样：

- `0%, 5%, 10%, ..., 100%`
- 这是主口径，因为不同 `Q_slosh` 会改变时间轴，但不应该改变轨迹几何轴

固定时间采样：

- 每 `1 s` 抽一帧
- 用于检查时间曲线连续性和漂移

峰值事件采样：

- `SL top-10 peaks`
- `/slosh/height top-10 peaks`
- 每个 peak 前后扩 `2 ~ 3` 帧
- 去重后进入人工复核列表

static bag：

- 每个 static bag 抽 `15 ~ 20` 帧
- 用于估计静态 jitter 和 bias floor

盲标要求：

- 将抽样帧打乱命名
- 人工标注时不显示 `Q_slosh`
- 人工标注时不显示 supervised 预测值
- 人工标注时不显示 `/slosh/height`

原因：

- 防止“Q 越大应该越不晃”的主观预期影响标注

## 8. 指标设计

### 8.1 证据链指标

supervised height vs human label：

- `MAE`
- `RMSE`
- `Corr`
- `bias_mean`
- `p95 abs error`
- `max abs error`
- `|err| > 0.3 mm` 比例
- `low <= 0.2 mm` 的 MAE
- `mid 0.2 ~ 0.5 mm` 的 MAE
- `high > 0.5 mm` 的 MAE

static bag：

- static mean
- static std
- static p95 range
- static drift between pre/post block

### 8.2 控制效果指标

supervised height 主指标：

- `p95`
- `AUC above 0.5 mm`

supervised height 辅助指标：

- `max`
- `RMS`
- 超过 `0.5 mm` 的持续时间
- 峰值后衰减时间

模型侧辅助指标：

- `/slosh/height` 的 `max / p95 / RMS`
- `/slosh/height_pred_max` 的 `max / p95`
- `/slosh/height_pred_max` 是否保守覆盖 supervised high-peak 区域

### 8.3 控制可比性指标

每个 bag 必报：

- completion time
- average speed
- max speed
- max `|ax_est|`
- max `|ay_est|`
- tracking error
- path progress alignment
- solver status
- solve time

如果存在 solver fail 或明显异常控制段，该 bag 需要单独标记。

## 9. 路径分段分析

不要只报整段 bag 平均。

建议按路径分段：

- 起步段
- 直线加速段
- 主要转弯段
- 高曲率段
- 终点收尾段

每段分别计算：

- supervised height `p95`
- supervised height `AUC above 0.5 mm`
- `/slosh/height` `p95`
- max `|ay_est|`
- tracking error

原因：

- 晃动主要由加速度和转弯激励触发
- 整段平均会把关键高曲率段稀释掉

## 10. 可比性排除规则

预先定义降级规则。

如果某个 Q 组与 Q0 基线相比出现以下情况，则对应结果不能直接写成“纯 anti-slosh 改善”，只能写成“速度/跟踪 trade-off 下的结果”：

- completion time 差异超过 `10%`
- average speed 差异超过 `10%`
- 路径进度曲线明显失配
- tracking error 明显恶化
- solver fail 频繁出现
- 起点姿态不满足固定路径 replay 门限
- RealSense static bag 显示明显光照/曝光漂移

如果 Q 增大后液面下降，但 completion time 同时明显增加，也不能直接写：

- `Q_slosh` 主动抑制了晃动

更稳的写法是：

- `Q_slosh` 引入了更保守的控制行为，并降低了液面风险；纯 anti-slosh 因果仍需在速度可比条件下进一步确认

## 11. 判定标准

### 11.1 证据链可用标准

如果新抽样人工标注满足：

- `MAE <= 0.25 mm`
- `Corr >= 0.85`
- `p95 abs error <= 0.60 mm`
- `static jitter <= 0.08 mm`

则可将 supervised height 作为本轮控制器对比的离线评估器。

如果不满足，则降级为：

- 仅做趋势性辅助证据
- 高峰帧必须增加人工复核比例

### 11.2 控制有效标准

若 `Q5/Q10` 相比 `Q0` 在以下至少两个指标上改善：

- supervised height `p95`
- `AUC above 0.5 mm`
- 超阈值持续时间
- `RMS`

且改善幅度满足至少一条：

- 相对下降 `>= 20%`
- 绝对下降 `>= 0.3 mm`

同时满足：

- completion time 没有超过 `10%` 的不利变化
- average speed 没有超过 `10%` 的不利变化
- tracking error 没有明显恶化
- 路径进度对齐可接受

则可以写：

- 有较强证据表明 slosh-aware cost 降低了液面风险

如果改善只有：

- `0.05 ~ 0.1 mm`

或只出现在单个 bag，则只能写：

- 观察到趋势性改善，但当前证据不足以支持强结论

## 15. 预期论文表述边界
