# 20260518 MPC 终点收敛与固定路径验证方案

目标：

```text
先验证当前 MPC terminal 是否稳定收敛；
如果 terminal 收敛，再进入固定路径 MPC cost 对比；
本方案只验证 MPC cost / terminal，不涉及 OSCRS / GeoRef / path post-processor。
```

核心原则：

```text
1. 先跑 terminal smoke，不通过就不录固定路径 cost 主实验。
2. 固定路径对比只改变 MPC cost 参数，不改变路径、不打开 OSCRS。
3. 真实液面结论以 RGB 视觉为准，/slosh/height 只作为模型调试量。
4. terminal_slowdown / CAPTURE_BRAKE 段只用于判断终点是否平稳，不作为 slosh cost 主效果窗口。
```

PASS 标准：

```text
diagnose_terminal_overshoot.py:
  不出现 GOAL_PASSED；
  不出现 GOAL_PASSED_THEN_TERMINAL_TURNBACK；
  max_odom_v_near 建议 <= 0.10-0.12 m/s；

  first_terminal_mode = CAPTURE_BRAKE 或 REACHED；
```

## 4. 固定路径结果分析

先做 terminal 截窗：

```bash

  --plots
```

再做 cost contribution：

```bash
python3 /home/geist/scout_ws/src/scout_apps/control/scout_local_planner/scripts/analysis/extract_mpc_cost_breakdown.py \
  /home/geist/slosh_bags/real/20260518_fixed_path_cost \
  --phase TRACKING \
  --out-dir /home/geist/slosh_bags/real/20260518_fixed_path_cost/cost_breakdown
```

再做 RGB 视觉液面分析，按：

```text
docs/重要文档/红色液体视觉验证固定流程.md
docs/重要文档/论文参考总结/OSCRS模型保真度指标整理.md
```

注意：

```text
这里只借用“模型保真度/视觉评价指标”的分析方法；
实验对象是 MPC cost，不是 OSCRS。
```

主判断窗口：

```text
TRACKING_PRE_TERMINAL:
  mpc_status = TRACKING
  terminal/mode 为空或 NONE
  goal_dist > terminal_slowdown_distance
```

NEAR_GOAL / CAPTURE_BRAKE：

```text
只用于说明 terminal 是否平稳；
不用于证明 slosh cost 主效果。
```

## 5. 是否进入下一步

进入 P3_mixed 的条件：

```text
1. terminal smoke 三包都无明显过冲；
2. P2_s_curve 的 C/D 对比中 terminal 没有污染主窗口；
3. cost_breakdown 显示 D 组 slosh cost 有可见占比；
4. D 组相对 C 组在 ay/omega/jerk 或 RGB 液面上至少有方向一致的改善。
```

如果 P2_s_curve 看不出差异：

```text
先查 horizon 内 eta 是否真的被预测出来；
再查 Q_slosh_eta 归一化尺度；
不要直接大幅堆 Q_slosh，也不要降低 R_a/R_omega 制造效果。
```
