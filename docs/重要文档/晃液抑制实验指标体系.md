# 晃液抑制实验指标体系

日期：2026-05-18  
目的：统一 Scout Mini 晃液抑制实验中“真实液面是否降低”“模型是否可信”“控制行为是否改变”三类问题的指标口径。

## 1. 先分清三个问题

晃液实验不能只用一个指标回答所有问题。必须拆成三层：

```text
1. 真实液面效果:
   RGB 视觉液面是否真的降低。

2. 模型保真度:
   /slosh/height 或 rollout 模型是否接近 RGB 真值。

3. 控制行为解释:
   MPC cost 是否改变了速度、加速度、jerk、路径跟踪和耗时。
```

报告结论顺序必须是：

```text
先写 RGB 真实液面结论；
再写 /slosh/height 是否同向；
最后用速度/加速度/cost 解释可能原因。
```

`/slosh/height` 不能替代 RGB 真值。

## 2. Ferrari 论文中的核心晃动减弱指标

Ferrari 等 2026 主要用液面最大晃动高度说明晃动是否减弱，而不是用摆角、液体动能或频域指标。

### 2.1 最大晃动高度 `eta_i(t)`

论文中第 `i` 个容器壁面处液面相对静止液面的最大爬升高度记为：

```text
eta_i(t)
```

MSD 模型积分得到模态平面位移 `(x_i, y_i)` 后，用类似下面的关系估计液面高度：

```text
eta_i(t) ∝ sqrt(x_i(t)^2 + y_i(t)^2)
```

含义：

```text
eta_i(t) 是用于说明液体晃动幅值的主物理量。
```

对应到 Scout：

```text
RGB:      H_vis(t) = abs(h_smooth_corr(t))
模型侧:   H_model(t) = abs(/slosh/height) 或 rollout height
```

### 2.2 阈值约束 `eta_lim`

Ferrari 优化问题要求运动过程中：

```text
eta_i(t) <= eta_lim
```

运动结束后还要求残余振荡满足：

```text
eta_i(t) <= 0.2 * eta_lim,  t > t_end
```

含义：

```text
晃液减弱不仅是峰值更低，还包括运动结束后残余振荡小。
```

对应到 Scout：

```text
tracking window:
  统计正常跟踪阶段的 RGB p95 / peak / RMS。

post-terminal window:
  单独统计终点后残余振荡，不混入主 tracking 效果。
```

### 2.3 优化收益 `gamma_opt`

Ferrari 定义：

```text
gamma_opt =
  100 * (eta_max,Nopt - eta_max,Opt) / eta_max,Nopt
```

其中：

```text
Nopt = non-optimized trajectory
Opt  = optimized trajectory
```

含义：

```text
gamma_opt > 0: 优化后最大液面峰值降低；
gamma_opt = 0: 没有改善；
gamma_opt < 0: 优化后反而更高。
```

对应到 Scout：

```text
gamma_opt_rgb_peak =
  100 * (RGB_peak_C - RGB_peak_D) / RGB_peak_C

gamma_opt_rgb_p95 =
  100 * (RGB_p95_C - RGB_p95_D) / RGB_p95_C

gamma_opt_model_p95 =
  100 * (model_p95_C - model_p95_D) / model_p95_C
```

注意：

```text
Ferrari 主要用 maximum sloshing height / peak；
Scout 实物 RGB 容易受反光、单帧误检和分辨率影响，所以主表建议同时报告 p95 和 peak。
```

## 3. 真实液面 RGB 指标

### 3.1 主指标：`RGB abs(h_smooth_corr) p95`

定义：

```text
h_final = median(h_left, h_center, h_right)
h_corr = h_final - h0
h_smooth_corr = rolling_median(h_corr, window=5)
H_vis(t) = abs(h_smooth_corr(t))

RGB_p95 = p95(H_vis(t))
```

回答的问题：

```text
大部分时间内真实液面偏离是否降低。
```

优点：

```text
比 peak 抗单帧误检；
比均值更关注高晃动片段；
适合做主表格。
```

局限：

```text
median(L,C,R) 会压低左右倾斜型晃动；
若差值小于视觉检测误差，只能说“不可分辨”，不能说策略有效或无效。
```

### 3.2 Ferrari-style 主指标：`RGB peak`

定义：

```text
RGB_peak = max_t H_vis(t)
```

回答的问题：

```text
最大液面峰值是否降低。
```

优点：

```text
最接近 Ferrari 的 eta_max / gamma_opt 口径。
```

局限：

```text
对反光、HSV 局部误检、640x480 量化台阶非常敏感。
```

使用建议：

```text
论文主表可报告 peak，但不要只靠 peak 下结论；
必须配合 p95、debug frame 和 h_max_lcr 检查。
```

### 3.3 空间倾斜指标：`range_lcr`

定义：

```text
range_lcr(t) = max(h_left, h_center, h_right) - min(h_left, h_center, h_right)
```

回答的问题：

```text
液面左右/中间是否出现明显倾斜。
```

适用场景：

```text
S 弯、横向加速度 ay 主导、液面主要表现为左右倾斜时。
```

常用统计：

```text
range_lcr_p95
range_lcr_rms
range_lcr_peak
```

判读：

```text
若 h_smooth_corr p95 不变，但 range_lcr 降低，
可以说“整体高度幅值未降低，但横向倾斜幅度降低”。

若 range_lcr 上升，
不能宣称横向液面晃动降低。
```

### 3.4 保守最高侧指标：`h_max_lcr_corr`

定义：

```text
h_max_lcr(t) = max(h_left, h_center, h_right)
h_max_lcr_corr(t) = h_max_lcr(t) - h_max_lcr_initial
```

回答的问题：

```text
最危险的一侧液面最高爬升是否降低。
```

常用统计：

```text
p95(abs(h_max_lcr_corr))
peak(abs(h_max_lcr_corr))
```

局限：

```text
比 median 更保守，但也更容易被局部检测错误放大。
```

### 3.5 高晃动帧比例

定义：

```text
ratio_h_gt_1mm = count{H_vis(t) > 1.0 mm} / count{t}
ratio_range_gt_1mm = count{range_lcr(t) > 1.0 mm} / count{t}
```

回答的问题：

```text
高晃动状态持续时间是否减少。
```

优点：

```text
比 peak 稳；
比 p95 更直观。
```

注意：

```text
阈值必须根据本批次视觉噪声和液面量级选择；
不要跨不同相机分辨率/标定批次直接复用阈值。
```

### 3.6 时间变化率指标

定义：

```text
dhdt = d(H_vis) / dt
drange_dt = d(range_lcr) / dt
```

推荐使用平滑版本：

```text
H_vis_smooth05 = rolling_median(H_vis, 0.5 s)
range_smooth05 = rolling_median(range_lcr, 0.5 s)

dh_smooth05_rms = RMS(d(H_vis_smooth05)/dt)
drange_smooth05_rms = RMS(d(range_smooth05)/dt)
```

回答的问题：

```text
液面变化是否更平缓。
```

适用场景：

```text
策略降低 jerk 或降低激励变化率，但不一定降低液面峰值时。
```

重要边界：

```text
时间变化率下降不等于液面幅值下降。
只能表述为“液面变化趋势更平缓”。
```

## 4. 模型侧指标

### 4.1 `/slosh/height` p95 / peak / RMS

定义：

```text
H_model(t) = abs(/slosh/height)
model_p95 = p95(H_model)
model_peak = max(H_model)
model_rms = RMS(H_model)
```

用途：

```text
判断 MPC 内部模型是否认为晃动降低。
```

边界：

```text
这是模型侧结果，不是真实液面结论。
```

### 4.2 Ferrari-style 模型保真度 `gamma_model`

Ferrari 论文中的 `gamma_model` 主要用于模型预测与实验结果的一致性评价，不是直接衡量晃动减弱的指标。

Scout 使用：

```text
gamma_model_pct =
  100 * integral [H_model(t) - H_vis(t)] dt
      / (integral H_model(t) dt + epsilon)
```

判读：

```text
gamma_model_pct > 0: 模型整体偏保守；
gamma_model_pct ≈ 0: 模型整体吻合；
gamma_model_pct < 0: 模型整体低估，安全风险较高。
```

同时必须报告：

```text
RMSE
correlation
U_p95 = max(0, RGB_p95 - model_p95)
U_peak = max(0, RGB_peak - model_peak)
A_rank
```

### 4.3 排序一致性 `A_rank`

定义：

```text
A_rank =
  mean over pairs(i,j) [
    sign(model_metric_i - model_metric_j)
    ==
    sign(RGB_metric_i - RGB_metric_j)
  ]
```

回答的问题：

```text
模型能否指导“哪个策略/候选更低晃”。
```

判读：

```text
A_rank >= 0.80: 排序较可信；
0.50 <= A_rank < 0.80: 只能辅助；
A_rank < 0.50: 不足以指导选择。
```

## 5. 控制行为指标

这些指标不能直接证明液面降低，但用于解释为什么 RGB 变或不变。

```text
v_p95 / v_max:
  是否只是开慢了。

ax_p95 / ax_rms:
  纵向加速度脉冲是否降低。

ay_p95 / ay_rms:
  横向加速度是否降低。

jerk_p95 / jerk_rms:
  加速度变化是否更平滑。

tracking duration:
  是否因为开得更慢而暴露更长残振时间。

path_len_m / tracking error:
  是否通过偏离路径换取低晃。

pct_slosh_total:
  slosh cost 是否在 MPC objective 中真正可见。
```

## 7. 结论口径模板

### 7.1 RGB 幅值降低成立

```text
RGB p95 / peak / RMS 均下降，且下降幅度超过视觉检测误差；
速度、加速度和路径误差没有引入不可接受 trade-off。
因此可认为策略降低了真实液面晃动。
```

### 7.2 模型降低但 RGB 不降

```text
策略降低了模型侧 /slosh/height，并改变了车辆行为；
但 RGB p95 / peak 未显示可分辨下降。
因此不能证明真实液面晃动降低。
主要问题可能是模型保真度、关键激励维度或视觉分辨率。
```

### 7.3 幅值不降但变化率下降

```text
RGB 幅值指标未下降；
但 dh/dt 或 d(range_lcr)/dt 下降，说明液面变化趋势更平缓。
该结果只能作为“平滑性改善”证据，不能替代液面峰值降低证据。
```

### 7.4 分辨率不足

```text
若 RGB p95 差值小于视觉检测误差，尤其在 640x480 下只有 0.01~0.10 mm 量级，
应写为“当前分辨率下未观察到可分辨差异”，并用 1280x720 或 1920x1080 复核。
```

## 8. 20260518 C/D 指标扫描教训

本批次固定 S 弯 C/D 对比中：

```text
D 组降低了 v_p95、ay_p95 和模型侧 /slosh/height；
D 组 slosh cost 在 MPC 中有约 20% 可见占比；
RGB abs(h_smooth_corr) p95 基本持平；
RGB peak / h_max_lcr / range_lcr 不支持 D 组幅值优势；
部分时间变化率指标显示 D 组液面变化更平缓。
```

因此该批次最稳妥结论是：

```text
D 组改变了车辆行为，并降低模型侧高度；
但未证明 RGB 真实液面幅值降低；
可能存在液面变化平滑性改善，但需要更高分辨率和更多重复验证。
```
