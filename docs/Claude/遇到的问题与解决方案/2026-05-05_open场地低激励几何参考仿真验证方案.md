# 2026-05-05 open 场地低激励几何参考仿真验证方案

## 1. 问题

现在需要验证：

```text
低激励几何参考生成是否能在相同 MPC tracker 下降低 /slosh/height。
```

关键是控制变量。

不要在主实验里使用 maze 自动规划对比相同终点，因为：

```text
maze_course.world + map_carto.pbstream 会引入障碍物、全局规划差异、局部可达性和贴墙误差；
相同终点不等于相同路径；
结果会混入 planner 路径差异，而不是只比较 anti-slosh reference geometry。
```

主实验应使用：

```text
open_walled.world + map_sim_empty.pbstream
固定起点
固定 PATH_FILE 回放
同一 MPC tracker
只改变 reference geometry
```

## 2. 实验结论口径

主问题：

```text
有无低激励几何参考生成，在同一 MPC 跟踪器下是否降低 model-estimated /slosh/height。
```

主对比：

```text
B0: old/radius geometry + MPC tracker
Ours: geo56 low-excitation geometry + same MPC tracker
```

不作为主实验：

```text
maze 自动规划相同终点；
不同控制器算法对比；
MPC 内 slosh cost 作为 proposed。
```

旧 MPC slosh cost、OUTPUT_GUARD、PMG、PROFILE_REF_V2 可以作为消融或失败分析，不作为最终主方法。

## 7. 指标解释

主晃动指标：

```text
h_rms     平均晃动强度
h_p95     95 分位晃动高度，建议作为主指标
h_max     最大瞬时晃动，高敏感但可作为安全指标
eta_dot   液体模态速度，表示液体还在动得多快
energy    综合 eta 与 eta_dot 的模态能量
```

车辆/执行指标：

```text
tracking_time       主段用时，判断是否靠减速
ay_p95              横向加速度 95 分位
track_p95           路径跟踪误差 95 分位
odom_ax_p95         实际纵向加速度 95 分位
odom_jerk_p95       实际纵向 jerk 95 分位
solve_success_ratio MPC 求解成功率
```

执行链指标：

```text
ref_ax_p95   参考轨迹隐含 ax
cmd_ax_p95   MPC 输出 cmd_vel 的 ax
odom_ax_p95  底盘实际 odom ax
```

用于确认：

```text
低激励 reference 是否真的被 MPC/底盘执行。
```

## 8. 通过标准

主表建议标准：

```text
h_rms / h_p95 / h_max 下降
eta_dot / energy 下降
tracking_time 不增加，或 <= +15%
solve_success_ratio >= 0.97
```

当前 geo56 已知边界：

```text
ay_p95 可能上升
track_p95 可能略超 +15%
```

论文中需要诚实报告 trade-off，不要写成全指标完美通过。

## 10. maze 场地如何使用

maze 不作为主实验。

如果后续需要补泛化实验，可以这样定位：

```text
open fixed-path:
  主实验，验证机理。

maze same-goal:
  附加实验，验证在复杂导航中的可用性。
```

maze 实验不能替代 open fixed-path 主实验，因为：

```text
相同 goal 不保证相同 path；
全局规划器可能生成不同几何；
路径差异会污染 anti-slosh 方法对比。
```
