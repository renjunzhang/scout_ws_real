# 2026-05-13 晃液模型与 RGB 真实值分析录包方案

## 问题

当前 OSCRS 已经能在软件通路中完成候选生成、可行性过滤、rollout 预测、hard-gate 和选择。但这只证明代码通路成立，不证明晃液模型的真实预测能力成立。

核心风险：

```text
模型认为候选 B 比候选 A 更稳，但 RGB 视觉真实液面不一定同意。
如果 A_rank 接近 0.5，OSCRS 等价于用不可靠的尺子选路。
```

约束：

```text
1. RGB 视觉液面结果是实物液面主指标；
2. /slosh/height 只能作为 observer/model 信号，不能替代 RGB 真值；
3. 不通过放宽 eta_lim_mm 或降低 prediction_v_max 制造 takeover；
4. 先做可辨识动作，再做 P2/P3 策略对比。
```

## 成功标准

最小成功标准：

```text
1. straight_ax 组能解释 eta_x 主导行为的峰值、相位、残振；
2. turn / s_curve 组能解释 eta_y 主导行为的方向和相位；
3. P2/P3 的 RAW / GeoRef / OSCRS 三策略排序，模型 A_rank_p95 >= 0.70；
4. 如果 A_rank < 0.70，不进入新 G 层 generator 实现，优先重审 R 层模型。
```

推荐目标：

```text
A_rank_p95 >= 0.80
A_rank_rms >= 0.70
```

## 小车行为设计

### 1. 静止基线

动作：

```text
小车静止 20-30 s。
RGB 视频必须完整看到液面。
```

用途：

```text
1. RGB 零位；
2. 相机噪声；
3. /slosh/height 静态偏置；
4. 后续 h_mm_smooth_corr 去 baseline。
```

### 2. 直线纵向激励

动作：

```text
straight_ax_low : 0 -> 0.5 m/s -> stop -> 静止 6 s
straight_ax_mid : 0 -> 1.0 m/s -> stop -> 静止 6 s
straight_ax_high: 0 -> 1.5~2.0 m/s -> stop -> 静止 6 s
```

用途：

```text
1. 主要辨识 eta_x；
2. 检查 ax_est -> eta_x -> height 的相位、峰值、残振；
3. P3 纵向脉冲问题必须先由这一组确认。
```

### 3. 纯转弯横向激励

动作：

```text
turn_left_mid  : 左转定半径或 90 度弯 -> 静止 6 s
turn_right_mid : 右转定半径或 90 度弯 -> 静止 6 s
```

用途：

```text
1. 主要辨识 eta_y；
2. 检查左右方向是否对称；
3. 检查 yaw / 离心抛物面项是否过强或过弱。
```

### 4. P2 / P3 策略对比

动作：

```text
P2_s_curve:
  RAW_TUNED
  GEOREF_TUNED
  GEOREF_OSCRS_ACTIVE

P3_mixed:
  RAW_TUNED
  GEOREF_TUNED
  GEOREF_OSCRS_ACTIVE
```

用途：

```text
1. P2 检查横向换向与连续路径相位；
2. P3 检查 ax + ay 耦合和进出弯纵向脉冲；
3. 真正判断 OSCRS 这把尺子能不能用于选路。
```

## 录包要求

每个 trial：

```text
1. 开始前静止 5 s；
2. 动作期间不人为打断；
3. 动作结束后静止 4-6 s；
4. RGB 视频必须清楚看到液面；
5. 非 static 组至少重复 3 次；
6. bag 和 RGB 文件名必须共享 run_id 或时间戳。

```

## 分析顺序

推荐顺序：

```text
1. static_01
2. straight_ax_low/mid/high
3. turn_left/right
4. P2_s_curve RAW/GEOREF/OSCRS
5. P3_mixed RAW/GEOREF/OSCRS
```

决策：

```text
1. straight_ax 对不上 -> 先修 eta_x / ax 输入 / 阻尼；
2. turn 对不上 -> 先修 eta_y / yaw / parabola 项；
3. 单轴都对、P3 不对 -> 查 ax+ay 耦合和 MPC tracking pulse；
4. 单包指标能对但策略排序 A_rank 低 -> 不扩 G 层，先重审 R/S 层；
5. A_rank 达标且 P3 显示关键维度候选塌缩 -> 再进入 corner_profile generator。
```
