### 3.2 GeoRef 升格为约束优化

把 sweep_p3_geometry_candidates.py 这类网格搜索升格为显式约束最优化，
回应 RAL 对 path smoothing 的质疑。

数学形式：

```text
min_{p(s)}   ∫ ( κ(s)² + λ_dκ · κ'(s)² ) ds

s.t.  ‖p(s) - p_raw(s)‖_∞ ≤ Δ_drift
      p(0) = p_raw(0),  p(L) = p_raw(L)
      θ(0) = θ_raw(0),  θ(L) = θ_raw(L)
      |length - L_raw| ≤ ε_L · L_raw
      |H(jω(v_nom, κ(s)))| · v_nom² · |κ(s)| ≤ η_max  ∀s

其中:
  H(jω) 为 ω_n, ζ 二阶振子频响幅值
  ω(v, κ) = v · κ            横向激励频率
  η_max  由模态能量预算决定   论文里写为 design parameter
```

实现：

```text
路径离散化: spline control points {p_i}
求解器:    scipy.optimize.minimize SLSQP (CPU, 离线生成够用)
单路径求解: 目标 < 30s
```

替换的脚本：

```text
scripts/generate_anti_slosh_path_candidates.py   (sweep)
scripts/sweep_p3_geometry_candidates.py          (sweep)
新建:
scripts/optimize_modally_constrained_reference.py
```

W1 内只完成数学+实现+离线验证，不做在线节点。
