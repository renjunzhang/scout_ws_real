### 关键行为

1. `TRACKING → SETTLING → REACHED` 状态机已打通
2. `N_settle` 按 `ceil(4π / ω₀ / dt)` 自动计算（当前 ω₀≈31 rad/s，dt=0.05s → N_settle=8）；`settling/required_steps > 0` 时优先用配置值
3. SETTLING 终止条件（全部满足）：`|η_x|, |η_y| < eta_tol` && `|η̇| < eta_dot_tol` && `|v| < speed_tol` && `|ω| < omega_tol`
4. 机器人重新离开终点区域（`goal_dist > settling/release_distance`）→ 退回 TRACKING
5. `timeout_s` 到时强制 REACHED，避免卡死
6. 编译已验证通过（scout_local_planner + local_planner_node）
