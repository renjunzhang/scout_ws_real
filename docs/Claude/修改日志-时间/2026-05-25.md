## P3 ζ 离线保真度对比脚本

- 新增 `scripts/analysis/analyze_zeta_fidelity_ablation.py`。
- 目的：在不修改在线 MPC 的前提下，用同一批 bag 的 `/slosh/ax_est`、`/slosh/ay_est` 重放二阶晃液模型，对比 `ζ=0.05` 与 Ferrari 物理 `ζ` 是否改善 RGB 保真度。
- 默认窗口：`TRACKING -> first terminal - 1s`，避免 terminal approach jerk 问题混入主效果统计。
- RGB 主指标：`max(left, center, right)`，与当前 Ferrari-style maximum wall-rise 口径一致。
- 输出：per-bag、group summary、A_rank summary、图和 Markdown 报告。

### 运行结果

- 数据集：`/data/a/slosh_bags/real/20260522_fixed_path_cost_d200`

- 输出：`/data/a/slosh_bags/real/20260522_fixed_path_cost_d200/zeta_fidelity_ablation_20260525`
- 主要结果：
  - `ζ=0.05` replay：p95 `A_rank=0.711538`，`gamma=134.739`，`RMSE=0.833365mm`，`corr=0.298876`
