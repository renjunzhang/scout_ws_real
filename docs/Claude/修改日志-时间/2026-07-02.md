# 2026-07-02 修改日志

## SPMPC 实物内部晃动诊断补强

### 背景

实物内部消融中出现 B0 观感/指标优于 B_slosh、B_ours 的现象。前期 bag 与代码审查指出：旧记录无法直接证明 hard cap、slosh cost 尺度、eta-dot 项、fixed_closed_loop 相位补偿是否按预期真正进入 solver；且旧 sidecar 中曾出现 `container/slosh_height_max=0.0025`，而运行时代码读取的是 `slosh/slosh_height_max`。

### 本次改动

- 新增模块化诊断结构：
  - `EffectiveConfigDebug`
  - `SloshHardConstraintDebug`
  - `SloshCostMonitor`
  - `CmdOdomAlignmentDebug`
- 新增/补强 ROS 诊断 topic：
  - `/spmpc/debug/effective_config`
  - `/spmpc/debug/slosh_hard_constraint_effective`
  - `/spmpc/debug/slosh_cost_monitor`
  - `/spmpc/debug/cmd_odom_alignment`
- 保持旧 topic 兼容：
  - 未改变 `/spmpc/cost_breakdown` 布局。
  - 未改变 `/spmpc/debug/slosh_hard_constraint` 旧 5 字段布局，扩展信息放到新的 effective topic。
- 增加 hard cap 显式覆盖路径：
  - `spmpc_fixed_path.launch` 与 `spmpc_experiment.launch` 增加 `slosh_height_max` 参数。
  - 覆盖路径写入 `slosh/slosh_height_max`，与 C++ `loadSloshParams()` 读取路径一致。
- 更新 `run_continuous_real.sh`：
  - 支持 `SLOSH_HEIGHT_MAX`、`V_REF`、`DELAY_PHASE_MODE`、`DELAY_PHASE_LINEAR_DELAY_SEC`、`DELAY_PHASE_ANGULAR_DELAY_SEC`。
  - 录制新增 diagnostics topics。
  - 生成 `${BAG_NAME}_run_meta.env`，记录 variant、solver backend、w_slosh、v_ref、slosh_height_max、delay phase 与 record topics。
