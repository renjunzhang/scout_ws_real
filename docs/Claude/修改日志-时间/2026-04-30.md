### 1. 旧 MPC 代价函数路线失效总结

新增：

```text
docs/Claude/总结/2026-04-30_MPC代价函数旧方案失效总结.md
```

核心结论：

```text
MPC 内部 slosh soft cost 可以改变控制行为，
但不能稳定、可泛化地把液体晃动压下去。
```

主要原因：

- slosh 抑制放在短 horizon QP 内部太晚；
- soft cost 与 tracking cost 竞争；
- 惩罚 `eta` 不等于耗散 `eta_dot` 和总模态能量；
- terminal cost 不能解决路径中段激励；
- hard box constraint 容易制造 QP infeasible；
- 计划输入与真实执行激励存在差异；
- P3 主导通道是 longitudinal `eta_x`，不是简单 lateral `ay`。

论文口径调整：

```text
不能写：MPC cost actively suppresses sloshing.
应写：slosh-aware MPC framework + energy-aware reference generation.
```

ax_i = (v_i^2 - v_{i-1}^2) / (2 ds)
