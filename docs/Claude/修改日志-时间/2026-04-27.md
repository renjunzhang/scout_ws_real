## 5. P4 SMOOTH 仿真对照（失败结论）

固定路径（`PATH_MODE=template_goal`，开阔场地，同起点同 yaw），三包同路径：
NOM / SMOOTH_DOMEGA / SMOOTH_CTRL。

主段口径：`mpc_status == TRACKING && terminal/mode == NONE`。

| 指标（vs NOM） | SMOOTH_DOMEGA | SMOOTH_CTRL |
|---|---:|---:|
| track_dist_p95 | −21.2% | −23.8% |
| heading_err_p95 | −1.2% | +0.4% |
| odom_ay_abs_p95 | +37.1% | +20.7% |
| odom_kappa_abs_p95 | +52.3% | +63.4% |
| odom_wz_rms | +18.9% | +19.6% |

判读：

- 跟踪精度真的改善 → "平滑导致路径贴合差"假设被推翻。
- 但实际 odom 激励 p95 显著恶化（ay +20~37%、κ +52~63%）。
- 机理：R_domega 加重后 planner 被迫选更长持续时间、更高瞬时曲率的弧通过相同弯道，v·ω 持续值与峰值同时升高 → η 受 ay 直接驱动 → 模态能量恶化。

衍生结论：

> **预览曲率前馈 cap（P3B/P3C 类）的物理基础不成立**——odom 实测 κ 远大于参考路径 κ，前馈永远偏乐观。这与 P3B/P3C 此前的失败完全自洽。

- 具体方向优先考虑预测域内对 `E = eta_dot^2 + omega_n^2 * eta^2` 的 terminal/window 代价，或显式约束 `E_{k+1} - E_k` 的软惩罚；不要再只压 `v`、`omega`、`v*omega` 的幅值。

```text
mpc/Q_modal_energy
mpc/modal_energy_window_start_ratio
mpc/modal_energy_terminal_factor
```

实现：

```text
J_E = Q_modal_energy * (eta_dot_x^2 + eta_dot_y^2
      + omega_n^2 * (eta_x^2 + eta_y^2))
```

- `slosh_omega_n` 由 `SloshIntegration::getModalParams().omega_n` 注入到 `MPCParams`。
- 代价只作用于 horizon 后段，默认从 70% 处开始。
- 只加状态二次软代价，不新增硬约束，不会因为当前 slosh 已超限导致 QP infeasible。
- YAML / launch 默认 `Q_modal_energy=0.0`，不改变现有 NOM/FAS/GOV/ISR/AY_COST 行为。
- `run_sim_fixed_path_bag.sh` 新增 `CONDITION=ENERGY_WIN`，默认：

```text

Q_slosh_eta_dot=0
Q_ay_pred=0
Q_modal_energy=1.0
modal_energy_window_start_ratio=0.7
modal_energy_terminal_factor=1.0
```

## 24. 结构性复盘：停止继续堆 MPC soft cost

触发原因：

- 可追溯矩阵 `NOM16-18` vs `ENERGY_WIN16-18` 已确认 D1C 强参数复验失败。
- 04-27 已完成的 `FAS_Q5 / GOV_AY / ISR / AY_COST / ENERGY_WIN` 均未稳定满足成功判据。
- 继续扫 `Q_slosh / Q_ay_pred / Q_modal_energy / GOV_AY threshold` 的预期成功率低于 80%，不符合当前实物实验成本约束。

代码复盘事实：

- `DiffDriveModel` 预测域 slosh 激励为 `ax=a`、`ay=v*omega`。
- `PathHandler` 先生成固定路径上的速度剖面，再由 MPC 在该参考上做 tracking。
- 仿真默认参考较激进：
  - `vehicle/v_max=3.0`
  - `v_nominal=2.4 m/s`
  - `path_handler/max_lat_accel=2.0`
  - `Q_v=8.0`
  - `Q_contour=45.0`
  - `Q_omega_ff=1.5`
  - `R_domega=4.0`
- `Q_modal_energy` / `Q_ay_pred` 均是软代价，不是对未来能量单调下降或真实液面高度下降的约束。
- `/slosh/height` 是模型估计，不是真实液面测量；它和视觉液面仍需分开表述。

判断：

- 当前失败不是单个权重没调好，而是 anti-slosh 权限放在了偏后层级。
- 固定路径和高速参考先决定了主要激励，MPC soft cost 只能事后折中，常见结果是改变相位、延长激励时间或移动峰值，而不是稳定降低模态能量。
- 反应式 `GOV_AY` 能削当前 odom ay，但不能保证削在正确相位，也不能保证不提高曲率/持续时间。
- 预测域 `ENERGY_WIN` 能表达“希望末端能量小”，但不能保证实际闭环中能量下降；可追溯复验已经否定其作为当前主线。
