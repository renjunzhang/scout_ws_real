## PMG 离线验证路线

新增方案文档：

```text
docs/Claude/修改方案-时间-简介/2026-04-29_PMG离线验证设计.md
```

决策：

- 不继续在 MPC QP 内增加新的 slosh cost 或 hard constraint；
- 不继续调 fixed `OUTPUT_GUARD` 的 `ay_limit / domega_limit`；
- 候选下一版是 `PMG`（Predictive Modal Guard），但必须先离线证伪；
- PMG 必须使用 signed `eta_y / eta_y_dot / u_y=v*omega`，不能退化为 `abs(v*omega)` 幅值裁剪；
- 第一版只做 lateral，不扩展 `eta_x`。

模型复核：

```text
当前 37 mm 配置:
R = 0.0185 m
h = 0.058 m
zeta = 0.05
omega_n = 31.25 rad/s
f_n = 4.97 Hz
```

判断：

- `omega_n` 来自几何公式；
- `zeta=0.05` 是采集阶段初值；
- 当前未找到 37 mm 试管的 `omega_eff / zeta_eff` 残差或置信区间；
- 因此 PMG 不能直接进闭环，必须先做 `omega_n/zeta` 置信度复核和 offline replay。

### PMG 设计补充

根据复核意见，补齐 PMG 离线验证的 6 个落地口径：

- Step 0 前置 baseline reconstruction 校准：用 bag 内实测 `odom_v / odom_omega` 重放 lateral slosh 动力学，并与 bag 内 `/slosh/state`、`/slosh/height` 对比；若 `h_p95` 偏差超过 15%，counterfactual replay 不可信；
- 明确算法常数：`tau=2*pi/omega_d`，同时扫 `0.10/0.20/0.40 s`；`eta_threshold` 取同一路径 NOM 主段 `eta_max_p95`；`u_y` 在窗口内保持当前 odom 值；cap 用单变量解析求解；
- 明确鲁棒性扫描：PMG 内部使用扰动 `omega_tilde/zeta_tilde`，reconstruction 仍使用 baseline 参数，测试模型偏差下是否仍有效；
- 明确辨识 fallback：优先找 `|cmd_v|<0.05` 且 `|cmd_omega|<0.10` 持续 `>=0.5s` 的低输入段；若无片段，则用频域强制响应或补专项自由衰减实验；
- 明确主段口径：只分析 `/mpc_status==TRACKING AND /terminal/mode==NONE`；
- 明确触发差异阈值：P3 PMG 与 fixed guard 触发重合率 `<60%` 且平均触发提前量差异 `>0.15s`。

边界也写入方案：

- PMG v1 只 cap `cmd_omega`，不改 `cmd_v`；
- 离线通过只代表值得进仿真闭环，不代表实物有效；
- 若 PMG 不通过，不写控制器代码，转向真实液面视觉、P3 路径可达性或专项自由衰减辨识。

## PMG Step 1 signed replay

对 `offline_pmg_replay.py` 增加 `--pmg-replay`：

- 使用 signed `eta_y / eta_y_dot`；
- `eta_x` 通道固定按记录的 `/slosh/ax_est` 重放；
- `eta_y` 通道使用 `0.88 * odom_v(t-0.10) * odom_omega(t-0.10)` 作为 nominal ay proxy；
- 每条路径的 `eta_threshold` 从同路径 NOM 主段 `|eta_y| p95` 自动计算；
- 对线性二阶系统在 `[0,tau]` 网格上求 signed `eta_y` 双侧约束；
- 通过单变量区间求交得到允许的 `u_y` 区间，不使用 bisection；
- 输出 PMG active ratio、fixed guard overlap、counterfactual `h_p95 / eta_dot / ay_p95`。


## PMG C++ diff 体检修正

查看当前 C++ diff 后修正两处实现问题：

1. `output_ay_guard` 与 PMG 同时开启时不再静默串联。
   - 原实现：只 `ROS_WARN`，然后 `OUTPUT_GUARD -> PMG` 串联生效；
   - 问题：这会污染 PMG 闭环验收，无法区分旧 fixed guard 和 PMG 的贡献；
   - 修正：PMG 启用时若发现 `output_ay_guard/enable=true`，启动时 `ROS_WARN` 并禁用 `output_ay_guard`，保持 PMG 实验纯净。

2. combined PMG 内部顺序改为先 longitudinal、再 lateral。
   - 原实现：先按旧 `v` 限 `omega`，再由 longitudinal 分支修改 `v`；
   - 问题：最终 `v*omega` 可能不再满足 lateral signed cap；
   - 修正：先用 `eta_x / eta_x_dot` 限 `dv/dt` 得到最终 `v`，再用最终 `v` 计算并限制 `omega`。

3. 停车指令跳过输出层 guard。
   - 原风险：`publishCmdVel(0,0)` 后 PMG longitudinal 可能把 `filtered_v` 从 0 改回非零，阻止停车；
   - 修正：`stop_cmd` 直接重置滤波器，并跳过 `output_ay_guard` 和 PMG，只发布零速度。

当前实现约束：

```text
PMG 默认关闭。
PMG 与 output_ay_guard 不组合。
combined 模式顺序：longitudinal -> lateral。
停车指令优先级最高。
```

补充修正：

- `extract_slosh_metrics.py`、`offline_pmg_replay.py`、`diagnose_p3_failure_modes.py` 的 condition 识别加入 `PMG / PMG_COMBINED / PMG_LONG / PMG_LAT`；
- `scripts/README.md` 的 `CONDITION` 列表同步加入 PMG 条件；
- 目的：避免后续 PMG 闭环 bag 被归类为 `UNKNOWN`，影响 group summary。

## PROFILE_ENERGY 后续方案记录

在继续假设 `/slosh/height` 是真实液面高度的前提下，当前最有希望的控制改进方向不是继续调 MPC 内部 slosh cost，也不是 output cap / PMG，而是把抑制逻辑前移到速度剖面生成层。

已新增方案文档：

```text
docs/Claude/修改方案-时间-简介/2026-04-29_PROFILE_ENERGY速度剖面改进方案.md
```

核心思路：

```text
PROFILE_ENERGY / EASP:
  在 PathHandler::updateSpeedProfile() 生成 v_ref(s) 时，
  用未来窗口的 kappa / dkappa / ay / omega / alpha / ax 风险
  生成更连续、更低激励的速度剖面。
```

与 PMG 的区别：

- PMG 在 `publishCmdVel()` 后处理，会与下一周期 tracking 补偿耦合；
- `PROFILE_ENERGY` 在参考生成层提前降低激励，让 MPC 直接跟踪低激励 `v_ref`；
- 方案必须显式约束 `ax / alpha / eta_dot` 风险，避免只压 `h_p95` 而抬高 `eta_dot`。

最小实现建议：

```text
新增 CONDITION=PROFILE_ENERGY
默认关闭
基于现有 selective profile 扩展
新增 energy_profile_* 参数
先 P2 ×3，通过后才录 P3 ×3
```

停止条件：

```text
P2 eta_dot 上升
P2 tracking_time > +15%
P2 h_p95 不降
P3 不能稳定 reached
P3 h_p95 / energy / eta_dot 任一不降
```

成功率估计：

```text
P2 通过：约 70%
P3 通过：约 35~45%
P2+P3 都通过：约 30~40%
```

## PMG C++ 实施（默认关闭）

按上面 spec 实现 PMG 输出层 cap，全程默认关闭。仿真闭环未验证，实物未验证。

修改文件：

```text

```

### 设计落点

- Hook：复用 `publishCmdVel()` 输出层位置；PMG 启用时与 OUTPUT_GUARD 互斥，不做串联组合。
- 状态：`slosh_integration_.getSloshState()` → `(eta_x, eta_x_dot, eta_y, eta_y_dot)`。
- 参数：`omega_n` 取 `slosh_integration_.getModalParams().omega_n`，`zeta` 取 `slosh_params_.damping_ratio`，启动时一次性继承（圆柱试管 x/y 通道对称，单组）。
- 算法：`pmgFreeResponseEta` + `pmgUnitStepResponseEta` 闭式 + `pmgSignedCap` 区间求交，与 `offline_pmg_replay.signed_pmg_u` 一一对应。

### 默认值

```yaml
pmg:
  enable: false
  mode: combined        # lateral | longitudinal | combined
  tau: 0.20
  eta_x_threshold: 0.0023   # max(P2,P3) NOM 主段 |eta_x| p95 * 0.9
  eta_y_threshold: 0.0023   # max(P2,P3) NOM 主段 |eta_y| p95 * 0.9
  grid: 24
  min_v: 0.05
```

### 互斥规则

- PMG 与 `output_ay_guard` 同时开启 → 启动时 ROS_WARN，并禁用 `output_ay_guard`，避免未验证的输出层 cap 串联污染 PMG 验收。
- 非法 `pmg/mode` 字符串 → ROS_ERROR + 强制关闭 PMG。
- `slosh_enabled_=false` 而 `pmg/enable=true` → ROS_ERROR + 强制关闭 PMG。

```text
/slosh/pmg_eta_x_pred_peak   (Float32)  cap 后 [0,tau] 预测 |eta_x| 峰值
/slosh/pmg_eta_y_pred_peak   (Float32)  cap 后 [0,tau] 预测 |eta_y| 峰值
```
