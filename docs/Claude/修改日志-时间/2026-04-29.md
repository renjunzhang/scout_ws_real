### P2 OUTPUT_GUARD PASS 组

输入：

```text
/data/a/slosh_bags/sim/20260428/20260428_P2_s_curve_OUTPUT_GUARD_run04_210756.bag
/data/a/slosh_bags/sim/20260428/20260428_P2_s_curve_OUTPUT_GUARD_run05_211217.bag
/data/a/slosh_bags/sim/20260428/20260428_P2_s_curve_OUTPUT_GUARD_run06_211517.bag
```

命令：

```bash
python3 src/scout_apps/control/scout_local_planner/scripts/analyze_slosh_peak_precursors.py \
  --peak-signal height \
  --top-k 3 \
  --lookbacks 0.5,1.0,1.5,2.0 \
  --csv /tmp/peak_p2_output_guard_height_20260429.csv \
  /data/a/slosh_bags/sim/20260428/20260428_P2_s_curve_OUTPUT_GUARD_run04_210756.bag \
```


判断：

- P2 中 `OUTPUT_GUARD` 确实削低峰前 `cmd_ay / odom_ay / cmd_dwz`。
- 虽然单个峰前 `energy_delta` 不一定更小，但整段统计 `h_rms / h_p95 / energy / eta_dot / ay_p95` 全部下降。
- P2 的有效性更像来自“降低高幅值执行激励峰”，而不是严格的单峰能量增长率控制。

### P3 OUTPUT_GUARD FAIL 组

输入：

```text
/data/a/slosh_bags/sim/20260428/20260428_P3_mixed_OUTPUT_GUARD_run01_213032.bag
/data/a/slosh_bags/sim/20260428/20260428_P3_mixed_OUTPUT_GUARD_run01_213321.bag
```

命令：

```bash
python3 src/scout_apps/control/scout_local_planner/scripts/analyze_slosh_peak_precursors.py \
  --peak-signal height \
  --top-k 3 \
  --lookbacks 0.5,1.0,1.5,2.0 \
  --csv /tmp/peak_p3_output_guard_height_20260429.csv \
  /data/a/slosh_bags/sim/20260428/20260428_P3_mixed_OUTPUT_GUARD_run01_213032.bag \
  /data/a/slosh_bags/sim/20260428/20260428_P3_mixed_OUTPUT_GUARD_run01_213321.bag
```

去掉每包第一个初始 peak 后，峰前 1s 均值：

```text
P3_NOM:
cmd_ay_abs_max       2.31192
cmd_ay_abs_integral  1.56060
odom_ay_abs_max      1.72176
odom_ay_abs_integral 0.83226
cmd_dwz_abs_max      7.10424
cmd_dwz_abs_integral 2.54192
track_dist_max       0.54563
energy_delta         0.04776

P3_OUTPUT_GUARD:
cmd_ay_abs_max       1.96741
cmd_ay_abs_integral  1.43344
odom_ay_abs_max      1.34997
odom_ay_abs_integral 0.75867
cmd_dwz_abs_max      6.00000
cmd_dwz_abs_integral 2.62468
track_dist_max       0.61038
energy_delta         0.05106
guard_ratio          0.48925
guard_first_lead_s   0.84250
```

判断：

- P3 中 guard 正常激活，且峰前 `cmd_ay / odom_ay` 也被削低。
- 但 P3 主段总体指标仍为 FAIL：

```text
h_rms +2.8%
h_p95 +0.7%
energy +3.1%
eta_dot +6.9%
ay_p95 +12.8%
```

- 因此 P3 失败不是“guard 没触发”，也不是“完全没削掉 ay 幅值”。
- 更可信原因是固定阈值削顶改变了通过方式、持续时间或相位；P3 中 `track_dist_max` 上升，`cmd_dwz_abs_integral` 没有下降，峰前 `energy_delta` 反而略高。

### 阶段结论

```text
OUTPUT_GUARD 证明最终执行激励层是关键，但固定阈值 guard 不是最终方案。
下一步不能继续扫 ay_limit/domega_limit。
应先做相位/窗口感知诊断或 OUTPUT_GUARD_V2，而不是继续录 P3 重复样本。
```
