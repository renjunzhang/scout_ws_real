```bash
roslaunch scout_local_planner slosh_experiment_sim.launch \
  Q_slosh:=5.0 \
  slosh_use_imu_yaw_rate:=true \
  slosh_use_imu_lateral_accel:=true \
  risk_scheduler_enable:=true
```

录包目录：


### 2. 离线分析

对每条 bag：

```bash
rosrun scout_local_planner analyze_settling_day3.py <bag>
```

- `/mpc/status_val success_ratio`

- `/risk_scheduler/fallback_active true_ratio`

### 3. 参数试探

优先试探：

| 组别 | 目的 | 参数 |
|---|---|---|
| baseline | 当前 C 配置复测 | 当前 YAML |
| conservative risk | 降低风险调度激进程度 | `gamma=3.0`, `rho_0=0.4`, `rate_limit=0.02`, `beta=0.2` |
| relaxed settling | 放宽 settling 终止 | `eta_tol=0.002`, `eta_dot_tol=0.05` |
| no IMU ay | 判断 IMU ay 是否导致不可行 | `slosh_use_imu_lateral_accel=false`, `risk_scheduler_enable=true` |

如果需要频繁改参数，考虑只给 `slosh_experiment_sim.launch` 增加 sim-only 参数 arg，不改实物 launch。
