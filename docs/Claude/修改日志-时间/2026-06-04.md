# 2026-06-04 修改日志

## SPMPC ranked review issues 修复

### 修改范围

- `src/scout_apps/control/spmpc_local_planner/core/costmap_grid`
  - `CostmapGrid` 支持 `OccupancyGrid.info.origin` yaw，world→map 使用 origin 逆旋转。
  - `setGrid()` 将 `data` 规范化到 `width*height`，短缺格子按 unknown 填充，避免 `costAtCell()` 越界读。

- `src/scout_apps/control/spmpc_local_planner/ros/spmpc_local_planner_ros`
  - `WAITING_FOR_ODOM` / `WAITING_FOR_REFERENCE_PATH` / `WAITING_FOR_TF_POSE` 状态主动发布零 `/cmd_vel`。
  - slosh observer 按 odom stamp 的 `dt_safe` 按需重配离散矩阵，避免加速度 dt 与 slosh step dt 不一致。
  - 未知 `planner_variant` 显式告警后回退 B0，避免静默误跑。

- `src/scout_apps/control/spmpc_local_planner/solvers/continuous_mpcc_solver_acados`
  - acados solve status 非零时在读取 NLP 输出前直接返回失败，避免发布无效轨迹/代价。
  - 明确 `u=[a,omega,v_s]` 语义：`cmd_v` 由首帧加速度积分并限幅得到，`v_s` 仅为虚拟 progress speed。
  - acados CMake 探测支持 `lib` / `lib64`，且 B0 generated solver 可单独启用 continuous 后端；slosh generated solver 存在时再启用 slosh capsule。

- `src/scout_apps/control/spmpc_local_planner/core/spmpc_problem`
  - `sameReferencePath()` 改为逐点比较位置和 yaw，避免同起终点但中间路径变化时沿用旧 progress。

- `src/scout_apps/control/spmpc_local_planner/reference/reference_path`
  - yaw 插值改为 shortest-angle 插值，修复跨 `±pi` 时插到 0 的问题。

- `src/scout_apps/control/spmpc_local_planner/launch`
  - `spmpc_point_to_point.launch` 补齐并转发 `solver_backend` / `w_slosh`。
  - `spmpc_fixed_path.launch` 补齐并转发 `cmd_vel_topic` / `publish_cmd_vel`。

- `src/scout_apps/control/spmpc_local_planner/scripts`
  - `phase3_smoke.sh` 支持 `SOLVER_BACKEND` / `W_SLOSH`，支持 `PHASE3_MODE=p2p`，录制 `/spmpc/solver_backend`，并将配置错误状态与 ready 状态区分。
  - `verify_continuous_smoke.sh` 校验实际 `/spmpc/solver_backend` 与 requested continuous 后端一致，录包补充 reference path、`/tf`、`/tf_static`。
  - `rollout_sampling_solver` 复用 `solve()` 已算出的起点 projection，避免每个 primitive 重复投影。
