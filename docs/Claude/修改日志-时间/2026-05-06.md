## 在线 path post-processor 第一版

目标：

```text
把 README-NEW.md 中的在线 path post-processor 方案落成最小 ROS 节点，
使 scout_global_planner 生成的 nav_msgs/Path 可以先经过低激励几何后处理，
再交给 scout_local_planner MPC tracking。
```

新增文件：

```text
src/scout_apps/control/scout_local_planner/scripts/anti_slosh_path_post_processor.py
src/scout_apps/control/scout_local_planner/launch/anti_slosh_path_post_processor.launch
```

节点接口：

```text
sub: /scout/global_path_raw
pub: /scout/global_path_anti_slosh
pub: /anti_slosh_path/debug/original
pub: /anti_slosh_path/debug/mild
pub: /anti_slosh_path/debug/medium
pub: /anti_slosh_path/debug/strong
pub: /anti_slosh_path/metrics
```

第一版算法：

```text
sanitize raw path
resample by ds
generate original / mild / medium / strong smoothing candidates
gate by max_drift, length_ratio, endpoint_error, min_segment_length, direction
score by kappa_p95, dkappa_p95, length_ratio, max_drift
publish best candidate
```

当前边界：

```text
不做 costmap collision check
不做 slosh ODE rollout
不做 SLSQP/global optimization
```

因此该版本只能用于 open field / known safe corridor 的在线接入验证；
maze 或复杂障碍环境仍需要补 footprint/costmap collision check 后才能作为安全结论。
