# 2026-07-04 修改日志

## SPMPC 实物 delay 默认口径修正

### 背景

2026-07-04 仿真 delay 归因显示：`fixed_closed_loop 0.08 / 0.05` 不能再作为实物默认必开配置；它应当作为待验证变量，与 `delay off` 做同一版代码、同一路径和同一共享约束下的对照。否则现场执行文档会同时出现“当前推荐 fixed 0.08/0.05”和“不要默认开启 fixed 0.08/0.05”的矛盾。

### 本次改动

- 更新 `src/scout_apps/control/spmpc_local_planner/scripts/run_spmpc_real_fixed_path_trial.sh`：
  - 默认 `DELAY_PHASE_MODE=off`；
  - 默认 `DELAY_PHASE_LINEAR_DELAY_SEC=-1.0`；
  - 默认 `DELAY_PHASE_ANGULAR_DELAY_SEC=-1.0`。
- 更新 `docs/实物实验注意事项/对比试验/实物对比实验/B0_B_slosh_B_ours_SPMPC内部晃动高度实物验证指南.md`：
  - 明确当前默认调试口径为 `delay off`；
  - 明确 `fixed_closed_loop 0.08 / 0.05` 是待验证变量，不是默认推荐；
  - 明确 `shadow 0.08 / 0.05` 只用于诊断 predicted state，不替换 solver input；
  - 明确 `fixed_closed_loop 0.15 / 0.22` 只用于旧问题复现；
  - 调整实物 run 顺序为先 `B_slosh_delay_off`，再 `B_slosh_delay_080_050`，再 `B0_delay_off`；
  - 保留“被动诊断全录；每个 run 只改一个主动变量”的口径，并明确本轮不跑 hard constraint。
- 更新 `docs/实物实验注意事项/对比试验/实物对比试验启动指南.md` 与 `src/scout_apps/control/spmpc_local_planner/scripts/README.md`，避免一键脚本示例仍默认指向 fixed delay。
