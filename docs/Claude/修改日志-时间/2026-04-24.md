## 6. P1 代码改动：加入 `Q_slosh_eta_dot`（2026-04-25）

### 背景

32 包实物实验分析结果显示，当前 anti-slosh MPC 在 P2_s_curve 和 P3_mixed 两条路径上均无法稳定优于 NOM 基线（视觉口径），`/slosh/height` 口径也只在 P3 上有部分支持。

分析原因：现有代价只惩罚 `eta_x / eta_y`（液体模态位移），不惩罚 `eta_x_dot / eta_y_dot`（模态速度）。控制器可以在短时间内将 eta 压回零，但允许高速振荡，导致 MPC 视窗内实际液体相位控制能力弱。

### 修改范围

| 文件 | 修改内容 |
|---|---|
| `include/scout_local_planner/types.h` | `MPCParams` 新增 `Q_slosh_eta_dot = 0.0` |
| `src/cost_function.cpp` | `evaluate()` 和 `getQuadraticCost()` 中增加 eta_dot 代价项 |
| `src/local_planner_ros.cpp` | 读取参数 `mpc/Q_slosh_eta_dot`；启动 log 增加输出 |
| `config/mpc_params.yaml` | 新增 `Q_slosh_eta_dot: 0.0`，实物入口默认关闭 |
| `config/mpc_params_sim.yaml` | 新增 `Q_slosh_eta_dot: 0.0` |
| `launch/slosh_experiment.launch` | 新增 `Q_slosh_eta_dot` launch arg 和 param |
| `launch/slosh_experiment_sim.launch` | 新增 `Q_slosh_eta_dot` launch arg 和 param |

说明：仿真和实物入口保持同步新增参数，避免两套实验口径分叉；默认值均为 `0.0`，不改变旧行为。

### 实现口径

```text
J_slosh =
  Q_slosh_eta     * (eta_x² + eta_y²)          [原有，Q_slosh_eta = Q_slosh * h_coeff²]
  + Q_slosh_eta_dot * (eta_x_dot² + eta_y_dot²) [新增，直接 QP 权重，不经 h_coeff 缩放]
```

`Q_slosh_eta_dot` 默认 `0.0`，保证旧行为不变。

### 验证命令

```bash
catkin_make --pkg scout_local_planner  # 编译通过 ✓
```

静态行为检查（仿真启动后）：
```bash
roslaunch scout_local_planner slosh_experiment_sim.launch Q_slosh:=0 Q_slosh_eta_dot:=0.0
```

仿真消融实验（P2_s_curve）：
```bash
# FAS_Q5 基线（保持不变）
roslaunch scout_local_planner slosh_experiment_sim.launch Q_slosh:=5 Q_slosh_eta_dot:=0.0

# FAS_Q5_DOT 小值测试
roslaunch scout_local_planner slosh_experiment_sim.launch Q_slosh:=5 Q_slosh_eta_dot:=0.05
```

指标：观察 `/slosh/height` 的 `peak / p95 / RMS` 是否下降。

### 验证结果

仿真 8 包（P2_s_curve + P3_mixed × 4 条件）+ 3 包诊断包。结论：

- `Q_slosh_eta_dot=0.05`：激励可比条件下（P2_s_curve）η̇_rms 不降反升（+0.145 mm/s），h 无改善
- `Q_slosh_eta_dot=0.20`：h 有改善（Δh_peak=−0.75 mm），但 η̇_rms 仍升高（+0.949 mm/s）；P0 直线对照包证明改善来自激励相位偏移，不是阻尼
- 真实机制：惩罚 η̇² 使优化器把激励移到振荡零点（η 小、η̇ 大），比值 η̇/(ω₀η) 从 0.76 升至 0.98

P1 结论：代码保留，但机制为相位偏移而非阻尼；不作为主要 anti-slosh 结构。进入 P2。

## 7. P2 代码改动：加入 terminal slosh cost（2026-04-25）

### 背景

P1 实验和对 32 包实物数据的机制分析表明：
- `Q_slosh_eta`（η-only 代价）在 S 弯路径上可构成性加剧晃动（FAS_Q5 的 `/slosh/height` peak 比 NOM 高 19%）
- 原因是 η-only 惩罚使优化器将激励时机移到液体位移峰值附近，结果是平均 η 更高
- 解决方案：在预测窗口末端同时惩罚 η 和 η̇（总模态能量 E = ω₀²η² + η̇²），逼迫 MPC 规划出"到达末端时液体位移和速度同时小"的轨迹

### 修改范围

| 文件 | 修改内容 |
|---|---|
| `include/scout_local_planner/types.h` | `MPCParams` 新增 `terminal_factor_slosh_eta`、`terminal_factor_slosh_eta_dot`，默认 0.0 |
| `src/cost_function.cpp` | terminal ramp 块中叠加 slosh 终端放大系数（η 和 η̇ 独立，仅在 base cost > 0 时生效） |
| `src/local_planner_ros.cpp` | 读取 `mpc/terminal_factor_slosh_eta` 和 `mpc/terminal_factor_slosh_eta_dot` |
| `config/mpc_params_sim.yaml` | 新增两个参数，默认 0.0 |
| `config/mpc_params.yaml` | 新增两个参数，默认 0.0 |
| `launch/slosh_experiment_sim.launch` | 新增两个 launch arg 和对应 param |
| `launch/slosh_experiment.launch` | 新增两个 launch arg 和对应 param |
| `scripts/run_sim_fixed_path_bag.sh` | 新增 `FAS_Q5_TERM` 条件；MPC_ARGS 中传入两个新参数 |

### 实现口径

terminal ramp 最后 `terminal_ramp_steps` 步内，在现有 ec/etheta/v 放大的基础上，叠加：

```
if terminal_factor_slosh_eta > 0 AND Q_slosh_eta > 0:
    Q_ETA_X *= 1 + alpha × (terminal_factor_slosh_eta − 1)
    Q_ETA_Y *= 1 + alpha × (terminal_factor_slosh_eta − 1)

if terminal_factor_slosh_eta_dot > 0 AND Q_slosh_eta_dot > 0:
    Q_ETA_X_DOT *= 1 + alpha × (terminal_factor_slosh_eta_dot − 1)
    Q_ETA_Y_DOT *= 1 + alpha × (terminal_factor_slosh_eta_dot − 1)
```

两个 factor 独立控制，默认 0.0，旧行为完全不变。

### 验证命令

```bash

```

仿真验证（P2 第一轮）：

```bash

  rosrun scout_local_planner run_sim_fixed_path_bag.sh

# FAS_Q5 对照

  rosrun scout_local_planner run_sim_fixed_path_bag.sh

# FAS_Q5_TERM（P2，Q_slosh=5, Q_slosh_eta_dot=0.02, factor_eta=10, factor_eta_dot=10）
```

成功判据：

- `/slosh/height RMS` 相比 FAS_Q5 下降，且 ay_rms 差 < 10%
- η̇_rms 不升高（区别于 P1 的相位偏移）
- `task_time` 增加 ≤ 15%
- `success_ratio` ≥ 0.97

### 验证结果

仿真 3 包（P2_s_curve：NOM / FAS_Q5 / FAS_Q5_TERM，2026-04-25）。分析方法：提取 TRACKING 阶段（排除 terminal recovery 占比影响）。

| 指标 | NOM | FAS_Q5 | FAS_Q5_TERM |
|------|-----|--------|-------------|
| h_peak (mm) | 8.74 | 7.92 | **7.34** |
| h_p95 (mm) | 6.55 | 6.46 | **5.35** |
| h_rms (mm) | 2.96 | 3.21 | **2.85** |
| η̇_rms (mm/s) | 16.12 | 15.90 | **13.53** |
| η̇/(ω₀η) | 1.207 | 1.099 | **1.053** |
| ay_rms (m/s²) | 0.842 | **1.009** | 0.844 |
| omega_rms (rad/s) | 0.524 | **0.583** | 0.461 |
| task_time (s) | 16.58 | 16.16 | 17.15 |
| success_ratio | 0.971 | 0.984 | 0.984 |

**激励可比性（TERM vs FAS_Q5，TRACKING 段）**：omega_rms 差 20.8%，ay_rms 差 16.3%，均超出 10% 限制。h 改善不能独立归因于 terminal cost。

**P2 成功判据逐项**：

- h_rms 下降（vs FAS_Q5）：delta=−0.36 mm ⚠️ 激励不可比，不可归因
- h_peak 不恶化：delta=−0.57 mm ✓
- η̇_rms 不升高：15.90 → 13.53 mm/s（−14.9%）✓ **P1 区别标志满足**
- task_time 增加 ≤ 15%：6.1% ✓
- success_ratio ≥ 0.97：0.984 ✓

**机制发现**：FAS_Q5（η-only）的 omega_rms 比 NOM 高 11%（0.583 vs 0.524），与 P1 结论一致——η-only 代价使优化器选择更高转速产生峰值相位激励。FAS_Q5_TERM 的 omega_rms 反而降至 0.461（低于 NOM），说明 terminal energy cost 渗透至整段路径规划，不只作用于末端段。

**P2 结论**：初步有效信号，但激励不可比。η̇_rms 下降满足 P2 核心特征（区别于 P1），但 terminal_factor=10 影响力过强。

**下一步**：录制 factor=3 的小值对照（`TERM_S`），验证激励可比性能否恢复。

```text

```
