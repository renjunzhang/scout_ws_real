## 2. 实现 PROFILE_SELECTIVE 段选择性速度剖面

修改文件：

- `src/scout_apps/control/scout_local_planner/include/scout_local_planner/types.h`
- `src/scout_apps/control/scout_local_planner/src/local_planner_ros.cpp`
- `src/scout_apps/control/scout_local_planner/src/path_handler.cpp`
- `src/scout_apps/control/scout_local_planner/launch/slosh_experiment_sim.launch`
- `src/scout_apps/control/scout_local_planner/scripts/run_sim_fixed_path_bag.sh`
- `src/scout_apps/control/scout_local_planner/scripts/extract_slosh_metrics.py`
- `docs/Claude/修改方案-时间-简介/2026-04-27_Anti-Slosh_方向修正.md`

修改内容：

- `PathHandlerParams` 新增选择性速度剖面参数：
  - `selective_profile_enable`
  - `selective_kappa_threshold`
  - `selective_dkappa_threshold`
  - `selective_lat_accel`
  - `selective_omega_max`
  - `selective_alpha_max`
- `LocalPlannerROS` 增加对应 ROS 参数读取。
- `PathHandler::updateSpeedProfile()` 增加段选择性限速：
  - 仅在 `|kappa|` 或 `|dkappa/ds|` 超阈值的采样点生效；
  - 触发点叠加更保守的横向加速度、角速度、角加速度预算；
  - 默认关闭，不影响旧实验条件。
- `SpeedProfile` 日志增加 `selective=<count>`，用于确认选择性限速是否实际触发。
- `slosh_experiment_sim.launch` 暴露选择性参数入口。
- `run_sim_fixed_path_bag.sh` 新增 `CONDITION=PROFILE_SELECTIVE`。
- `extract_slosh_metrics.py` 增加 `PROFILE_SELECTIVE` 条件识别。

`PROFILE_SELECTIVE` 默认参数：

```text
VEHICLE_V_MAX=3.0
PATH_MAX_LAT_ACCEL=2.0
SPEED_PROFILE_OMEGA_MAX=1.5
SPEED_PROFILE_ALPHA_MAX=5.0
MAX_TAN_ACCEL=2.0
MAX_TAN_DECEL=2.0

SELECTIVE_PROFILE_ENABLE=true
SELECTIVE_KAPPA_THRESHOLD=0.9
SELECTIVE_DKAPPA_THRESHOLD=12.0
SELECTIVE_LAT_ACCEL=1.2
SELECTIVE_OMEGA_MAX=1.2
SELECTIVE_ALPHA_MAX=3.5
```

设计目的：

- 避免 `PROFILE_SAFE` 全局降速导致的节流和曲率副作用；
- 只在高曲率/曲率变化段前移 anti-slosh 权限；
- 仍保持 `Q_SLOSH=0 / Q_AY_PRED=0 / Q_MODAL_ENERGY=0`，不回到 MPC soft-cost 路线。
