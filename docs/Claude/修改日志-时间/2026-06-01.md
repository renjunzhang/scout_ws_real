## spmpc cost 归一化口径

- 更新 `docs/Claude/修改方案-时间-简介/2026-06-01_spmpc_local_planner规控一体新主线方案.md`。
- 在 §3.5 中新增 cost normalization 小节。
- 明确 Route B 规控一体 MPC 必须使用参考尺度无量纲化：
  - contour 使用 `corridor_width / 2`；
  - lag 使用 `v_nominal * dt`；
  - control 使用 `a_max`、`omega_max`；
  - slosh 使用 `slosh_height_ref`；
  - modal velocity 使用 `omega_n * eta_ref` 对齐。
- 记录与当前 `scout_local_planner` 一致的 slosh 权重口径：
  - `Q_eta = Q_slosh * h_coeff^2 / h_ref^2`；
  - `h_ref = slosh_height_ref`，默认沿用 5 mm；
  - `Q_eta_dot` 使用 `slosh_eta_dot_ratio / omega_n^2` 的等价口径。
- 明确 progress 项单独处理，不和误差类项混归一化，防止规控一体 planner 为抢进度而容忍路径偏差或绕路。
