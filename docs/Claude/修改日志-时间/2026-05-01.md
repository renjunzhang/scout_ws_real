## 3. PROFILE_ENERGY rollout 时间预算修正

时间：2026-05-01 12:58 CST

针对上一节结论，修改 Step2 接受/回滚逻辑：

```text
旧逻辑：
  proposed_time <= current_profile_time * 1.15

问题：
  这是“相对本轮 profile”的局部预算；
  多轮 correction 或较慢 geometry baseline 下，会默许整体时间继续变长。

新逻辑：
  rollout_base_time = geometry profile time before rollout correction
  rollout_time_budget = rollout_base_time * energy_profile_rollout_time_budget_ratio
  proposed_time <= rollout_time_budget
```

新增参数：

```text
path_handler/energy_profile_rollout_time_budget_ratio
默认值：1.05
运行时建议先用：1.03
```

设计含义：

```text
PROFILE_ENERGY_GEO 负责给出可接受的几何速度基线；
PROFILE_ENERGY rollout correction 只能在该基线附近做局部相位修正；
不允许 rollout 为了降 h_p95 把整体 tracking_time 明显拉长。
```

已验证：
