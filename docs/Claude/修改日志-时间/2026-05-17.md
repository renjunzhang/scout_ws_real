## 扩展实物录包为完整实验包

背景：

```text
用户担心下一轮实物录制后又发现缺少关键 topic 或 launch 参数，
导致需要重新录包。

当前最大数据量来自 RealSense RGB/depth，补齐低频诊断 topic 和参数快照的成本较低。
```

改动：

```text
src/scout_apps/control/scout_local_planner/scripts/record_slosh_experiment.sh
  增加录制前 sidecar 元数据：
    *_info.txt
    *_rosparam.yaml
    *_topics.txt
    *_nodes.txt
  默认改为 SLOSH_RECORD_ALL=true，即 rosbag record -a 全量录制当前 ROS master 上存在的话题；
  保留 TOPICS 白名单，磁盘压力过大时可用 SLOSH_RECORD_ALL=false 回退；
  补齐 RealSense aligned depth / metadata / compressed 别名；
  补齐 camera gyro/accel/imu 可能输出；
  补齐 /joint_states、/battery_state；
  补齐 /slosh/output_guard_active；
  补齐 Cartographer scan matched / constraint / landmark 常见输出。

docs/重要文档/20260513_SloshPriorityMPC有效性验证方案.md
  增加“完整实验包”录制说明；
  明确正式实验优先使用默认全量录制；
  明确 bag 同目录会保存参数、topic、node 快照，用于后续复核。
```

结论：

```text
后续正式实物 bag 不再只依赖最小分析话题。
默认全量录制可以避免因为遗漏某个诊断 topic 重新录包；
白名单模式仅作为磁盘/写入压力过大时的回退方案。
如果后处理发现某个结论需要确认当时的参数、节点或 topic 是否存在，
优先查 sidecar 文件，不应因为缺少参数快照重新录包。
```
