# 2026-04-22 修改日志

## 新增 red_liquid_calibrate.py

**文件**：`src/scout_apps/sensors/realsense_liquid_measurement/scripts/red_liquid_calibrate.py`

**背景**：液体从黑色切换为红色后，旧的灰度梯度椭圆链（RGB_calibrate.py + RGB_infer_from_bag.py）在红色液体图像上失效（椭圆厚度几乎为 0px，实质上仍在抓灰度强边）。新方案切换为"红色液柱上边界 + 三条竖直高度标尺"。

**功能**：

交互式标定工具，生成供 `red_liquid_infer_from_bag.py` 使用的 YAML。

流程：
1. Phase ROI_DRAG：拖拽选管区 ROI（或 `--roi-x/y/w/h` 跳过）
2. Phase WALLS：点击左内壁、右内壁（只记 x 坐标）
3. Phase LEFT/CENTER/RIGHT：在左/中/右三条标尺列依次点击 0mm→2mm→4mm→6mm→8mm 的 y 位置
4. Enter 保存 YAML

按键：`u` 撤销 / `r` 重置当前阶段 / `q`/`Esc` 退出

**输出 YAML 格式**：
```yaml
roi: {x, y, w, h}
tube_inner: {x_left, x_right}
rotation_deg: 0.0
rulers:
  left:
    x_roi: <float>
    reference_points:
      - {y_px_roi: <float>, h_mm: 0.0}
      ...
  center: ...
  right:  ...
```

**标尺 x 位置**：从管壁自动计算（默认 0.2 / 0.5 / 0.8 比例），可通过 `--ruler-x-fractions` 覆盖。

## Review 修复（4 个 Finding）

### Fix 1（高优先级）：标尺 x 位置改为用户点击，不再按比例自动计算

**文件**：`red_liquid_calibrate.py`

原来 `ruler_x_fracs = (0.2, 0.5, 0.8)` 自动推算三条标尺的 x 坐标，与物理标尺贴纸位置可能不一致。

改动：
- 新增 `Phase.LEFT_X / CENTER_X / RIGHT_X`（9 个 phase，原 6 个）
- `_St` 增加 `ruler_actual_xs: List[Optional[float]]`，`ruler_x()` 直接返回用户点击值
- 新的流程：`ROI → WALLS → LEFT_X → LEFT → CENTER_X → CENTER → RIGHT_X → RIGHT → Done`
- `LEFT_X / CENTER_X / RIGHT_X` 阶段：鼠标悬停显示半透明彩色竖线预览，点击锁定 x 坐标
- 删除 `--ruler-x-fractions` CLI 参数
- `undo()` / `reset_phase()` 支持所有新 phase

### Fix 2（高优先级）：超出标定范围时输出 clipped 标志，不静默截断

**文件**：`red_liquid_infer_from_bag.py`

原来 `_px_to_mm` 超范围直接返回端点值，峰值段数据会被静默饱和。

改动：
- `_px_to_mm` 返回 `(Optional[float], bool)` 其中 `bool=True` 表示 clipped
- `detect_red_liquid` 返回值新增 `clipped: List[bool]`（第 4 个元素）
- `render_debug`：clipped 帧的检测线变红色，标签加 `[CLIP]`
- `save_csv`：新增 `clipped_left/center/right` 和 `any_clipped` 列（均为 0/1）

### Fix 3（中优先级）：保存前单调性校验

**文件**：`red_liquid_calibrate.py`

`_write_yaml` 保存前对每条标尺检查 `y(0mm) > y(2mm) > ... > y(8mm)`；不满足则拒绝保存并打印具体哪两个点违反约束。

## HSV 取样工具 + 时域平滑

### 新增 red_liquid_sample_hsv.py

**用途**：对若干参考帧手动点击红色液柱像素，自动输出 HSV 分布统计和建议的 `--hue*/--sat-min/--val-min` 参数。

**使用方式**：
```bash
python scripts/red_liquid_sample_hsv.py \
    --images debug_000000.png debug_000300.png \
    --calibration /home/a/scout_ws/red_liquid_3rulers.yaml
```
每张图点击红色液柱主体（避开反光），Space 切下一张，Enter 输出建议。
输出示例：
```
  --hue1-low 0 --hue1-high 14 --hue2-low 165 --hue2-high 179 --sat-min 75 --val-min 45
```

**关键设计**：
- 每次点击采样 `patch_radius=2` 的邻域（5×5=25像素），避免单像素噪声
- H 值在 0/180 处断裂，分别统计低H段 (0..90) 和高H段 (91..179)，各自求 p2/p98 再加 `h_margin`
- S/V 取 p5 后减 `sv_margin` 作为下界，保留液体主体同时过滤暗背景

### red_liquid_infer_from_bag.py 加时域平滑

新增 `--smooth-frames N`（默认 1=关闭）：对 `h_mm_final` 和 `h_mm_corr` 做滚动中位数平滑。

新增 CSV 列：`h_mm_smooth`（平滑后的 final）、`h_mm_smooth_corr`（平滑后的零点校正）。

图表新增 `corr+smooth` 曲线（实线青色），`corr` 曲线变为半透明虚线。

### Fix 4（已知问题，暂不修复）

`rotation_deg` 默认 0.0，倾斜管会导致三路系统偏差。短期先接受，可在 debug 图和 CSV 里比较三路差值；长期需给 calibrate 工具加轴线估计步骤。

**典型启动命令**：
```bash
python scripts/red_liquid_infer_from_bag.py \
    --bag /data/a/slosh_bags/real/0422/slosh_Q0_20260422_150601_5.bag \
    --calibration /data/a/calib/Q0_red_calib.yaml \
    --out-dir /data/a/results/0422_block2_Q5_red \
    --debug-every 30
```
