定位与目的：

```text
phase4 短路径 (3.8 m) 验证了工程链路与 OSCRS_MEDIUM 在短路径下能 takeover；
但视觉真值在 run01/run02 方向不稳定 (A_rank=0.5),

phase5 在 phase3 同样 14 m 长路径 (含弯) 同 session 录全
RAW + FIXED_MILD + OSCRS_MEDIUM_ACTIVE 三组对比,
目标达成 SOP §11.3 主效果判据 + Ferrari-style 模型保真度。
```

### 关键设计

#### 1. 同 session 重录而非复用 phase3 长路径数据

```text
phase3 长路径 RAW + FIXED 数据已存在且 yaw 修复在 phase3 时已生效 (EQUAL=True),
但液位 / 标定 / 定位均不可跨 session 复用：
  - 间隔 ≥ 1 天, 液位漂 mm 级污染 sub-mm 信号 ablation;
  - RealSense / 三标尺 / HSV 重新搭场地后必须重标;
  - AMCL 在不同 session 同坐标可能落到物理不同位置;
  - 论文方法学不接受跨 session 拼数据。

phase3 数据仅作历史诊断证据保留，不进 phase5 主表。
```

#### 2. §0 录前参数 sanity 独立 session（必做）

```text
phase4 通过的 (ay_ratio_limit=3.0, oscrs_residual_ratio=0.2) 不保证长路径够：
  - phase3 长路径实测 medium ayr ∈ {3.08, 3.45} → 3.0 几率被 ay gate 拦;
  - 长路径残振时间更长 → 0.2 几率被 residual gate 拦;
  - 主 session 现场调参 30-60 min 期间液位漂 mm 级, 污染同液位前提。

独立 sanity session 工作流：
  起链路 → 定位 smoke → 静止包 → 视觉标定 (引用 §4.2-§4.5)
  → OSCRS_MEDIUM smoke × 1 (引用 §5.3, RUN_ID=sanity01)
  → validate (oscrs --require-non-original)
  → 决策按 §11.3:
       A 档 (selected ∈ {mid,medium}, fb=0, takeover=1)  → 锁定
       B 档 (selected=mild, fb=0)                          → 锁定 (论文标注)
       C 档 (fb=2/3 / safety_alarm)                        → 改一参重 smoke
              最多 3 轮: ay 3.0→3.5 → residual 0.2→0.5 → 停

输出 locked_params.yaml:
  ay_ratio_limit / oscrs_residual_ratio / 锁定时间 / verified_by bag。

phase5 §5.3 GEOREF_OSCRS_MEDIUM_ACTIVE_REAL launch 必须用此 yaml 锁定值,
不再现场决策。
```

三轮全失败处置：

```text
- 不强行救 OSCRS;
- phase5 缩为 RAW + FIXED × 3 两组;
- 论文写"OSCRS 在该长路径无可行参数"作 negative ablation。
```

#### 3. §11 现场快速决策卡（validate FAIL → 改什么）

```text
实物现场操作员无法实时与 Claude 对话, 一页查表自助。
按 condition + fb 分支列出所有可能 FAIL 形态:
  §11.1  RAW FAIL                3 类 (goal / MBF / 误启 post-proc)
  §11.2  FIXED FAIL              6 类 (按 mild reject reason 分支)
  §11.3  OSCRS FAIL              按 fb 分支 (fb=0 mild 接受 / fb=2 / fb=3)
  §11.4  通用 FAIL                4 类 (yaw / 定位 / 液位 / 三档全失败)
  §11.5  何时停 phase5 整体        5 触发
  §11.6  现场不要做的事            6 条

每条处理标 [现场可改] / [停录返回] / [可继续录],
明确哪些当场调 launch 一参重 smoke, 哪些必须等回来后处理。

sanity 通过后主 session 决策卡几乎不触发。
```
