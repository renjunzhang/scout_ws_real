## 修复 RealSense 固定参数脚本 dynparam get 兼容性

### 背景

- 实物机执行 `set_realsense_rgb_manual_params.sh` 时出现：
  - `dynparam: error: too many arguments`
- 原因是该 ROS 环境下 `rosrun dynamic_reconfigure dynparam get /camera/rgb_camera exposure` 不兼容，只支持读取整个 node 配置。

### 修改

- 将脚本改为：
  - `dynparam get /camera/rgb_camera` 读取整份配置；
  - 用 `awk` 从配置文本中解析 `exposure / gain / white_balance`；
  - 最后打印当前参数时也使用同一方式，避免再次触发 `too many arguments`。
