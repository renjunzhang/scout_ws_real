## RealSense 红色液体交互调参退出保护

### 背景

- 实物机上按 Esc 退出 `interactive_realsense_red_tuner.py` 后，RealSense 话题可能消失，需要重启相机甚至重启电源；
- 该脚本主窗口原来同时接受 `q` 和 Esc 退出，容易误触发不稳定路径。

### 修改

- 修改 `src/scout_apps/sensors/realsense_liquid_measurement/scripts/interactive_realsense_red_tuner.py`：
  - 主调参窗口只允许 `q` 正常退出；
  - Esc 在主窗口中被忽略，并打印 `Press q to quit cleanly` 警告；
  - ROI 选择提示改为用 `c` 取消，避免在不稳定 RealSense 设置上按 Esc。

### 验证

```bash
python3 -m py_compile src/scout_apps/sensors/realsense_liquid_measurement/scripts/interactive_realsense_red_tuner.py
```

- 语法检查通过。

## RealSense 红色液体交互调参辅助线

### 背景

- 实物布置时需要快速判断试管是否位于画面中心，以及静止液面是否位于 ROI 上半部推荐位置；
- RealSense 原始图像话题没有辅助线，直接靠肉眼对齐容易反复调整。

### 修改

- 在 `interactive_realsense_red_tuner.py` 中增加显示层辅助线：
  - 青色十字线：画面中心线；
  - 绿色横线：建议静止液面目标线，默认位于 ROI 高度 `0.425` 处；
  - 辅助线只影响调参窗口和保存预览图，不写回 `/camera/color/image_raw`；
  - 新增 `--no-guide-lines` 可关闭辅助线；
  - 新增 `--liquid-target-frac` 可调整目标液面线位置。

### 验证

```bash

```

- 正式实验需要一个不依赖 OpenCV 窗口的固定曝光/增益/白平衡入口。

### 修改

- 新增 `src/scout_apps/control/scout_local_planner/scripts/set_realsense_rgb_manual_params.sh`：
  - 默认 `MODE=freeze_current`：读取当前 `exposure/gain/white_balance`，关闭自动曝光/自动白平衡，再把当前值写回相机；

  - 支持 `MODE=manual`，通过 `EXPOSURE` / `GAIN` / `WHITE_BALANCE` 环境变量显式指定；

- 更新 `docs/重要文档/20260527_SloshPriorityMPC正式对比实验验证方案.md`：
