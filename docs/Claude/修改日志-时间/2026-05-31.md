# 2026-05-31 修改日志

## 正式对比实验验证方案急修

### 背景

- 当前代码已切到 `experiment_group` 驱动的 C/D/E/F/RPP_STYLE/BIAGIOTTI/TOPPRA/RUCKIG 对比实验结构；
- `docs/重要文档/20260527_SloshPriorityMPC正式对比实验验证方案.md` 之前被压成最小骨架版，缺少实物现场可直接执行的顺序；
- 文档中还残留了几处与当前代码不一致的命令口径，例如 `R_a/R_da` arg、Biagiotti 的 `--zeta` / `--provenance-json`。

### 修改

- 重写 `docs/重要文档/20260527_SloshPriorityMPC正式对比实验验证方案.md` 为实物现场 SOP：
  - 补齐传感器栈启动、可选 RealSense 调参、P2 S 弯模板路径生成、goal 发送、CSV 生成、MPC 启动、录包、检查项和分析口径；
  - 明确 `experiment_group` 是唯一正式切换字段；
  - 明确 C/D/E/F/RPP_STYLE/BIAGIOTTI/TOPPRA/RUCKIG 的代码派生关系；
  - 修正 roslaunch arg 为当前真实参数名 `mpc_R_a` / `mpc_R_da` 等；
  - 修正 Biagiotti CSV 命令为当前脚本支持的 `--damping-ratio` / `--debug-prefix`；
  - 明确 RGB 主指标继续使用 `max(left, center, right)`，`/slosh/height` 只作为模型辅助。

- 修正 real/sim launch：
  - `max_lat_accel_safety` 默认从 `0.0` 改为 `2.5`；
  - 原因：`mpc_params*.yaml` 已定义 safety 层横向加速度硬上限为 2.5，但 launch arg 默认 0.0 会覆盖 YAML，导致所有方法默认关闭 safety cap；
  - 该 cap 是所有 baseline 共用安全层，不是 RPP_STYLE 专属。
