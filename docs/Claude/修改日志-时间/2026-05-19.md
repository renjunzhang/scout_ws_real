## 更新固定路径 MPC cost / ax-jerk 调参验证方案

背景：

```text
20260518_fixed_path_cost 分析显示：
  D 组降低了 v/ay/model_p95，且 pct_slosh_total 约 20%，说明 slosh cost 已经参与优化；
  但 model_peak 没有下降，RGB h_abs_peak / p95 也没有下降；
  model_peak 多发生在 first terminal 前约 0.03s；
  D 组 RGB peak 三次集中在路径早段 s≈1.5m；
  该处 D 组 ay 已下降，但 odom_ax 没有明显下降。

因此下一轮实验重点从“继续堆 Q_slosh”改为：
  在同一固定路径和同一基础参考输入下，验证提高 R_a / R_da 是否能压住早段 ax 与 RGB peak。
```

修改：

```text
docs/重要文档/20260518_MPC终点收敛与固定路径验证方案.md
```

内容：

```text
1. 第二阶段从 C/D 两组扩展为 C/D/E/F 四组：
   C = SMOOTH_SPEED_RELAXED
   D = SLOSH_PRIORITY
   E = AX_JERK_PRIORITY
   F = SLOSH_PLUS_AX_JERK

2. 明确本轮不改固定路径速度剖面，不启用 OSCRS / GeoRef / energy_profile / input_shaping / risk_scheduler / speed_governor。

3. 增加 E/F 启动命令：
   E: Q_slosh=0, R_a=1.0, R_da=2.0
   F: Q_slosh=5, R_a=1.0, R_da=2.0

4. 录包目录切到：
   /home/geist/slosh_bags/real/20260519_fixed_path_cost

5. 分析口径增加两个局部窗口：
   EARLY_AX_WINDOW: s=1.0-2.0m 和 s=1.2-1.8m
   PRE_TERMINAL_1S: first terminal/capture 前 1s

6. 明确明天重点比较：
   E vs C：单纯 ax/jerk 优先级是否降低早段 RGB peak；
   F vs D：同样 Q_slosh 下提高 R_a/R_da 是否进一步降低早段 ax/RGB peak；
   F vs E：slosh cost 在 ax/jerk 更平滑前提下是否仍有额外收益。
```

约束：

```text
真实液面结论仍以 RGB 视觉为主；
/slosh/height 只作为模型侧和调试指标；
terminal 段不作为 slosh cost 有效性的主证据。
```
