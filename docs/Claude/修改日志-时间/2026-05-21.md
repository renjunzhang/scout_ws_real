## 新增 RealSense 红色液体交互式调参窗口

背景：

```text
用户希望在实物现场通过可视化窗口调节更清晰的相机参数组合，
用于改善红色液体 RGB 分割、降低反光和模糊对 peak / p95 指标的影响。
```

新增：

```text
src/scout_apps/sensors/realsense_liquid_measurement/scripts/interactive_realsense_red_tuner.py
```

功能：

```text
1. 在 RealSense 节点启动后，订阅 /camera/color/image_raw。
2. 通过 dynamic_reconfigure 实时调节：
   - exposure
   - gain
   - white_balance
3. 同时通过 OpenCV trackbar 调节红色分割 HSV 参数：
   - hue1_low / hue1_high
   - hue2_low / hue2_high
   - sat_min
   - val_min
   - morph_kernel
4. 可视化显示：
   - 原始 RGB + ROI
   - ROI 放大
   - HSV red mask
   - mask 叠加 + 液面上边界
5. 按 s 保存当前 camera 参数、HSV 参数、预览图和 Markdown 报告。
6. 按 r 恢复启动时的 auto exposure / auto white balance 状态。
```

文档：

```text
docs/重要文档/红色液体视觉验证固定流程.md
  新增 7.1.7 交互式 RealSense 红色液体调参窗口。
```

边界：

```text
1. 不修改 MPC / OSCRS / 录包逻辑。
2. RealSense 彩色镜头光圈固定，脚本只调 exposure / gain / white_balance。
3. 该脚本需要实物机图形界面；离线服务器不能直接运行窗口。
```

验证：

```text
python3 -m py_compile src/scout_apps/sensors/realsense_liquid_measurement/scripts/interactive_realsense_red_tuner.py
```

## 新增 /slosh/height peak 回放诊断脚本

背景：

```text
用户希望按顺序判断：
1. 自动化 peak 回放诊断；
2. peak 是 k=0 当前峰值还是 horizon 未来峰值；
3. 多数 k=0 时先治理前 0.5-1.0s ax/jerk；
4. 多数 k>0 时才考虑 slosh height soft constraint；
5. terminal 附近 peak 单独统计，不混进主效果窗口。
```

新增：

```text
src/scout_apps/control/scout_local_planner/scripts/analysis/analyze_slosh_peak_context.py
```

功能：

```text
1. 读取 /slosh/height、/mpc/slosh_horizon_summary、/mpc/cost_breakdown、
   /reference/implied_ax/ay/jerk、/odom、/cmd_vel。
2. 分别统计：
   - pre_terminal
   - main_excluding_terminal_margin
   - terminal_near
3. 对每个 peak 输出：
   - peak_t_s / peak_mm / p95 / rms
   - horizon_kmax_at_peak
   - horizon_peak_class = CURRENT_K0 / FUTURE_K_GT_0
   - peak 前 0.5s / 1.0s 的 ref/odom/cmd ax 与 jerk absmax
   - pct_v_at_peak / pct_slosh_at_peak
   - recommendation
4. 输出 CSV、分组摘要、Markdown 报告和可选 peak replay 图。
```

已跑 20260520 固定路径包：

```text

  FUTURE_K_GT_0: 8 (53.3%)
  terminal_near within pre_terminal: 11 (73.3%)

关键分组：
  F pre_terminal:
    peak mean = 1.972 mm
    CURRENT_K0 = 3/3
    terminal_near = 3/3
    time_to_terminal_mean = 0.085 s

  F main_excluding_terminal_margin:
    peak mean = 1.366 mm
    FUTURE_K_GT_0 = 3/3
```

判读：

```text
当前 F/G 主线中的 /slosh/height peak 主要是 terminal 前 0.03-0.13s 的 k=0 当前状态峰值；
因此不应把 terminal-near model peak 混入 slosh cost 主效果窗口。

若只看去掉 terminal 末 0.5s 的 main effect 窗口，
F 组 peak 显著低于 pre_terminal 总 peak；
后续若要压 main effect 内的未来峰值，可再讨论 soft constraint + slack。
```
