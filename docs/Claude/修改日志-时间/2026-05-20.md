副现象：

```text
  fixed_path_cost_effect/fixed_path_cost_effect_summary.csv
```

分层归因（再次确认之前的诊断）：

```text
MPC 命令层 ax_p95 = 2.29 m/s^2（cmd_vel.linear.x 差分）：
  比实物 0.28 已经 8x 高。
  原因：sim 中 odom = cmd（无打滑），MPC 反馈完美 → 自己敢开更猛；
        实物轮胎打滑 → MPC 看到响应慢 → 自我保守。
底盘层放大 2.29 → 4.01 m/s^2：
  skid_steer 插件 torque=1000，无 wheelAcceleration 限制，
  瞬时跟踪 cmd_vel，对 cmd 阶跃产生冲击响应。
两层叠加 = 实物 14x。
```

判定与决定：

```text
sim 当前可用范围：
  trajectory 拓扑验证（能不能停在 goal）        OK 可直接用
  Q_slosh 0 vs 5 趋势对比                       OK 可定性
  ax/ay/jerk/slosh 绝对值与实物互通               不可用
  RL 训练直接 zero-shot 到实物                    不可用

修到能数值互通需要：
  1. cmd_vel rate limiter 节点（~1 小时）+ 标定（半天）→ 估计 sim ax 4.0 → 0.8（降 5x）
  2. 仍距实物 0.28 约 3x，paper 数据仍不能直接拿 sim 出
  3. RA-L 投稿（2026-08）核心数据已经在实物上，paper 数据从实物出更直接

结论：不再为 sim-real 数值 gap 投入。sim 保留做 smoke test：
  - 新 MPC commit 后跑一次确认不崩、能停 goal
  - paper figure 的 trajectory overlay 截图（定性）
  - 训 RL 阶段再评估平台（Isaac Sim / MuJoCo）

主线回到实物 bag 录制 + 分析。
```

```text

原文“所有组使用同一个 P2_s_curve.json”容易误导为所有包必须复用同一个 JSON。
```

```text

```

要点：

```text

   同一模板、同一 goal、同一生成参数；
   每包前回到同一物理起点和朝向；
   允许重新生成 /scout/global_path_fixed。

2. 录包后用：
   path_len；
   trajectory_overlay；
   起始 tracking error；
   检查路径一致性。
```

## MPC one-step preview slosh 代价开关

背景：

```text
用户提出：D 组像是在看到液体快晃后再避开，能否“前看一步”，
即用 rollout 出来的下一步液体状态增强当前控制对晃动的敏感性。

代码审查结论：
当前 QP 已经对 horizon 内 x_1..x_N 的 eta/eta_dot 加状态代价；
直接再罚 eta_{k+1} 与简单增大 Q_slosh 高度重合。
因此本次做成可回退的 preview 加权入口：
  slosh_preview_factor = 0 默认关闭；
  >0 时只对预测状态 x_1..x_N 额外加 slosh 权重，
  让 cost 更偏向当前控制导致的未来响应，而不改变 x_0。
```

修改：

```text
src/scout_apps/control/scout_local_planner/include/scout_local_planner/types.h
  MPCParams 新增 slosh_preview_factor，默认 0.0。

src/scout_apps/control/scout_local_planner/src/cost_function.cpp
  buildQPCost() 中，当 k>0 且 slosh_preview_factor>0 时，
  对 ETA_X / ETA_Y / ETA_X_DOT / ETA_Y_DOT 额外叠加 preview * Q_slosh_*。

src/scout_apps/control/scout_local_planner/src/local_planner_ros.cpp
  读取 mpc/slosh_preview_factor；
  slosh enabled 日志打印 preview_factor；
  /mpc/cost_breakdown 的 J_slosh_eta / J_slosh_eta_dot 复用同样 preview 加权，
  不新增字段，保持分析脚本兼容。

src/scout_apps/control/scout_local_planner/config/mpc_params.yaml
src/scout_apps/control/scout_local_planner/config/mpc_params_sim.yaml
  默认 slosh_preview_factor: 0.0。

src/scout_apps/control/scout_local_planner/launch/slosh_experiment.launch

  增加 launch arg slosh_preview_factor，默认 0.0，并传入 mpc/slosh_preview_factor。
```

回退方式：

