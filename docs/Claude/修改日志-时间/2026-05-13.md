## Step 0 实现: phase4 模型保真度 ablation

新增离线分析脚本：

```text
src/scout_apps/control/scout_local_planner/scripts/analysis/phase4_model_fidelity_ablation.py
```

用途：

```text
1. 读取 phase4 visual summary 中的 run01/run02 RAW / FIXED_MILD / OSCRS_MEDIUM_ACTIVE；
2. 使用 RGB 视觉 CSV 的 h_mm_smooth_corr 作为实物液面主指标；
3. 对 bag 中 /slosh/ax_est、/slosh/ay_est、/odom yaw rate 做离线 replay；
4. 比较 M0/M1/M2/M3 四组模型的单包保真度和 run 内 pairwise A_rank。
```

ablation 组：

```text
M0_online_recorded:
  使用已录 /slosh/height，扣 static median 后作为当前在线模型基线。

M0b_replay_observer:
  observer height_coeff + 当前 damping + 当前 parabola 设置，离线 replay /slosh/ax_est 和 /slosh/ay_est。

M1_ferrari_height_coeff:
  Ferrari closed-form height_coeff + 当前 damping + 当前 parabola 设置。

M2_parabola_off:
  Ferrari closed-form height_coeff + 当前 damping + parabola off。

M3_ferrari_full:
  Ferrari closed-form height_coeff + Ferrari physics damping + parabola on。
```

输出：

```text
docs/Claude/分析数据/phase4_model_fidelity_20260513/model_fidelity_ablation_phase4.csv
docs/Claude/分析数据/phase4_model_fidelity_20260513/model_selection_fidelity_phase4.csv
docs/Claude/分析数据/phase4_model_fidelity_20260513/A_rank_by_model_phase4.csv
docs/Claude/分析数据/phase4_model_fidelity_20260513/A_rank_by_model_phase4.md
```

本轮运行结果：

```text
M0_online_recorded:       A_rank_p95=1.000 (6/6)
M0b_replay_observer:      A_rank_p95=0.500 (3/6)
M1_ferrari_height_coeff:  A_rank_p95=0.500 (3/6)
M2_parabola_off:          A_rank_p95=0.500 (3/6)
M3_ferrari_full:          A_rank_p95=0.833 (5/6)
```

解读：

```text
1. 录包中的在线 /slosh/height 与 RGB p95 排序一致；
2. 但用 /slosh/ax_est、/slosh/ay_est 离线重放 observer 口径只有 A_rank_p95=0.500；
3. 因此需要区分“在线 observer 状态输出”与“离线 rollout 重放”；
4. 只切 Ferrari height_coeff 不足以改善 p95 排序；
5. Ferrari physics damping + Ferrari height_coeff 的组合在 phase4 p95 排序上通过 0.80 门槛；
6. rms 排序仍只有 0.667，不能把模型写成全面可信；
7. 该结论仍以 RGB 视觉 CSV 为真值，/slosh/height 只是 M0 模型变体。
```


```text

2. 不降低 prediction_v_max；
3. 不把 /slosh/height 当实物主指标；
4. 不实现 corner_profile / lateral_offset 等新 generator；
5. 本轮仍保持“Phase A 诊断先行”，后续是否进入 Phase B 由 RAW / GeoRef / OSCRS 多包对比和模型保真度 gate 决定。
```
