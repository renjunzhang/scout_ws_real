# 2026-06-05

## SPMPC P2P continuous MPCC 稳定化

- 在 `point_to_point.yaml` 中加入 P2P 专用保守参数：降低 `v_max/omega_max`，放宽 `goal_tolerance`，并降低 P2P 下 `B_ours/B_ours_anti` 的 `w_smooth/w_slosh`。
- 新增 `ReferencePathPreprocessor`，在 reference 层完成近重复点删除、弧长重采样、轻量平滑和 yaw 重算，避免把路径几何处理耦合进 ROS callback 或 solver。
- 为 `continuous_mpcc_acados` 增加基于差速底盘微分平坦性的 primal warm-start：从平滑 reference 推出 `theta/v/omega/a` 作为 acados 初值；该功能默认关闭，仅 P2P 配置开启。
- 对 continuous MPCC 输出的 `cmd_omega` 按运行时 `omega_max` 限幅，使 P2P lowered yaw-rate 参数能约束实际下发命令。

## SPMPC acados warm-start 模块化重构

- 新增 ROS-free `warm_start/` 模块，包含 `WarmStartGenerator` 接口、diff-drive flatness 实现、mecanum 预留骨架和 factory，避免 warm-start 逻辑继续散落在 acados solver 或 ROS adapter 中。
- `DiffDriveFlatnessWarmStart` 现在从 `ReferenceSpline` 生成 `x/u` horizon 初值，使用 `omega = kappa * v`，并对 `v/omega/a/v_s` 做限幅和有效性检查。
- slosh horizon 初值改为通过 `SloshDynamics::step()` 从当前 `SloshState` 按 warm-start 加速度激励 rollout；不可 rollout 时保持当前 slosh state，不再简单全置零。
- `ContinuousMpccSolverAcados` 只通过 `WarmStartGenerator` 接口拿初值，并增加 previous-solution shift 与 conservative seed fallback；warm-start 失败不会直接导致 solver 崩溃。
- 增加 `/spmpc/debug/warm_start` 与 `/spmpc/debug/warm_start_status` 诊断输出，并新增 `DiffDriveFlatnessWarmStart` gtest 覆盖直线、曲率限速和 slosh rollout。

## SPMPC soft terminal stopping

- 参考 `scout_local_planner` 的 terminal slowdown / capture-stop 思路，为 `spmpc_local_planner` 新增 ROS-free `TerminalController`，统一管理终点减速 envelope、capture-stop latch、低速/低角速度到达判定和速度变化率限制。
- 将 `GOAL_REACHED` 判定从 primitive / acados 两个后端中上移到 `SpmpcProblem`，保证 `B0/B_smooth/B_slosh/B_ours` 使用同一套 terminal policy。
- terminal policy 第一版只做 post-solve `cmd_v` envelope / rate-limit clamp，不改 SPMPC cost 权重，不单独增强 `B_ours`，避免污染主体路径段的液体晃动抑制判断。
- 新增 `/spmpc/terminal/debug` 与 `/spmpc/terminal/mode` 诊断，用 `pre_terminal_phase` / `terminal_phase` 区分主体 tracking 段和终点停车段，便于后续只统计 terminal 前的对比指标。
- 新增 `test_terminal_controller` gtest，覆盖远离终点、slowdown envelope、capture-stop、低速/低角速度 gate、goal-behind stop 和 rate-limit 防硬停。
