## 步骤 3 — P3 ζ 物理标定（Ferrari 式 3）

**目的**：把拍脑袋的 ζ=0.05 换成从容器几何 + 水物性算出的 ζ_n。论文方法节多一句
"first-principles damping ratio from Ferrari Eq.(3)"。

**前置**：知道 Scout 杯子 R (内半径) 与 h (液体静液高度)。

### 3.1 代码改动

```text
[3.1.1] params (mpc_params.yaml / mpc_params_sim.yaml):
  slosh_estimator:
    zeta_source: manual                       # "manual"（默认）/ "physics"
    zeta: 0.05                                  # 仅 manual 生效
    liquid_kinematic_viscosity: 1.0e-6        # m²/s, 水 @ 20°C
    liquid_density: 1000.0                    # kg/m³
    container_inner_radius: <R 数值>          # m，物理量
    liquid_static_height: <h 数值>            # m，物理量

[3.1.2] launch (slosh_experiment.launch + _sim.launch):
  5 个新 arg + 5 个对应 <param>

[3.1.3] slosh_integration.cpp:
  新增 static double compute_zeta_from_physics(R, h, nu, mu, mode_index)
  实现 Ferrari Eq.(3):
    ζ_n = 0.92 · sqrt(ν/μ) / sqrt(g R³)
          · [1 + 0.318/sinh(ξ_{1n} h/R) · (1 + (1-h/R)/cosh(ξ_{1n} h/R))]
    （ξ_{1,1} = 1.841）

[3.1.4] SloshIntegration::configure:
  if (params.zeta_source == "physics"):
      params.zeta = compute_zeta_from_physics(...)
      ROS_INFO("[slosh] computed zeta_1 = %.4f (Ferrari Eq.3)", params.zeta);
```

### 3.2 验收

- [ ] catkin_make 通过
- [ ] zeta_source=manual + 旧 zeta=0.05 → sim S 曲线 cmd_vel / slosh/* byte-equal
- [ ] zeta_source=physics → 启动日志打印 zeta，量级应在 0.02–0.10
- [ ] sim D 组对照（manual vs physics），model peak 差异 < 30%（数值健康检查）

### 3.3 commit


## 步骤 4 — P1 ω²·d / ω̇·d 偏置耦合补偿（own contribution）

**目的**：当前 ay = v·omega 只覆盖路径切向曲率离心，缺 yaw 旋转 × 容器偏置的
ω²·d 离心项与 ω̇·d 切向项。补这两项 = 模型保真度大幅提升 = 论文核心方法贡献。

**前置**：**用卷尺量 Scout 杯子相对 base_link yaw 轴的水平偏置 d_x, d_y**。

### 4.1 量偏置

```text
1. 让小车水平静止;
2. 用卷尺量容器中心垂直投影到底盘 yaw 轴的水平距离;
   - d_x: 容器在 base_link 前方多少米（正前为正）
   - d_y: 容器在 base_link 左方多少米（正左为正）
3. 重复量 3 次，取均值，记录在实验本/项目笔记里。
```

### 4.2 代码改动

```text
[4.2.1] params:
  slosh_estimator:
    container_offset_x: <d_x 数值>            # m
    container_offset_y: <d_y 数值>            # m
    yaw_offset_excitation_enable: false       # 默认 disable，向后兼容

[4.2.2] launch:
  3 个新 arg + 对应 <param>

[4.2.3] slosh_integration.h / .cpp:
  扩展 update 接口 / 内部:
    void update(double ax_path, double ay_path,
                double omega_z, double alpha_z);   // 现有签名
    内部计算:
      a_yaw_x = -omega² · d_x - alpha_z · d_y
      a_yaw_y = -omega² · d_y + alpha_z · d_x
      ax_excit = ax_path + (yaw_offset_excitation_enable ? a_yaw_x : 0)
      ay_excit = ay_path + (yaw_offset_excitation_enable ? a_yaw_y : 0)
  （注：把 enable 标志放在 SloshParams 内,update 不变签名）

[4.2.4] 调试 publisher（可选，建议做）:
  /slosh/excitation_ay_path      （旧 v*omega 项）
  /slosh/excitation_ay_yaw       （新 -ω²·d_y + α·d_x 项）
  /slosh/excitation_ax_yaw       （新 -ω²·d_x - α·d_y 项）
```

### 4.3 验收

- [ ] catkin_make 通过
- [ ] yaw_offset_excitation_enable=false → sim S 曲线 byte-equal
- [ ] enable=true + d_x=d_y=0 → byte-equal（退化等价）
- [ ] enable=true + 真实偏置：
  - sim 纯转 cmd（v=0, omega=0.5）：新增 /slosh/excitation_*_yaw 非零
  - sim S 曲线：model peak 与 disable 相比变化可见
- [ ] 实物 F 配置对照 1 包：
  - bag replay (observer-only) 模式下，新 observer 的 γ_model 与旧版对比应**下降**

### 4.4 commit

```text
"P1: 加入 yaw-offset 离心耦合 (ω²·d / ω̇·d)，默认 disable"
```

## 风险与回退

| 风险 | 触发 | 回退 |
|---|---|---|
| 步骤 1 C 组 path_len 不一致（>5% 差） | spawn 位姿漂移 | 重新校准固定路径起点 |

| 步骤 4 P1 enable 后 sim 不稳 | omega² 项数值爆 | 加 saturation `min(abs(...), some_limit)` |
| 步骤 4 实物 D/F + P1 比 no-P1 RGB 更高 | 偏置量错或方向错 | 重量 d_x/d_y，先做 sim 离线对照 |
