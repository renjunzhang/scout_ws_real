## Step 4：ISR ZV Shaper 实现（Day 5 前置）

若 Step 2 通过，开始实现 ISR 条件（主实验四条件之一）。

### 4.1 ZV Shaper 算法

```python
# 参数来自 Day 1 辨识结果：ω₀, ζ
omega_d = omega_0 * sqrt(1 - zeta**2)
t1 = pi / omega_d                        # 有阻尼半周期
K = exp(-zeta * pi / sqrt(1 - zeta**2))
A1 = 1.0 / (1.0 + K)
A2 = K / (1.0 + K)

# 应用于 v_ref(t)：
v_shaped(t) = A1 * v_ref(t) + A2 * v_ref(t - t1)
```

### 4.2 实现位置

- `PathHandler::getSpeedAtS()` 之后，在 `v_ref` 写入 `ref_points[i].v` 之前应用
- 新增参数：
  - `isr/enable`（bool，默认 false）
  - `isr/omega_0`（rad/s，来自辨识）
  - `isr/zeta`（无量纲，来自辨识）
- 独立开关，不影响其他条件

### 4.3 验证

编译通过后，用仿真快速验证：

- ISR 关闭时，v_ref 与原版一致
- ISR 开启时，v_ref 平滑度提升（无突变），且整体响应有延迟 ≈ t1
