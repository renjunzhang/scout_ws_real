## 1. 现场录包前检查

### 1.1 所有条件都检查

```bash
rostopic hz /imu/data
rostopic echo -n1 /imu/data/header
rostopic echo -n5 /imu/data
```

通过标准：

- `/imu/data` 约 `50 Hz`
- `frame_id` 非空，当前通常应为 `imu_link`
- 静止时 `angular_velocity.z` 接近 `0`
- 静止时 `linear_acceleration.z` 接近 `+9.8 m/s²`
- 静止时 `linear_acceleration.y` 不应有明显大偏置

### 1.2 `PROP_Q5` 额外检查

`risk_scheduler` 虽然不直接把 IMU ay 作为 slosh 模型激励，但会用它计算：

```text
u_k = |a_y_imu - v*omega| / a_uncert_max
```

所以 `PROP_Q5` 运动前必须检查：

```bash
rostopic echo -n5 /slosh/imu_ay_bias_ready
rostopic echo -n5 /slosh/imu_ay_filtered
rostopic echo -n10 /risk_scheduler/u_k
rostopic echo -n10 /risk_scheduler/fallback_active
```

通过标准：

- `/slosh/imu_ay_bias_ready = 1`
- 静止 `/slosh/imu_ay_filtered` 接近 `0`
- 静止 `/risk_scheduler/u_k` 不长期接近 `1`
- `/risk_scheduler/fallback_active` 不长期为 `true`

如果 bias 没 ready：不要开始正式 motion bag，重新静止等待或重启 planner。

## 2. Bag 级离线复核

### 2.1 IMU ay 健康度

```bash
python3 src/scout_apps/control/scout_local_planner/scripts/imu_ay_tool.py analyze <bag>
```

重点看：

- `static imu_ay_filtered` 均值是否接近 `0`
- `left-turn imu_ay_filtered` 是否为正
- `right-turn imu_ay_filtered` 是否为负
- `corr(imu_ay_filtered, v*omega)` 是否为正且足够高
- `imu_ay_bias_ready_ratio` 是否正常

### 2.2 Scheduler 健康度

```bash
python3 src/scout_apps/control/scout_local_planner/scripts/analyze_day3_abc_smoke.py <bag>
python3 src/scout_apps/control/scout_local_planner/scripts/diagnose_real_tuning.py <bag> --brief
```

重点看：

- `/risk_scheduler/u_k` 的 mean / p95 / max
- `/risk_scheduler/fallback_active true_ratio`
- `/slosh/imu_ay_bias_ready true_ratio`
- solver success ratio

### 2.3 标签规则

| 标签 | 判定 |
|---|---|
| `IMU_PASS` | IMU 频率正常，bias ready，fallback 不长期触发 |
| `IMU_WARN` | `u_k` 或 fallback 偶发异常，但不主导整包 |
| `IMU_FAIL` | IMU 断流、bias 未 ready、fallback 长期 true、ay 符号明显错误 |

主统计只用 `IMU_PASS`；`IMU_WARN` 可进敏感性分析；`IMU_FAIL` 不进主统计。

## 4. 重要边界

当前代码中的 `a_y_imu` 是：

```text
(/imu/data.linear_acceleration.y - imu_ay_bias) * imu_ay_scale
```

它不是完整外参补偿后的车体横向加速度。

当前没有做：

- TF 旋转
- roll / pitch / yaw 安装角标定
- `base_link -> imu_link` 平移补偿
- 杠杆臂项 `alpha × r` 和 `omega × (omega × r)`

因此：

- 现在可以写：`bias-corrected IMU ay as auxiliary uncertainty signal`
- 不建议写：`extrinsic-calibrated lateral acceleration`
- 若要把 IMU 作为论文级 slosh 状态估计基石，后续需要完整外参和补偿模型
