## 3. 直接观察

### 3.1 所有包都能正常完成控制闭环

- `solve success` 都在 `0.977 ~ 1.000`
- 没有出现明显的“整包不可用”情况
- 从控制链路角度看，这批红色液体实验包是 **可分析的**

### 3.2 真正开启 `risk_scheduler` 的包只有 PROP2 口径

从 `/risk_scheduler/rho_k` 消息数看：

- `145809_5`：`176`
- `150105_10`：`177`
- `150240_10block1_PROP2`：`201`

其余包均为 `0`。

因此，当前可以比较明确地说：

- `PROP2` 类包确实开启了 risk-adaptive scheduling
- `PROP1`、`FAS`、`NOM`、`ISR`、block2 普通 `Q` 包都没有 risk scheduler 输出

### 3.3 risk scheduler 开启后，`v_des_eff` 确实被压低

对比 `Q=5`：

- `PROP1(Q=5)`：`v_des_eff p95 = 2.400`
- `FAS(Q=5)`：`v_des_eff p95 = 2.400`
- `PROP2(Q=5)`：`v_des_eff p95 = 2.232`

对比 `Q=10`：

- `block2 Q10`：`v_des_eff p95 = 2.400`
- `PROP2(Q=10)`：`v_des_eff p95 = 2.222`

这说明：

- risk scheduler 在当前实物实验中不是“挂着没起作用”
- 它已经实际介入了速度参考

### 3.4 但“压速”还没有直接转化成最好的 tracking error

以 `Q=5` 组为例：

- `FAS(Q=5)`：`dist p95 = 4.348 m`, `heading p95 = 74.47 deg`
- `PROP2(Q=5)`：`dist p95 = 4.886 m`, `heading p95 = 85.68 deg`
- `PROP1(Q=5)`：`dist p95 = 5.761 m`, `heading p95 = 101.90 deg`

当前结果是：

- `PROP2(Q=5)` 比 `PROP1(Q=5)` 好
- 但还没有优于 `FAS(Q=5)`

这和之前实物阶段的经验是一致的：

- risk scheduler 确实工作了
- 但它不天然保证 tracking error 更小
- 它更可能改善的是风险暴露与激励分布，而不是单纯 path error

### 3.5 block2 这组三包控制表现最好

从 `dist p95 / heading p95` 看：

- `block2 Q0`: `3.993 m / 45.36 deg`
- `block2 Q5`: `2.824 m / 27.14 deg`
- `block2 Q10`: `3.203 m / 36.88 deg`

这三条整体明显优于 block1 的对应量级。

说明至少有一个事实：

- **block2 的执行条件更干净**

可能原因包括：

- 起点/姿态更一致
- 轮胎/地面状态更稳定
- 这批红色液体录制后段整体运行状态更顺

当前如果后续要做视觉主分析，建议优先从 block2 三条包开始看。

## 9. 与论文贡献点的对应关系（阶段性判断）

本节对照 [`论文提纲.md`](/home/a/scout_ws/docs/Claude/总结/论文提纲.md) 中的贡献点，说明当前 0422 首批 10 包能够支撑什么、还不能支撑什么。

### 9.1 贡献 1：Risk-Adaptive Scheduling Layer

这是当前方法设计中最强、最值得保留为主贡献的部分。

当前实物数据已经支持以下事实：

- `PROP2` 类 bag 中 `/risk_scheduler/rho_k` 有输出，说明 scheduler 在实物中实际运行
- `PROP2_Q5` 的 `v_des_eff p95 = 2.232`，低于 `FAS_Q5 / PROP1_Q5` 的 `2.400`
- 说明 scheduler 不是“挂着没起作用”，而是已经真实改变了速度参考

但当前数据还不能支撑“PROP 全面优于 FAS”的强结论：

- `FAS_Q5` 的 `smooth peak` 最低，说明固定 Q 在压瞬时最高峰上更强
- `PROP2_Q5` 的 `smooth p95 / smooth RMS` 更低，说明自适应调度更像在降低持续风险暴露
- 当前每个条件只有 1 次运行，不能做统计检验

因此当前推荐论文口径是：

> Risk-adaptive scheduling redistributes control conservatism according to online risk and reduces sustained slosh-risk exposure, with moderate speed tradeoff.

不应写成：

> PROP consistently outperforms fixed-Q MPC in all liquid peak metrics.

### 9.2 贡献 2：IMU-Calibrated Excitation Estimation

这是当前证据最弱的贡献。

当前实物实验中，主要启用的是：

```bash
slosh_use_imu_yaw_rate:=true
slosh_use_imu_lateral_accel:=false
```

这说明当前实物 compare 已经使用 IMU yaw-rate，但还没有完成 IMU lateral acceleration 作为平面激励输入的完整验证。也就是说：

- 可以说框架支持 IMU-calibrated excitation estimation
- 可以说当前实现中已接入 IMU yaw-rate
- 但还不能说 IMU 校准激励带来了可量化改善

若要把它作为独立贡献，需要补充 A/B/C 对比：

- A：`odom + odom`
- B：`IMU yaw + odom ay`
- C：`IMU yaw + IMU ay`

并比较：

- 急转段激励估计偏差是否降低
- MPC 内部 slosh 状态与外部视觉液面测量的相关性是否提高

在这组实验完成前，IMU 贡献建议降级为“辅助模块 / 实现细节”，不要作为已经验证的强贡献。

### 9.3 贡献 3：Terminal Settling MPC Mode

SETTLING 代码逻辑已存在，但当前实物配置显式关闭：

```yaml
settling:
  enable: false
```

因此 0422 这 10 个实物包中没有观测到 `SETTLING` 是预期行为，不是 bug。

当前能说的是：

- SETTLING 是代码就绪、但实物验证未完成的功能
- 当前实物 compare 只验证 tracking / motion phase 的液面响应
- 当前数据不能证明终点 residual slosh settling 性能

如果论文要把 Terminal Settling 作为完整贡献，需要额外完成：

1. sudden-stop 实验辨识 `ω0 / ζ`
2. 基于 `ω0` 设定 `N_settle·dt ≥ 4π/ω0`
3. 开启 `settling_enable=true` 做 T2 实物验证
4. 比较有/无 SETTLING 的终点液面尾段和 settling time

在完成 T2 前，不建议把 C5 写成已经完整验证的方法。

### 9.4 这批数据对“液体抑制是否有效”的回答

当前答案是：**有初步效果，但不能夸大。**

从主 compare 的视觉量看：

| 条件 | smooth peak (mm) | 相对 NOM | smooth p95 (mm) | 相对 NOM |
|---|---:|---:|---:|---:|
| NOM | 5.123 | baseline | 2.764 | baseline |
| ISR | 4.884 | -4.7% | 2.934 | +6.1% |
| FAS_Q5 | 4.012 | -21.7% | 2.567 | -7.1% |
| PROP2_Q5 | 4.345 | -15.2% | 2.234 | -19.2% |

当前可以得出的阶段性结论：

- `NOM` 整体最差，说明无抑制基线确实有更高液面响应
- `ISR` 有轻微压峰作用，但对持续风险没有稳定优势
- `FAS_Q5` 对瞬时峰值抑制最明显
- `PROP2_Q5` 对持续风险指标（p95 / RMS）更有优势

因此，当前最稳妥的论文表述是：

> Compared with nominal tracking and classical input shaping, slosh-aware MPC reduces measured liquid-surface response on the real robot. Fixed-Q MPC is effective at suppressing peak excursions, while risk-adaptive scheduling shifts the behavior toward reduced sustained risk exposure.

中文表述：

> 相比无抑制和 ISR，加入液体晃动代价的 MPC 已经表现出真实抑晃效果。固定 Q 更擅长压瞬时峰值，自适应调度更擅长降低持续风险暴露。

当前不应表述为：

- `PROP` 已经全面优于 `FAS`
- `Q_slosh` 越大效果越好
- `/slosh/height` 的排序可以直接替代真实视觉液面排序

### 9.5 投稿前最短补实验路线

按当前阻塞程度，推荐优先级如下：

| 优先级 | 任务 | 解锁内容 |
|---|---|---|
| P0 | 固定路径重复实验：`NOM / ISR / FAS_Q5 / PROP2_Q5` 每组 ≥5 次 | 统计检验；证明 slosh-aware MPC 与 scheduler 的趋势是否稳定 |
| P0 | 红色液体三标尺视觉链 repeatability 验证 | 主视觉指标可信度 |
| P1 | `FAS_Q5 vs PROP2_Q5` 成对实验 | Risk-Adaptive Scheduling 的独立贡献 |
| P1 | sudden-stop 辨识 `ω0 / ζ` | slosh 模型参数与 SETTLING 设计依据 |
| P2 | `settling_enable=true` 的 T2 实物验证 | Terminal Settling MPC Mode |
| P2 | IMU A/B/C 对比实验 | IMU-Calibrated Excitation Estimation |

### 9.6 当前一句话判断

当前数据最强支持的是：

> slosh-aware MPC 相比 NOM / ISR 已经有真实抑晃趋势。

当前还不能强支持的是：

> 完整 PROP 已经全面优于固定 Q 的 FAS。

Risk-Adaptive Scheduling 是最有论文新意的结构贡献，但还需要重复实验和 `FAS vs PROP` 成对统计来坐实。IMU 和 SETTLING 目前属于实现就绪或部分接入状态，尚未达到独立强贡献的数据支撑强度。
