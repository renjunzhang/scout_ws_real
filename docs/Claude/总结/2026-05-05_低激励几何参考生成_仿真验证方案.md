# 2026-05-05 低激励几何参考生成仿真验证方案

## 1. 论文对比主线

当前最合理的论文主线不是：

```text
MPC 内部 slosh cost 成功主动抑制晃动
```

而是：

```text
低激励几何参考生成 + MPC 跟踪
```

核心观点：

```text
对于 /cmd_vel 接口的移动机器人液体搬运任务，
把防晃放进 MPC soft cost 或 cmd_vel 后处理都容易和 tracking 冲突；
更有效的做法是把防晃前移到 reference generation 层，
生成低 kappa / 低 dkappa / 低 ax-jerk 的几何参考，
然后让 MPC 只作为 constrained tracker 执行。
```

因此论文实验应重点比较：

```text
1. 防晃在 MPC 内部或 cmd_vel 后处理
2. 防晃在速度剖面层
3. 防晃前移到几何参考生成层
```

但最终 proposed 只写第 3 类。

## 2. 是否需要对比旧 MPC / cmd_vel 后处理

需要，但作为 baseline / ablation，不作为主方法。

建议保留以下旧路线对比：

```text
B2: MPC slosh-cost
  Q_slosh / Q_eta_dot / terminal slosh cost
  目的：证明把 slosh 放进 QP soft cost 不稳定或收益有限。

B3: cmd_vel post-processing
  OUTPUT_GUARD / PMG
  目的：证明输出层裁剪会带来相位错误、eta_dot 上升或路径泛化失败。

B4: speed-profile only
  PROFILE_ENERGY / PROFILE_REF_V2
  目的：证明只改 v(s) 能降低部分晃动，但会遇到 ay/tracking/time trade-off。
```

写法要谨慎：

```text
这些不是失败垃圾实验，而是支撑 reference-first 结论的消融证据。
```

## 3. 是否需要对比“有无几何参考生成”

必须对比。这是主实验。

主表应围绕同一个 MPC tracker，比较不同 reference：

```text
B0: Original / old geometry + MPC
B1: Radius-smoothed geometry + MPC
Ours: Low-excitation geometry geo56 + same MPC
```

这里的关键是：

```text
MPC 跟踪器相同；
改变的只有前端几何参考。
```

这能直接证明创新点来自 reference generation，而不是 MPC 参数调参。

## 4. 是否需要对比其他控制器算法和 MPC

不建议作为主实验。

原因：

```text
1. 当前代码和实验平台已经围绕 MPC tracker 构建；
2. 重新实现 HSMC、LQR、pure pursuit、PID 等控制器会引入大量新变量；
3. 论文主问题不是“哪个 tracker 最好”，而是“防晃应放在哪一层”；
4. 时间成本高，容易偏离当前已经拿到的 positive result。
```

可以在 related work 中讨论其他控制器，但仿真实验不必实现。

如果审稿风险需要补一个非 MPC 对照，最多使用已有系统中容易启用的：

```text
pure pursuit / 原始路径跟踪器
```

但这不是当前最快完成路线。

## 5. 要不要删除 MPC 跟踪器里的防晃

代码里不必删除，论文 proposed 中应关闭。

建议做法：

```text
保留 Q_slosh / risk_scheduler / PMG / PROFILE_REF_V2 入口作为消融；
proposed 配置中全部关闭；
论文明确写：MPC is used as a constrained tracking layer, not as the primary slosh suppressor.
```

创新点不会因为关闭 MPC 内部防晃而不够。

当前创新点应写成：

```text
1. 提出低激励几何参考生成层，用 kappa/dkappa/ax/jerk/slosh rollout 筛选候选路径。
2. 系统证明同一 MPC tracker 下，低激励几何参考能降低 model-estimated slosh height。
3. 通过失败消融说明 MPC soft cost、cmd_vel 后处理和 speed-only retiming 的边界。
```

这是更稳的创新定位。

## 6. Proposed 方法定义

Proposed：

```text
Low-excitation geometric reference generation + MPC tracking
```

实现结构：

```text
原始路径 / 任务目标
        ↓
离线几何候选生成
        ↓
kappa / dkappa / ax / jerk / slosh rollout 筛选
        ↓
低激励几何参考 PATH_FILE
        ↓
现有 MPC tracker
        ↓
cmd_vel
```

当前最佳 proposed 配置：

```text
PATH_ID=P3_geo56
CONDITION=CUSTOM
PATH_FILE=docs/Claude/分析数据/generated_paths/P3_mixed_geo_i56_g55_d18.json
MPC_CMD_VEL_LEAD_TIME=0.05
Q_slosh=0
Q_slosh_eta_dot=0
risk_scheduler=false
input_shaping=false
PROFILE_REF_V2=false
```

注意：

```text
CUSTOM 在这里不是“无方法”，而是“使用自定义低激励几何路径 + 普通 MPC tracking”。
论文里建议重命名为 Ours-Geo 或 GeoRef。
```

## 7. 仿真验证矩阵

### 主实验表

建议主表只放最清晰的 4 组：

| 组别 | 路径/方法 | MPC 配置 | 目的 |
|---|---|---|---|
| B0 | Original P3 / old P3 geometry | 普通 MPC | 原始任务基线 |
| B1 | P3_mixed_radius | 普通 MPC | 人工平滑/半径放大 baseline |
| B2 | P3_mixed_radius + PROFILE_REF_V2 | 普通 MPC + speed profile | speed-only / retiming baseline |
| Ours | P3_geo56 | 普通 MPC | 低激励几何参考 proposed |

最关键对比：

```text
B1 vs Ours:
  同样是普通 MPC tracker；
  差别是几何参考是否低激励。
```

### 失败路线消融表

单独放一张 failure/ablation 表：

| 组别 | 方法 | 结论 |
|---|---|---|
| MPC slosh cost | Q_slosh / Q_eta_dot / terminal | 不稳定，无法跨路径泛化 |
| OUTPUT_GUARD | cmd_vel 后处理 | P2 局部有效，P3 失败 |
| PMG | phase-aware cmd cap | 离线正信号，闭环 eta_dot 上升或不稳定 |
| PROFILE_ENERGY | speed-only rollout correction | 能降部分 slosh，但 time/ay/track trade-off |

这张表的作用：

```text
证明为什么本文最终采用 reference-generation-first。
```

## 8. 指标与验收标准

主指标：

```text
h_rms
h_p95
h_max
eta_dot_rms
modal_energy
```

必须报告的执行/车辆指标：

```text
tracking_time
track_p95
ay_p95
odom_ax_p95
odom_jerk_p95
solve_success_ratio
```

主张成功时至少满足：

```text
h_rms / h_p95 / h_max 下降
eta_dot / energy 下降
tracking_time 不显著增加，建议 <= +15%
solve_success_ratio = 1.0 或 >= 0.97
```

当前 geo56 的边界要诚实报告：

```text
ay_p95 和 track_p95 仍有 trade-off。
```

不要把它包装成全指标完美通过。

## 11. 推荐写法

论文方法标题：

```text
Low-Excitation Geometric Reference Generation for Slosh-Aware MPC Tracking
```

方法描述：

```text
We generate a low-excitation geometric reference before MPC tracking. The MPC is kept as a constrained tracking controller, while slosh suppression is achieved by reducing curvature, curvature variation, and acceleration/jerk-induced modal excitation at the reference-generation layer.
```

不要写：

```text
The MPC suppresses sloshing through slosh cost.
```

可以写：

```text
The same MPC tracker is used across baselines; the improvement comes from changing the reference geometry rather than tuning the MPC slosh cost.
```

## 12. 实物前的条件

仿真通过后再上实物。

实物前必须明确：

```text
1. /slosh/height 在仿真中是模型估计值；
2. 实物需要视觉液面或人工标注验证；
3. 实物先跑低风险速度，不直接复用仿真最高速度；
4. 实物主目标先验证趋势，不追求完全复现百分比。
```

实物最小集：

```text
old geometry baseline x2
geo56 proposed x2
```

实物指标：

```text
视觉液面高度
tracking_time
是否溢出/是否明显晃动
odom_ax / odom_ay
```
