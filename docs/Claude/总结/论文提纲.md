## 方法节提纲（目标：~2.5 页）

### II. Problem Formulation（~0.3 页）

**内容**：
- 机器人模型：差速轮，状态 `(x, y, θ, v, ω)`
- 液体晃动子模型：等效摆 ODE
  ```
  η_x'' + 2ζω₀η_x' + ω₀²η_x = -a_x/g
  η_y'' + 2ζω₀η_y' + ω₀²η_y = -a_y/g
  ```
  增广状态 `(η_x, η̇_x, η_y, η̇_y)` → 总状态 8 维
- 激励输入：`a_x = v·v'`，`a_y = v·ω`（差速轮特有的 bilinear 结构）
- 控制目标：在满足路径跟踪精度和任务时长约束的前提下，最小化液面峰值和残余晃动

**写作要点**：
- 明确说明 ω₀ 和 ζ 是通过实验辨识得到的（不是从理论计算）
- 说明为什么 `a_y = v·ω` 的 bilinear 结构使得简单加速度限制不是最优（引出风险自适应的必要性）

---

### III. Slosh-Augmented Tracking MPC（~0.5 页）

**内容**：
- PathHandler 生成局部参考点 `ref_points`（Frenet 坐标）
- QP 求解器：状态 8 维，控制 `(v, ω)`，时域 N 步
- 当前代价函数骨架：
  ```
  J = J_tracking + Q_η·(η_x² + η_y²) + J_input
  ```
- 约束：速度/加速度盒约束，modal proxy 约束 `|η| ≤ η̄`，speed governor

**写作要点**：
- 这一节建立 baseline 系统（固定 Q_η），后续节 IV 再引入自适应
- 明确说明这是 tracking MPC，不是 MPCC（路径进度不是优化变量）
- 说明 QP 在 40Hz 控制频率下的求解时间（可信度数据）

---

### IV. Risk-Adaptive Scheduling Layer（~0.8 页）

**内容（核心贡献 1）**：

#### IV-A. Two-Layer Architecture

给出 algorithm box，明确 outer/inner loop 分离和单步延迟：

```
Algorithm 1: Risk-Adaptive Scheduling

Outer loop (每控制周期开始前执行):
  Input: 上一周期冻结的 monitor rollout {ĥ^pred_max_{k-1}, E^slosh_{k-1}}, 
         当前 IMU 读数 a_{y,imu}, 当前运动学估计 v·ω, 
         目标距离 d_goal
  
  1. 计算 physical risk:
     r_k = w_h·clip(ĥ^pred_max_{k-1}/h_max) + w_e·clip(E^slosh_{k-1}/E_max) 
           + w_t·clip((d_goal_threshold - d_goal)/d_goal_threshold)
  
  2. 计算 excitation uncertainty:
     u_k = clip(|a_{y,imu} - v·ω| / a_uncert_max)
  
  3. 计算统一风险指标:
     ρ_k = w_r·r_k + w_u·u_k  ∈ [0,1]
  
  4. 调度三个 QP 参数 via s(ρ_k) = σ(γ·(ρ_k - ρ_0)):
     Q_{η,k}     = Q_η^min + (Q_η^max - Q_η^min)·s(ρ_k)
     η̄_k         = η̄^max - Δη̄·s(ρ_k)
     v_ref_eff_k = v_ref_k·(1 - β·s(ρ_k))

Inner loop (40Hz QP solver):
  Input: Q_{η,k}, η̄_k, v_ref_eff_k (from outer loop)
  Output: (v_cmd, ω_cmd), monitor rollout (供下周期 outer loop 使用)
```

#### IV-B. Properties of the Scheduling Function

说明 s(·) 的三个性质：
1. **单调性**：ρ_k 增大 → 更保守控制（安全属性）
2. **有界性**：s(ρ) ∈ [0,1] → QP 参数始终在物理有意义范围内
3. **不改变 QP 结构**：参数化调度而非在线优化，凸性保留

#### IV-C. Physical Interpretation

- r_k：液面风险本体（来自冻结 monitor，不依赖当前 QP 输出）
- u_k：激励输入不确定性（来自独立 IMU 观测）
- 两者分离消除"优化器自己给自己打分"的循环

### V. IMU-Calibrated Excitation Estimation（~0.4 页）

**内容（核心贡献 2）**：

- slosh 子模型的平面激励输入 `(a_x, a_y)` 当前由 odom 差分估计
- `a_y = v·ω` 在急转弯瞬间有相位滞后；odom 轮速滑移会引入系统误差
- 提出 bias-compensated IMU 替代方案：
  ```
  a_y_est = a_{y,imu} - bias_ay   (静止标定 bias)
  ω_est   = ω_{imu}               (IMU yaw rate，已接入)
  ```
- consistency gate：`|a_{y,imu} - v·ω|` 过大时（即 u_k 大），提高 ρ_k，保守控制，不盲信某一路
- 三配置对比：A（odom+odom）/ B（IMU+odom）/ C（IMU+IMU）

**写作要点**：
- 这里的贡献是"校准激励输入"，不是"估计液面状态"——不需要做液面观测器闭环
- consistency gate 的作用：把 IMU 可信度量化为 ρ_k 的一项，不是单独的逻辑判断

---

### VI. Terminal Settling MPC Mode（~0.5 页）

**内容（核心贡献 3）**：

- 状态机扩展：`TRACKING → SETTLING → REACHED`
- SETTLING 模式设计依据：
  - 时域 `N_settle·dt ≥ 4π/ω₀`（覆盖 ≥2 个振荡周期）
  - 代价切换：`Q_tracking = 0`，`Q_η = Q_η^max`，`Q_v` 大
  - 终止条件：`|η| < ε_η AND |v| < ε_v`
- 关键指标：`settling_time`（进入 SETTLING 到满足终止条件的时长）
- 说明为什么当前硬停会激发自由振荡（从 ODE 初始条件分析）

**写作要点**：
- 这一节的物理依据是：`N_settle·dt ≥ 4π/ω₀`，所以 ω₀/ζ 辨识结果必须在这里引用
- 对比数据：有/无 SETTLING 模式的 settling_time

### VIII. Ablation Study（~1 页）

**对比层级说明**：

- 当前论文主对比聚焦 **anti-slosh strategy**，而不是扩展为不同 tracking controller 架构的大规模比较。
- 为控制变量并保证公平性，固定同一条路径跟踪底座，仅比较：
  - 无抑制；
  - 经典 input shaping；
  - 固定 slosh-MPC；
  - 自适应完整方法。
- 当前阶段**不引入**：
  - `LQR tracking`
  - `TEB / pure pursuit`
  - 其他外部 tracking controller family
- 原因：
  1. 论文当前主张是 anti-slosh 策略，而不是新 tracking controller 架构；
  2. ISR 已能补足“外部经典 baseline”缺口；
  3. 引入 LQR / TEB / pure pursuit 会显著扩大实现与公平性论证范围。

**六个消融条件**：

| 条件 | Q_η | 调度 | IMU 校准 | Settling |
|---|---|---|---|---|
| C0：Nominal tracking | 0 | — | — | — |
| C_ISR：Input shaping baseline | 0 | — | — | — |
| C1：Fixed Q_η | Q_fix | — | odom | 硬停 |
| C2：Fixed Q_η + constraint | Q_fix | — | odom | 硬停 |
| C3：ρ_k adaptive | 自适应 | ✓ | odom | 硬停 |
| C4：ρ_k + IMU calibration | 自适应 | ✓ | IMU | 硬停 |
| **C5：Ours（完整方法）** | **自适应** | **✓** | **IMU** | **T2** |

每个条件运行 ≥5 次（固定路径，固定液量）。

**主指标（liquid response）**：
- 侧视液面峰值：`peak_mm` 均值 ± 标准差
- 残余晃动 `settling_time`（仅 C5 vs 硬停对比）
- 超阈值时间比例（0.5mm / 1.0mm 阈值）

**辅指标（因果链 / 工程代价）**：
- IMU `a_y` RMS（说明底盘激励确实更温和）
- 任务完成时间（证明速度没有大幅牺牲）
- 路径跟踪误差 RMSE
- QP 求解时间均值（实时性证明）

**统计检验**：
- 主指标在 C0 vs C5 之间做 Wilcoxon 秩和检验（非正态分布）
- 报告 effect size（Cohen's d 或 rank-biserial correlation）
