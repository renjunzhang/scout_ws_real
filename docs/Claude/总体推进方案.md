## Day 2（周二）：ρ_k 调度器实现

**目标**：把三块松散启发式（Q_η, η̄, v_ref）绑定到统一的 ρ_k 调度层

### 实现规格

**新增 ROS 节点**（或在 `LocalPlannerROS` 内新增调度类）：

```cpp
// RiskScheduler 类，在每个控制周期 outer loop 执行

struct RiskState {
    double r_k;          // physical risk [0,1]
    double u_k;          // excitation uncertainty [0,1]
    double rho_k;        // unified risk [0,1]
    double s_rho;        // s(rho_k) after sigmoid
    bool fallback_active; // IMU 异常回退标志
};

// 输入（来自上一周期冻结的 monitor rollout）：
//   h_pred_max_prev, E_slosh_prev, d_goal
// 输入（来自当前 IMU 观测）：
//   a_y_imu（已扣零偏），v*omega（运动学）
// 输出：
//   Q_eta_k, eta_bar_k, v_ref_eff_k
```

**r_k 计算**：
```cpp
double h_risk = clip(h_pred_max_prev / h_max, 0.0, 1.0);
double e_risk = clip(E_slosh_prev / E_max, 0.0, 1.0);
double goal_risk = clip((d_goal_thresh - d_goal) / d_goal_thresh, 0.0, 1.0);
double r_k = w_h * h_risk + w_e * e_risk + w_t * goal_risk;
```

**u_k 计算**（需要 lateral_accel 预处理链路在线）：
```cpp
double ay_imu = slosh_imu_ay_filtered_;   // 已有话题
double ay_kin = current_v * current_omega; // 运动学估计
double u_k = clip(fabs(ay_imu - ay_kin) / a_uncert_max, 0.0, 1.0);
```

**调度函数（带变化率限制）**：
```cpp
double rho_k = w_r * r_k + w_u * u_k;
double s_rho = sigmoid(gamma * (rho_k - rho_0));

// 期望值
double Q_eta_desired = Q_eta_min + (Q_eta_max - Q_eta_min) * s_rho;
double eta_bar_desired = eta_bar_max - delta_eta_bar * s_rho;
double v_ref_eff_desired = v_ref * (1.0 - beta * s_rho);

// 变化率限制（防 chattering）
Q_eta_k = clip(Q_eta_desired, Q_eta_prev ± dQ_eta_max_per_step);
eta_bar_k = clip(eta_bar_desired, eta_bar_prev ± d_eta_bar_max_per_step);
v_ref_eff_k = clip(v_ref_eff_desired, v_ref_eff_prev ± dv_ref_max_per_step);
```

**Fallback 逻辑**：
```cpp
bool imu_timeout = (ros::Time::now() - last_imu_stamp_).toSec() > 0.1;
bool bias_not_ready = !imu_ay_bias_ready_;
bool u_k_high = (u_k > u_threshold_high) && (++u_high_count_ >= 10);

if (imu_timeout || bias_not_ready || u_k_high) {
    fallback_active_ = true;
    Q_eta_k = Q_eta_fix;  // 回退到固定参数
    eta_bar_k = eta_bar_fix;
    v_ref_eff_k = v_ref;
} else {
    fallback_active_ = false;
    u_high_count_ = 0;
}
// 发布 /risk_scheduler/fallback_active
```

**新增发布话题**：
```
/risk_scheduler/rho_k           (std_msgs/Float32)
/risk_scheduler/r_k             (std_msgs/Float32)
/risk_scheduler/u_k             (std_msgs/Float32)
/risk_scheduler/s_rho           (std_msgs/Float32)
/risk_scheduler/Q_eta_k         (std_msgs/Float32)
/risk_scheduler/fallback_active (std_msgs/Bool)
```

**Day 2 完成标准**：
- 编译通过，跑 bag 回放，`/risk_scheduler/rho_k` 随运动状态有合理变化
- `fallback_active` 在 IMU 话题断开时正确触发
- Q_η 和 η̄ 在高曲率段自动升高（用之前的 bag 验证）
- rate limit 有效：相邻周期 Q_η 变化 ≤ `dQ_eta_max_per_step`

### 下午：T2 settling MPC 模式

**状态机修改**（在 `LocalPlannerROS` 的状态机里加 SETTLING 状态）：

```cpp
// 在当前状态机的 GOAL_STOP_PENDING 之前插入 SETTLING

enum class MpcState {
    IDLE, TRACKING, SETTLING,  // ← 新增
    GOAL_STOP_PENDING, REACHED, ERROR
};

// 进入 SETTLING 的条件：
//   当前在 TRACKING，且 d_goal < d_settle_enter_threshold
//   且 |eta_x| + |eta_y| > eta_settle_trigger（液面还在晃）

// SETTLING 模式 MPC 参数：
//   N_settle = ceil(4 * pi / (omega0 * dt))  // 覆盖 2 个振荡周期

// 终止条件：
//   (|eta_x| < eps_eta AND |eta_y| < eps_eta AND |v| < eps_v)
//   OR timeout > T_settle_max

// 输出：/slosh/settling_time（Float32，进入 SETTLING 到终止的时长）
```

## Day 5（周五）：主实验

**目标**：跑完主表四个条件，每个 ≥5 次，全程侧视相机同步录制

**四个实验条件**：

| 条件 | 缩写 | 配置 |
|---|---|---|
| Nominal tracking | NOM | Q_η=0，无任何 slosh 处理 |
| Input-shaped reference | ISR | ZV shaper 作用于 v_ref（ω₀ 已知），Q_η=0 |
| Fixed anti-slosh MPC | FAS | Q_η=Q_fix（固定，当前已有），无自适应 |
| **Proposed full method** | PROP | ρ_k 自适应 + IMU ay 校准 + T2 settling |

**ISR 实现**（需要 Day 2 或 3 额外加入）：
```python
# ZV shaper，一次性实现：
# t1 = pi / omega_d（有阻尼半周期）
# A1 = 1/(1+K), A2 = K/(1+K), K = exp(-zeta*pi/sqrt(1-zeta^2))
# 对 v_ref(t) 做：v_shaped(t) = A1*v_ref(t) + A2*v_ref(t-t1)
# 在 PathHandler 的 v_ref 生成后应用
```

**实验规范**：
```
- 固定全局路径（同一条含直道+S弯的路径）
- 固定液量（Day 1 确定的液位）
  注：试管尺寸和液位后续可能调整，但本轮实验全程使用同一组配置
  每次更换试管/液位后，需重新跑 sudden-stop 辨识新的 ω₀/ζ（约 0.5 天）
- 每条件 ≥5 次，同一天连续跑
- 每次实验同步录：/cmd_vel, /odom, /slosh/*, /risk_scheduler/*, /imu/data, 侧视相机
- 每次开始前确认 IMU 零偏已锁定（/slosh/imu_ay_bias_ready = true）
- 实验间隔 ≥30 秒（液面完全静止）
```

**Day 5 完成标准**：
- NOM/ISR/FAS/PROP 各 ≥5 次 bag 录好
- 每条 bag 都有侧视相机时间戳对齐的视频
- 简单检查：PROP 的 peak_mm 视觉上明显低于 NOM
