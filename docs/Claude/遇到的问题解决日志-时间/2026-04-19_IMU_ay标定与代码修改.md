## 本轮修改目标

为 IMU ay 增加离线标定比例系数（scale factor）支持，解决杠杆臂和重力分量导致 `imu_ay_filtered` 幅值与 `v·ω` 不匹配的问题，提高 risk_scheduler 中 u_k 的估计精度。

---

## 已完成修改

### 1. local_planner_ros.h

**文件**：`src/scout_apps/control/scout_local_planner/include/scout_local_planner/local_planner_ros.h`

新增字段：

```cpp
double imu_ay_scale_ = 1.0;   // 离线标定比例系数：calibrated = (raw - bias) * scale
```

位置：L237，紧接在 `imu_ay_bias_trim_ratio_` 之后。

### 2. local_planner_ros.cpp

**文件**：`src/scout_apps/control/scout_local_planner/src/local_planner_ros.cpp`

**修改 1**：参数读取（L281 附近）

```cpp
pnh.param("slosh_estimator/imu_ay_scale", imu_ay_scale_, 1.0);
```

**修改 2**：应用 scale（L569）

```cpp
// 原来
imu_ay_unbiased_ = ay_raw - ay_bias;

// 修改后
imu_ay_unbiased_ = (ay_raw - ay_bias) * imu_ay_scale_;
```

默认 `imu_ay_scale_=1.0`，不改变现有行为，向后兼容。

### 3. 新增标定脚本

**文件**：`src/scout_apps/control/scout_local_planner/scripts/calibrate_imu_ay.py`

功能：
- 输入：rosbag（标准动作序列：静止 5s → 左弧线 5s → 右弧线 5s）
- 自动检测静止段（估 bias）和运动段（线性拟合 scale）
- 拟合方法：过原点线性回归 `ay_unbiased = scale * v·ω`
- 输出：`imu_ay_calibration.yaml`（含 scale 值）+ 可选验证图

用法：

```bash
python3 scripts/calibrate_imu_ay.py <bag_file> --output imu_ay_calibration.yaml --plot
```
