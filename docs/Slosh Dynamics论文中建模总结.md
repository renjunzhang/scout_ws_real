# `Sloshing Dynamics Estimation for Liquid-filled Containers under 2-Dimensional Excitation` 建模总结

## 1. 论文到底在做什么

这篇论文的目标不是做 CFD，也不是做基于图像的状态观测器，而是：

- 对**圆柱容器在二维平面运动下**的液体晃动建立一个**离散等效力学模型**
- 用这个模型的广义坐标，去**估计液面晃动高度**
- 再和实验视频提取到的液面峰值做对比验证

这里的 `estimation` 更准确地说是：

- 已知容器激励 `S̈0 = [ẍ0, ÿ0]^T`
- 先求等效模型的广义坐标 `(x_n, y_n)`
- 再由 `(x_n, y_n)` 映射出液面高度

它**不是**卡尔曼滤波器意义上的状态估计器，也**不是**视觉-IMU 融合 observer。

---

## 2. 建模对象与适用范围

论文假设：

- 容器是**圆柱形**
- 运动是**二维平面运动**
- 主要关心液面峰值高度，而不是完整流体场
- 采用**模态等效**思路，把流体近似成若干个等效模态质量

论文把液体运动分成 3 种 regime：

1. 小幅振荡，液面可近似为平面
2. 中等幅值振荡，液面不再是平面
3. 强非线性运动，液面会出现瞬时尖峰和 swirling

其中这篇论文主要处理前两类；第三类只在实验讨论里作为误差来源提到，不纳入主模型。

---

## 3. 等效力学模型

论文采用的是**2-DOF 质量-弹簧-阻尼器**的等效模型，而不是摆模型。

对一个半径为 `R`、液高为 `h`、总液体质量为 `m_F` 的圆柱容器，模型包含：

- 一个随容器刚体运动的刚性质量 `m_0`
- 若干个表示各阶液体晃动模态的模态质量 `m_n`
- 每个 `m_n` 配一个弹簧 `k_n` 和阻尼 `c_n`

第 `n` 个模态的广义坐标是：

- `x_n`
- `y_n`

也就是该模态质量相对参考位置在平面内的位移。

模型参数通过以下等效条件确定：

1. 总质量守恒
2. 小振荡下质心高度不变
3. 第 `n` 模态固有频率与连续体模型一致
4. 作用在容器壁上的晃动力与连续体模型一致

论文给出的关键结果是：

- 模态固有频率 `ω_n`
- 模态质量 `m_n`
- 阻尼比 `ζ_n`

其中 `ξ_1n` 是 Bessel 函数导数零点，对应“第一周向模态、第 n 个径向模态”。

---

## 4. 两种动力学模型：L 与 NL

### 4.1 L 模型

L 模型对应“小振荡、液面近似平面”的情况。

对第 `n` 个模态，线性化后得到两条**解耦**的二阶方程：

\[
\ddot{x}_n + 2 \zeta_n \omega_n \dot{x}_n + \omega_n^2 x_n = -\ddot{x}_0
\]
\[
\ddot{y}_n + 2 \zeta_n \omega_n \dot{y}_n + \omega_n^2 y_n = -\ddot{y}_0
\]

所以它本质上就是：

- 线性
- 二阶
- 沿 `x/y` 两个方向对称
- 输入是容器平动加速度 `ẍ0, ÿ0`

### 4.2 NL 模型

NL 模型对应“液面不再保持平面”的中等幅值运动。

它的关键做法是：

- 让模态质量 `m_n` 在一个**抛物面**上滑动
- 再配一个**非线性弹簧**

论文给出的抛物面约束是：

\[
z_n = \frac{C_n}{2R}(x_n^2 + y_n^2)
\]

其中 `C_n = R ω_n^2 / g`。

再用 Lagrange 方程推导出 `(x_n, y_n)` 的**耦合非线性 EOM**。  
这套 EOM 比 L 模型复杂得多，里面包含：

- 二次/高次项
- `x_n` 与 `y_n` 的耦合
- 与速度相关的非线性项

论文里取：

- `w = 2`
- `α_n = 0.58`

也就是用四次型非线性弹簧。

---

## 5. 液面高度是怎么从状态算出来的

这是这篇论文最关键的部分。

论文不是直接把 `(x_n, y_n)` 当成液面高度，而是：

1. 先用广义坐标描述模态质量位置
2. 再通过液体质心守恒和自由液面形状假设
3. 推导出液面高度 `η_n`

### 5.1 一维运动时的高度

若只考虑 `y` 方向激励，且忽略旋转晃动，则只有 `y_n` 非零。

此时：

- L 模型假设液面是平面
- NL 模型假设液面是非平面，形状由 Bessel 函数描述

最终得到：

L 模型：

\[
\eta_n = \frac{4 h m_n}{m_F R} y_n
\]

NL 模型：

\[
\eta_n = \frac{\xi_{1n}^2 h m_n}{m_F R} y_n
\]

这里的 `η_n` 是**有符号**的单侧液面高度。

### 5.2 二维运动时的最大液面高度

二维情况下，最大液面高度不一定总发生在固定的 `x` 或 `y` 方向，而是发生在一个瞬时旋转平面 `Π` 上。

这个平面的方向角为：

\[
\phi_n = \arctan \left(\frac{y_n}{x_n}\right)
\]

定义径向模态坐标：

\[
r_n = \sqrt{x_n^2 + y_n^2}
\]

于是二维情况下的**最大液面高度** `MSH` 变成：

L 模型：

\[
\eta_n = \frac{4 h m_n}{m_F R} \sqrt{x_n^2 + y_n^2}
\]

NL 模型：

\[
\eta_n = \frac{\xi_{1n}^2 h m_n}{m_F R} \sqrt{x_n^2 + y_n^2}
\]

这时 `η_n` 是**正值峰值**，表示该瞬时方向上的最大液面抬升。

---

## 6. L 与 NL 的关系

论文给出一个很重要的结论：

\[
\frac{\eta_n^{L}}{\eta_n^{NL}} = \frac{4}{\xi_{1n}^2}
\]

若只取第一模态，则：

\[
\frac{4}{\xi_{11}^2} \approx 1.18
\]

这说明：

- 对相同的 `(x_n, y_n)`，L 模型算出的液面高度总是比 NL 更大
- 也就是 **L 模型更保守**

论文实验也验证了这一点：

- `L` 模型通常高估峰值
- `NL` 模型整体跟踪更准
- 但两者在二维高加速度下都会在尖峰附近掉精度

---

## 7. 论文实验验证结论

实验条件：

- 圆柱容器，`R = 50 mm`
- 静止液高，`h = 70 mm`
- 液体为水
- 工业机器人执行三类路径
- 最大加速度可到 `9.5 m/s^2`

实验结果表明：

- 对一维和二维运动，L/NL 两种模型都能较好跟踪液面峰值趋势
- 加速度较小时，模型和实验吻合较好
- 加速度变大后，模型仍能抓住趋势，但峰值精度下降

论文给出的误差指标中：

- `|ε_L|` 基本不超过 `18%`
- `|ε_NL|` 基本不超过 `19%`
- 但 `NL` 的全过程跟踪通常更好
- `L` 因为总是偏大，所以更适合作为**保守风险估计**

论文认为误差主要来自：

1. 高动态下进入更强非线性甚至 swirling regime
2. 视频测量本身存在视野饱和和遮挡误差

## 8. 对当前工程最有用的几点

### 8.1 论文的核心状态不是液面高度，而是广义坐标

论文真正积分/传播的是：

- `x_n`
- `y_n`
- 及其导数

液面高度 `η_n` 是从这些广义坐标再映射出来的。  
这和你当前 `ETA_X / ETA_Y` 的理解是一致的：它们更接近**主模态广义坐标**，不是液面高度本身。

### 8.2 论文里的 `L/NL` 首先是在说“高度映射”和“动力学复杂度”

在论文原意里：

- `L`：线性 EOM + 平面液面高度映射
- `NL`：非线性 EOM + 非平面液面高度映射

但你当前代码里 `use_linear_model` 的实际效果并没有完全复现这层含义。  
你现在更像是：

- 状态传播仍是线性 MSD
- `height_coeff` 在 L/NL 两个公式之间切换

所以你当前代码里的 `use_linear_model`，更准确地说是在切：

- **高度映射系数**

而不是完整切换到论文中的 **非线性动力学模型**。

### 8.3 论文里的二维激励输入是平动加速度，不是 IMU yaw/alpha 直接入模

论文的主输入是：

\[
S̈_0 = [ẍ_0, ÿ_0]^T
\]

也就是说它关心的是**容器平动激励**。  
它没有把 `omega_z`、`alpha_z` 作为主模型输入单独展开成你当前代码这种 IMU 接口形式。

这对你当前工程的启示是：

- `a_y` 这类平动/横向激励，和论文主建模思路更一致
- `yaw_rate`、`alpha_z` 更像是你为了移动机器人平台和风险监测做的工程扩展

### 8.4 论文里的“抛物面”与当前代码的 `parabola term` 不是一回事

这一点很容易混淆。

论文中的“NL 模型是抛物面”指的是：

- 模态质量在一个抛物约束面上运动
- 这是**动力学建模的一部分**

而你当前代码里的：

\[
\eta_{parabola} = \frac{R^2 \omega^2}{4g}
\]

是一个基于角速度的**额外高度监测项**，用于补充当前高度风险估计。  
它不是这篇论文 NL 动力学的直接原式。

所以不能简单说：

- “我开了 parabola term，所以就等于用了论文 NL 模型”

这个说法是不成立的。

---

## 9. 一句话总结

这篇论文的建模主线可以概括为：

**用圆柱容器的等效模态质量-弹簧-阻尼模型，先求二维激励下的主模态广义坐标，再通过质心守恒和液面形状假设，把广义坐标映射成液面高度；L 模型更保守，NL 模型更准确，但在强非线性尖峰下两者都会失真。**
