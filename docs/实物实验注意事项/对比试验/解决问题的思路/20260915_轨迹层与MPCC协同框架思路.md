# 轨迹层与 MPCC 协同：框架修改思路

方案日期：2026-09-15；实现状态更新：2026-09-16。分支：`feat/spmpc-liquid-control`。**区域内自主几何、完整轨迹规划、进度参考、任务期限和离线后缀诊断已实现为软件候选；尚未完成 ROS1 整节点编译、实时性验收或新实物验证。** 当前实现、参数、复现命令及正负结果见[实现与软件验证记录](20260916_两层协同实现与软件验证记录.md)。论文机制和后续研究边界继续按本文保留。

## 1. 要解决什么问题

**用户明确的目标：MPCC 在允许区域内自主选择曲率更小的路径；参考路径提供路线引导，较小的跟踪误差不作为主要成绩。** 在完成运输、满足区域/运动边界和共同耗时要求的前提下，联合考虑缓弯、液体晃动和停车残余。

轨迹层安排全程几何、速度与停车，MPCC 根据实际状态继续选择局部几何和运动时序。优先验证下层确实具有自主选路能力，再接入全程计划。固定几何的速度优化保留为隔离速度作用的对照，不作为方法主线的能力边界。

当前 MPCC 已能调整加减速、转向和进度，但贴线、速度跟踪、低速惩罚与进度奖励可能限制调整空间。旧版远期晃动预测偏小也可能影响动作选择；“跟踪太紧”还不是已确认根因。不能把地图上的轨迹重合解释成控制动作完全相同，也不能预设偏离越大越防晃。

`diag/lt-dwa-collision-tracking` 是用户此前一直使用的实物实验分支。9 月 14 日已记录的 diag 实验尚无重复的全程内部降晃收益；其随后四子步积分修正也不能由旧包直接验收。当前 feat 已有统一液体模型、四子步 RK4、代价缩放修正及可选完整停车；这些是软件基础，尚无对应新版本的实车降晃结论。

这是当前软件候选的架构；ROS 整链与实物部分仍待验收。剩余段检查首阶段只分析，不筛选发布命令；进入在线目标或约束需另行实现和验证。独立液面测量用于评价，当前不把它作为已经具备的实时控制反馈。

| 层次   | 决定什么                                               | 给下一层什么                                             |
| ------ | ------------------------------------------------------ | -------------------------------------------------------- |
| 轨迹层 | 区域内怎样安排全程几何、连续转弯、速度和最终停车       | 名义运动、命令及预测响应、路线进度关联与剩余任务要求     |
| MPCC   | 根据实际状态在区域内选择局部轨迹、转弯半径、速度和进度 | 本周期控制动作及后续预测，继续由现有唯一出口发布速度命令 |
| 底盘   | 按自身延迟和动态响应执行命令                           | 实际运动反馈；它可能偏离名义计划                         |

### 2.1 上层先求一个完整问题

主线在同一路线及允许区域、相同起终条件、运动限制和共同到达期限下，优化全程几何与速度，并比较普通缓弯安排与加入液体目标的防晃安排。已知量包括导航引导曲线、完整初态、待执行命令、模型参数、区域和停车要求；决策是能通过现有发布接口执行的全程运动。液体与实际运动由当前共源动力学传播。名义位置可在区域内变化，不对引导曲线施加逐点贴合等式。

建议先给定名义运输时长，在共同期限内研究曲率、全程液体响应、运动代价和停车残余的折中；需要比较不同名义时长时单独列出。**完整任务液体优化借鉴 R32，区域内几何决策借鉴 D19/D20 的局部规划机制**；联合问题属于本项目适配。参数化必须同时能改变几何与时序，可研究完整命令序列，或可执行的几何节点加时间律。仅有固定路径上的速度节点不足以表达主线目标；进度 jerk 与实际命令 jerk 也不能混用。

计划必须能到达真实目标位姿并完成制动、命令/FIFO 释放及液体尾段传播。只到达路径进度终点、只让瞬时液体位移过零，都不足以代表完成。固定几何对照仍沿用这些条件，用于量化只有改速时能获得多少收益。

## 3. 路径和速度怎样放宽

1. **路径提供方向，区域给出选路空间。** 首版明确静态可行区域及通行顺序，边界考虑车体尺寸与余量；规划器可以切角、扩大转弯半径和改变转向时机，具体取决于区域与任务。现有 `corridor_width` 主要参与误差归一化，不能直接当作已经实现的安全走廊。
2. **contour 作弱正则，lag 保持路线进度关联。** 不以更小的横向偏差评优，也不设置到中间参考点必须回线的终端要求。lag 维持虚拟进度与实际位置的对应，不能同时盲目清零；检查投影跳变、自交和近邻路径。原导航引导曲线与上层名义轨迹的身份分开，更新名义轨迹不自动收紧贴线要求。
3. **允许暂时减速，保留共同耗时要求。** 实际速度参考、虚拟速度参考、anti-creep 应使用同一有效计划语义，检查 progress 是否抵消提前减速。到达期限与剩余任务检查单独定义；增加进度奖励不等于按时完成。R15 提供速度与控制余量的权衡思路，不直接给出本任务的权重。
4. **把缓弯偏好明确放入优化。** 在正常移动段研究实际路径曲率幅值与变化的代价，液体位移/速度目标继续评价防晃；两者分别统计。仅增加 slosh 项或按参考曲率限速，不能保证选出小曲率路径。
5. **先验证自主几何，再分离速度作用。** 在相同初态和可行区域下，检查弱化贴线、加入曲率偏好各自是否改变真实预测路径；固定几何的速度优化作对照。Full/Smooth 共享区域、曲率偏好及其他非液体目标，不能把共同几何改进归因于液体项。

目标、运动/区域边界、液体性能目标与已知物理上限分别记录。液体恢复预算沿用当前策略的显式语义，不能用有限代价惩罚代替物理限制；未知杯沿余量仍记为未知。模型节点满足约束与实物全过程不溢出分开评价。

曲率在近似无侧滑的正常移动段满足 `kappa = omega_actual / v_actual`，不是 `omega_cmd / v_s`。建议以实际行驶弧长统计曲率幅值及变化，避免仅因减速而把同一几何报告成更缓；低速、停等和原地转向单列，不能直接除以接近零的速度或把这些段记作零曲率。其优化中的可微表达、适用域和低速角运动处理需在 P1 明确。较小曲率与较低晃动分别验收；共同期限、区域和运动消耗要求限制无意义绕行。

首版在无障碍、明确静态区域的转弯场景开展，先证明现有 MPCC 经目标/约束修改能主动选择更缓路线，再接入上层全程几何与速度安排。跨通道全局选路、动态避障和受扰恢复能力优化后续研究。

## 4. 两层必须接得上

- **共用物理定义。** 复用当前 feat 的实际运动、旋转液体模型与积分规则；名义实际速度和发布命令分开保存，待执行命令历史纳入预测。
- **传递整个预测窗口的参考与区域。** 当前单个 `v_ref_current` 不足以表达前方安排，需要逐阶段参考、区域约束和剩余任务信息。上层名义几何可供热启动或弱偏好，区域内选路权限由任务给定，不随新参考而收紧。
- **在线只有一套进度决策。** 用导航引导曲线的弧长定义路线进度，并保存名义轨迹到它的关联。实际行驶弧长、名义时钟分别记录，不新增独立控制进度；实际曲率也不能用路线进度速度替代实际车速计算。
- **调整后重新预测液体。** 在线改变速度或轨迹后，从当前估计状态重新传播；上层液体序列不能按索引伸缩后冒充实际状态。
- **全程安排包含停车。** 复用当前 `TaskStopManager` 的真实任务终点处理，普通 2 秒预测窗口末端不强制停车。剩余时间不足或计划失效要明确报告。

### 4.1 在线调整后，怎样处理剩余计划

例如名义计划安排在弯前减速，而实际底盘因执行延迟晚到了一段时间：下层按当前完整状态和真实命令历史重新预测，在线进度可以调整；名义液体状态不被直接赋给实际估计状态。上层计划身份保持可追溯，在线参考重新装配不自动意味着上层又完成了一次全程优化。

受 R13/R19 启发，先实现以下**离线检查候选**：

1. 取 MPCC 返回的预测末端完整状态及其预计有效时刻，保留液体相位、command/actual、FIFO、jerk 记忆和进度。
2. 按明确的进度/阶段匹配规则取候选名义后缀，从这个末端状态继续传播。出现位姿、速度或命令衔接偏差时真实保留；不能投影成名义状态或清空队列。必要的接续控制也必须显式生成并核验。
3. 传播到实际任务终点及固定停车窗口，检查运动/区域/液面边界、到达期限、车体停稳和残余晃动，保留候选身份和失败原因。
4. 分别记录“候选通过”“候选未通过”“未完成检查”。没有找到合格候选不证明所有后续运动都不可行；检查通过也仅支持该模型、初态和候选下的名义结果。

当离线检查能区分有后果差异的动作后，再研究怎样把剩余代价或可接续条件纳入在线优化，并测量开销。只做解后统计不能声称已经影响决策。使用历史状态凸包、严格 terminal set、funnel 或受扰恢复能力优化留作后续；本轮没有继承 R19 的递归可行性或 R16 的鲁棒保证。

### 4.2 信息条件与停车时间

当前可用的是车体反馈、最终命令历史及 IMU 驱动的液体模型估计。C06 的 LESO 创新项需要液体位移输出，其测量与平坦性条件不能直接移植。C11 也使用实际加速度传播液体状态，说明此类信息能支持模型驱动的在线调整；在本项目当前单向模型下，未知初始液体状态或独立液体扰动不会仅凭车体运动自动被校正。

弧长用于关联移动段参考，停等和停车尾段仍在时间域演化；同一个进度可能对应多个停等时刻，不能只凭 `s` 选取液体相位。任务起点、到达期限和停车窗口采用一致的事件定义，各组分别记录几何到达、车体停稳和液体稳定时间。窗口不能随某组晃动较慢而延长。

## 5. 先证明什么

### 5.1 主对比：原始路径＋普通 MPCC vs 完整协同方法

用户明确的主基线是：**初始导航路径不经过本方法的几何/防晃轨迹层处理，直接提供给无液体优化的普通 MPCC。** 完整方法从同一初始导航路径和任务条件出发，通过轨迹层及在线 MPCC 自主安排实际路线与运动。主比较评价整套方法的改善。

| 项目         | 主基线：原始路径＋普通 MPCC                         | 完整协同方法                                                                   |
| ------------ | --------------------------------------------------- | ------------------------------------------------------------------------------ |
| 上层处理     | 无新增几何优化、防晃规划或全程重定时                | 区域内联合规划几何、速度、液体响应与停车                                       |
| 下层决策     | 保留普通 MPCC 的正常运动/进度决策与合理的非液体设置 | 区域内自主几何、曲率偏好、液体目标与进度决策                                   |
| 在线液体机制 | 液体代价、液面约束、液体恢复及液体后缀指导均关闭    | 采用冻结 profile 明确列出的液体代价及可选边界/恢复；剩余段指导需实现后单独标识 |
| 输入与评价   | 同一原始路线、起终条件、区域、物理限制和耗时要求    | 同左，比较实际路径曲率、晃动、任务完成及时间/长度取舍                          |

“初始路径不处理”允许两组共同的必要数值插值、坐标转换与进度投影，记录其规则及几何误差；它不包含新增的缓弯优化或防晃时序安排。“无液体优化”指液体不参与动作选择；仅关闭液面硬约束仍可能保留液体代价，不能据此标为普通 MPCC。液体监视器可以继续用于评价，不能通过恢复、命令筛选或停车判定影响基线动作。

原始参考路径保持相同，并不要求普通 MPCC 每拍严格贴线；它仍保留正常优化能力和同一可行区域。主对比允许完整方法采用新增曲率偏好、参考正则及上层机制，这属于整套方法差异；若多项同时改变，收益不能全部归因于 slosh。两组使用同版本车体/执行器模型、求解配置、基本运动限制及共同制动设置，评价窗口一致。diag 旧包保留历史身份，不能直接替代这个新版本基线。

### 5.2 用匹配设置分辨贡献

开发先用明确区域的单弯及连续弯小问题验证 MPCC 的自主选路：同初态、同任务，分别检查跟踪正则和曲率偏好的影响；输出实际路径、曲率、速度、转向时机和晃动。随后在匹配的下层几何/曲率设置中开展以下四组，解释上层与在线液体机制的增量；这些是消融组，A 组已有普通缓弯上层，不充当第 5.1 节的原始路径基线。

| 上层参考         | 在线液体目标关闭 | 在线液体目标开启 |
| ---------------- | ---------------- | ---------------- |
| 普通缓弯运动安排 | A                | C                |
| 防晃轨迹优化     | B                | D                |

B/A 检查上层加入液体目标的贡献，D/B 检查在线液体目标增量，D/C 检查防晃上层相对普通上层的增量。四组都采用同一种在线进度模式及区域内几何自由度，共享曲率偏好、跟踪正则和其他非液体设置；不能直接把 A/C 与旧 diag 包等同。另保留无上层但采用相同新几何配置的 MPCC，分辨全程安排本身的贡献；它与采用普通非液体设置的主基线分别标记。

“在线液体目标开/关”需要列出具体代价、约束与恢复开关。若只验证液体代价作用，建议保留共同液体传播与监视器，液体硬约束/恢复另做对照；若同时改变多项，则解释为组合机制。剩余段检查首轮只诊断，不能在 A/B 中暗中用液体评分筛选动作。

按因素分别增加以下比较，不把多个机制一次改变后的收益归到某一项：

| 比较                                       | 保持什么一致                                                   | 唯一需要检验的机制                                                                                |
| ------------------------------------------ | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 固定参考几何 vs 区域内自主几何             | 起终条件、区域、运动限制、耗时要求和液体设置；记录实际速度差异 | 几何自由度的增量；同样开放几何时再单独比较曲率偏好开/关                                           |
| 同一防晃计划：固定时序跟踪 vs 在线进度调整 | 模型、状态信息、非时序目标、运动/区域限制、液体机制和停车评价  | 固定时序版按任务时钟查询参考，不随误差重置时钟；在线版允许改变进度。参考/进度项的必要差异显式记录 |
| 剩余段信息进入决策前/后                    | 同一计划、在线进度模式和液体设置                               | 仅当该机制真正进入目标或约束后，检验是否减少短视动作；离线报告本身不算控制增益                    |

固定时序对照受 C06/B11 的参考跟踪结构及 R08 的 MPC/MPCC 比较启发，是我们的实验设计，不是这些论文的 Scout 复现。旧阅读笔记中的 B/D 名称与本表四组含义不同，记录时使用完整方法名称。

R36 的 ZV/FIR 可作为简单防晃参照，先在其适用的直线任务中核验，并计入整形延迟；曲线扩展要重新检查底盘可执行性。加入轨迹层后，R32/C06/B11 成为直接的结构比较对象，旧总览中的“补充基线”定位需按新任务重判，但不自动等于已实现的实验 baseline。

先报告到达、区域/运动超限和求解失败，再比较实际移动段曲率峰值、弧长加权曲率 RMS、转向变化、全程晃动、停车残余、路径长度及实际耗时。低速停转单列，跟踪误差只作路线偏离诊断。独立仿真对象与液面测量用于确认效果；共用模型的自洽检查只能解释机制。没有可靠实时液面反馈时，主要对照不能使用未来扰动或真实液体状态。
