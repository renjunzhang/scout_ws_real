## 1. 用户已经明确的目标

**主对照固定为 B0 与我们的双层防晃 MPCC。目标是在相同运输任务下抑制晃动，先建立成立条件清楚的理论依据，再通过仿真和实物检验。**

1. 给两种方法同一个 S 形参考路径；沿用当前主线的空间约定：参考路径提供路线引导，允许在相同物理区域内优化实际几何和速度。跟踪误差不是主要成绩。固定几何曲线的比较可作为后续隔离实验，不替换这条主线。
2. B0 使用普通 MPCC，不使用上层防晃计划，不把液体代价、液面约束或液体风险调速加入控制决策。车辆、执行器和公共运动约束仍应正确、完整。
3. 完整方法的上层安排全程几何、速度时序、液体响应及停车；下层按当前运动和液体估计状态滚动优化。
4. 仿真和实物采用相同的两条评价链：**solver 预测运动对应的液面高度，以及 IMU 实测运动驱动 slosh model 得到的高度。**
5. **RGB 暂不纳入当前开发阶段，也不作为推进这一阶段的前置条件。** IMU 测到的是运动量；通过模型得到的高度应称为“IMU 驱动的液面高度估计/重建”，不能称作直接实测液面。
6. 最终希望形成自己的论文。当前目标是证明并解释相对 B0 的防晃收益，不能把“加入了 slosh 权重”“轨迹更缓”或“程序能运行”直接当成效果成立。

第 1 条空间语义来自既有[协同框架](20260915_轨迹层与MPCC协同框架思路.md)。具体 S 路径、区域、运行速度、时间容差、重复次数及最低有效收益尚未冻结。下文的指标主次和分阶段安排是实施建议，不冒充用户已经确定的数值协议。

**同日后续补充：用户明确“最后肯定有 RGB，只是现在还没做”。** 本文两条模型高度链限定当前开发验证，最终论文将加入 RGB 作为实物液面效果的主要测量依据。最终主比较、外部算法、两层消融及三条证据链详见[方法与试验章节书写思路](../../../论文书写/书写思路/20260916_双层防晃MPCC方法与试验章节书写思路.md)。这项补充不表示 RGB 已完成或正式协议已冻结。

## 2. 参考论文与本项目的研究问题

参考：Andrea Ferrari 等，*Time-Optimal Anti-Sloshing Trajectory Planning for Multiple Liquid-Filled Containers Subject to SCARA Motion*，IEEE RA-L，11(2):1762–1769，2026，DOI：[10.1109/LRA.2025.3643281](https://doi.org/10.1109/LRA.2025.3643281)。本轮已阅读本地 8 页 PDF，并核对实验图及表；Zotero key 为 `GENJ8QMV`。

原文 §III-A 优化给定路径的运动时序；§III-B 同时优化路径与时序；式 (19)/(23) 同时处理运输中液面限制与停机后残余。§IV 的复杂路径案例说明，允许更缓的转弯可以改善液体响应及运输效率。原文实验高度来自视频，不能把该证据直接移用为本项目 IMU 模型高度的独立验证。其多容器、SCARA、离线时间最优设定也不同于当前移动底盘在线控制。

本项目拟回答：

> 在共同 S 形运输任务、空间和运动约束下，上层全程防晃规划与下层在线 MPCC 协同，能否在相近运输耗时下降低运动测量驱动的液体响应，并改善停车残余？

理论机制是液体具有振荡记忆，连续转弯之间存在相位关系。上层利用全程信息协调激励；下层根据实际状态修正执行偏差。更小曲率只能在相应速度条件下降低向心激励；更平滑的命令也不自动意味着更低的液面峰值。是否防晃必须通过液体动力学及执行结果评价。

当前上层的 `transport_duration` 是任务给定量，尚不是自由终止时间优化；当前定位为**运输效率约束下的双层防晃规划与控制**。旋转液体模型已有文献基础，不能仅将模型接入两层就宣称新的理论贡献。

## 3. “理论上成立”需要证明到什么程度

### 3.1 一个有条件的名义性能结论

设完整控制序列为 $U$，两种方法的可行集合均为 $\mathcal F$，普通 MPCC 目标为 $J_0$。选定晃动指标，例如固定评价时长 $T$ 内：

$$
S(U)=\int_0^T h(t;U)^2\,dt.
$$

如果两种方法具有同样的完整初态、物理模型、时长、约束及非液体目标，并分别获得全局最优解：

$$
U_B\in\arg\min_{U\in\mathcal F}J_0(U),\qquad
U_S\in\arg\min_{U\in\mathcal F}\big[J_0(U)+\lambda S(U)\big],\quad\lambda>0,
$$

由两次最优性可得：

$$
\lambda\big[S(U_S)-S(U_B)\big]
\le J_0(U_B)-J_0(U_S)\le0.
$$

因此 $S(U_S)\le S(U_B)$。在固定 $T$ 下对应模型高度 RMS 不劣于 B0。严格降低还要求存在可行的改进空间；这个结论不自动保证峰值、P95、停车残余也各自降低。

**这是条件性推导，不是当前软件已经满足的定理。** 当前 raw 与完整方法的 contour 权重、几何目标、参考均有变化；液体代价包含模态位移、模态速度和终端项，并非上述单一高度积分；IPOPT/有限次 RTI 没有全局最优保证。单次预测优化也不能直接推出滚动闭环全任务的性能支配。

### 3.2 更直接的名义验证方案：保留 B0 比较候选

建议在同一模型、完整初态、任务及评价窗口下生成 B0 名义全程轨迹，统一传播其液体响应，作为完整方法的性能参照。可以研究如下接受条件：

$$
S(U_{\mathrm{candidate}})\le S(U_B)+\varepsilon_{\mathrm{num}}.
$$

$\varepsilon_{\mathrm{num}}$ 只覆盖预先核定的数值误差；“不劣”不等于已取得有意义的改善。最低实用改善应结合试验重复性另外定义。

实施前必须核验 B0 轨迹确实能表示在共同候选集合中，并满足同样的区域、时间、目标、FIFO、jerk 与停车条件。不能假设 B0 的闭环轨迹天然满足上层所有参数化约束，也不能使用未来实测数据生成所谓在线比较候选。

这个条件可以检查候选解，无需把局部求解冒称为全局最优。但它只支持**所核验名义全程计划**的结论。下层改变几何和时序后，需要重新传播液体；如何通过剩余任务和终端条件保持全程优势仍是研究内容。当前后缀检查只是离线诊断，尚未实现上述非劣接受机制，也没有闭环递归可行或性能保证。

| 项目 | B0 | 双层防晃完整方法 |
| --- | --- | --- |
| 共同输入 | 同一原始 S 路径、起终状态、物理区域及任务条件 | 相同 |
| 上层防晃计划 | 不使用 | 使用全程几何/速度/液体计划 |
| 下层液体决策 | 关闭 | 开启液体状态代价；硬约束是否开启需另冻结 |
| 执行器及运动约束 | 保留共同的延迟、响应、速度、加速度、jerk 等约束 | 相同物理约束 |
| 评价液体模型 | 旁路运行，只评价、不改变 B0 命令 | 同一评价模型；同时保留 solver 内部预测 |
| 当前入口对应 | `raw_mpcc` / B0 | `planned_slosh` |

主实验评价完整方法相对 B0 的整体收益，不把该差异全部解释为单独某一个权重的作用。两组共享场地、载荷、容器/液量、数据处理、控制频率、物理约束、时间要求和合理调参预算，不能故意弱化 B0 或只给完整方法修复公共执行链。

当前 `planned_mpcc` 已使用上层液体计划，与 `planned_slosh` 只隔离下层液体项，**不是本轮主基线 B0**。后续为解释双层作用，可在仿真补“仅上层”“仅下层”；如需隔离上层液体建模贡献，另在相同规划架构中关闭上层液体项。补充消融不替换 B0 主比较，也不要求首轮实物一次完成所有组。

## 5. 两条高度评价链及统计口径

### 5.1 统一模型、初态和时间轴

统一采用冻结的模型版本、容器参数、高度换算和处理流程，例如 modal 高度：

$$
h=c_h\sqrt{\eta_x^2+\eta_y^2}.
$$

- **预测链：** solver 的预测实际运动 → 液体传播 → $h_{\mathrm{pred}}(t_k+\tau\mid t_k)$。使用实际运动预测和已建模执行器历史，不能直接把命令加速度当成容器实际激励。
- **测量驱动链：** 仿真 IMU 或实车 IMU → 统一的标定、重力/外参处理、时间对齐与滤波 → 连续液体传播 → $h_{\mathrm{IMU}}(t)$。容器偏置修正及横向激励只能按约定计入一次。
- 两组评价器使用相同的初始化规则，保持完整振荡记忆；不能逐拍置零，不能把丢帧后的重置值拼成降晃收益。评价器不读取各组不同的控制代价或权重。
- IMU 评价来源与完整方法的控制初态来源是两个配置项；本轮已确定前者使用 IMU，后者仍需显式冻结。不能因当前 planned_slosh 默认采用 odom 就把 odom 高度替代 IMU 主评价。

当前 B0 不含液体状态，[solver](../../../../src/scout_apps/control/spmpc_local_planner/src/solvers/continuous_mpcc_solver_acados.cpp)将对应预测高度写为 0。该零值是缺少模型状态的占位，不是零晃动。应利用同一旁路液体模型、可追溯的液体初态和 B0 预测运动重建预测高度；不能从 24 维车体预测凭空造液体初态。旁路评价链尚需按新版本接通并验证，不能假定旧分析脚本已全部兼容。

### 5.2 指标与窗口建议

| 类别 | 建议记录 | 用途 |
| --- | --- | --- |
| 主效果指标 | 运输全过程 $h_{\mathrm{IMU}}$ RMS | 检验整体模型液体响应是否降低 |
| 过程补充 | 峰值、P95；启用阈值时记录超限量和持续时间 | 防止仅均方值下降却出现更高峰值 |
| 停车残余 | 到站停车后固定窗口的 RMS、峰值；可选沉降时间 | 评价运输结束后的液体响应 |
| 预测诊断 | 固定提前量的 MAE/RMSE、按提前量分组的偏差 | 检查预测与实际执行响应的一致性 |
| 任务/效率 | 完成率、实际耗时、区域/运动约束违反 | 确认降晃没有依赖未完成任务或明显增加耗时 |
| 运行代价 | 在线整控制周期耗时、超期率、失败/接管；上层离线计算另列 | 检验方法的运行可行性 |

建议运输窗从统一运动起点判据开始，到相同位置/朝向/实际速度/命令队列条件确认到站停车为止；不只依据首次进目标圈或状态字符串。停车后窗口建议 5 s，正式采集前冻结。若比较共同 deadline 后的残余，应另列共同绝对时刻窗口，不与各自到站后窗口混算。

共同 deadline 只限制最长时间，**不代表实际耗时相同**。运输时间容差需事先确定；明显不匹配时另报告耗时—高度权衡，不能用事后拉伸时间轴伪造等时比较。第 3 节定理使用固定 $T$，不能直接套到时长不同的实测 RMS 上。

预测可先选 $\tau=0.2/0.5/1.0$ s 等固定提前量，按 `solver_input_epoch + tau` 对齐未来测量驱动状态，具体值随冻结时域确定。每拍预测时域最大值不是当前高度；$\tau=0$ 可能就是输入 observer 状态，也不是独立预测验证。未来命令会被重新规划，因此上述误差包含重规划与执行偏差，不能全解释为液体模型辨识误差。

相对改善按独立运行/配对计算，例如：

$$
R_H=100\%\,\frac{H_{B0}-H_{\mathrm{Full}}}{H_{B0}}.
$$

同时报告绝对差值；B0 指标接近零时不以百分比作主要结论。丢帧、重置、故障和未完成任务按预先约定分类，不能将无效高度补零，也不能只保留完成者制造总体收益。若报告成功运行的条件统计，同时报告全部尝试及失败原因。

## 6. 从仿真到实物的推进顺序

| 阶段 | 具体工作 | 应获得的证据 / 进入下一阶段的条件 |
| --- | --- | --- |
| 0：冻结问题 | 固定 S 路径、区域、起终状态、时间与运动约束、两组配置、评价模型及窗口 | 有可追溯任务和配置；B0 没有液体控制介入；评价器两组一致 |
| 1：模型和评价链 | 同输入核对上层、下层、旁路评价器的传播；核对 B0 高度重建、时间轴、液体初态、连续性及区间峰值 | 差异有来源、有数值误差界；无占位零值、重复积分或重置收益 |
| 2：名义全程潜力 | 相同 S 任务及理想模型下比较 B0 与完整方法；先给充分求解预算；核验完整轨迹和停车 | 至少找到可重复核验的优势及其条件，说明速度/几何/相位怎样产生收益；若没有优势，回到目标和可行空间诊断 |
| 3：闭环仿真 | 接入真实在线频率、有限求解预算及仿真 IMU 链；再加入执行器/液体参数失配、噪声和时间抖动 | 收益是否保留、在哪些条件失效；完成率、时限和两个高度链同时有记录 |
| 4：ROS1 集成与低速实物 smoke | 完成整节点编译、接口/回放核验、最终发布链检查；修复影响状态和命令可信度的问题后做空场低速单次功能核验 | 版本/配置一致，时间和状态链连续，命令/停车符合冻结条件；smoke 只证明运行，不作为降晃结论 |
| 5：配对实物对照 | 同一 S 任务下交替/平衡顺序运行 B0 与 Full，初态按相同规则恢复，保留全部 bag/失败记录 | 获得配对的高度、残余、实际耗时、完成率和计算数据；用重复试验评估收益与不确定性 |
| 6：范围与论文证据 | 根据名义结果补速度/弯道尺度、模型失配及必要消融；整理正负结果 | 说明有效范围、两层作用和失败边界；只写证据已经支持的结论 |

阶段 2 的理想真实液体状态反馈只能标为“模型内潜力”；阶段 3 的主比较必须使用计划部署的传感和状态链，不能让完整方法读取未来扰动或仿真液体真值，而 B0 受真实测量限制。完全相同的控制/对象模型可以验证实现一致性，不等于鲁棒性验证；失配范围优先来自现有标定，探索性范围须单独标注。

首轮先完成一条共同 S 路径的名义主对照，再拓展工况。重复次数先用小规模配对预试验估计变异，再根据最低有效改善和精度要求冻结；不能把大量采样点当成大量独立实验，也不能把完全相同确定性仿真反复运行当成独立证据。实物可用平衡的 ABBA 或预先随机化区组，方法切换前按同一规则恢复起点和液体初态。

无输出回放不覆盖真正发布命令的所有后处理分支，需要另在隔离输出条件下核验最终发布路径。进入实物前重点处理[现有复盘](../../后续改进/20260916_当前主线复盘与剩余缺口.md)中的发布时效/改写、可信状态恢复、定位进度、停车完整核验、普通求解失败接管及参考端点；启用硬液面上限时还需核验周期内峰值。这里记录验证顺序，不执行机器人操作。

## 7. 期望结果及不能算成功的情况

**期望结果：在共同运输条件下，完整方法相对 B0 的 IMU 重建高度可重复降低，停车残余改善，任务完成和运输效率保持，且计算负担适合在线执行。** solver 预测用于解释这一收益与偏差。

| 观察结果 | 应如何判断 |
| --- | --- |
| 名义模型有明确收益，闭环仿真和实物配对也保留，耗时匹配 | 支持当前条件下的模型评价防晃有效性，再量化幅度和不确定性 |
| 只有 solver 预测降低，IMU 重建不降或升高 | 执行效果尚未成立；检查预测、命令、执行器与状态链 |
| 只有停车后残余下降，运输全过程 RMS/峰值更高 | 只支持残余改善，不能表述为全程降晃 |
| 高度降低但明显更慢、提前停住或未到目标 | 不能作为等效率任务下优于 B0 的证据 |
| 只证明曲率降低、命令变平滑 | 支持运动形态改变，还没有证明防晃 |
| 名义全程充分求解也无收益 | 先检验是否存在可行收益空间及目标冲突；不能预设换到实物就会成功 |

不在结果产生前写入“降低 20%/50%”等收益结论。主指标、最低有效改善、耗时容差和统计方法应在正式比较前确定。也不宣称全过程绝对零晃动、真实液面硬不溢出、全局时间最优或闭环递归可行。
