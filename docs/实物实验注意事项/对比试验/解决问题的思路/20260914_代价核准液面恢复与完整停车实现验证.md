## 2. V2：代价分项与减速空间

实际旧生成物的 `cost_scaling` 为 `[dt]*60+[1]`，而 running 表达式已除以 60。相同原始代价下，running 总量约为 `dt*J`，终端为 `J`，相对比例约 30。现在明确采用：

```text
J = (1/N) * sum(L_k, k=0..N-1) + Phi_N
acados cost_scaling = [1] * (N+1)
```

这是一种平均 running 加一次终端的权重约定，不声称终端权重已通过实车调优。全部误差仍按原参考尺度归一化。

符号分项固定顺序：contour、lag、progress、实际速度、虚拟速度、anti-creep、control、smooth、液体位移、液体速度、slack、stop。`J_v` 包含实际/虚拟速度两项；这两个细项不在 `total()` 中重复累加。`J_terminal` 收纳普通终端项；`J_slack`、`J_stop` 各自包含 running 和终端贡献，不再重复归入 `J_terminal`。

C++ 调用生成 C，用返回的完整轨迹和精确 stage parameters 重建分项；再调用 `ocp_nlp_eval_cost` 取得真实 solver objective。容差为 `1e-8*(1+abs(J_solver))`，不一致返回 `COST_RECONSTRUCTION_MISMATCH`。不再漏计 anti-creep，也不把终端节点当作普通 stage。

`anticreep_gain` 已成为参数向量的一部分，ROS 初始化时读取；默认 8，改为 0 只去掉额外低速惩罚。实际速度低于局部参考时，其速度偏差系数为 `(1+gain)*w_v`；虚拟速度的额外惩罚也复用 `w_v`。没有修改默认速度/液体权重来预设结论。

### 固定转弯快照对照

使用最终 B0/slosh 生成物，三组人工全状态快照，分别保持相同初态、历史队列和非 anti-creep 参数；每个快照/增益组合重复 SQP_RTI 30 次。不是实车 bag，也不是每周期一次 RTI 的闭环。路径点由 `y=0.3*x²` 或 `y=0.8*x²` 构造，实际初速 0.2 m/s，线速度队列为其稳态命令；第三组另加 `[eta_y,eta_y_dot]=[0.0005,0.002]`。

| 场景 | gain 8→0：1 秒预测实际速度 m/s | gain 8→0：峰值模态高度 mm | gain 8→0：contour RMS mm |
|---|---|---|---|
| 较缓转弯 | 0.23027→0.23027 | 0.12990→0.12990 | 5.923→5.923 |
| 较急转弯 | 0.19160→0.16223 | 0.29890→0.30718 | 17.601→15.293 |
| 较急转弯、已有初始晃动 | 0.19162→0.16223 | 0.90897→0.90897 | 17.600→15.292 |

六组全部 status=0，代价重建最大绝对误差 `1.74e-17`。较急转弯的 lag RMS 为 4.955→1.894 mm；关掉 anti-creep 后进度也减少。单次 solver 中位 4.04–4.31 ms，P95 4.11–4.48 ms，包含初次迭代，使用本机 GENERIC BLASFEO、无 OpenMP；不包含 ROS 调度，也不是实车周期耗时上界。

结论限于：**anti-creep 的确能压缩提前减速空间，但关掉并未显示降晃收益，保留默认 8**。不同 objective 的总数值不能直接作为两组性能优劣指标。

## 3. V3：有界恢复，保留真实初态和历史

性能目标 `H_target=slosh_height_max`，恢复预算为 `budget_m`：

```text
H_cap = H_target                       # 严格模式
H_cap = H_target + budget_m            # 恢复模式
H_physical = freeboard_m - physical_margin_m   # 只有 freeboard_m > 0 才已知
H_cap = min(H_cap, H_physical)         # 物理边界已知时
```

已知物理边界时要求 `0 < H_target < H_physical`。`freeboard_m=0` 明确表示未知；不允许只有 margin 而没有 freeboard。这里约束的是 `h_modal`，安装倾斜、其它液面成分及模型误差需由真实裕度预算覆盖，不能据此保证实物不溢出。

恢复采用平方模态幅值上的非负松弛，并解析消元：

```text
sigma = max(||eta||² - (H_target/c_h)², 0) / eta_ref²
J_slack = linear_weight*sigma + quadratic_weight*sigma²
||eta||² / (H_cap/c_h)² - 1 <= 0
```

因松弛惩罚单调增加、预算由独立硬边界限制，最优松弛恰等于真实超量，无需额外求解变量。`sigma` 无量纲，预算和诊断中的高度超量用米；这不是直接对米单位高度超量施加相同数值权重。初始节点、全部延迟前缀节点和终端节点均受 cap 约束，并计入松弛惩罚。有限下界 -2 是非活跃边界，因为左侧表达式始终 ≥ -1。

初始高度超过预算/物理边界时明确失败；已知非零历史导致后续暂时越过 target 时，可以在 cap 内恢复。**不缩小液体初态、不改 FIFO、不放宽运动边界**。NoState 与液面约束组合明确拒绝。求解后再检查完整节点峰值，超过预算返回失败；物理边界采用触及即失败。

恢复诊断包含启用/实际使用、严格目标是否满足、预算、cap、真实初始高度、最大超量、超限节点数和物理边界是否已知。恢复模式不会把旧 `hard_constraint_enable` 标成 true；用了松弛的周期 `strict_target_satisfied=false`。节点约束不构成连续时间或实物高度保证。

开发配置暂沿用既有 1 mm 性能目标，增加 3 mm 离线预算，尚未由容器余量或 Smooth-only 实测重放校准。进入新 C03 前仍须用统一模型重放及实物误差确定目标、预算和 margin；不能将这些开发值自动转为冻结值。

## 4. V4：真实任务终点、执行尾段和余振

只有进度接近真实路径终点才激活停车；路径中途从几何上靠近终点不会触发。OCP 根据每个预测进度计算：

```text
d = max(stop_goal_s - s, 0)
t_margin = linear_delay + linear_tau + a_max/jerk_max
v_stop = sqrt((a_max*t_margin)² + 2*a_max*d) - a_max*t_margin
v_ref_stage = min(v_ref_curvature, v_stop)
```

这里是有延迟/惯性/jerk 裕度的参考速度，非停车距离定理。实际与虚拟速度参考、anti-creep 使用同一减速要求，进度奖励在终点降为零；临近真实终点增加 actual/command 速度、队列、加速度记忆和液体残余能量的代价。`stop_goal_s` 为路径终点减去半个位置容差。普通 2 秒窗口末端不强制停车。

到达交接条件后，终点模块持有命令，分别记录 `TERMINAL_DRAINING` 和 `TERMINAL_SETTLING`。制动使用真实发布命令及加速度记忆，满足离散 jerk，并提前保留将负加速度释放到零所需的速度余量。逐段执行共享实际运动/液体传播，滚动原有 FIFO，直到命令、加速度记忆、队列清零，实际线/角速度足够小。

稳定指标同时包含位移和模态速度：

```text
H_res = c_h * sqrt(eta_x² + eta_y² + (eta_x_dot² + eta_y_dot²)/omega_n²)
```

在仍有尾段激励时继续传播，不能仅以停车瞬间高度小为稳定。到达 quiet 阈值后 `H_res` 用作残余能量指标，并纳入尾段峰值检查；严格的无激励幅值上界解释只适用于实际激励为零的模型条件。开发阈值为实际速度绝对值各 ≤ 0.001、`H_res ≤ 1 mm` 持续 0.3 s。body stopped 和 liquid stable 的任务时间分别记录，等待不计作运动中降晃收益。

稳定计时同时检查共同 solver epoch 与原始 robot/liquid 测量时间：共同时间重复/倒退时无效；只有两份原始测量都更新才累计，两次稳定新测量之间才计时。重复测量暂停，倒退、缺失或超过两周期的观测间断重置连续稳定计时；20 Hz 测量配合 30 Hz 控制仍可累计。离线无原始时间戳调用保留共同时间或 dt。到点后出现外扰会撤销 reached，重新获得完整稳定保持；首次停车/稳定事件时间不改写，已有超时也不解除。停车后超过 15 s 未在期限内稳定，失败锁存到新任务；重复发布同一路径不能清除超时。尾段预测最长 8 s，超时、无法满足 jerk 的真实历史、命令越界及液体 cap 越界均明确失败。越界检查在 `GOAL_REACHED` 之前执行，稳定阈值或历史 reached 锁存都不能绕过。

异常仍进入现有失败零命令语义；紧急失败零命令不承诺正常停车的 jerk 性质。完整模式要求显式执行器主线、terminal 与 MPC handoff、jerk 开启、NoState 关闭、common epoch 与发布契约拒绝后改写开启。B0 完整停车同样消费液体状态，纳入 observer 有效性/新鲜度与时间对齐门。

测试夹具同步调整：恒值历史首条从 9.0 s 移至 9.5 s，以满足原有 0.5 s timeout；解析 FOPDT 加速度比较从 1e-9 改为 1e-8，容纳共享 RK4 的约 1.4–1.65e-9 微分误差，速度比较仍为 1e-9。没有放宽生产动力学或运动边界。末次只调整 ROS 发布/诊断分支，使用静态调用链复核；本机不能完成该节点的 ROS1 编译。

## 8. 尚未解决的实物前置问题

### 8.1 静止附近的负速度与非负实际速度约束

实际 acados 包装层、零命令/FIFO/加速度记忆、相同其余状态下，扰动测试结果如下；B0 与 slosh 均复现，真实 x0 未裁剪：

| 初始实际 v（m/s） | 两种模型结果 |
|---|---|
| -0.001 | `ACADOS_SOLVE_FAILED_4`，QP `ACADOS_MINSTEP` |
| -0.0001 | 同上 |
| 0 | 成功 |
| +0.0001 | 成功 |

实际速度未来节点下界为零，延迟前缀不可由新命令控制；FOPDT 中微负速度会继续保持负值。实物上静止噪声或轻微回退都可能触发，因此这是**未关闭的实车运行风险**。不能悄悄裁剪初态，或在没有依据时放宽全部运动约束。下一步先测静止速度偏置/量化/噪声和真回退，制定区分命令非负约束与实际运动允许域的策略，再加入回归测试。临时复现脚本 `/tmp/scout_hardware_perturbation.cpp`，输出 `/tmp/scout_hardware_review_native/hardware_perturbation.log`；不是实车实验。

### 8.2 时间、传感器和液体误差

- 离散 jerk 只保证名义网格的命令序列；发布时间抖动和执行器动态下的物理 jerk 尚未证明。不能只改 C++ 差分 dt 而破坏与 OCP 的契约。前推到求解前时刻，仍未补偿后续计算、传输延迟；提前发送只能减少额外诊断延迟。
- 固定 FOPDT 在静止、低速死区、摩擦和换向时可能不适用。9 月 2 日阶跃记录中 0.05 m/s 起效约 369 ms、0.15 m/s 约 139 ms；odom 与 NOKOV 的角运动建立也并非完全同步，见[执行器辨识分析](../实物对比试验分析/20260902_底盘速度阶跃与执行器能力辨识分析.md)。
- `quiet_v/quiet_omega=0.001` 尚未对静止噪声校准。IMU 姿态/去重力/偏置、滤波相位、地缝、滚俯运动、侧滑及单模态/阻尼误差都可能改变观测与真实液面，当前观测器仍是模型估计，不是直接液面反馈。
- 容器静液面余量和 margin 未提供，1 mm 目标/3 mm 恢复预算仍是开发值。节点高度与 quiet 阈值下残余能量不是物理不溢出保证；须先有固定监视器、统计窗口和实物误差预算，再冻结新 C03。
