## 4. 与 P0/P1-shadow 改动的关系

本轮复跑是在 P0 online diagnostics + P1-shadow 代码加入后进行的，但 `delay_phase.mode` 默认仍为 `off`。

结论：

```text
1. 默认 off 时，新增 delay_phase 代码未导致 SPMPC 内部消融矩阵运行失败。
2. 本轮不是 delay_phase shadow 对比实验；不用于证明 predictor 精度。
3. P1-shadow 的功能 smoke 证据仍以单独的 delay_phase_mode=shadow smoke 为准。
```
