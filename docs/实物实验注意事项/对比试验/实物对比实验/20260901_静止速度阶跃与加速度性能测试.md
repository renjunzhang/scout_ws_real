# 静止速度阶跃与加速度性能测试

## 目的

小车静止时直接发送一次固定速度，分别测试：

- 转向：开始转动的时间、角速度建立速度、有效角加速度和停转性能；
- 直线：开始移动的时间、线速度建立速度、有效加速度、减速度、制动距离和侧向偏移。

本测试不启动 MPC、路径跟踪或 slosh 控制，只测量最终 `/cmd_vel` 到底盘实际运动的响应。

实际运动只允许通过外层 runner 启动。底层 Python publisher 还会独立检查显式 arm token 和 `/use_sim_time`，避免绕过 runner 的人工解锁直接动车。

## 是否需要动捕

这个精确版脚本必须有 NOKOV：

- 转向测试以 NOKOV 角速度为主结果，IMU 角速度和里程计用于交叉检查；
- 直线测试以 NOKOV 位置得到的真实速度为主结果，里程计用于交叉检查；
- 制动距离和侧向偏移必须由 NOKOV 位置计算；
- 不把 IMU 线加速度直接当主结果，因为安装姿态、重力分量和零偏很容易放大误差。

如果没有 NOKOV，可以只看 IMU/里程计做快速粗测，但不建议用来标定 MPC 中的延迟和执行器参数。当前脚本会在 NOKOV 缺失时拒绝实测。

## 脚本与默认设置

```text
src/scout_apps/control/spmpc_local_planner/scripts/run_spmpc_mocap_velocity_step_trial.sh
```

每次均为：静止 `3 s` → 固定速度 `4 s` → 零指令 `3 s`，指令频率 `50 Hz`。

| 模式 | 默认指令 | 脚本允许的最大幅值 |
|---|---:|---:|
| 转向 | 左转 `0.20 rad/s` | `0.30 rad/s` |
| 直线 | 前进 `0.10 m/s` | `0.15 m/s` |

## 使用方法

先确认底盘、NOKOV、`/imu/data` 和 `/odom` 正常，并停止 MPC 与遥控节点。脚本会拒绝已有 `/cmd_vel` 发布者。

只检查参数，不动车：

```bash
bash src/scout_apps/control/spmpc_local_planner/scripts/run_spmpc_mocap_velocity_step_trial.sh

TEST_AXIS=linear \
bash src/scout_apps/control/spmpc_local_planner/scripts/run_spmpc_mocap_velocity_step_trial.sh
```

左转实测：

```bash
TEST_AXIS=angular \
STEP_DIRECTION=left \
RUN_LABEL=MOCAP_ANGULAR_STEP_L01 \
VALIDATE_ONLY=false \
ARM_MOTION=YES \
bash src/scout_apps/control/spmpc_local_planner/scripts/run_spmpc_mocap_velocity_step_trial.sh
```

直线前进实测：

```bash
TEST_AXIS=linear \
STEP_DIRECTION=forward \
STEP_MAGNITUDE=0.10 \
RUN_LABEL=MOCAP_LINEAR_STEP_F01 \
VALIDATE_ONLY=false \
ARM_MOTION=YES \
bash src/scout_apps/control/spmpc_local_planner/scripts/run_spmpc_mocap_velocity_step_trial.sh
```

反向测试只需把 `left` 改为 `right`，或把 `forward` 改为 `reverse`。建议每个方向重复 `5` 次，只修改 `RUN_LABEL` 编号，最后取中位数。

实测前必须确认地面平整、急停可用、转动或直线运动空间无障碍。默认直线测试会行进约 `0.4 m`，需预留额外制动距离。

## 输出与计算方法

脚本结束后自动生成 bag、JSON 报告和响应曲线。主要指标为：

- `onset`：指令发出后，连续超过静止噪声门槛的首个运动时刻；
- `t50` / `t90`：达到本次实际稳态速度 `50%` / `90%` 的时间；
- `a_eff`：从实测速度 `10%` 到 `90%` 的平均斜率，用于表示有效加速度；
- `brake_onset` / `stop`：发出零指令后，开始明显减速和可检测停止的时间；
- `decel_eff`：实测速度从 `90%` 降到 `10%` 的平均斜率；
- 直线模式额外输出零指令后的制动距离和最大侧向偏移；
- 转向模式额外输出零指令后继续转过的角度。

`a_eff` 不是对位置做二次微分，因此对动捕噪声更稳健。`t90` 包含速度逐渐建立的过程，不能全部当成纯延迟。标定 MPC 时应分开使用 `onset` 和 `10%–90%` 建立时间。
