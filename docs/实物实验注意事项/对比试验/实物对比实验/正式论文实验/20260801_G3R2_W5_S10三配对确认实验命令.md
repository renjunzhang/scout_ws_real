# G3R2 W5_S10 三配对确认实验命令

## 1. 冻结结论与范围

G3R2 单次筛选报告状态为 `PROMOTE_FOR_PAIRED_CONFIRMATION`，唯一晋级候选是：

```text
condition = W5_S10
w_slosh   = 5.0
w_smooth  = w_alpha = w_du_a = w_du_vs = 1.0
RGB P95 单次改善 = 0.076923 mm（约 11.1%）
```

本阶段仅做 development 配对确认，不计入正式样本量。固定比较 `Bsmooth` 与 `W5_S10`，共 3 个 block、6 条 trial；不再探索或修改权重。

晋级门槛：

- 配对平均 RGB P95 改善至少 `0.05 mm`；
- 至少 2/3 block 同向，且中位数改善为正；
- 配对平均 RGB RMS 不恶化；
- raw processed-IMU P95 平均退化不超过 `0.05 mm`；
- 禁止单 block 主导，leave-one-block-out 方向必须均为正；
- 每条 tracking、时间戳、IMU source、fallback/reset 和图像禁录门槛均需 PASS。
