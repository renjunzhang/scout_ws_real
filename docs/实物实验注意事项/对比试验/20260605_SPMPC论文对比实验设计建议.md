# SPMPC 论文对比实验设计建议

## 1. 主实验：固定路径跟踪 Fixed-path Tracking

用于证明 SPMPC 的主体液体晃动抑制能力。

### 内部消融

| 方法 | 目的 |
|---|---|
| B0 | non-slosh continuous MPCC baseline |
| B_smooth | 验证控制平滑项作用 |
| B_slosh | 验证 slosh-aware 模型/代价作用 |
| B_ours | 验证 slosh-aware + smooth 的完整方法 |

注意：B0 只能称为内部 non-slosh MPCC baseline，不应直接等同于 de Groot 2025 / mpc_planner 的完整复现。

### 外部 baseline

| 方法 | 目的 |
|---|---|
| TEB | 传统优化式局部规划 baseline |
| DWA | 传统速度采样局部规划 baseline |
| mpc_local_planner / mpc_planner | 需要补齐的权威 optimization baseline；只有依赖和仿真跑通后再加入正式表格 |

## 2. 扩展实验：点到点导航 Point-to-point Navigation

用于展示真实导航入口下的可用性，不建议作为最核心结论。

建议方法：

```text
B_ours
TEB
DWA
```

若 DWA 或 mpc_local_planner 仍不稳定，应标注为诊断性结果，不要强行作为正式公平对比。

## 3. 当前补强优先级

```text
1. 先把 TEB + DWA + SPMPC 内部消融做扎实，保证参数、路径、终点策略和统计窗口公平。
2. 同时补一个 mpc_planner / mpc_local_planner，作为权威 optimization baseline。
3. mpc_planner / mpc_local_planner 跑通前，不把 B0 冒充为 de Groot 2025 / mpc_planner 完整复现。
```

公平性要求：

```text
- B0 / B_smooth / B_slosh / B_ours 使用同一套 terminal policy。
- TEB / DWA 使用相同场景、路径/目标、速度限制和评价指标。
- 主体抑晃指标优先统计 terminal 前的 pre_terminal_phase。
```

## 4. TEB / DWA 公平性处理

TEB / DWA 要作为强 baseline，需要认真调到稳定、平滑、可复现，但不应加入液体晃动模型或 slosh-aware cost。

### 应该做

```text
- 使用同一起点、目标、地图、路径/目标输入和记录时长。
- 使用统一或可解释的速度、角速度、加速度限制。
- 调参到能稳定跟踪/到达，避免明显震荡、暴冲、NO_VALID_CMD 或 transformed plan 为空。
- 使用相同评价指标和统计窗口。
- terminal 前主体段统一统计；若 TEB/DWA 没有 /spmpc/terminal/debug，可用相同终点距离阈值切分 terminal 区。
```

### 不应该做

```text
- 不给 TEB / DWA 加 slosh dynamics。
- 不给 TEB / DWA 加液体高度代价、eta/eta_dot 代价或 slosh-aware optimization。
- 不把魔改后的 slosh-aware TEB/DWA 当作标准 TEB/DWA baseline。
```

### 可以做的“液体友好”普通调参

```text
- 降低最大速度和最大角速度。
- 限制线加速度和角加速度。
- 提高轨迹/速度平滑性。
- 减少急转、急停和终点震荡。
```

论文表述建议：

```text
TEB and DWA are tuned conservatively for stable and smooth liquid-transport navigation, but they do not use the proposed slosh dynamics or slosh-aware cost.
```

## 5. 指标建议

主体 tracking 指标只统计 terminal 前：

```text
pre_terminal_phase = 1
```

建议报告：

```text
tracking error
slosh height peak
eta_dot peak
control smoothness
solver time
failure count
```

terminal 停车段单独报告：

```text
stop distance
cmd_v jump / deceleration
terminal slosh peak
whether final stop is stable
```

## 6. 推荐论文结构

```text
Main evaluation:
  fixed-path tracking: B0 / B_smooth / B_slosh / B_ours + TEB / DWA

Supplementary evaluation:
  point-to-point navigation: B_ours / TEB / DWA
```

结论：固定路径跟踪作为主实验，点到点导航作为补充实验；所有 SPMPC variants 使用同一套 terminal policy，正式抑晃指标优先看 terminal 前的主体路径段。
