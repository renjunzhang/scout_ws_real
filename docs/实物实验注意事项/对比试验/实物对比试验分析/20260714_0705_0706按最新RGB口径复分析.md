## 1. 复分析范围与目的

本轮只分析正式 SPMPC N=3：

```text
20260705: B0 / B_slosh / B_ours，各 N=3，共 9 bags
20260706: B_smooth / B_slosh / B_ours，各 N=3，共 9 bags
```

不纳入：gate、smoke、delay 调试包和 LT-DWA。

本轮没有重复解码约 180GB RGB 图像，而是复用已有逐帧 `*_red_top.csv`。理由：

1. 18 个 CSV 均完整存在；
2. 使用的三标尺 YAML 与 20260714 TEB 分析文件 SHA256 完全一致；
3. 原 CSV 保留 `h_mm_left/center/right` 和 `h_mm_max_lcr`，可以重新执行零点、平滑、progress 和保真度统计；
4. 本轮新增的是统一零点判断、`GOAL_REACHED+2s` 保真度、阈值召回率和排序保真度。

## 2. 固定视觉口径与零点判断

主指标：

```text
h_max_lcr(t) = max(left, center, right)
H_vis(t) = abs(rolling_median(h_max_lcr, window=5) - h0)
```

0705/0706 与 0713 TEB 的录包时序不同：

```text
首个 ACADOS_OK 距 bag start: 10.05~12.36s
```

因此两天都有可靠的 tracking 前静止段，正式零点继续使用：

```text
h0 = median(first 30 valid RGB frames)
```

18 包 h0 范围为 `0.000~0.276mm`。这里不使用 0713 TEB 的 `calibration_zero` 特例。

质量检查：

| check | result |

| RGB 总帧 | `29179` |
| progress 10%~90% RGB samples | `12915` |
| confidence mean | `0.990~1.000` |

| core 8mm upper clip | `0/18` |

## 7. 跨日 bridge 复核

同一方法从 0705 到 0706 的变化：

| method | RGB p95 | RGB peak | RGB RMS | model p95 |
|---|---:|---:|---:|---:|
| B_ours | `+84.7%` | `+47.0%` | `+70.5%` | `+3.5%` |
| B_slosh | `+86.8%` | `+32.5%` | `+44.5%` | `-2.0%` |

RGB 跨日变化远大于模型变化，说明光学状态、初始液面、相机/容器姿态或当天运动条件会显著影响绝对视觉幅值。结论：

```text
0705 与 0706 不能直接做强跨日 RGB 排序；
0706 的 B_ours bridge 只用于说明当天 B_ours 与 B_smooth 基本持平；
外部 baseline 与内部方法的最终比较仍应优先同日录制或明确标为跨日参考。
```

## 8. 最终结论

1. 复分析完整复现了 0705/0706 历史 progress 主表，原 RGB 提取结果有效。
2. 0705 支持 B_ours 相对 B0 降低真实 RGB 液面包络。
3. 0706 不支持 B_ours 的 RGB 显著优于 B_smooth，但支持其模型侧存在 smooth-only 之外的作用。
4. B_slosh 的 internal model 最低，但 RGB 排序最差且保真度低估最严重，只适合作为 slosh-only ablation。
5. `/spmpc/slosh_height` 只能作为控制侧机制辅证，不能替代 RGB ground truth、不能单独决定方法排序，也不能直接作为实物 hard gate 证据。
6. 最终内部方法仍保留 B_ours；论文 claim 应区分“模型侧额外效果”和“RGB 真值是否显著改善”。
