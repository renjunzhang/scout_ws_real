# 20260731 动捕辅助 IMU 平面外参冻结分析

> 结论：**保持当前名义平面外参，不把 `r02` 拟合的小修正写入 runtime。**
>
> 决策 ID：`KEEP_NOMINAL_PLANAR_EXTRINSIC`
>
> 边界：这是满足当前平面 anti-slosh/G2S 需求的外参分析，不是完整六轴 hand-eye calibration。

## 1. 为什么在 G2S 前做这一步

如果直接用名义 IMU 外参与 odom 比较，结果会混合“输入源质量”和“IMU 外参误差”。因此 G2S 前先用不含 RGB 正式 outcome 的既有动捕 bag 分析平面外参，并将选参与验证严格分开。

数据边界：

| 数据 | 角色 | bag SHA-256 |
| --- | --- | --- |
| `compact_r02` | 唯一 tuning/选参数据 | `ee3d102914d9707aa505a87b303ae224ed87bbd129516165f5b89c7e17a41df4` |
| `remote_r03` | 高幅值 held-out validation | `b05f69f8850271625a75ea3650df0992970c1df79f4db035bf578f1356d20ef8` |
| `planar_r03` | 干净命令标签 held-out validation | `faab5c00082b185fe23729d4e957f62be7a727e31266a38f81612aefc04567c1` |

`remote_r03` 和 `planar_r03` 只用于验证已锁定的 `r02` 候选，未用它们回调候选参数。

## 2. 方法

固定处理链：

```text
/imu/data
→ 利用 IMU quaternion 去重力
→ 每条 bag 的静止头段 bias
→ 中心三次局部多项式，主窗口 0.51 s
→ 时间配对 mocap(t_imu - 0.015 s)
→ Tracker0 位置二阶微分得到刚体加速度
→ 在 base/tube frame 中拟合 IMU yaw 与 XY 杠杆臂
```

刚体换算为：

```text
a_Tx = a_Ix - alpha_z*r_y - omega_z^2*r_x
a_Ty = a_Iy + alpha_z*r_x - omega_z^2*r_y
```

`Tracker0 -> base_link` 的平面 yaw 仅用 `r02` 的近直线段冻结：

```text
yaw_base - yaw_Tracker0 = -2.2844 deg
selected samples         = 424
residual std             = 1.2284 deg
```

两条验证 bag 的独立诊断值分别为 `-2.2907 deg` 和 `-2.3767 deg`，未反向写回 tuning 值。

## 3. `r02` 锁定候选

0.51 s 主窗口下，`r02` 拟合得到：

```text
imu_to_base_yaw          = +0.6000 deg
imu -> tube lever arm XY = [-0.11436, +0.05406] m
```

但这不代表应立即改 runtime。当处理窗口从 `0.31 s` 变到 `1.01 s` 时：

```text
yaw: +0.40 ~ +0.60 deg
r_x: -0.114 ~ -0.099 m
r_y: +0.046 ~ +0.064 m
```

候选与当前名义值已很接近；该量级小修正必须在 held-out 上一致改善，才有理由替换 runtime 值。

## 4. 当前杠杆臂是否必要

与“不做杠杆臂补偿”相比，当前名义杠杆臂将动态 XY 联合 RMSE 降低：

| 数据 | 无杠杆臂 RMSE | 当前名义外参 RMSE | 改善 |
| --- | ---: | ---: | ---: |
| `compact_r02` | 0.036106 | 0.028921 | 19.90% |
| `remote_r03` | 0.083966 | 0.076509 | 8.88% |
| `planar_r03` | 0.072468 | 0.049090 | 32.26% |

这说明当前 `[-0.100,+0.045] m` 的杠杆臂方向正确且必须保留。

## 5. 锁定候选的 held-out 结果

| 数据 | 当前名义 RMSE | `r02` 候选 RMSE | 候选相对改善 |
| --- | ---: | ---: | ---: |
| `remote_r03` | 0.076509 | 0.076844 | **-0.438%** |
| `planar_r03` | 0.049090 | 0.047926 | **+2.371%** |

候选在一条验证 bag 上改善，在另一条上恶化，方向不一致；而且改变量相对 G2S 的 `10%` 输入源实质改善门槛很小。

三条 bag 独立拟合只作可辨识性诊断：

| 数据 | yaw | `r_x` | `r_y` |
| --- | ---: | ---: | ---: |
| `compact_r02` | +0.60 deg | -0.1143 m | +0.0541 m |
| `remote_r03` | -0.50 deg | -0.0925 m | +0.0492 m |
| `planar_r03` | +0.40 deg | -0.1298 m | +0.0556 m |

这个离散度不支持把某一条 bag 的小数点拟合值写入实车配置。

## 6. 冻结决策

当前 runtime 保持：

```text
base_link -> imu_link translation = [+0.100, -0.045, 0.000] m
base_link -> imu_link yaw         = 0 deg
imu -> tube/base target XY        = [-0.100, +0.045] m
imu_to_base_yaw                   = 0 rad
```

决策是：

```text
runtime_extrinsic_action = KEEP_NOMINAL_PLANAR_EXTRINSIC
G2S                     = GO after binding this report/hash
full six-axis claim     = NO
runtime TF/config edit  = NO
r04 required now        = NO
```

这个决策不是“没做外参标定”，而是：使用独立 tuning/validation 证据后，确认当前名义平面外参已落在数据可支持的范围内，且小修正没有一致泛化。
