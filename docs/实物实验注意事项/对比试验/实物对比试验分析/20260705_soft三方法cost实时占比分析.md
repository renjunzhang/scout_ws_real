## 5. 怎么解释今天的结果

### 5.1 progress 仍然是主导项

三组的 `progress_abs` 中位数都在约 `60%~66%`：

```text
B0      p50 ≈ 65.5%
B_slosh p50 ≈ 60.5%
B_ours  p50 ≈ 62.0%
```

说明当前 MPCC 仍主要由 progress reward 推动车体沿路径前进。slosh cost 不是主导项，因此不会把轨迹变成“为了液体完全保守不走”。这也是三包都能 GOAL_REACHED 的原因之一。

### 5.2 slosh cost 虽小，但足以改变局部决策

`B_slosh` 的 slosh 占比：

```text
p50 ≈ 1.46%
p95 ≈ 4.60%
max ≈ 8.05%
```

`B_ours` 的 slosh 占比：

```text
p50 ≈ 2.03%
p95 ≈ 10.17%
max ≈ 20.29%
```

这说明 slosh soft cost 没有压倒 progress，但在局部弯道/激励阶段能进入优化器权衡，因此今天能看到 `/spmpc/slosh_height` 的 p95、RMS 和 max_10_90 下降。

### 5.3 B_ours 的 smooth 不是全程主导，而是局部介入

`B_ours` 的 smooth 占比：

```text
p50 ≈ 0.086%
p95 ≈ 1.827%
max ≈ 22.118%
```

含义：

```text
大部分时间 smooth cost 不大；
少数转向/速度变化阶段 smooth priority 会明显介入；
这解释了 B_ours 的 cmd_omega p95/max 最低。
```

也就是说，`B_ours` 当前不是“全程被 smooth cost 拖死”，而是在局部尖峰处更强地限制控制变化。

### 5.4 为什么 B_ours slosh 不如 B_slosh 低？

虽然 `B_ours` 的 slosh cost 占比比 `B_slosh` 高，但它还同时承担更强的 smooth/control 约束：

```text
B_ours control p95 ≈ 10.45%，max ≈ 19.85%；
B_ours smooth p95 ≈ 1.83%，max ≈ 22.12%。
```

这会让优化器在某些阶段选择“更平滑/更保守的角速度”，而不是最大限度压低 slosh observer。对应今天的现象：

```text
B_slosh：slosh 抑制最强；
B_ours：slosh 也低于 B0，但主要优势是 cmd_omega 更平滑。
```

## 6. 总结

今天 hard 没开，所以这三包是一个干净的 soft-cost 对比。

cost 实时占比说明：

```text
1. B0 的 slosh cost 为 0，符合 baseline 定义。
2. B_slosh 的 slosh cost 中位占比约 1.46%，p95 约 4.60%，足以降低 internal slosh。
3. B_ours 的 slosh cost 中位占比约 2.03%，p95 约 10.17%，同时 smooth/control 在局部更强。
4. progress reward 仍然占 60% 左右，是主导项，所以三者都能稳定到点。
5. B_ours 的 smooth cost 不是全程主导，而是在少数转向变化阶段显著介入，解释了它角速度最平滑但 slosh 抑制不如 B_slosh。
```

一句话结论：

```text
今天的 cost 分布是合理的：slosh soft cost 没有压倒 tracking/progress，但确实在 B_slosh/B_ours 中实时生效；B_slosh 更偏抑制晃动，B_ours 更偏平滑控制。
```
