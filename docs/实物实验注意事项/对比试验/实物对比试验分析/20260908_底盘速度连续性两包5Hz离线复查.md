## 1. 结论与后续判断

**两包均有可信的、与运动阶段相关的约 5 Hz 信号成分，主要证据来自原始 IMU，原始 NOKOV 位姿提供有限支持。支持“没有 MPC 参与发布运动命令时，这类扰动也能出现”，但不足以确认与后来 C03 振动同源，也不能据此认定纵向速度存在周期性卡顿。**

| 问题 | TRAP：梯形速度 | LA：二次速度边沿 |
| --- | --- | --- |
| 主要阶段 | 加速后段、恒速；减速较弱、峰位不稳 | 加速、恒速及减速前中段 |
| 恒速原始 IMU 带内拟合峰 | ay / wx：约 4.73 / 4.74 Hz | ay / wx：约 4.95 / 4.93 Hz |
| 持续纹波 | 恒速前后半段均保留目标频带成分 | 恒速前后半段均保留目标频带成分 |
| 停车后衰减尾波 | 较晚尾段约 7.0～7.25 Hz | 较晚尾段约 6.35～6.45 Hz |
| 命令对应成分 | 恒速严格为 0.8 m/s，未见对应的持续周期调速 | 同左 |

恒速约 2 s，FFT bin 约 0.5 Hz，Hann 等效噪声带宽约 0.76 Hz。表中小数来自原生时间正弦拟合的搜索结果，**不代表 ±0.01 Hz 的辨识精度**。两包还有明显的约 6～10 Hz 成分，不能概括为全程只有一个固定 5 Hz 主峰。

旧报告支持“odom 整体连续、孤立 NOKOV 二次求导尖峰不可靠”；这一点仍保留。旧结论不能扩展为“原始传感器不存在任何小幅高频扰动”。本复查针对频带问题，不将它直接升级为底盘卡顿或结构共振的唯一因果结论。

## 3. 命令与传感器证据

每包 `/cmd_vel` 共 736 条：预设轮廓发布器 729 条，另有 7 条收尾零命令；stamped 副本各 732 条。以接收时刻 10 ms 门限、禁止重复使用样本配对，729 条实际主命令全部匹配，六个 Twist 分量误差均为 0。余下 3 条副本处于快速阶段边界且数值重复。旧审计的“100%”是可重复使用最近邻的覆盖率，不等于 732 对唯一对应。

bag 的命令来源、metadata 与预设轮廓共同支持本次运动命令没有由 MPC 生成；不能仅凭录包白名单里没有 MPC 话题来作此判断。`/cmd_vel` 无 header，其 bag 接收时刻只用于数值审计和次要时间抖动诊断，**不作精确物理相位**。stamped 坡段内部去趋势后的目标带拟合峰幅仅约 `3～6×10⁻⁶ m/s`；完整坡段端点残差不能解释成持续周期命令。速度连续也不意味着阶段切换处加速度连续，仍可激发瞬态。

以下均为本次相同处理定义下的 4.5～5.5 Hz 带内 RMS，不与旧图不同平滑后的振幅混比：

| 通道与阶段 | TRAP | LA |
| --- | ---: | ---: |
| IMU ay，起步前静止（m/s²） | 0.000401 | 0.000429 |
| IMU ay，恒速（m/s²） | 0.04937 | 0.04991 |
| IMU wx，恒速（rad/s） | 0.006705 | 0.006551 |
| NOKOV cross，起步前静止（mm） | 0.01466 | 0.02415 |
| NOKOV cross，恒速（mm） | 0.08973 | 0.07711 |
| NOKOV z，起步前静止（mm） | 0.06744 | 0.05351 |
| NOKOV z，恒速（mm） | 0.07197 | 0.05893 |

原始 IMU 的目标带成分在运动时明显增加；原始 NOKOV 横向投影和部分姿态有邻频支持，**z 则接近静止背景，不能单独证明真实振动**。NOKOV `cross` 是世界平面净位移方向的垂直投影，不是已标定的底盘横轴；没有用动捕二次求导尖峰作振动证据。odom 恒速目标带 RMS 约 `0.00047/0.00124 m/s`，未提供强的同频纵向速度证据。

停车尾段的原始 IMU ax 存在衰减摆动。`post_zero+0.28～1.2 s` 拟合约为 TRAP `7.0 Hz / 0.20 s`、LA `6.35 Hz / 0.22 s`；提前到 `+0.18 s` 纳入大幅反弹，会变为约 `5.5/5.6 Hz`。不能挑选接近 5 Hz 的窗口认定同一模态。该拟合仅描述 IMU 输出，不等于已辨识机械阻尼；动捕停车后大量重复位姿，也没有充分独立支持该尾波。

## 4. 方法与限制

阶段以 metadata 首末 stamped header 定义，并核对阶段标签。各阶段独立处理；另取 `core=[first+0.4 s,last−0.1 s]` 检查边界影响。速度坡段按 TRAP 一次/LA 二次趋势去除，位置对应二次/三次，IMU 和姿态用一次趋势；保留原曲线并增加一阶检查敏感性。未拼接阶段做频谱。

采用整窗 Hann PSD、无补零，先看 0.5～20 Hz，再积分 4.5～5.5 Hz。原生时间联合拟合多项式与正弦；另用固定 5 Hz、1 s 滑窗及不重叠恒速两半检查持续性。两秒数据不能证明长期相位稳定，重叠滑窗不算独立重复试验，未以单窗 coherence 作为证据。

IMU/odom 约 50 Hz；NOKOV 平均约 90 Hz，但典型间隔约 10 ms，夹杂近同时突发消息及 20～70 ms 空隙。NOKOV 停车后相邻完整位姿重复比例约 87%/86%，因此静止噪声底也需谨慎解释。异常间隔邻点剔除仅用于保留原时间轴的拟合敏感性检查，不将剩余点拼为等间隔 FFT。

原始 IMU 仍包含重力投影、安装位置运动和设备处理；IMU 与 NOKOV 外参、杆臂、物理时延、设备滤波及抗混叠未由旧包核实。小于 1 ms 的 header 到 bag 时间差不能代替物理时延标定。没有给出精确纵向增益、跨传感器物理相位或唯一根因。
