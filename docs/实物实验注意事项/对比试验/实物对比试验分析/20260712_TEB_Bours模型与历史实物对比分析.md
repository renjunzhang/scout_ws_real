```text
TEB tracking p95:         15.4cm
0712 B_ours gate:          3.84cm
0705/0706 SPMPC methods: 约 3~5cm
```

同时：

```text
TEB cmd_v mean 10%~90%:       0.300m/s
B_ours gate cmd_v mean:        0.318m/s
TEB |omega| p95:               0.153rad/s
B_ours gate |omega| p95:       0.212rad/s
```

TEB 使用更低角速度，并允许更大的路径偏差，因此更快到点且模型晃液更低。当前结果支持：

```text
在 tracking p95 <=0.30m 的预设 gate 内，TEB 是成功、快速且模型高度较低的外部 baseline。
```

但不支持：

```text

```

正式表必须同时展示 tracking、goal time、actual cmd 和模型高度，不能只按 slosh peak 排序。

## 7. 当前结论

1. TEB 三次均成功到点、无人工接管、runner limiter fraction 为 `0`。
2. TEB 描述性 N=3 的模型高度低于当日 B_ours gate；保守 clean N=2 和统一 odom replay 仍保持同一方向。
3. TEB 的模型侧表现约等于历史最强的 B_slosh，并明显低于历史 B0、B_smooth 和 B_ours。
4. 0712 B_ours gate 与 0705/0706 B_ours 历史结果一致，可作为有效当日 bridge。
5. TEB 的代价是 tracking p95 增至约 `15.4cm`，约为 B_ours gate 的 4 倍；其更低模型高度不能脱离这一任务质量差异解释。
6. TEB N3 存在核心段 rosbag buffer drop，当前只能记为 diagnostic/descriptive run。若论文要求 clean formal N=3，应修复录包吞吐后补跑一次替代 N3。
7. 本报告未使用 RGB；真实液面结论仍需后续统一 RGB `H_vis` 分析确认。

## 8. 为什么 TEB 的 model peak 低于 B_ours

保守 clean TEB N=2 与当日 B_ours gate 的 `10%~90%` 执行量对比：

| metric | TEB clean N=2 | B_ours gate | difference |
|---|---:|---:|---:|
| actual/cmd `v` mean | `0.300m/s` | `0.318m/s` | TEB 低约 `5.8%` |
| cmd `v` p95 | `0.300m/s` | `0.428m/s` | TEB 没有同样的速度上冲 |
| `|omega|` p95 | `0.159rad/s` | `0.212rad/s` | TEB 低约 `24.9%` |
| `|omega|` max | `0.247rad/s` | `0.270rad/s` | TEB 低约 `8.5%` |
| tracking p95 | `15.47cm` | `3.84cm` | TEB 约为 `4.0x` |
| goal time | `33.65s` | `37.62s` | TEB 快约 `10.6%` |

slosh model 的主要输入为：

```text
ax = dv/dt
ay = v * omega
```

因此当前 peak 排序主要由以下因素共同造成：

```text
1. TEB 的角速度 p95 明显更低，直接降低横向激励 |v*omega|；
2. TEB 的线速度几乎固定在 0.30m/s，没有 B_ours 约 0.43m/s 的 p95 上冲，
   因而纵向加速度激励也更弱；
3. TEB tracking p95 达到约 15.4cm，说明它没有像 B_ours 那样紧贴 fixed path，
   在弯道可能采用更缓的实际曲率或切弯，从而进一步减少转向激励；
4. TEB 即使平均速度略低，仍更快到点，也支持“实际运动路径更直接/跟踪更松”
   而不是“单纯靠大幅降速换低 peak”的解释；
5. B_ours 同时优化 progress、tracking、slosh 和 smooth，不是只最小化模型高度。
```

另外，方法原生 peak 的降幅约 `41.2%`，而相同 odom evaluator 下的降幅为
`29.7%`。约一部分差异来自 B_ours delay-compensated internal state 与 standalone
monitor 输入/滤波链路不同，但统一 evaluator 仍保留明显差异，所以不能全部归因于
模型统计口径。

当前最合理的结论是：

```text
TEB 的 model peak 更低，主要因为转向激励更小、速度变化更弱，并以更松的路径跟踪
作为代价；速度均值略低是次要因素，不是唯一原因。
```
