## 0. 汇报主线（一句话版）

从原来的 **fixed-path tracking MPC 纯控制器**，升级到当前 **slosh-aware continuous MPCC 规控一体 SPMPC**：把路径进度、局部轨迹、控制输入和液体二阶模态状态放进同一个滚动优化问题；同时用 RGB 真值验证模型保真度，并在仿真/实物中分析不同 slosh-aware 设计的有效性与局限。

建议主结论不要讲成“我们已经完全证明方法最优”，而应讲成：

1. 已经完成从纯跟踪控制到规控一体 SPMPC 的系统搭建。
2. slosh model 有明确二阶 ODE 物理来源，能作为趋势 proxy，但不能替代 RGB 真值。
3. 实物中单独 slosh cost 未必有效，`B_slosh` 反而引起更强速度调制；`B_ours` 的优势来自 **slosh cost + smooth/control shaping**。
4. 当前结果支持“规控一体 + 平滑优先级”这条路线，但还需要更严格的完整 N=3 仿真、DWA/MPC 实物补齐、模型参数/约束升级。

### Slide 3. 研究背景：为什么移动机器人运输液体很难

**Takeaway**：移动机器人运输开口液体时，路径跟踪性能和液面稳定性不是独立问题。

**要点**：
- 底盘加减速、转向角速度和角加速度会激发液体晃动。
- 单纯追求路径跟踪/到点速度，可能导致液面峰值增大。
- 液体晃动具有 **动态记忆**：当前液面不只由当前加速度决定，还与历史激励有关。
- 因此需要把“走得准、走得快、晃得小”放在同一个优化框架里权衡。

**图建议**：
```text
底盘运动输入 a/omega/alpha  →  容器惯性激励  →  液体二阶响应  →  液面峰值/残振
```

### Slide 4. 问题定义：液体运输中的多目标冲突

**Takeaway**：本项目关注 fixed path 场景下的局部规控：沿给定路径到达目标，同时抑制晃液。

**建议公式/定义**：

- 给定全局/固定参考路径：
  \[
  \mathcal{P}(s)=[x_r(s), y_r(s), \theta_r(s)]
  \]
- 当前 SPMPC OCP 控制变量：
  \[
  u=[a,\alpha,v_s]
  \]
  旧 `scout_local_planner` 的控制量不同，本页只作为当前方法的问题定义。
- 目标：
  - tracking / contour error 小
  - progress 快
  - 控制平滑
  - slosh response 小

**可讲句子**：
- “我们不是只做液体检测，也不是只做路径跟踪，而是把晃液状态放进局部规控优化。”

### Slide 9. 为什么纯控制器不够

**Takeaway**：固定参考跟踪控制难以主动调整路径进度和控制平滑策略来避免激发液体。

**要点**：
- 如果参考速度或路径进度已固定，控制器只能被动跟踪。
- 液体响应有滞后，局部短期“减速/再加速”可能反而激发晃动。
- 需要优化器在 horizon 内决定：
  - 什么时候推进路径进度；
  - 什么时候牺牲速度换平滑；
  - 如何避免高频速度调制。

**连接到后文实物结果**：
- 实物中 `B_slosh` slosh cost 已启用，但速度调制更强，液面反而更高。
- 这说明“有 slosh cost”不等于“真实液面一定降低”。

### 4.1 Slosh model 的来源与保真度

### Slide 10. Slosh model 来源：二阶模态 ODE

**Takeaway**：当前 slosh model 是带记忆的二阶动力系统，不是静态加速度映射。

**来源路径**：
- `/data/a/Obsidian/vaults/StudyVault/30-Projects/MPC/当前晃液二阶ODE模型理解.md`
- `src/scout_apps/control/slosh_models/include/slosh_models/liquid_slosh_model.h`
- `src/scout_apps/control/slosh_models/src/liquid_slosh_model.cpp`
- `docs/重要文档/论文参考总结/Ferrari2026_方法剖析.md`
- `docs/重要文档/论文参考总结/Scout当前晃液模型与Ferrari2026模型差异总结.md`

**参考来源**：
- 当前代码注释参考：*Sloshing Dynamics Estimation for Liquid-filled Containers under 2-Dimensional Excitation*，ECCOMAS 2021。
- Ferrari 2026 用作方法对照：MSD 模型、闭式高度系数、残振评价等可借鉴，但任务形态不同，不能直接照搬。

**公式**：

\[
\ddot{\eta}_x+2\zeta\omega_n\dot{\eta}_x+\omega_n^2\eta_x=-a_x
\]

\[
\ddot{\eta}_y+2\zeta\omega_n\dot{\eta}_y+\omega_n^2\eta_y=-a_y
\]

\[
x_{slosh}=[\eta_x,\dot{\eta}_x,\eta_y,\dot{\eta}_y]^T
\]

**可讲数字**：
- 当前容器参数下：`omega_n ≈ 31.25 rad/s`，`f_n ≈ 4.97 Hz`。
- 对当前容器参数/一阶模态，当前 height coefficient 比 Ferrari 闭式口径约高 `18%`，更保守但不一定更贴合视觉真值。

### 4.2 我们的方法的数学分析

### Slide 14. SPMPC 状态、控制与动力学

**Takeaway**：SPMPC 将路径进度与机器人动力学、液体模态状态统一建模。

**主线状态**：

\[
x=[p_x,p_y,\theta,v,s,\omega,\eta_x,\dot{\eta}_x,\eta_y,\dot{\eta}_y]^T
\]

**控制输入**：

\[
u=[a,\alpha,v_s]^T
\]

**机器人连续动力学**：

\[
\dot{p}_x=v\cos\theta,\quad \dot{p}_y=v\sin\theta
\]

\[
\dot{\theta}=\omega,\quad \dot{v}=a,\quad \dot{\omega}=\alpha,\quad \dot{s}=v_s
\]

**液体模态动力学**：

\[
\ddot{\eta}_x+2\zeta\omega_n\dot{\eta}_x+\omega_n^2\eta_x=-a_x,\quad
\ddot{\eta}_y+2\zeta\omega_n\dot{\eta}_y+\omega_n^2\eta_y=-a_y
\]

上述方程分别沿 body x/y 方向成立；当前主实验默认容器偏置为零，因此可写成该简化分轴形式。

**讲法**：
- `s` 让路径进度成为优化变量。
- `alpha` 让角速度平滑进入模型本身。
- `eta` 让优化器看到液体的历史响应。

---

### Slide 15. 目标函数：contour/lag/progress/smooth/slosh 的统一权衡

**Takeaway**：SPMPC 的目标不是简单跟踪时序参考，而是沿路径推进并控制晃液激励。

**建议写成简化形式**：

\[
\min \sum_{k=0}^{N-1}
q_c e_{c,k}^2 + q_l e_{l,k}^2
- q_p v_{s,k}
+ q_v(v_k-v_{ref,k})^2
+ r_u\|u_k\|^2
+ r_{\Delta u}\|\Delta u_k\|^2
+ q_\eta\|\eta_k\|^2
+ q_{\dot{\eta}}\|\dot{\eta}_k\|^2
+ J_{terminal}
\]

**代价分解 topic**：`/spmpc/cost_breakdown`

字段可对应：
- `J_contour`
- `J_lag`
- `J_progress`
- `J_v`
- `J_control`
- `J_smooth`
- `J_slosh_eta`
- `J_slosh_eta_dot`

**讲法**：
- `B0`：无 slosh cost。
- `B_slosh`：加入 slosh cost。
- `B_ours`：slosh cost + 更强 smooth/control shaping。

### Slide 16. 约束与当前边界

**Takeaway**：当前主线已具备运动学/控制约束，但 corridor/obstacle/hard slosh 还不能过度宣传。

**当前主线约束**：

\[
v_{min}\le v\le v_{max}
\]

\[
\omega_{min}\le \omega\le \omega_{max}
\]

\[
a_{min}\le a\le a_{max},\quad \alpha_{min}\le \alpha\le \alpha_{max}
\]

\[
v_{s,min}\le v_s\le v_{s,max}
\]

**必须说清楚的边界**：
- corridor/obstacle/homotopy 接口已有，但当前主线不能说成完整接入。
- slosh hard constraint 当前不应作为已验证主结论。

| variant | slosh p95 | slosh peak | p95 `|dv/dt|` | mean `v` | mean `J_slosh_total` | mean `pct_slosh_total` |
|---|---:|---:|---:|---:|---:|---:|
| `B0` | 1.128 mm | 1.912 mm | 0.405 | 0.350 | 0.0000 | 0.00% |

- `B_slosh` 不是 cost 没加载；slosh cost 平均占比 `11.81%`。

### Slide 26. 当前阶段结论

**Takeaway**：当前阶段支持“slosh-aware + smooth priority”的路线，但不能过度宣传单独 slosh cost 或最终全 planner 优劣。

**可以明确说**：
1. SPMPC 规控一体主线已打通，具备仿真和实物闭环证据。
2. slosh model 有物理来源，趋势可用，绝对值需要 RGB 校验。
3. 实物中 `B_ours` 相比 `B_slosh` 显著降低液面。
4. `B_slosh` 没优于 `B0` 的原因，很可能是单独 slosh cost 引起更强速度调制。

**不能过度说**：
1. 不能说 `B_slosh` 已严格优于 `B0`。
2. 不能说 TEB 一定优于/劣于 SPMPC。
3. 不能把 `/spmpc/slosh_height` 当真实液面。
4. 不能把跨批次 strict 结果拼成最终论文级四 planner 结论。
5. 仿真中 MPC/TEB/DWA 有 strict 证据，但实物中 TEB 仍需原始 calibration 复核，DWA/MPC 实物证据尚未齐。
