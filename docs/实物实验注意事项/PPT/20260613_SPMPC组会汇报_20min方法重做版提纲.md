## 3. 数学证明/分析讲法

### 3.1 Markov 增广

晃液模型不是静态映射：

```text
当前液面 != f(当前加速度)
```

而是有内部状态的二阶系统：

```text
x_slosh = [eta_x, eta_x_dot, eta_y, eta_y_dot]^T
```

只用车辆状态 `[x,y,theta,v]` 时，对晃液问题不是 Markov；加入 `eta/eta_dot` 后可以写成：

```text
s_{k+1}=f(s_k,u_k)
```

这就是它能进入 MPC/MPCC horizon 预测的理由。

### 3.2 二阶 ODE 与离散化

连续模型：

```text
eta_ddot_x + 2*zeta*omega_n*eta_dot_x + omega_n^2*eta_x = -a_x
eta_ddot_y + 2*zeta*omega_n*eta_dot_y + omega_n^2*eta_y = -a_y
```

状态空间：

```text
x_dot = A_c x + B_c u
x_{k+1} = A_d x_k + B_d u_k
A_d = exp(A_c T_s)
```

### 3.3 为什么 slosh-aware 不等于 smooth-only

模态响应可以写成卷积形式：

```text
x_k = A_d^k x_0 + sum(A_d^{k-1-j} B_d u_j)
```

因此液面响应依赖整段控制序列、残振状态和相位。两条控制序列即使有相同的平滑度或加速度范数，也可能产生不同液面峰值。`smooth-only` 只是间接减少激励，`slosh-aware` 则直接惩罚预测的 `eta/eta_dot` 响应。

### 3.4 谨慎 claim

可以说：

> 在稳定二阶模态模型下，slosh-aware 代价能够直接约束预测液面响应，并给出预测 RMS/peak 上界关系。

不能说：

> 已证明当前非凸实时 OCP 全局最优，或已用模型 proxy 证明实物真实降晃。
