# 20260611 隔离 Scout Mini 仿真环境使用 SOP

## 结论

以后常规仿真、Cartographer 定位、SPMPC 固定路径跟踪、仿真版主线 smoke，默认使用隔离仿真环境：

```text
/data/a/scout_sim_replacement
```

不再把 `/home/a/scout_ws` 里的旧仿真环境作为日常仿真入口。旧 workspace 只作为只读代码/接口参考，或在明确需要对比旧仿真时单独说明后再使用。

## 安全边界

- 新仿真文件、地图、日志、结果都放在 `/data/a/scout_sim_replacement`。
- 不修改旧仿真 world/map/URDF/model/spawn/Cartographer/TF 等文件。
- 不删除旧代码、旧 bag、旧实验数据。
- 不使用 `git reset`、`git clean`、`git checkout`、`git push`。
- 不使用 broad `killall` / `pkill`。
- 运行脚本只停止自己追踪到的子进程 PID。
- `/home/a/scout_ws` 可以被只读 source，用来复用现有 `spmpc_local_planner`、Cartographer 包和 teleop 工具，但不作为仿真环境修改对象。

## 推荐启动方式：两步启动

### 1. 启动仿真 + Cartographer 定位 + RViz

```bash
MAP_FILE=/data/a/scout_sim_replacement/maps/proxy_world_manual_saved_20260611_154348.pbstream \
USE_RVIZ=true \
/data/a/scout_sim_replacement/scripts/launch_proxy_sim_localization_env.sh
```

该命令只启动：

```text
roscore
proxy Gazebo sim
Cartographer localization
proxy tracking RViz
```

不会启动 SPMPC，也不会发布跟踪路径。

启动后先确认 RViz 中能看到：

```text
/map
/scan_front
RobotModel
TF
```

### 2. 另开终端接入 SPMPC + S-curve 路径

```bash
GOAL_X=5.0 GOAL_Y=0.0 GOAL_YAW=0.0 \
PATH_TEMPLATE=s_curve \
/data/a/scout_sim_replacement/scripts/launch_proxy_spmpc_localized_attach.sh
```

该命令只启动：

```text
/scout/global_path_fixed publisher
spmpc_local_planner
```

不会重新启动 roscore、Gazebo、Cartographer、RViz。

默认 attach 脚本会等 `/proxy_tracking_rviz` 存在后再启动 SPMPC，确保先看地图和定位，再跑控制。

## 一键启动方式

需要快速启动完整流程时可以使用：

```bash
MAP_FILE=/data/a/scout_sim_replacement/maps/proxy_world_manual_saved_20260611_154348.pbstream \
USE_RVIZ=true \
GOAL_X=5.0 GOAL_Y=0.0 GOAL_YAW=0.0 \
PATH_TEMPLATE=s_curve \
/data/a/scout_sim_replacement/scripts/launch_proxy_sim_localization_spmpc.sh
```

该脚本内部顺序为：

```text
proxy sim -> Cartographer localization -> 等 /map 和 TF ready -> tracking RViz -> S-curve path/SPMPC
```

## 手动建图流程

### 1. 启动建图环境

```bash
MAP_BASENAME=proxy_world_manual_$(date +%Y%m%d_%H%M) \
USE_RVIZ=true \
MAPPING_RVIZ=true \
/data/a/scout_sim_replacement/scripts/build_proxy_world_cartographer_map.sh
```

建图环境使用：

```text
ROS_MASTER_URI=http://localhost:11332
GAZEBO_MASTER_URI=http://localhost:11366
```

### 2. 另开终端启动键盘遥控

```bash
source /opt/ros/noetic/setup.bash
source /home/a/scout_ws/devel/setup.bash
export ROS_MASTER_URI=http://localhost:11332

roslaunch scout_bringup scout_teleop_keyboard.launch
```

说明：这里复用 `/home/a/scout_ws` 的 teleop 工具，只发布 `/cmd_vel`，不修改旧 workspace。

### 3. 建图驾驶建议

- 慢速前进、慢速转弯。
- 沿边界走，尽量覆盖墙和角点。
- 尽量闭环回到起点附近。
- 不要长时间原地快速自转；带一点前进更利于建图。
- 建议线速度约 `0.15 ~ 0.25 m/s`，角速度约 `0.3 ~ 0.5 rad/s`。

### 4. 保存地图

如果建图脚本仍在前台运行，回到建图终端按：

```text
Ctrl-C
```

脚本会捕获中断并保存地图。

如果已经建完但脚本没保存，也可以在 mapping 仍运行时手动调用 `/write_state` 保存；保存目标必须在 `/data/a/scout_sim_replacement/maps` 下。

## 关键 TF 链

定位/建图时应该存在：

```text
map
└── odom
    └── base_footprint
        └── base_link
            ├── nanoscan3_front
            └── imu_link
```

检查命令：

```bash
source /opt/ros/noetic/setup.bash
export ROS_MASTER_URI=http://localhost:11328
rosrun tf tf_echo map base_link
```

建图环境中端口换成：

```bash
export ROS_MASTER_URI=http://localhost:11332
```

检查雷达：

```bash
rosrun tf tf_echo map nanoscan3_front
```

## 常用检查命令

### 查看关键话题

```bash
source /opt/ros/noetic/setup.bash
export ROS_MASTER_URI=http://localhost:11328

rostopic list | grep -E '^/(map|scan_front|odom|cmd_vel|cmd_vel_drive|scout/global_path_fixed|spmpc/status)$'
```

### 查看 SPMPC 状态

```bash
rostopic echo /spmpc/status
```

### 查看地图是否有数据

```bash
rostopic echo -n 1 /map
```

## 旧 scout_ws 仿真环境使用原则

默认不再使用旧仿真入口，例如：

```bash
rosrun scout_local_planner launch_sim_nav_stack.sh
```

除非明确要做旧仿真对比或排查历史差异，否则不要再用旧仿真环境作为 SPMPC 仿真测试入口。

常规流程统一使用 `/data/a/scout_sim_replacement`。
