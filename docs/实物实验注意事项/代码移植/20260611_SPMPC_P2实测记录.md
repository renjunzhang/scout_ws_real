## RGB 液面分析（TRACKING 窗口）

去掉起点静止段和终点 TERMINAL_SLOWDOWN/REACHED 段，仅统计 TRACKING 阶段的视觉液面。

RGB 推断命令：

```bash
python3 src/scout_apps/sensors/realsense_liquid_measurement/scripts/red_liquid_infer_from_bag.py \
  --bag <BAG> \
  --calibration /home/geist/slosh_bags/real/20260611_calib/red_3ruler.yaml \
  --out-dir <OUT_DIR> \
  --topic /camera/color/image_raw \
  --zero-correction-frames 30 \
  --smooth-frames 5 \
  --debug-every 30
```

指标口径：`max-LCR smooth = rolling_median(max(h_left, h_center, h_right), window=5)`，对应文档 `红色液体视觉验证固定流程.md` §5 的 `H_vis(t)`。

### 结果对比

| variant | TRACKING 时长 | 帧数 | max-LCR p95 | max-LCR peak | max-LCR rms | median p95 | progress |
|---|---|---|---|---|---|---|---|
| **B0** | 37s | 1012 | **1.10 mm** | 1.52 mm | 0.68 mm | 0.68 mm | 0 → 99.3% |
| **B_slosh** | 41s | 1106 | **2.74 mm** | 3.33 mm | 1.61 mm | 2.31 mm | 0 → 99.7% |
| **B_ours** | 41s | 1103 | **1.59 mm** | 2.46 mm | 0.94 mm | 1.01 mm | 0 → 100.0% |

### 判读

```text
1. B0（纯 tracking，无 slosh）：基准液面 p95 = 1.10 mm，全场最低。
2. B_slosh（slosh state + cost，无 smooth priority）：液面反而最高（2.74 mm），
   比 B0 高出 1.64 mm。单独加 slosh cost 不降真实液面。
3. B_ours（slosh state + cost + smooth priority）：液面拉回 1.59 mm，
   比 B_slosh 降低 1.15 mm（42%），接近 B0 水平。
   
   结论：smooth priority 叠加对真实液面抑制有效；
   单独 slosh cost 不足以降低视觉液面，需与 smooth priority 联合使用。
```

按 `红色液体视觉验证固定流程.md` §7.1.4 口径：RGB p95 差值 0.49 mm（B_ours vs B0），在 1920x1080 分辨率下属于可分辨差异。
