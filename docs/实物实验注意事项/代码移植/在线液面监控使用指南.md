# 在线液面监控使用指南

一站启动 RGB 视觉液面 + 独立 slosh 模型 + 监控面板。不依赖 SPMPC，TEB/DWA/SPMPC 通用。

## 1. 前提

- 传感器栈已启动（`/camera/color/image_raw`、`/odom`）
- 当天已完成三标尺 + HSV 标定，YAML 就绪

## 2. 一站启动

```bash
roslaunch realsense_liquid_measurement online_liquid_monitor_combined.launch \
  calibration:=/home/geist/slosh_bags/real/<DATE>_calib/red_3ruler.yaml
```

可选偏置（静止时显示 -3mm 就设 3.0）：

```bash
roslaunch realsense_liquid_measurement online_liquid_monitor_combined.launch \
  calibration:=/home/geist/slosh_bags/real/20260611_calib/red_3ruler.yaml \
  height_bias_mm:=3.0
```

偏置也可写入 `red_3ruler.yaml` 的 `height_bias_mm:` 字段，一劳永逸。

## 3. 窗口说明

启动后弹出 matplotlib dark 面板，五个区域：

| 区域 | 内容 |
|---|---|
| 左上 | RGB overlay（`/liquid/debug_image`） |
| 右上 | SPMPC 状态 / solver 耗时 |
| 中左 | **Height Trend** — 实时液面趋势图 |
| 中右 | KPI 卡片（RGB p95/peak、模型 p95、odom 速度） |
| 底部 | 按钮栏 + 话题健康状态 |

### Height Trend 曲线

| 线 | 颜色 | 含义 |
|---|---|---|
| **max** | 青色粗线 | RGB max-LCR（左中右三标尺取最大），**真实液面高度** |
| L / C / R | 浅蓝/绿/橙 | 三列各自高度 |
| **model** | 紫色虚线 | 独立 slosh 模型高度（读 `/odom` 推算，不依赖 SPMPC） |

## 4. 单组实验标准操作

每组 variant 对照：

```text
1. 窗口点 START  ─→ 开始录制 session
2. 启动 planner / 跑完一圈
3. 窗口点 STOP   ─→ 停止录制
4. 窗口点 ZERO   ─→ 归零（可选，静止时校准）
5. 窗口点 EXPORT ─→ 保存 CSV + SVG 曲线
6. 下一组：再点 START，重复
```

### EXPORT 输出

保存到 `~/liquid_monitor_exports/`：

```text
liquid_session_20260611_223000.csv   ← 逐帧数据
liquid_session_20260611_223000.svg   ← 高度趋势图
```

CSV 列：`t_s, max_lcr_mm, L_mm, C_mm, R_mm, model_h_mm, cmd_v, odom_v, solver_ms`

## 5. 一键归零

如果自动零点偏了，等液体静止后：

```bash
rosservice call /online_liquid_height/reset_zero
```

或者窗口点 **ZERO** 按钮（只归当前显示，不重置自动零点）。

## 6. 按钮

| 按钮 | 颜色 | 功能 |
|---|---|---|
| START | 绿 | 清空 session，开始录制 |
| STOP | 红 | 停止录制 |
| ZERO | 黄 | 以当前高度为零点 |
| EXPORT | 蓝 | 导出 CSV + SVG |

## 7. 常开配置

默认 `max_session_sec:=0`（不限时），`history_sec:=60`（趋势图显示最近 60 秒）。如需调整：

```bash
roslaunch realsense_liquid_measurement online_liquid_monitor_combined.launch \
  calibration:=... \
  _history_sec:=120.0 \
  _max_session_sec:=0.0
```

## 8. 故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| 窗口无 RGB overlay | 检测节点未连接相机 | 确认 `/camera/color/image_raw` 有数据 |
| Height Trend 显示 "Waiting" | `/liquid/height` 无数据 | 确认 online_liquid_height 节点存活，检查标定路径 |
| 紫色 model 线无数据 | slosh_monitor 死了或 `/odom` 无数据 | `rosnode list | grep slosh`，确认 odom 正常 |
| 静止时显示非零 | 零点自动估计偏差 | 点 ZERO 或设 `height_bias_mm:=` 修正 |
| 窗口关闭 | Ctrl-C 或点 q/Esc | 重跑 launch 即可，不影响传感器栈和 planner |

## 9. 管线架构

```
相机 ─→ online_liquid_height ─→ /liquid/height          ─┐
                    (RGB max-LCR)  /liquid/debug_image      │
                                                            ├─→ liquid_monitor 窗口
/odom ─→ slosh_monitor ─→ /slosh/height                  ─┘
/cmd_vel            (独立模型, 不依赖 SPMPC)
```

两个检测源互不依赖，任意一个挂了不影响另一个。关闭监控窗口不影响数据流。
