# 在线液面监控使用指南

本指南用于实物现场的 **RGB 红色液体在线监控**。

当前推荐的一站式监控只做：

```text
RealSense RGB → online_liquid_height → /liquid/height, /liquid/height_lcr, /liquid/debug_image → dashboard
```

它 **不启动独立 slosh model**，也不把 `/slosh/height` 画到右侧波形图里。右侧 Height Trend 只对应 RGB 检测得到的高度数据：`max-LCR / L / C / R`。

论文/正式分析仍以离线 bag 后处理为准；在线监控用于现场安全观察、标定检查和快速判断。

---

## 1. 前提

- 传感器栈已启动，至少有：
  - `/camera/color/image_raw`
- 当天已完成三标尺标定，YAML 就绪。
- HSV 参数必须显式记录在 launch 命令中，避免默默使用代码默认值。
- 启动监控后，建议先让液体静止，等待在线节点锁定前 30 帧零点，再启动 planner。

---

## 2. 一站式 RGB-only 启动（推荐）

```bash
roslaunch realsense_liquid_measurement online_liquid_monitor_combined.launch \
  calibration:=/home/geist/slosh_bags/real/<DATE>_calib/red_3ruler.yaml \
  image_topic:=/camera/color/image_raw \
  process_every:=1 \
  height_bias_mm:=0.0 \
  hue1_low:=0 hue1_high:=11 \
  hue2_low:=173 hue2_high:=179 \
  sat_min:=80 val_min:=162
```

20260611 P2 本批实测口径示例：

```bash
roslaunch realsense_liquid_measurement online_liquid_monitor_combined.launch \
  calibration:=/home/geist/slosh_bags/real/20260611_calib/red_3ruler.yaml \
  image_topic:=/camera/color/image_raw \
  process_every:=1 \
  height_bias_mm:=0.0 \
  hue1_low:=0 hue1_high:=11 \
  hue2_low:=173 hue2_high:=179 \
  sat_min:=80 val_min:=162
```

说明：

- `online_liquid_monitor_combined.launch` 会启动：
  - `online_liquid_height_node.py`
  - `liquid_experiment_monitor.py`
- 它不会启动 `slosh_models/slosh_monitor.launch`。
- dashboard 的 `show_model=false`，右侧波形图只显示 RGB 曲线。

## 3. 只发布 `/liquid/*`，不打开 dashboard

如果只需要在线发布 RGB 液面 topic，不需要 matplotlib 面板：

```bash
roslaunch realsense_liquid_measurement online_liquid_height.launch \
  calibration:=/home/geist/slosh_bags/real/<DATE>_calib/red_3ruler.yaml \
  image_topic:=/camera/color/image_raw \
  process_every:=1 \
  publish_debug:=true \
  height_bias_mm:=0.0 \
  hue1_low:=0 hue1_high:=11 \
  hue2_low:=173 hue2_high:=179 \
  sat_min:=80 val_min:=162
```

发布：

| topic | 类型 | 含义 |
|---|---|---|
| `/liquid/height` | `std_msgs/Float32` | RGB max-LCR 高度，带在线零点和 `height_bias_mm` 修正 |
| `/liquid/height_lcr` | `std_msgs/Float32MultiArray` | `[left, center, right]` 三列高度 |
| `/liquid/height_median` | `std_msgs/Float32` | 三列 median 质检量 |
| `/liquid/debug_image` | `sensor_msgs/Image` | overlay 调试图，需 `publish_debug:=true` |

---

## 4. HSV 参数

当前实物 RGB 推断建议显式使用：

```text
hue1_low=0
hue1_high=11
hue2_low=173
hue2_high=179
sat_min=80
val_min=162
```

这些参数已经暴露在：

```text
online_liquid_height.launch
online_liquid_monitor_combined.launch
```

不要只依赖代码默认值。代码默认 HSV 是通用默认值，不等价于当前实物 P2 这批离线 RGB 分析口径。

---

## 5. `height_bias_mm` 符号规则

在线节点计算逻辑是：

```text
published_height = raw_max_lcr - auto_zero_h0 - height_bias_mm
```

因此 `height_bias_mm` 的符号应 **与当前静止显示值同号**：

| 静止时在线显示 | 应设置 |
|---:|---:|
| `+3 mm` | `height_bias_mm:=3.0` |
| `-3 mm` | `height_bias_mm:=-3.0` |
| `0 mm` | `height_bias_mm:=0.0` |

不要写反。若显示 `-3mm` 却设 `height_bias_mm:=3.0`，会被修成约 `-6mm`。

---

## 6. 自动零点与重置

`online_liquid_height_node.py` 会用前 30 个有效处理帧锁定在线零点 `h0`。

现场建议：

```text
1. 启动在线监控。
2. 保持车辆和液体静止。
3. 等日志出现 zero locked。
4. 再启动 planner 或开始实验。
```

如果自动零点锁错了，保持液体静止后重置：

```bash
rosservice call /online_liquid_height/reset_zero
```

dashboard 里的 **ZERO** 按钮只用于当前显示/导出的 session 归零，不等价于重置 `online_liquid_height_node.py` 的自动零点。

## 7. 窗口说明

启动后弹出 matplotlib dark 面板：

| 区域 | 内容 |
|---|---|
| 左上 | RGB overlay：`/liquid/debug_image` |
| 右上 | Height Trend：RGB 高度趋势图 |
| 中左 | KPI 卡片 |
| 中右 | topic health |
| 底部 | START / STOP / ZERO / EXPORT 按钮 |

### Height Trend 曲线

| 线 | 颜色 | 含义 |
|---|---|---|
| **max** | 青色粗线 | RGB max-LCR，高度主监控量 |
| L | 浅蓝 | left ruler 高度 |
| C | 绿色 | center ruler 高度 |
| R | 橙色 | right ruler 高度 |

当前 recommended combined launch 下没有紫色 `model` 曲线；KPI 会显示 `RGB ONLY`。

## 8. 单组实验标准操作

每组 variant 对照：

```text
1. 窗口点 START  ─→ 清空并开始当前 session
2. 启动 planner / 跑完一圈
3. 窗口点 STOP   ─→ 停止当前 session
4. 窗口点 ZERO   ─→ 可选，仅归当前 dashboard 显示/导出基线
5. 窗口点 EXPORT ─→ 保存 CSV + SVG 曲线
6. 下一组：再点 START，重复
```

注意：正式论文真值仍用 bag 离线 `red_liquid_infer_from_bag.py` 复算；dashboard export 只作为现场记录和快速检查。

## 9. EXPORT 输出

默认保存到：

```text
~/liquid_monitor_exports/
```

文件示例：

```text
liquid_session_20260611_223000.csv
liquid_session_20260611_223000.svg
```

CSV 列当前保留兼容字段：

```text
t_s, max_lcr_mm, L_mm, C_mm, R_mm, model_h_mm, cmd_v, odom_v, solver_ms
```

在 RGB-only combined launch 下，`model_h_mm` 不参与右侧波形图，通常为空/NaN；主要看：

```text
max_lcr_mm, L_mm, C_mm, R_mm
```

## 10. 故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 窗口无 RGB overlay | 检测节点未连接相机，或 `publish_debug` 未开 | 确认 `/camera/color/image_raw` 有数据；combined 默认 `publish_debug=true` |
| Height Trend 显示 `Waiting` | `/liquid/height` 无数据 | 检查 `online_liquid_height` 节点和 calibration 路径 |
| RGB 检测线明显跑偏 | calibration/ROI/ruler 不匹配 | 重新确认当天 YAML；把实际 YAML 和 bag 一起归档 |
| 红色噪声很多 | HSV 太宽或光照变化 | 显式传入 `hue1/hue2/sat_min/val_min`，必要时重新标定 HSV |
| 静止时显示非零 | 自动零点或 bias 偏 | 保持静止后 `rosservice call /online_liquid_height/reset_zero`；或按同号规则设置 `height_bias_mm` |
| 右侧没有 model 曲线 | 正常 | 当前 combined 监控是 RGB-only，不画 slosh model |
| 窗口关闭 | Ctrl-C 或 q/Esc | 重跑 launch；不影响传感器栈和 planner |

## 11. 管线架构

当前推荐 RGB-only 架构：

```text
/camera/color/image_raw
        │
        ▼
online_liquid_height_node.py
        │
        ├── /liquid/height       RGB max-LCR
        ├── /liquid/height_lcr   [L, C, R]
        ├── /liquid/height_median
        └── /liquid/debug_image
                    │
                    ▼
liquid_experiment_monitor.py  → 右侧 Height Trend 只画 RGB max-LCR/L/C/R
```

不再自动启动：

```text
slosh_models/slosh_monitor.launch
/slosh/height
```

如果后续确实需要把模型曲线叠加到 dashboard，必须显式设置 `show_model:=true` 并提供 `model_height_topic`，且在实验记录中把 RGB 真值和模型估计分开标注。
