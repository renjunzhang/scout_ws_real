## 1. 实施边界

本子阶段新增 stateless 的 `KnownPrefixPropagator`，将 common-epoch 物理状态从非网格 `t0` 传播到下一 OCP 起点 `T_k^-`。输入命令只来自已经跨过唯一 publisher 边界并成功进入 `CommandHistorySnapshot` 的事实。

它不：

- 接受 solver candidate 或 mailbox proposal；
- 修改、提交或伪造 history event；
- 调用固定 `dt` OCP stage 的 issue map/queue shift；
- 传播虚拟进度 `s`；
- 接 ROS、progress projector、warm start 或 acados。

Stage 1 仍为：

```text
BLOCKED_PENDING_DEDICATED_IDENTIFICATION_EVIDENCE
```

因此 delay bound、delay、tau/gain 与液体参数仍只是显式合成输入，没有写正式 preset、声明实车 fidelity 或打开 Stage 3 codegen。

## 2. 唯一物理时间线

对权威事件 `e_i`：

```text
r_i = e_i.cycle.release_model
q_i = e_i.command
```

对 `delay_c/dt=m_c+beta_c` 先复用 Stage 2c 的 integer-snap 规则。分通道纯延迟的生效时刻是：

```text
effective_i,c = T_{i+m_c}^model + beta_c*dt
```

理想实数网格上它等于 `r_i+delay_c`，但实际 `T_i` 是 `round(i*1e9/30)` 的整数纳秒。整数部分必须用绝对 cycle offset 到达 `T_{i+m}`，不能直接给 `T_i` 加 `m*double(dt)`；否则整拍延迟会在 `T_k` 前后人为偏移亚纳秒，与 Stage 2e selector 语义不一致。

实现在以 `t0` 为原点的相对秒时间轴上计算 `effective`，避免把 double fractional duration 直接加到大绝对纳秒并隐藏溢出。线、角切换时刻取精确并集，每个区间使用不插值的 ZOH target 调用 Stage 2d `propagateSegment()`。

前缀区间严格是：

```text
[t0,T_k)
```

所以：

- `effective == t0` 的命令在第一段已生效；
- `effective == T_k` 的命令不进入 prefix 物理区间；
- history 中的 event 必须严格早于 `T_k`，否则该 cycle 已经过期，fail closed；
- snapshot 最后事件之后只能 hold 其真实命令，不生成新 event/generation。

只有小于约 `2 fs` 的 double 表示噪声被归一到已有起点/终点/切换点；纳秒级或更大的真实不同切换仍保留独立子段。

## 3. 双时钟与 causality

prefix 动力学只使用 `cycle.release_model`。`actual_model/actual_steady` 只证明 publish receipt 真实且 snapshot 已可见，不再进入一套额外物理延迟。相同 planned event 在不同 actual publish jitter 下必须生成完全相同的 prefix 时间线和数值结果。

运行前同时验证：

- `t0 <= snapshot_model <= T_k^model`；
- `snapshot_steady <= T_k^steady`；
- snapshot/target `reset_epoch` 一致；
- 最后 event 恰为 target cycle 的前一个绝对 release cycle；
- target 相对前驱的 steady/model 间隔都与 30 Hz 绝对网格一致；
- snapshot 内命令、publisher authority、generation、cycle 和时间顺序自洽。

任一未来 event、epoch 失配、目标 cycle 过期或 snapshot 越过 target 均拒绝，不静默忽略极端命令后继续求解。

## 4. coverage 与权威状态重建

覆盖左边界保守取：

```text
coverage_left = t0 - max(L_max,v,L_max,omega)
```

并复用 Stage 2b：

```text
history.coverage(coverage_left,T_k,maximum_history_gap_ns)
```

必须存在 `stamp <= coverage_left` 的真实前驱，内部相邻 gap 和末端 future hold 都不得超过门限。容量 prune、左前驱缺失、33333333/33333334 ns 边界和 int64 时间溢出全部 fail closed。

成功时，`T_k^-` 的非进度状态由最后真实 event 重建：

```text
publisher = latest.publisher_state_after
older[0] = previous event command
older[1] = event before previous
...
```

hold 不 shift queue、不改 publisher acceleration，也不增加 generation。结果保留 history generation、coverage audit 和固定容量分段 trace，供后续 horizon snapshot/回放重建。

## 5. `s` 不可表示

`KnownPrefixExecutionState` 只包含：

```text
physical = pose + actual + liquid
publisher
linear/angular older
```

它没有 `progress` 字段，也不复用 Stage 2e 含 `s` 的 `PreIssueActuatorState`。历史中没有权威 `v_s`，因此不存在“默认保留或用旧计划外推”的隐式路径。Stage 2g 必须在传播后 pose 上单独做 forward-only 局部投影。

## 6. 失败原子性与合成 golden

`propagate()` 先在局部 result/physical 中完成 coverage、timeline、分段物理传播与 authority 重建，只在全部成功后一次赋给 output。历史/时间/数值任一失败都不留下半传播状态。

主 golden 使用：

```text
30 Hz cycle 0..7 已 emitted，target=cycle 8
t0=176000000 ns，T_8=266666667 ns
delay_v=0.5 dt，delay_omega=1.25 dt
```

独立硬编码的 6 段 target 为：

```text
(4,-2) -> (5,-2) -> (5,-2.5)
       -> (6,-2.5) -> (6,-3) -> (7,-3)
```

测试同时核对完整 pose/actual/liquid golden、publisher/older、coverage/future-hold、actual jitter 不变性、起点/终点开闭边界、零时长 identity、`NQ=1/2/4`、前驱/gap/未来 event/epoch/时间/数值失败及 sentinel output 原子不变。

该 golden 只验证合成数值语义；新联合 prefix 的实车 fidelity 仍必须由 Stage 1 互斥 development/validation/final-test 证据单独通过。
