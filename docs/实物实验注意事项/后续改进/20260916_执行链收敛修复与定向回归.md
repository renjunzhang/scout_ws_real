## 2. 修复后的行为

| 收敛项 | 当前行为 | 限制 |
| --- | --- | --- |
| 求解与发布 | RTI 按实际剩余预算启动，次数只作上限；发布前再核验单调时钟耗时和输入 epoch 年龄，过期拒绝 | 单次 acados 调用不可抢占；没有硬实时保证 |
| 最终命令 | trajectory 四组关闭重复 shared limiter，改写即拒绝；dry-run 走同一接纳路径，外部审计更新真实上一条命令基线 | ROS 发送接口仍待整节点验证；dry-run 不发送和记录新命令 |
| 定位接纳 | 在投影前按实测运动检查位置/航向创新；突跳不成为锚点，短跳恢复原坐标后可继续 | 不检测所有缓慢漂移；持续重定位需明确新任务或重启 |
| 液体恢复 | observer 时间增量必须等于完整积分区间；已有状态断流、传播失败或重置 epoch 后等待可信初始化 | filter READY 不能授权液体零初态；当前操作流程为静置后重启 |
| 完整停车 | 同一管理器核验初态、FIFO、每条停车命令及传播子步实际速度；子步液面峰值交由原液面策略核验 | 硬上限开关保持独立；子步采样不是连续时间证明，OCP 完整时域硬约束仍按节点 |
| 普通失败 | 仅普通数值失败/计算预算耗尽，且本周期停车尾段通过全部核验时接管；停车所有权保持至任务重置 | 状态、历史、配置错误和过期结果不能复用尾段；未完成任务仍记失败 |
| 参考端点 | 使用真实非零单侧段；普通拟合用局部归一化 QR，再转为原 OCP 绝对进度系数 | 不修改生成求解器维度；不能保证所有期限终点问题可解 |

### 单拐角名义回归

复用上一轮冻结的 `corner_plan.json`，不重新调权重、不重建计划；只跑以下四组，不重跑旧 24 组矩阵。这是既有场景的回归，**不是新 S 路线验证协议**。`tau×1.15` 只改变被控对象的一阶响应，控制器模型保持名义值。

| 组别 | 完成 | 完成时间 s | 最早求解失败 / 最终失败 | 核心 wall P95 / max ms |
| --- | --- | --- | --- | --- |
| geometry，tau×1 | 否 | — | 10 s：`ACADOS_SOLVE_FAILED_4`，接管后 12.033 s：`TASK_DEADLINE_MISSED` | 19.68 / 55.63 |
| geometry，tau×1.15 | 否 | — | 同上 | 19.75 / 56.12 |
| raw / B0，tau×1 | 是 | 11.267 | 无 | 18.50 / 25.70 |
| planned_slosh / Full，tau×1 | 是 | 5.533 | 无 | 26.22 / 69.83 |

两组 geometry 在首次失败处的参考 yaw 均为正确的 `π/2`，不再是此前退化值；但数值失败仍在。随后按本周期尾段持续停车，最终位置误差分别为 `0.05495 / 0.05720 m`，仍超出 `0.05 m` 目标容差。因此端点修复没有消除期限末段求解问题；不能只读最终 `TASK_DEADLINE_MISSED` 而漏报更早的 solver 失败。JSON 保存了全部状态转换。

B0 / Full 的正则曲率积分为 `5.457 / 1.573`，模型节点液面峰值为 `0.893 / 1.194 mm`。Full 更缓且更快，但峰值更高，耗时也未匹配，仍无相近耗时下降晃的结论。失败 geometry 的不完整运输段不参与成功效果比较。

以上名义运行固定最多 5 次 RTI，**未设置在线时间预算**；最长核心耗时 `69.83 ms` 超过 33.33 ms 周期。新增预算/过期拒绝防止继续接纳超期结果，不表示有限预算下已能稳定完成任务。耗时也不含 ROS 整发布链，不能作为 30 Hz 验收。
