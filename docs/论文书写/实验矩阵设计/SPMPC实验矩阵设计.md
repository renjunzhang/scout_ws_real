# SPMPC 实验矩阵设计

本文实验章节建议围绕一个主问题组织：显式晃液状态预测是否能在普通平滑控制之外，为移动底盘开口液体运输带来可解释的液面响应改善，并且不以不可接受的路径跟踪、任务时间和在线计算代价为条件。

## 总体安排

实验不建议写成一张大表，而应按证据强度递进：

| 层级 | 实验组 | 主要回答的问题 | 论文中的作用 |
|---|---|---|---|
| 1 | 内部消融 | SPMPC 是否只是更强的 smooth-only 控制 | 支撑核心方法贡献 |
| 2 | Governor 消融 | 软速度参考适配是否带来额外收益 | 支撑第二方法模块 |
| 3 | 终端停车过渡消融 | 到达终点附近的残余晃动能否进一步降低 | 可作为补充方法贡献 |
| 4 | 外部局部规划器对比 | 普通在线局部规划器是否已足够 | 支撑方法定位 |
| 5 | 实物验证与模型一致性 | 内部模型趋势是否被真实液面观测支持 | 支撑实验可信度 |
| 6 | 在线求解与执行诊断 | 方法是否仍是可部署的在线局部规划器 | 支撑工程可行性 |

## 1. 核心内部消融矩阵

这是最重要的主实验，优先放在实验章节主表中。

| 变体 | 晃液状态/代价 | 平滑权重 | Governor | 目的 |
|---|---|---|---|---|
| `B0` | 无 | 弱 | 关 | 基础 MPCC 参考，验证路径任务可完成 |
| `B_smooth` | 无 | 强 | 关 | 检验只增强控制平滑性是否足够 |
| `B_slosh` | 有 | 弱 | 关 | 检验显式晃液状态预测是否有独立作用 |
| `B_ours` | 有 | 强 | 关 | 检验基础 SPMPC 在跟踪、平滑和防晃之间的折中 |

建议主比较：

| 对比 | 解释 |
|---|---|
| `B_smooth` vs. `B0` | 只增强平滑性带来的变化 |
| `B_slosh` vs. `B0` | 晃液状态预测的独立作用 |
| `B_slosh` vs. `B_smooth` | 显式状态预测是否超过 smooth-only |
| `B_ours` vs. `B_smooth` | 完整基础 SPMPC 是否超过 smooth-only |
| `B_ours` vs. `B_slosh` | 强平滑项是否改善可执行性与跟踪表现 |

核心指标：

| 类别 | 指标 |
|---|---|
| 真实液面 | RGB p95/max/RMS、残余振荡 |
| 模型代理量 | `H_model` p95/max/RMS |
| 任务完成 | 成功率、到达时间、超时 |
| 路径跟踪 | 投影误差 p95、最大路径偏差 |
| 控制行为 | `|omega|` p95、速度/角速度变化、加速度 RMS |
| 在线计算 | 求解时间中位数、p95、失败次数 |

写作原则：

- 主结论优先使用 p95 和 RMS，不把单次 max 尖峰作为主要证据。
- 若模型代理量下降但 RGB 没有同向下降，只能写模型内部预测改善，不能写真实液面改善。
- 若 `B_slosh` 或 `B_ours` 更慢，要明确说明液面改善伴随到达时间代价。
- `B0` 可作为参考基线，但如果它在 RGB RMS 上不明显劣于 `B_slosh`，不要把 `B0` 作为主降幅叙事对象。

## 2. Slosh-risk Reference Governor 消融

该实验应单独成表，不建议混入核心内部消融表。

| 变体 | 基础规划器 | Governor | 目的 |
|---|---|---|---|
| `B_ours` | 基础 SPMPC | 关 | 参考组 |
| `B_ours_gov` | 基础 SPMPC | 开 | 检查软速度参考适配的增量作用 |

必须保持一致的条件：

| 条件 | 要求 |
|---|---|
| 参考路径 | 相同 |
| 名义速度参考 | 相同 `v_ref` |
| 底盘速度/加速度约束 | 相同 |
| SPMPC 权重 | 相同 |
| 终止条件 | 相同 |
| RGB/液位评价流程 | 相同 |

额外指标：

| 指标 | 作用 |
|---|---|
| `beta_raw` | governor 原始候选选择 |
| `beta_f` | 变化率限制后的实际缩放 |
| saturated rate | 是否频繁进入所有候选均超阈值的状态 |
| transient rate-limited rate | 是否因变化率限制导致短时风险未被完全压低 |
| 到达时间增加量 | 判断是否只是变慢 |

写作原则：

- Governor 只能写成软参考适配，不写成 hard safety layer。
- 不声称无溢出保证。
- 若没有完整数据，只在方法节和实验设计中保留口径，不进入主结果表。

## 3. 终端顺滑停车过渡消融

如果希望把“终点顺滑停车过渡”作为额外方法点，应单独设计实验，避免与全程 smooth 权重混淆。

| 变体 | 终端停车策略 | Governor | 目的 |
|---|---|---|---|
| `B_ours_no_stop` | 普通到点/硬终止 | 关 | 参考组 |
| `B_ours_stop` | 顺滑停车过渡 | 关 | 检查终端残余晃动 |
| `B_ours_stop_gov` | 顺滑停车过渡 | 开 | 检查停车过渡与 governor 的组合效果 |

重点指标：

| 类别 | 指标 |
|---|---|
| 终端液面 | 到达后固定时间窗口内 RGB RMS、p95、残余振荡衰减时间 |
| 终端控制 | 最后一段速度、加速度、角速度变化 |
| 任务代价 | 到达时间、终端停稳时间 |

写作原则：

- 该实验回答的是“终点附近残余晃动/停车冲击”，不是全程液面改善。
- 若结果明显，可作为第三个方法贡献的候选。
- 若数据不足，只作为未来工作或补充实验计划。

## 4. 外部局部规划器对比

外部方法用于证明普通在线局部规划器不一定能覆盖开口液体运输需求。建议优先选择能稳定跑通、接口可对齐、日志可复现的方法。

| 方法 | 是否传播液体状态 | 层级 | 建议用途 |
|---|---|---|---|
| DWA | 否 | 普通在线局部规划器 | 经典速度空间局部规划参考 |
| TEB | 否 | 普通在线局部轨迹优化 | 强平滑/时间弹性局部规划参考 |
| `mpc_local_planner` | 否 | 普通 MPC 局部规划 | 与 MPC/MPCC 层级更接近 |
| LT-DWA | 否 | 改进型局部规划/跟踪方法 | 作为本课题已有外部局部规划参考 |
| SPMPC / `B_ours` | 是 | 本文方法 | 主方法 |

对齐要求：

| 项目 | 要求 |
|---|---|
| 起点/终点/路径 | 一致 |
| 最大线速度/角速度 | 尽量一致 |
| 线加速度/角加速度限制 | 尽量一致 |
| 任务失败判据 | 一致 |
| 到达判据 | 一致 |
| 日志字段 | 轨迹、速度命令、RGB/液位、求解时间或计算耗时 |

建议结论口径：

- 如果外部方法更快但液面更差，强调任务效率与液面响应的权衡。
- 如果外部方法轨迹更平滑但 RGB 指标不优，强调平滑性不等价于晃液状态预测。
- 如果某个外部方法无法公平复现，不进入主排名，只作为相关工作和实验讨论中的层级参照。

## 5. 移动底盘防晃近邻方法对比

这类方法不是普通局部规划器，而是用于说明本文与已有液体运输工作的层级差异。

| 类型 | 示例 | 是否建议进入主表 |
|---|---|---|
| 固定路径速度剖面 | Hamaguchi 式路径/速度剖面 | 能公平复现时进入补充表 |
| 输入整形 | 对速度或加速度命令做输入整形 | 能对齐接口时进入补充表 |
| 离线液体约束轨迹优化 | Lim 式离线轨迹优化 | 通常作为层级参照 |
| 给定轨迹跟踪控制 | 防晃跟踪控制 | 通常作为层级参照 |

写作原则：

- 不把不同平台、不同控制输入、不同决策层级的方法强行写成同层 baseline。
- 能复现才定量比较；不能复现就作为相关工作和讨论中的层级定位。

## 6. 实物实验矩阵

实物实验不一定覆盖所有仿真矩阵，重点是提供真实液面观测证据。

推荐优先级：

| 优先级 | 实物组 | 最小重复次数 | 目的 |
|---|---|---|---|
| P0 | `B0`, `B_smooth`, `B_slosh`, `B_ours` | 每组 3 次以上 | 核心内部消融 |
| P1 | `B_ours`, `B_ours_gov` | 每组 3 次以上 | governor 增量验证 |
| P1 | `B_ours_no_stop`, `B_ours_stop` | 每组 3 次以上 | 终端停车过渡验证 |
| P2 | DWA/TEB/LT-DWA 与 SPMPC | 每组 3 次以上 | 外部局部规划器实物代表性对比 |

当前如果数据有限，主论文可以先采用代表性固定路径实物结果，但必须明确：

- 固定路径；
- 小样本；
- 代表性试次；
- 真实液面结论仅来自 RGB/液位观测；
- 模型代理量只用于解释趋势。

## 7. 模型代理量一致性诊断

模型代理量一致性不作为方法性能排名主表，而是作为解释性诊断。

| 指标 | 作用 |
|---|---|
| `gamma_bias` | 判断模型整体偏保守或低估 |
| `gamma_abs` | 判断模型与外部观测的整体偏差 |
| RMSE | 评价数值误差 |
| 相关系数 | 评价趋势一致性 |
| 相位偏移 | 判断模型是否滞后或超前 |
| 峰值/分位低估 | 检查是否存在危险低估 |

写作原则：

- 可以写“模型代理量与 RGB 在组间趋势上相符”。
- 不写“模型代理量就是真实液面高度”。
- 不用模型代理量单独证明防晃效果。
- 不把 `/spmpc/slosh_height` 写成论文主概念，只在实现映射中说明其对应某种 `H_model` 口径。

## 8. 推荐论文实验章节结构

```text

4.2 内部消融：晃液状态预测 vs 控制平滑性
4.3 Slosh-risk Reference Governor 与终端停车过渡消融
4.4 普通局部规划器与移动底盘防晃近邻方法对比
4.5 实物实验：真实液面响应与模型一致性
4.6 在线求解性能与执行诊断
```

如果 governor 和终端停车数据暂时不足，建议改成：

```text
4.1 实验设置与评价指标
4.2 内部消融：晃液状态预测 vs 控制平滑性
4.3 普通局部规划器与移动底盘防晃近邻方法对比
4.4 实物实验：真实液面响应与模型一致性
4.5 在线求解性能与执行诊断
```

并在正文中说明 governor 和终端停车过渡只保留方法定义或待补充实验口径。

## 9. 当前最稳的论文主张

在当前证据强度下，最稳的主张是：

> 显式传播低阶晃液状态的在线 MPCC 局部规划，能够在单纯控制平滑性之外，对真实液面响应改善提供额外解释力。

更谨慎的贡献表述为：

| 贡献 | 当前证据状态 | 建议写法 |
|---|---|---|
| 液体动态记忆增强的在线 MPCC 局部规划 | 最强 | 主贡献 |
| Slosh-risk Reference Governor | 方法已有，实验待补 | 第二方法模块，结果不足时不强称性能收益 |
| 终端顺滑停车过渡 | 需要补实验 | 可作为潜在第三方法贡献 |
| 实验与验证协议 | 已有叙事价值 | 作为验证贡献，不宜替代方法贡献 |
