\begin{abstract}
Open-liquid transport on mobile bases requires local motion generation that accounts for the dynamic memory of the liquid free surface.
This manuscript develops the technical core of \SPMPC{}, a slosh-aware model predictive contouring control method that embeds a low-order liquid modal state into an online \MPCC{} local planner.
The formulation jointly predicts base motion, path progress, and liquid response, and it can be paired with a soft finite-horizon reference governor that contracts the speed reference before the \MPCC{} solve.
The evaluation structure isolates explicit slosh-state prediction from smooth-only motion generation and separates internal model proxies from external liquid observations.
\end{abstract}
