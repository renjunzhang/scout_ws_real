# SPMPC Method and Comparative Experiments

This directory contains a standalone IEEE conference-style document that focuses on the core body of the SPMPC paper:

- methodology;
- internal ablations;
- external planner comparisons;
- representative physical comparison results.

It uses the same `IEEEtran.cls` template as `docs/论文书写/草稿/spmpc_paper`.

Build:

```bash
cd docs/论文书写/草稿/Method
latexmk -pdf main.tex
```
