\begin{abstract}
This paper formulates an online slosh-aware path-progress planning method for a wheeled mobile base transporting an open liquid container along a geometrically feasible reference path.
The method augments the base and path-progress states with low-order liquid modal dynamics, allowing liquid dynamic memory to evolve inside a model predictive contouring control horizon.
The resulting optimal control problem jointly selects executable base motion and virtual path progress while penalizing predicted phase-dependent liquid response.
An optional predictive speed-reference shaping layer contracts the nominal speed reference using a short liquid-state rollout without overriding the optimized base command.
The resulting formulation provides a modular basis for separating liquid-state prediction inside the optimal control problem from optional speed-reference adaptation.
The evaluation uses matched internal baselines to distinguish liquid-state prediction from motion smoothing, and treats external liquid-surface observations separately from the model proxy.
\end{abstract}
