\begin{abstract}
Offline anti-slosh trajectories exploit future phase cancellation, but an online path-tracking correction can destroy that cancellation before the correction physically reaches a mobile base.
We formulate a phase-rejoining residual slosh-aware model predictive contouring controller (\SMPCC{}), which admits an online residual correction only if the state predicted after the identified command-to-motion delays passes a phase-indexed empirical test for rejoining the complete offline anti-slosh tail.
The controller aligns a source-stamped state to the expected command-publication time, propagates separate linear and angular command buffers and actuator dynamics, selects a neighboring monotone artifact phase, and solves a nominal-relative residual OCP through a common execution front and a short post-front residual window.
Acceptance requires both a 9-D robot--liquid empirical gate and a hard compatibility set for the pending execution state; a supervisor otherwise selects a phase-indexed stored action or requests zero velocity through the same publication and safety chain.
The planned evaluation uses an independent RGB max-LCR liquid-height outcome, OrdinaryMPCC and completion-time-matched controls, strict component ablations, held-out conditional false-safe analysis, and command-chain and runtime audits.
Formal performance claims are withheld in this core draft because the unequal-delay causal-front implementation, formal offline artifact, execution-compatibility set, and held-out gate have not yet passed their release gates.
The scope is frozen-path tracking in a static obstacle-clear workspace; online obstacle avoidance and a formal recovery guarantee are not claimed.
\end{abstract}
