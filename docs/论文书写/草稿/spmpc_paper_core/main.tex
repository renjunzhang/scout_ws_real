\begin{abstract}
This paper formulates an online receding-horizon local motion planner and controller for transporting an open liquid container along a prescribed geometrically feasible reference path.
The method jointly optimizes robot motion, virtual path progress, and a container-parameterized first-mode liquid model within a model predictive contouring control horizon.
Propagated modal displacement and velocity provide liquid dynamic memory, allowing the planned motion to depend on the current oscillation phase.
The evaluation uses matched slosh-agnostic and smooth-only MPCC variants, a completion-time-matched comparison, and geometry-based transfer across containers without controller-weight retuning.
\end{abstract}
