$\omega_1$, $c_h$, $\eta_{\mathrm{ref}}$, and
$\dot\eta_{\mathrm{ref}}$. It is a model-mismatch analysis and not a fourth
core method. Only a pre-specified physical comparison of this group with the
correctly parameterized $C_2$ trials can support a claim about the physical
necessity of geometry-based updating. A computational correct/incorrect replay
