\section{Development-Only Records}

The archived trials predate the frozen block protocol and are not used for
formal inference. Modal-only quantities must be recomputed from
$(\eta_x,\eta_y)$ before reporting.
The legacy statement $v_{\mathrm{ref}}=0.20\,\mathrm{m/s}$ is treated as a
compatibility item rather than proof of mismatch: the archived configuration
must be checked to determine whether it denotes a fixed reference or the
$v_{\mathrm{cruise}}$ input to the curvature-aware profile. Regardless of the
outcome of this check, the archived trials do not contribute to the formal
randomized-block sample size.
