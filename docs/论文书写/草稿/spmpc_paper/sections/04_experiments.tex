\section{Experimental Evaluation}
\label{sec:experiments}

The evaluation is designed to test one bounded claim: whether propagated liquid
dynamics change receding-horizon motion decisions and improve the measured
free-surface response along a prescribed path. The evidence proceeds from the
physical outcome to the executed motion that produced it, then examines the
completion-time alternative, transfer across container geometries, the effect
of liquid state on the optimizer, and real-time execution. Claims remain
restricted to matched internal \MPCC{} variants in the prescribed-path setting;
the study does not rank \SMPCC{} against global, obstacle-oriented, or other
liquid-transport planners.

\subsection{Evaluation Questions and Evidence Structure}

Four research questions organize the evidence:
\begin{itemize}
  \item \textbf{RQ1---Physical effectiveness and task performance:} Does
  \SMPCC{} reduce the measured free-surface response relative to Baseline and
  Smooth-only \MPCC{} while completing the prescribed path?
  \item \textbf{RQ2---Completion-time confound:} Does the benefit remain when
  Smooth-only \MPCC{} is matched to the completion time of \SMPCC{}?
  \item \textbf{RQ3---Container transfer:} Does geometry-based model
  reparameterization preserve the benefit without controller-weight retuning?
  \item \textbf{RQ4---State-dependent online planning:} Do liquid modal state
  and phase change the predicted motion plan and optimized first action in both
  controlled states and formal runtime replay, and can the resulting OCP be
  solved within the online deadline?
\end{itemize}

The mechanism analysis preserves the distinction between optimization and
execution. Let $\bm c=[v,\omega]^\top$ denote a velocity command. The evidence
chain is
\[
\begin{aligned}
(\kappa(s),\hat{\bm{x}}_{r,j},\hat{\bm{x}}_{\ell,j})
&\rightarrow \bm{u}^{\star}_{0:N-1\mid j},\\
\bm{u}^{\star}_{0:N-1\mid j}
&\rightarrow \bm c_{\mathrm{solver},j}
\rightarrow \bm c_{\mathrm{post},j}
\rightarrow \bm c_{\mathrm{pub},j},\\
\bm c_{\mathrm{pub}}
&\rightarrow \text{executed motion}
\rightarrow (a_{x,\mathrm{exec}},a_{y,\mathrm{exec}}),\\[-1mm]
(a_{x,\mathrm{exec}},a_{y,\mathrm{exec}})
&\Rightarrow
\begin{cases}
H_{\mathrm{modal}}, & \text{internal model response},\\
H_{\mathrm{vis}}, & \text{physical reference response}.
\end{cases}
\end{aligned}
\]
Here the raw solver, post-gate, and final published commands are separate log
layers. Only the published command and measured motion are connected directly
to the realized excitation. The final branch is an analysis structure rather
than a claim that $H_{\mathrm{modal}}$ causes $H_{\mathrm{vis}}$: the former is
an internal prediction or propagated model response, whereas the latter is the
calibrated vision-based experimental reference. A replay that stops before the
shared execution layer is interpreted only as an optimized first-action
difference.

\subsection{Experimental Setup and Compared Methods}

\subsubsection{Platform, paths, and containers}

Physical trials use a Scout Mini mobile base and cylindrical liquid containers
mounted at the base rotation center. The body-fixed $x_b$ axis points forward
and $y_b$ points laterally. The nominal container $C_1$ has inner radius
$R_c=18.5\,\mathrm{mm}$ and liquid depth $h=58\,\mathrm{mm}$. Container $C_2$
changes the radius and/or fill depth so that the first-mode natural frequency
changes by approximately 15--20\% or more. Before $C_2$ is frozen, its modal
frequency is checked against the camera frame rate and the validated visual
measurement bandwidth; parameter separation is not created by moving the
response outside the observation regime. A low-risk prescribed path and a
high-risk path with sustained curvature changes are used.

body-frame axes. Complete path coordinates, camera metadata, container

\subsubsection{Experimental matrix}

The formal design uses $n=8$ randomized blocks and 88 physical trials:
\begin{itemize}
  \item $C_1$ on the low-risk path: three methods, giving $3n=24$ trials;
  \item the high-risk path: $\{C_1,C_2\}$ crossed with the three methods within
  container super-blocks, giving $6n=48$ trials;
  \item $C_1$ on the high-risk path: Smooth-match and \SMPCC{}, giving
  $2n=16$ completion-time-matched trials.
\end{itemize}
The high-risk $C_1$ trials in the super-blocks serve both RQ1 and RQ3; they are
not collected twice. Method order is randomized within every block, and
container order is randomized or counterbalanced within each super-block.
RQ4 comprises controlled longitudinal and lateral phase studies, actual/zero
runtime-state replay, and runtime analysis. The phase and replay studies, as
well as the RQ3 parameter-switch and computational mismatch comparisons, add no
physical trials. A separate long-horizon audit uses eight $C_1$ trials on an
extended path containing five consecutive repetitions of the frozen high-risk
curvature sequence. These runs retain the propagated liquid state throughout
the complete sequence and are excluded from the 88-trial main comparison. An
optional $C_2$ mismatch group using frozen $C_1$ liquid parameters adds another
eight physical trials. Collecting either extension gives 96 trials, and
collecting both gives 104. Neither extension changes the RQ1--RQ4 comparison
hierarchy. Only the physical mismatch group can test whether reparameterization
is necessary rather than merely whether the optimizer is parameter sensitive.

If acquisition stops early, the evidence and manuscript claims are reduced
together. The 40-trial core package contains the high-risk $C_1$ three-method
comparison and the time-matched comparison; adding the low-risk path gives 64
trials, and adding the $C_2$ super-block component gives the complete 88-trial
design.

All controller weights, the configured damping ratio $\zeta$,
executed-command limits, shared deployment behavior, camera settings, and
synchronization rules are frozen and archived before formal acquisition.
Formal RGB outcomes are not inspected while these settings are selected.

\subsection{Measurements, Protocol, and Analysis}

\subsubsection{Recorded signals and physical reference}

Each trial records synchronized signals at the level at which they enter the
evidence chain:
\begin{itemize}
  \item the prescribed path, projected progress $s$, and curvature $\kappa(s)$;
  \item odometry $(x,y,\theta,v,\omega)$, path-tracking error, task state, and
  the common arrival decision;
  \item the actual pre-solve robot and liquid states, $s_{\min,j}$, effective
  speed reference, previous control, and solver/warm-start snapshot required
  for deterministic replay;
  \item the optimized first action and the predicted $v_{k\mid j}$,
  $\omega_{k\mid j}$, $v_{s,k\mid j}$, and liquid rollout;
  \item the raw solver command, post-gate command, final published command,
  limiter flags, fallback state, and previous published command;
  \item propagated modal state
  $(\eta_x,\dot\eta_x,\eta_y,\dot\eta_y)$ and $H_{\mathrm{modal}}$;
  \item calibrated visual free-surface response $H_{\mathrm{vis}}$;
  \item solve time, solver status, deadline miss, intervention state, fallback
  action, and achieved control interval.
\end{itemize}

The online log retains the first action and available predictions. The frozen
RQ4 replay tool additionally exports the complete horizon of
$v$, $\omega$, $v_s$, $\eta_x$, $\dot\eta_x$, $\eta_y$, $\dot\eta_y$, $a$,
and $\alpha$; an XY path or a short horizon summary is not sufficient for the
state-dependence analysis.

Prediction and execution are not conflated. Inside the OCP,
$a_{x,k\mid j}=a_{k\mid j}$ and
$a_{y,k\mid j}=v_{k\mid j}\omega_{k\mid j}$. Realized excitation is derived
from synchronized odometry and executed commands using the pre-specified
processing rule
\[
  a_{x,\mathrm{exec}}\approx\dot v_{\mathrm{odom}},
  \qquad
  a_{y,\mathrm{exec}}\approx
  v_{\mathrm{odom}}\omega_{\mathrm{odom}}.
\]
The differentiation and filtering procedure is frozen before formal outcomes
are inspected. Physical motion and excitation metrics use odometry and
published commands; predicted quantities are used only for mechanism analysis.

Command intervention is defined before formal acquisition. For frozen
tolerances $\epsilon_v$ and $\epsilon_\omega$, the trial-level intervention
ratio is
\begin{equation}
\begin{aligned}
  r_{\mathrm{int}}
  =\frac{1}{N_c}\sum_{j=1}^{N_c}
  \mathbb I\!\big(&
  |v_{\mathrm{pub},j}-v_{\mathrm{solver},j}|>\epsilon_v\\[-1mm]
  &\lor
  |\omega_{\mathrm{pub},j}-\omega_{\mathrm{solver},j}|>\epsilon_\omega
  \big).
\end{aligned}
  \label{eq:intervention_ratio}
\end{equation}
An admission threshold $r_{\mathrm{int,max}}$ is frozen from independent
deployment tests for the nonterminal main-motion interval. Exceeding this
threshold in a formal trial is reported rather than excluded. If the shared
execution layer frequently overrides the optimizer, physical differences are
attributed to the final executed trajectory, not directly to the raw OCP
command.

Only two liquid-response quantities are used. $H_{\mathrm{modal}}$ is the
internal modal response and OCP penalty, whereas $H_{\mathrm{vis}}$ is the
calibrated vision-based experimental reference and the primary physical
evidence. The same fixed camera geometry, region of interest, calibration, and
extraction settings are used for all controller variants. The formal
configuration disables the parabolic correction and publishes a modal-only
log.

The camera is rigidly mounted relative to the container. Its model,
resolution, frame rate, pose, and region of interest are recorded.
Pixel-to-millimeter calibration is performed before the formal blocks using a
fixed procedure, and its resolution or repeated-calibration error is reported.
The extraction algorithm, filtering, missing-frame rule, and RGB--odometry
timestamp alignment are specified before outcomes are inspected. Controller
labels are not used to select trials, frames, or processing parameters.

Each trial begins only after the base is stationary and $H_{\mathrm{vis}}$
remains below a calibration-derived rest threshold for at least $2\,\mathrm{s}$.
The threshold is determined from stationary calibration data and is not
retuned by method. Every trial includes a fixed
$T_{\mathrm{post}}=5\,\mathrm{s}$ post-arrival observation interval.

\subsubsection{Primary, secondary, and diagnostic outcomes}

The first effective motion time $t_{\mathrm{move}}$ is determined by a frozen
velocity or command threshold and minimum duration. Together with the common
arrival rule, it defines the full motion window
\begin{equation}
  \mathcal W_{\mathrm{full}}
  =[t_{\mathrm{move}},t_{\mathrm{arrival}}].
  \label{eq:full_motion_window}
\end{equation}
The primary physical outcome is the trial-level 95th percentile
\begin{equation}
  H_{\mathrm{vis,p95}}^{\mathrm{full}}
  =Q_{0.95}\!\left(
  H_{\mathrm{vis}}(t):t\in\mathcal W_{\mathrm{full}}
  \right).
  \label{eq:primary_rgb_outcome}
\end{equation}
This window includes start-up and terminal braking, two physically relevant
excitation phases, but excludes pre-start waiting and post-arrival observation.
Motion-dependent process curves are aligned by normalized path progress
$\sigma=s/L$. The 10\%--90\% path-progress p95 is a pre-specified sensitivity
outcome that isolates the path interior from start and terminal handling; it
does not replace the full-window primary outcome.

Secondary outcomes are full-window $H_{\mathrm{vis}}$ RMS, 10\%--90\%
$H_{\mathrm{vis}}$ p95, post-arrival $H_{\mathrm{vis}}$ RMS over
$0\leq\tau=t-t_{\mathrm{arrival}}\leq T_{\mathrm{post}}$, completion time,
contour-error p95, and success rate. The path is also partitioned into five
pre-registered mechanism segments, $Z_1$--$Z_5$, spanning start-up, entry into
curvature, curvature reversal, re-acceleration, and terminal braking.

Mechanism diagnostics comprise $H_{\mathrm{modal}}$ p95,
$a_{x,\mathrm{exec}}$ RMS, $|a_{y,\mathrm{exec}}|$ p95, optimized
$\alpha_{0\mid j}^{\star}$ RMS and p95, layer-specific command total-variation
rate, thresholded direction-reversal rate, high-frequency command energy,
$r_{\mathrm{int}}$, and raw-to-published command differences. Real-time
outcomes are solve-time median, p95, and maximum, deadline-miss rate, solver
failure, fallback use, and achieved control frequency. None of these internal
or process diagnostics substitutes for the physical $H_{\mathrm{vis}}$
outcome.

One complete trial is the statistical sample. Video frames and points on an
aligned process curve are not treated as independent observations. Process
curves are interpolated to a pre-specified common $\sigma$ grid and shown as
the trial median with an interquartile band. Post-arrival curves use the common
time coordinate $\tau$. These bands are descriptive trial envelopes rather
than pointwise inferential confidence intervals.

\subsubsection{Randomization, paired analysis, and failure handling}

The comparison hierarchy is fixed before formal acquisition. For RQ1, the
primary contrast is \SMPCC{} minus Smooth-only \MPCC{}; \SMPCC{} minus
Baseline \MPCC{} is the key secondary contrast, and Smooth-only minus Baseline
is a mechanism diagnostic. For RQ2, the primary contrast is \SMPCC{} minus
Smooth-match \MPCC{}. This hierarchy is not revised in response to the observed
significance pattern.

The analysis uses within-block differences. For method $m$, reference method
$m'$, block $b$, and path $p$,
\begin{equation}
  \Delta_{b,p}^{m-m'}
  =Y_{m,b,p}-Y_{m',b,p}.
  \label{eq:block_difference}
\end{equation}
The primary estimand is the mean paired difference
\[
  \bar\Delta_p^{m-m'}
  =\frac{1}{n}\sum_{b=1}^{n}\Delta_{b,p}^{m-m'}.
\]
A negative value favors \SMPCC{} for liquid-response and error outcomes when
$m=\mathrm{S\text{-}MPCC}$. The paper reports raw trial points, block-paired
lines, $\bar\Delta_p^{m-m'}$, mean within-block relative change, and a 95\%
interval obtained by resampling whole blocks. The paired median is a robustness
summary. The RQ1 primary contrast additionally receives exact paired
sign-flip/randomization inference and leave-one-block-out analysis. If p-values
are reported for multiple secondary comparisons, their interpretation follows
a frozen hierarchy or Holm adjustment. Reaching $n=8$ does not by itself
establish statistical confirmation; interpretation combines paired
observations, effect magnitude, uncertainty, and the failure pattern.
Mixed-effects models are supporting analyses rather than replacements for the
paired raw data and small-sample robustness checks.

Exclusions are restricted to acquisition failures unrelated to a compared
method, such as a recording system that never started, an irrecoverably
corrupted camera stream, or a missing path before trial onset. Such a trial is
rerun within the same randomized block, and both the exclusion and replacement
are logged. A solver failure, timeout, path-tracking failure, or
safety-triggered termination during an otherwise valid trial is retained as a
method failure and is never replaced. Success is reported over all attempted
valid trials. Continuous outcomes are summarized for completed trials with the
corresponding numerator and denominator shown; undefined metrics from failed
trials are not imputed or silently discarded. Performance values are never
used to select trials or representative time series.

\subsection{RQ4: State-Dependent Planning, Propagated-State Effect, and Real-Time Feasibility}
\label{sec:rq4}

\subsubsection{Liquid-phase-dependent replanning}

The controlled phase study tests the OCP independently of physical-trial
variability. Two mechanism checkpoints are frozen before the formal outcomes
are inspected: a longitudinal checkpoint before start-up or re-acceleration,
and a lateral checkpoint before curve entry or curvature reversal. At each
checkpoint, the robot state, local path, container parameters, and modal energy
are fixed. Only the phase of one modal direction is changed.

With the pre-specified amplitude $A=0.5\eta_{\mathrm{ref}}$, the longitudinal
initial states are
\begin{equation}
\begin{aligned}
  &[A,0,0,0]^\top,\qquad
  [0,\omega_1A,0,0]^\top,\\
  &[-A,0,0,0]^\top,\qquad
  [0,-\omega_1A,0,0]^\top,
\end{aligned}
\label{eq:phase_initial_states}
\end{equation}
and the lateral states are
\begin{equation}
\begin{aligned}
  &[0,0,A,0]^\top,\qquad
  [0,0,0,\omega_1A]^\top,\\
  &[0,0,-A,0]^\top,\qquad
  [0,0,0,-\omega_1A]^\top.
\end{aligned}
\label{eq:lateral_phase_initial_states}
\end{equation}
For every initialization, the study records the complete predicted
$v_{k\mid j}$, $\omega_{k\mid j}$, $v_{s,k\mid j}$, modal-state, and
$H_{\mathrm{modal},k\mid j}$ horizons, together with
$a_{0\mid j}^{\star}$, $\alpha_{0\mid j}^{\star}$, and
$v_{s,0\mid j}^{\star}$. The comparison directly tests whether identical
robot and path states produce different future plans when liquid phase changes.
The allocation of longitudinal and lateral results between the main text and
supplementary material is frozen before the result values are inspected.

\subsubsection{Counterfactual replay of the propagated runtime state}

The constructed phase states establish whether the OCP is sensitive in
principle. A separate actual/zero replay tests whether the internally propagated
state recorded during formal high-risk trials changed the optimizer in normal
operation. This state is generated from odometry; it is not treated as a direct
measurement of the physical free surface.

For control cycle $j$, let $\mathcal S_j$ contain the pre-solve solver and
warm-start snapshot, previous solution, previous accepted control, previous
published command, guarded progress, effective speed reference, container
parameters, and any shared deployment context. The two branches are
\begin{equation}
\begin{aligned}
\mathcal P_{\mathrm{actual},j}
&=\mathcal P(\hat{\bm x}_{r,j},\hat{\bm x}_{\ell,j},
\mathrm{path}_j,\mathcal S_j),\\
\mathcal P_{\mathrm{zero},j}
&=\mathcal P(\hat{\bm x}_{r,j},\bm 0,
\mathrm{path}_j,\mathcal S_j).
\end{aligned}
\label{eq:actual_zero_replay}
\end{equation}
Both branches are cloned from the same immutable pre-solve snapshot; they are
not solved sequentially on one mutable solver instance. Before a cycle enters
the counterfactual comparison, the actual branch must reproduce the online
solver status, first control, and raw solver command within frozen numerical
tolerances. Nonreproduced cycles are reported as replay failures and are not
silently included in the action-difference distribution.

The primary replay quantities are
\begin{equation}
\begin{aligned}
\Delta a_{0,j}
&=a_{0,j}^{\star}(\hat{\bm x}_{\ell,j})
-a_{0,j}^{\star}(\bm 0),\\
\Delta\alpha_{0,j}
&=\alpha_{0,j}^{\star}(\hat{\bm x}_{\ell,j})
-\alpha_{0,j}^{\star}(\bm 0),\\
\Delta v_{s,0,j}
&=v_{s,0,j}^{\star}(\hat{\bm x}_{\ell,j})
-v_{s,0,j}^{\star}(\bm 0).
\end{aligned}
\label{eq:replay_first_action_difference}
\end{equation}
Complete-horizon differences in $v$, $\omega$, $v_s$, modal state, and
$H_{\mathrm{modal}}$ provide supporting mechanism detail. Control cycles are
not treated as independent samples. Each trial first yields the median and p95
of $|\Delta a_0|$, $|\Delta\alpha_0|$, and $|\Delta v_{s,0}|$, together with
the fraction exceeding frozen numerical tolerances; inference and display then
use trial-level summaries. The reproduction rate and replay-failure rate are
reported with these distributions.

Unless both branches are also passed through identical snapshots of the
terminal, gate, and rate-limiter logic, the quantities in
\cref{eq:replay_first_action_difference} are called optimized first-action
differences, not counterfactual executed commands. This replay tests whether
the propagated internal state affected optimization; it does not establish
that the propagated state equals the true liquid state or that the
counterfactual branch would improve the physical response.

\subsubsection{Real-time performance}

Online computation is evaluated over every formal physical trial. The reported
statistics are solve-time median, p95, and maximum, together with
\begin{equation}
  r_{\mathrm{miss}}
  =\frac{1}{N_c}\sum_{j=1}^{N_c}
  \mathbb I(T_{\mathrm{solve},j}>\Delta t).
  \label{eq:deadline_miss_ratio}
\end{equation}
Solver failure, fallback action, and achieved control frequency are reported
separately. The RQ4 figure combines phase-dependent predicted plans,
trial-level actual/zero optimized first-action differences, and the solve-time
empirical cumulative distribution. Use of SQP-RTI or acados alone is not taken
as evidence of real-time feasibility.

\subsection{Long-Horizon Propagation and Command-Regularity Audit}
\label{sec:long_horizon_command_audit}

This supporting audit tests two failure modes that are not separate research
questions: progressive disagreement in the uncorrected modal propagation and
command chatter that may be hidden by the shared execution layer. The audit
does not constitute a proof of closed-loop stability. It restricts its claim to
the tested duration, path family, container, and command limits.

\subsubsection{Long-horizon propagation audit}

Eight independent $C_1$ runs use a frozen extended path formed by five
consecutive repetitions of the high-risk curvature sequence. Each run begins
from the same pre-specified physical rest criterion. The modal state is
initialized once before motion and is not reset between repetitions. Controller
weights, path geometry, camera processing, command limits, and deployment logic
remain identical to the main \SMPCC{} trials. A complete extended run is the
statistical sample; its five repetitions are paired within-run observations and
are not treated as independent trials.

Let $r\in\{1,\ldots,R_{\mathrm{long}}\}$ index repetitions, with
$R_{\mathrm{long}}=5$, and let $\mathcal W_r$ be the matched motion window of
repetition $r$. Let $\epsilon_H>0$ be a frozen small-denominator safeguard.
The normalized modal--vision disagreement is
\begin{equation}
  d_{H,r}
  =100\,
  \frac{
  \int_{\mathcal W_r}
  |H_{\mathrm{modal}}(t)-H_{\mathrm{vis}}(t)|\,\mathrm dt}
  {\max\!\left\{
  \int_{\mathcal W_r}H_{\mathrm{vis}}(t)\,\mathrm dt,
  \epsilon_H
  \right\}}.
  \label{eq:long_horizon_disagreement}
\end{equation}
The primary drift contrasts are the within-run last-minus-first differences
\begin{equation}
\begin{aligned}
  \Delta d_H
  &=d_{H,R_{\mathrm{long}}}-d_{H,1},\\
  \Delta H_{\mathrm{vis,p95}}
  &=H_{\mathrm{vis,p95},R_{\mathrm{long}}}
  -H_{\mathrm{vis,p95},1}.
\end{aligned}
  \label{eq:long_horizon_drift_contrasts}
\end{equation}
The same paired comparison is reported for contour-error p95, completion time
per repetition, command-regularity metrics, solve time, solver failure, and
fallback use. All repetition-wise curves are also shown to expose nonmonotonic
failure patterns that a first--last contrast could miss.

The tolerances $\delta_{d_H}$, $\delta_{H}$, and $\delta_e$ for model
disagreement, physical liquid response, and tracking degradation are frozen
from camera calibration and independent deployment tests before the extended
runs are inspected. ``No systematic degradation over the tested duration'' is
reported only when the one-sided 95\% intervals for the paired last--first
effects remain below their corresponding tolerances and the complete failure
record shows no late-run concentration. Failure to reject a zero trend alone is
not interpreted as evidence of no drift. Because $H_{\mathrm{vis}}$ is a
nonnegative envelope, this audit evaluates amplitude disagreement and physical
performance; it does not establish signed modal-phase accuracy.

\subsubsection{Command-regularity audit}

Command regularity is evaluated from the existing formal trials and the
long-horizon runs without adding another controller variant. For command layer
$g\in\{\mathrm{solver},\mathrm{post},\mathrm{pub}\}$, define the angular
total-variation rate and finite-difference command acceleration over an
analyzed window of duration $T_e$ containing $N_c$ control cycles as
\begin{equation}
\begin{aligned}
  \operatorname{TVR}_{\omega}^{(g)}
  &=\frac{1}{T_e}
  \sum_{j=1}^{N_c-1}
  |\omega_{j+1}^{(g)}-\omega_j^{(g)}|,\\
  \alpha_{\mathrm{cmd},j}^{(g)}
  &=\frac{\omega_j^{(g)}-\omega_{j-1}^{(g)}}{\Delta t_j}.
\end{aligned}
  \label{eq:command_regularity_metrics}
\end{equation}
The paper reports $\operatorname{TVR}_{\omega}^{(g)}$, RMS and p95 of
$\alpha_{\mathrm{cmd}}^{(g)}$, optimized $\alpha_{0\mid j}^{\star}$ RMS and
p95, the analogous linear-command quantities, and the rate of thresholded
direction reversals. It also reports the fraction of command-spectrum energy
above a frozen cutoff $f_{\mathrm{hf}}$. The cutoff, reversal threshold, and
spectral preprocessing are fixed from the measured base bandwidth and
independent deployment data, not from formal method outcomes.

Baseline, Smooth-only, and \SMPCC{} are compared through the same randomized
blocks used by RQ1. The intended conclusion is noninferiority of \SMPCC{}
command regularity to Smooth-only within frozen tolerances
$\delta_{\mathrm{TVR}}$, $\delta_{\alpha}$, and $\delta_{E}$. This audit does
not require \SMPCC{} to be the smoothest method. A low published-command
variation is insufficient when the raw solver output has high variation or
when $r_{\mathrm{int}}$ indicates frequent rate limiting; such a result is
attributed to the execution layer rather than to the optimizer.

\subsection{Supporting Model Consistency and Sensitivity}

Model consistency is diagnostic rather than a primary method outcome. With a
small denominator safeguard $\epsilon_H>0$, the vision-normalized signed
integral bias is
\begin{equation}
  \gamma_{\mathrm{bias}}
  =100\,
  \frac{\int_0^{T_e}(H_{\mathrm{modal}}-H_{\mathrm{vis}})\,\mathrm dt}
  {\max\{\int_0^{T_e}H_{\mathrm{vis}}\,\mathrm dt,\epsilon_H\}}.
  \label{eq:model_bias}
\end{equation}
The absolute-disagreement index replaces the numerator by
$\int_0^{T_e}|H_{\mathrm{modal}}-H_{\mathrm{vis}}|\,\mathrm dt$. These
quantities evaluate the internal model against the experimental reference and
cannot replace the RGB outcomes in RQ1--RQ3. Vision-based external observation
and integral model--experiment comparisons have precedent in anti-slosh
validation \cite{C01_Ferrari2026}, but that precedent does not establish the
accuracy of the present camera, calibration, or extraction pipeline.

Sensitivity to $\omega_1$, $\zeta$, $c_h$, initial modal state, and execution
delay is evaluated in simulation or log replay and reported in the
supplementary material. The supplementary analysis also contains the complete
actual/zero and optional phase-flip replay distributions, actual-branch
reproduction diagnostics, command intervention distributions, and the
correct-versus-incorrect $C_2$ computational mismatch. These analyses refine
the mechanism and model limitations but do not create an additional research
question.

The optional physical mismatch group applies the frozen $C_1$ parameter set to
$C_2$ for eight high-risk \SMPCC{} trials and is not included in the 88-trial
main analysis. A claim that geometry-based updating is physically necessary is
considered only if this controlled physical extension changes
$H_{\mathrm{vis}}$ under the pre-specified comparison. A difference between
correct and incorrect parameters in simulation or replay establishes only
optimizer sensitivity.

parameter, initial-state, delay, and phase-flip sensitivity analyses, report the

physical mismatch result only if that extension is collected.}
