\begin{abstract}
Mobile bases carrying open liquid containers can excite free-surface oscillations during acceleration, braking, and turning, which can reduce transport reliability and increase spill risk.
Unlike rigid payloads, liquid motion has dynamic memory: its future response depends not only on instantaneous base acceleration, but also on the current modal displacement, modal velocity, and residual oscillation phase.
This paper studies online local planning for open-liquid transport along a given geometrically feasible reference path.
We propose \SPMPC{}, a slosh-aware model predictive contouring control method that augments the mobile-base and path-progress states with a low-order slosh modal state.
The resulting receding-horizon planner jointly optimizes contouring error, lag error, path progress, executable base commands, control smoothness, and predicted slosh response.
We also formulate a soft Slosh-risk Reference Governor, which contracts the speed reference before the \MPCC{} solve without directly overriding the final base command.
The evaluation separates internal model proxy quantities from external liquid-surface observations, and uses ablations and physical trials to examine whether explicit slosh-state prediction explains liquid-response improvements beyond smooth-only motion generation.
\end{abstract}
