\title{\SMPCC: Slosh-Aware Model Predictive Contouring Control for Open-Liquid Transport on Mobile Bases}

\author{Renjun Zhang%

\maketitle

\begin{abstract}
Mobile bases carrying open liquid containers can excite free-surface oscillations during acceleration, braking, and turning. Liquid motion has dynamic memory: its future response depends on the current modal displacement, modal velocity, and oscillation phase as well as future base excitation. This paper formulates \SMPCC{}, an online receding-horizon local motion planner and controller for transport along a prescribed geometrically feasible reference path. The method augments robot motion and virtual path progress with a container-parameterized first-mode liquid model whose state is propagated from odometry. A slosh-aware \MPCC{} problem then selects state-dependent motion while retaining executable base constraints and first-action receding-horizon output. The evaluation uses matched slosh-agnostic and smooth-only \MPCC{} variants, an independently tuned completion-time-matched comparison, and geometry-based transfer across containers without controller-weight retuning. Physical liquid-response claims rely on a calibrated vision-based reference measurement rather than the internal modal prediction.
\end{abstract}
