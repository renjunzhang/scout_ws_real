\section{实验与验证}

本节围绕 \SPMPC{} 的核心主张组织实验与验证：显式晃液状态预测是否能在单纯平滑控制之外提供可解释的防晃作用，并且不以不可接受的路径跟踪、任务完成时间或实时性代价为条件。实验采用仿真--实物双层证据链：仿真实验用于系统比较内部消融和外部基线，实物实验用于检查真实液面响应及模型代理量的解释能力，在线求解统计用于验证该方法仍满足移动底盘局部规划器的部署要求。

\subsection{实验设置与评价指标}

实验范围与问题定义保持一致：标准轮式移动底盘携带开口液体容器沿给定安全参考路径运动。仿真比较不同规划器在相同参考路径、底盘约束和任务终止条件下的行为；实物实验记录外部液面观测，并检查内部模型代理量是否具有解释价值。

为保证比较公平，正式实验固定起点、终点、参考路径、容器配置、任务终止条件和失败判据，并尽量对齐最大线速度、角速度、线加速度和角加速度。外部基线方法不使用液面状态作为控制输入。所有试次记录轨迹、速度、控制输入、求解时间、内部模型代理量和外部液面观测。这里需要特别区分两类量：\texttt{/spmpc/slosh\_height}、$H_{\mathrm{model}}^{\mathrm{modal}}$ 和 $H_{\mathrm{model}}^{\mathrm{full}}$ 只能作为模型内部预测或诊断代理量；真实液面结论必须依赖 RGB 最大 LCR、液面高度测量或其它外部观测指标。

为避免仅依赖内部模型指标评价方法效果，本文比较模型代理量与外部液面观测 $H_{\mathrm{vis}}(t)$。在模型--外部一致性分析中，记实际参与评价的模型代理量为 $H_{\mathrm{model}}^{\mathrm{eval}}(t)$；它可以取 $H_{\mathrm{model}}^{\mathrm{modal}}(t)$ 或 $H_{\mathrm{model}}^{\mathrm{full}}(t)$，但报告时必须明确说明采用哪一种口径。借鉴 Ferrari 等在跨平台防晃轨迹规划中将低阶模型液面高度与视频提取实验液面进行对照的验证口径\cite{C01_Ferrari2026}，本文采用带符号偏差评价模型整体偏保守或低估：
\begin{equation}
  \gamma_{\mathrm{bias}} =
  100\cdot
  \frac{\int_{t_0}^{t_1}\left(H_{\mathrm{model}}^{\mathrm{eval}}(t)-H_{\mathrm{vis}}(t)\right)\dd t}
  {\int_{t_0}^{t_1}H_{\mathrm{model}}^{\mathrm{eval}}(t)\dd t+\epsilon},
  \label{eq:gamma_bias}
\end{equation}
其中 $[t_0,t_1]$ 覆盖有效底盘命令开始到到达后的残余振荡记录窗口，$\epsilon$ 是防止分母退化的小常数。$\gamma_{\mathrm{bias}}>0$ 表示模型整体偏保守，$\gamma_{\mathrm{bias}}<0$ 表示模型整体低估外部液面指标。绝对偏差定义为
\begin{equation}
  \gamma_{\mathrm{abs}} =
  100\cdot
  \frac{\int_{t_0}^{t_1}\left|H_{\mathrm{model}}^{\mathrm{eval}}(t)-H_{\mathrm{vis}}(t)\right|\dd t}
  {\int_{t_0}^{t_1}H_{\mathrm{vis}}(t)\dd t+\epsilon}.
  \label{eq:gamma_abs}
\end{equation}
辅助指标包括 RMSE、相关系数 $\rho$、相位偏移 $\tau^\star$、峰值误差、高分位误差和最大局部低估量。模型--外部一致性只用于诊断解释，不替代真实液面结论，也不构成形式化防溢出保证。若 $H_{\mathrm{model}}^{\mathrm{eval}}$ 与 $H_{\mathrm{vis}}$ 存在显著相位差或局部峰值低估，相应结果应解释为模型诊断发现，而不是直接作为安全门限依据。

\subsection{仿真实验：内部消融与外部基线对比}

仿真实验用于在可控条件下系统比较不同规划策略。该部分首先通过内部消融分离控制平滑性与晃液状态预测的作用，再与普通在线局部规划器以及可公平复现的移动底盘防晃近邻方法比较。仿真结论应由相同任务接口、相同底盘约束和相同失败判据下的统计结果支持，而不是由单次示例轨迹或内部代理量单独支撑。

内部消融用于回答“\SPMPC{} 是否只是更强的平滑控制”。所有变体共享同一带路径进度状态的 \MPCC{} 框架、同一参考路径和同一底盘约束，只改变晃液模型/代价和平滑权重。变体定义已在 \cref{tab:method_variants} 中给出，包括 \texttt{B0}、\texttt{B\_smooth}、\texttt{B\_slosh} 和 \texttt{B\_ours}。

消融比较按四个问题组织。\texttt{B\_smooth} 与 \texttt{B0} 用于量化只增强平滑性带来的变化；\texttt{B\_slosh} 与 \texttt{B0} 用于量化显式晃液状态预测是否具有独立作用；\texttt{B\_ours} 与 \texttt{B\_smooth} 用于检验完整方法是否超越 smooth-only；\texttt{B\_ours} 与 \texttt{B\_slosh} 用于说明平滑控制仍然是生成可执行局部命令的一部分。只有当外部液面指标支持相同趋势时，才能将 \texttt{B\_ours} 相对于 \texttt{B\_smooth} 的差异解释为真实液面响应改善；若只有内部代理量下降，则只能说明规划器在自身模型下减小了预测晃液响应。

普通在线局部规划器对比用于检验“不传播液体状态的在线局部规划是否已经足够”。外部基线可以包括 DWA、TEB、\texttt{mpc\_local\_planner} 或 LT-DWA 系列规划器。它们与本文处于相近部署层级，能够在线生成底盘命令，但通常不传播液体动态记忆。进入主表的方法应满足接口可运行、底盘约束可对齐、任务定义一致和日志可复现等条件；比较指标包括成功率、到达时间、路径误差、外部液面指标和求解时间。

移动底盘防晃近邻方法用于解释本文与已有液体运输工作的层级差异。可比较对象包括 Hamaguchi 式路径/速度剖面、输入整形策略、Lim 式离线液体约束轨迹或其它能在同一任务中复现实验接口的防晃方法。若某类方法能在相同任务接口下公平复现，则进入定量比较；若无法公平复现，则只作为相关工作中的层级参照，不进入主结果表。该处理避免把不同平台、不同控制输入或不同决策层级的方法强行写成同层 baseline。

\paragraph{结果组织：} 内部消融结果表汇总外部液面响应、任务完成、路径跟踪、控制平滑性、模型--外部一致性和求解时间；代表性时间序列展示相近任务完成代价下仅平滑控制与晃液状态预测的差异。外部基线结果表分别报告普通局部规划器和可复现防晃近邻方法的比较结果；不可公平复现的方法仅作为层级参照，不进入定量排名。

\subsection{实物实验：真实液面响应与模型一致性}

实物实验用于检查仿真趋势是否能由真实外部液面观测支持，并验证内部模型代理量是否具有解释能力。实物平台记录最终发送到底盘的命令、外部液面观测、内部模型代理量和关键执行链路诊断，以区分方法效果与底盘执行、传感延迟或命令门控造成的影响。在实物实验中，\texttt{/spmpc/slosh\_height} 仍只作为模型内部代理量；真实液面响应结论应由 RGB、液位传感或其它外部液面观测支持。

实物比较优先覆盖能够直接回应主张的代表性设置，例如 \texttt{B\_smooth} 与 \texttt{B\_ours} 的对比，或在条件允许时加入 \texttt{B0}、\texttt{B\_slosh} 和普通局部规划器。报告时应同时呈现任务完成、路径跟踪、控制输入和外部液面响应，避免把降低速度或终端停顿误写为防晃效果。

模型--外部液面一致性分析在本节报告，指标定义见前文实验设置。该分析比较 $H_{\mathrm{model}}^{\mathrm{eval}}$ 与 $H_{\mathrm{vis}}$ 的幅值偏差、整体低估或保守性、相关性、相位偏移以及峰值/高分位误差，用于判断内部代理量能否解释外部液面变化。若模型代理量与外部观测存在明显幅值误差、局部低估或相位延迟，则相应结论应限制为模型诊断，而不能替代真实液面评价。

\paragraph{结果组织：} 实物结果图展示代表性外部液面曲线、底盘命令和模型代理量；统计表汇总真实液面响应、任务完成、路径跟踪和模型--外部一致性指标。真实液面结论只由外部观测支持，内部代理量仅用于解释规划器预测与外部响应之间的关系。

\subsection{在线求解性能与执行诊断}

在线求解性能单独报告，用于验证 \SPMPC{} 仍是可部署的滚动时域局部规划器，而不是离线防晃轨迹优化。统计内容包括 OCP 求解时间、控制频率、求解失败次数、超时次数以及极端试次。求解时间应至少报告中位数和高分位耗时，并与目标控制周期比较。

执行诊断用于解释实物系统中的偏差来源，包括求解器输出、最终 \texttt{/cmd\_vel}、命令限幅、终端减速、传感延迟和底盘执行响应等。上述诊断量服务于实验可解释性，不构成 \SPMPC{} 的核心方法贡献；若执行链路显著改变优化器输出，则相应实物结论应明确限定在该执行条件下。

\paragraph{结果组织：} 在线求解统计表报告求解时间分布、控制频率和失败次数；执行诊断图或表用于说明优化器输出与最终底盘命令之间是否存在明显差异。该部分的作用是支撑在线局部规划部署可行性，而不是给出独立的防晃性能结论。
