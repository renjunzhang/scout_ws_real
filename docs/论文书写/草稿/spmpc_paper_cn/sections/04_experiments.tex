\section{实验设计与验证计划}

本节目前只给出实验框架和写作口径，不填写尚未获得的实验结果。实验章节的作用不是形成规划器排行榜，而是围绕本文核心主张组织证据：\textbf{显式晃液状态预测是否能在单纯平滑控制之外进一步降低液体晃动，并且不以不可接受的路径跟踪、到达时间或实时性代价为条件。} 后续完成仿真或实物实验后，应在本节相应位置填入数据、图表和失败案例，而不是改变主线问题。

\subsection{实验场景与公平协议}

第一版实验范围应与本文问题定义一致：给定安全参考路径上的移动底盘开口液体运输。实验场景可以分为仿真验证和实物验证两层。仿真用于快速检查不同规划器在同一参考路径和约束下的行为；实物实验用于评价真实液面响应，并验证内部模型代理量是否具有解释价值。

公平协议应在所有正式对比前固定：

\begin{enumerate}
  \item \textbf{统一任务：} 相同起点、终点、参考路径、容器配置和任务终止条件；
  \item \textbf{统一底盘限制：} 尽量对齐最大线速度、角速度、线加速度和角加速度；
  \item \textbf{统一初始化：} 正式仿真比较应使用全新启动的仿真环境；若只是当前仿真诊断，应明确不计入正式结果；
  \item \textbf{统一评价：} 外部基线方法不使用液面状态作为控制输入；真实液面指标来自 RGB 或其它外部观测；
  \item \textbf{统一失败判据：} 记录超时、未到达、碰撞、明显偏离参考路径、求解失败等情况；
  \item \textbf{统一记录：} 保存轨迹、速度、控制输入、求解时间、内部晃液代理量和外部液面观测。
\end{enumerate}

这里需要特别区分两类量：\texttt{/spmpc/slosh\_height} 只能作为模型内部预测或诊断代理量；真实液体结论必须依赖 RGB 最大 LCR、液面高度测量或其它外部观测指标。

\subsection{外部局部规划器对比}

外部对比用于回答“普通在线局部规划器调好以后是否已经足够”。这一组基线方法不是为了证明 \SPMPC{} 在所有导航指标上排名第一，而是为了提供缺口证据：普通规划器可以在线生成可执行和平滑运动，但通常不传播液体动态记忆。

候选基线方法分为两类。第一类是同层移动机器人局部规划器，例如 DWA、TEB、\texttt{mpc\_local\_planner} 或 LT-DWA 系列规划器；它们是外部主对比对象。第二类是防晃速度剖面或离线参考轨迹，例如 Hamaguchi 式速度/路径剖面或 Lim 式晃液约束轨迹；它们用于解释相关工作差异，不一定作为同层在线基线进入主表。最终进入主表的方法必须满足接口可运行、约束可对齐、任务定义一致和日志可复现四个条件。

\subsection{结果小节占位结构}

实验完成后，本节可以按下面结构展开。当前版本只保留占位，避免在没有数据前写结果性判断。

\begin{enumerate}
  \item \textbf{实验设置与公平性检查：} 说明路径、容器、底盘限制、初始化、日志和评价方法是否一致；
  \item \textbf{内部消融：} 填入 \texttt{B0}/\texttt{B\_smooth}/\texttt{B\_slosh}/\texttt{B\_ours} 的主要表格和典型曲线；
  \item \textbf{外部规划器对比：} 填入普通局部规划器基线的对比表和代表性失败/成功案例；
  \item \textbf{真实液面观测：} 填入 RGB 或外部液面测量结果，并与内部代理量分开解释；
  \item \textbf{实时性分析：} 填入求解时间、控制频率和求解失败统计；
  \item \textbf{局限性：} 说明模型误差、权重敏感性、路径类型、液体参数和传感噪声等边界。
\end{enumerate}

最终写作时，若某个实验没有完成，应明确标注为未完成或移到后续工作，不能用内部代理量替代真实液面结论，也不能把计划对比写成已观测结果。
