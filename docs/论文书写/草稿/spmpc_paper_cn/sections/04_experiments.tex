\section{实验}

本节围绕 \SPMPC{} 的核心主张组织实验：显式晃液状态预测是否能在单纯平滑控制之外进一步降低液体晃动，并且不以不可接受的路径跟踪、到达时间或实时性代价为条件。尚未完成的实验结果在本文稿中以结果占位标注；这些占位只能用真实仿真、实物或外部液面观测数据替换，不能用内部代理量代替真实液面结论。

\subsection{实验设置与评价指标}

实验范围与问题定义保持一致：标准轮式移动底盘携带开口液体容器沿给定安全参考路径运动。仿真用于比较不同规划器在相同参考路径、底盘约束和任务终止条件下的行为；实物实验用于评价真实液面响应，并检查内部模型代理量是否具有解释价值。

正式比较应固定以下条件：相同起点、终点、参考路径、容器配置、任务终止条件和失败判据；尽量对齐最大线速度、角速度、线加速度和角加速度；外部基线方法不使用液面状态作为控制输入；真实液面指标来自 RGB 或其它外部观测；所有试次记录轨迹、速度、控制输入、求解时间、内部晃液代理量和外部液面观测。

这里需要特别区分两类量：\texttt{/spmpc/slosh\_height} 只能作为模型内部预测或诊断代理量；真实液体结论必须依赖 RGB 最大 LCR、液面高度测量或其它外部观测指标。

\subsection{内部消融实验}

内部消融用于回答“\SPMPC{} 的每个模块是否必要”。所有变体共享同一带路径进度状态的 \MPCC{} 框架、同一参考路径和同一底盘约束，只改变晃液模型/代价和平滑权重。变体定义已在 \cref{tab:method_variants} 中给出，包括 \texttt{B0}、\texttt{B\_smooth}、\texttt{B\_slosh} 和 \texttt{B\_ours}。

结果解释应围绕四组比较展开：\texttt{B\_smooth} 与 \texttt{B0} 用于量化平滑性收益；\texttt{B\_slosh} 与 \texttt{B0} 用于量化液体状态预测收益；\texttt{B\_ours} 与 \texttt{B\_smooth} 用于回答仅平滑控制是否足够；\texttt{B\_ours} 与 \texttt{B\_slosh} 用于说明平滑控制仍然是可执行局部规划的一部分。

\subsection{普通在线局部规划器对比}

普通在线局部规划器对比用于回答“非液体感知局部规划器调好以后是否已经足够”。外部基线可以包括 DWA、TEB、\texttt{mpc\_local\_planner} 或 LT-DWA 系列规划器。它们与本文处于相近部署层级，能够在线生成底盘命令，但通常不传播液体动态记忆。

正式进入主表的方法应满足四个条件：接口可运行、底盘约束可对齐、任务定义一致、日志可复现。比较结果不应被解释为一般导航排行榜，而应服务于本文缺口：当任务包含开口液体时，普通局部规划器的平滑性和在线性是否足以替代液体状态预测。

\paragraph{结果占位：} 当前尚未填入普通局部规划器对比数据。结果完成后，本段应给出各基线与 \SPMPC{} 的成功率、到达时间、路径误差、真实液面指标和求解时间，并保留失败或超时试次。

\subsection{移动底盘防晃近邻对比}

移动底盘防晃近邻方法用于解释本文与已有液体运输工作的层级差异。可比较对象包括 Hamaguchi 式路径/速度剖面、输入整形策略、Lim 式离线液体约束轨迹或其它能在同一任务中复现实验接口的防晃方法。它们的作用不是作为同层局部规划器排行榜，而是说明：具有液体模型的防晃方法若位于离线规划、速度剖面或跟踪控制层，与在线局部规划层的 \SPMPC{} 仍存在接口和决策层级差异。

\paragraph{结果占位：} 当前尚未填入移动底盘防晃近邻对比数据。若无法公平复现某类方法，应在本段明确说明其作为相关工作参照而非主实验基线，并避免把不可复现实验写成已完成结果。

\subsection{实时性、鲁棒性与实物验证}

实时性分析应报告 OCP 求解时间、控制频率、求解失败次数和极端试次。鲁棒性分析可覆盖不同路径类型、不同初始晃液状态、不同液位或不同权重设置。实物验证应记录最终发送到底盘的命令、外部液面观测、内部模型代理量和关键执行链路诊断，以区分方法效果与底盘执行、传感延迟或命令门控造成的影响。

\paragraph{结果占位：} 当前尚未填入实时性、鲁棒性和实物实验数据。结果完成后，本段应说明 \SPMPC{} 是否能够在目标控制频率下稳定求解，并用真实液面观测支持“降低晃动”而不是仅报告内部 \texttt{/spmpc/slosh\_height} 的降低。
