\section{实验设计与结果}

实验围绕一个核心判断展开：显式传播液体动态状态，能否在单纯增强运动平滑性之外改善外部液面响应。评价同时考虑任务完成、路径误差和控制行为，避免把持续降速误写为防晃性能。由于当前方法沿给定路径运行，实验结论也限定在这一任务范围内。

\subsection{实验设置与评价协议}

所有内部消融共享起点、终点、参考路径、底盘运动边界、预测时域、求解器后端和终止判据。核心二维消融关闭预测速度参考整形，使液体预测与平滑配置成为仅有的两个设计因子。外部方法比较时采用相同任务定义，并尽可能对齐线速度、角速度及其加速度边界。

实物评价使用三个时间口径。路径进度 10\% 至 90\% 的主窗口用于排除起步和终端判定对稳定运动统计的支配；全程窗口记录到达时间与任务成功；到达后的固定窗口用于分析残余振荡。当前表格报告主窗口结果。重复试次以均值加减标准差表示。

真实液面响应由标定后的 RGB 液面包络 $H_{\mathrm{vis}}$ 评价，主指标为 p95 和 RMS。内部代理量 $H_{\mathrm{model}}$ 采用 \cref{eq:h_model} 的统一口径，只用于解释规划器所预测的液体响应。两者量纲可以一致，含义并不相同。

模型与外部液面之间只做分层解释。若两类指标在组间呈现同向变化，可以说明低阶模型与外部响应具有趋势一致性；逐帧相位保真、真实高度重建和安全阈值有效性需要更强的标定与感知证据，不能由组均值代替。

\subsection{晃液预测与运动平滑性的二维消融}

\cref{tab:method_variants} 给出的四个变体构成二因素矩阵。$\mathrm{B}_{0}$ 与 $\mathrm{B}_{\mathrm{smooth}}$ 评价不含液体模型时的平滑作用，$\mathrm{B}_{0}$ 与 $\mathrm{B}_{\mathrm{slosh}}$ 评价弱平滑条件下液体预测的增量。完整矩阵还需要比较 $\mathrm{B}_{\mathrm{smooth}}$ 与 $\mathrm{B}_{\mathrm{ours}}$，从而判断强平滑条件下液体机制是否仍然有效。最后一组一因素比较由 $\mathrm{B}_{\mathrm{slosh}}$ 与 $\mathrm{B}_{\mathrm{ours}}$ 给出，用于分析液体模型启用后增强平滑的影响。

$\mathrm{B}_{\mathrm{smooth}}$ 与 $\mathrm{B}_{\mathrm{slosh}}$ 是对角线对比。它具有实际叙事价值，因为它检验晃液感知的弱平滑方法能否超过强平滑基线；但液体机制和平滑强度同时发生变化，因此这组差异不能被解释为液体预测的纯主效应。

当前实物统计覆盖 $\mathrm{B}_{0}$、$\mathrm{B}_{\mathrm{smooth}}$ 和 $\mathrm{B}_{\mathrm{slosh}}$。缺少 $\mathrm{B}_{\mathrm{ours}}$ 后，二维矩阵无法估计强平滑条件下的液体预测作用，也不能判断两个因素是否存在交互。现有数据因此用于提供趋势证据，不承担完整因果消融的结论。

\subsection{模型敏感性与在线计算}

低阶模型能否作为在线决策内核，不能只依据名义参数下的模型代理量判断。敏感性评价需要分别扰动固有频率、阻尼比与输入增益，并改变液体初始状态。固有频率可按名义值的 $\pm10\%$ 和 $\pm20\%$ 扫描，阻尼比采用更宽的相对偏差；非零初始模态用于模拟转弯前尚未衰减的残余晃动。输出应包括外部或高保真液面指标、任务完成情况，以及 $H_{\mathrm{model}}$ 相对评价量的退化幅度。

在线计算采用求解时间分布而不是单一平均值。除中位数和 p95 外，还需报告最大耗时、控制周期超时率、求解失败次数与实际控制频率。acados SQP-RTI 的使用说明了实现路径，不能代替本系统上的时间统计。

在上述统计补齐之前，本文不对模型参数鲁棒性或实时性作超出当前实物运行事实的推广。

\subsection{普通在线运动规划器对比}

内部 $\mathrm{B}_{0}$ 是识别液体预测作用的首要普通 \MPCC{} 基线，因为它与 \SPMPC{} 共享状态约束、路径进度、预测时域和数值求解框架。外部主基线宜保留一个可稳定复现的普通 MPC 或 MPCC 局部规划器，再加入 LT-DWA 作为具有长时域动力学搜索能力的对照\cite{D02_Jian2023}。DWA 与 TEB 可用于补充经典局部规划参考\cite{D15_Fox1997,D16_Rosmann2017}。

比较指标遵循局部规划器常用的任务效率、路径误差、控制平滑性和计算开销口径\cite{D21_Wen2021}，并额外加入相同的外部液面观测。各方法不使用液体状态作为反馈，只有 \SPMPC{} 传播低阶液体状态。

若实验仍采用无障碍固定路径，外部比较反映的是在线命令生成、跟踪和液体运输表现。DWA、TEB 与 LT-DWA 的局部避障能力没有被充分调用，结果不能外推为完整导航性能排名。在同口径结果完成前，本节不对外部方法作定量排序。

仅增强平滑性并未在这组试次中带来一致的外部液面收益。与 $\mathrm{B}_{0}$ 相比，$\mathrm{B}_{\mathrm{smooth}}$ 的 $|\omega|$ p95 从 $0.234$ 降至 $0.202\,\mathrm{rad/s}$，模型代理量也略有下降；RGB p95 和 RMS 则分别升至 $1.272$ 和 $0.639\,\mathrm{mm}$。更低的角速度高分位本身不足以说明真实液面响应改善。

在 $\mathrm{B}_{\mathrm{slosh}}$ 与 $\mathrm{B}_{\mathrm{smooth}}$ 的对角线比较中，模型 p95 和 RMS 分别降低 $36.4\%$ 与 $37.4\%$，RGB p95 和 RMS 分别降低 $29.2\%$ 与 $15.9\%$。$\mathrm{B}_{\mathrm{slosh}}$ 的 $|\omega|$ p95 反而略高，因此这组外部液面差异不能由较小角速度单独解释。这是当前结果中最直接的正向趋势。

代价同样存在。$\mathrm{B}_{\mathrm{slosh}}$ 的平均到达时间为 $36.851\,\mathrm{s}$，长于另外两组；其投影误差与角速度指标也不是最优。相对 $\mathrm{B}_{0}$，该变体降低了 RGB p95，但 RGB RMS 基本持平。故当前数据支持的是代表性固定路径条件下的液面响应趋势，不是所有任务指标上的全面占优。

内部代理量与 RGB 指标在 $\mathrm{B}_{\mathrm{slosh}}$ 相对 $\mathrm{B}_{\mathrm{smooth}}$ 的组间变化方向一致。这种一致性有助于解释低阶模型为何会改变规划结果，却不能证明两条时间序列具有逐帧保真度。模型代理量也不能替代外部液面观测。

当前结果来自小样本代表性试次，尚未形成完整的四单元实物矩阵。没有 $\mathrm{B}_{\mathrm{ours}}$ 的同口径统计，也没有模型敏感性、求解时间分布和普通规划器结果，因而不作统计显著性、参数鲁棒性或广泛规划优越性的主张。
