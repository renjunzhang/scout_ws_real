\section{结论与讨论}

本文计划将移动底盘开口液体运输中的防晃问题定位为在线局部轨迹规划问题，而不是普通路径跟踪问题或通用流体建模问题。核心观点是：液体晃动具有动态记忆，局部规划器需要在生成运动时传播液体模态状态，并在路径进度、底盘控制和预测液体响应之间进行权衡。

\SPMPC{} 的预期贡献是将低阶液体模态状态嵌入 alpha-state \MPCC{} 局部规划框架，在滚动时域内联合优化路径进度、线加速度、角加速度和预测液体响应。与固定路径速度剖面、离线防晃轨迹优化和给定轨迹后的防晃跟踪控制相比，本文强调在线局部规划层的防晃决策；与普通移动机器人 local planner 相比，本文强调液体动态状态和历史激励的作用。

实验讨论应回到以下问题：

\begin{itemize}
  \item 显式液体状态预测是否比 smooth-only 更能降低真实液面晃动？
  \item SPMPC 是否在保持到达和路径跟踪能力的同时降低晃动，而不是单纯变慢？
  \item 普通 local planner 在没有液体动态记忆时会暴露什么不足？
  \item 内部模型 proxy 与外部真实液面评价是否被清楚区分？
  \item 当前方法的边界在哪里？
\end{itemize}

第一版工作的局限包括：本文主要考虑给定安全参考路径上的局部轨迹规划；完整障碍物感知 \MPCC{}、homotopy/corridor 推理、随机机会约束、复杂自由液面高保真模型、在线液体参数自适应和真实化学实验室长期部署不作为本文主贡献。后续工作可以围绕更复杂环境中的 obstacle-aware 防晃局部规划、液体状态观测与模型自适应、多液位/多容器鲁棒性，以及真实实验室任务闭环部署展开。

最终结论应服务于一句话：

\begin{quote}
  SPMPC 不是“普通 local planner 加液体代价”，而是移动底盘液体运输方向中，面向在线局部轨迹规划阶段的防晃方法。
\end{quote}
