\section{引言}

移动机器人正在进入化学实验室、服务和工业转运等场景，其中一类具有代表性的任务是在室内环境中运输开口或半开口液体容器。与固体负载不同，液体会在加速、制动和转弯过程中产生自由液面晃动。对于实验室液体运输而言，液体晃动不仅会降低运输效率，还可能造成样品损失、环境污染、等待时间增加甚至任务失败。因此，移动底盘在执行液体运输任务时需要的不只是几何可行、速度平滑的运动命令，还需要能够感知液体动态响应的局部运动生成方法。

本文关注的问题是：在给定安全参考路径的条件下，标准轮式移动底盘如何在线生成可执行的局部运动，同时预测并抑制由底盘运动激发的开口液体晃动。该问题位于液体防晃运动生成与移动机器人局部规划的交界处。本文的基本判断是：\textbf{液体晃动不是简单的轨迹平滑问题，而是具有动态记忆的状态预测问题。} 相同的速度、加速度或 jerk 限制可能产生不同的液体响应，因为未来晃动不仅取决于未来激励，还取决于当前液体模态位移、速度和残余振荡相位。

\subsection{研究动机与问题缺口}

已有液体防晃研究已经形成了较长的发展脉络。低阶晃液建模与估计工作表明，容器运动引起的主导晃液可以用等效摆、质量--弹簧--阻尼或模态状态进行近似，并由容器加速度驱动\cite{A02_Guagliumi2021,A01_Leva2021}。输入整形和命令预整形方法说明，通过改变激励的频率成分可以降低残余振动\cite{A07_Singer1990}。在移动底盘或移动容器场景中，Hamaguchi 等人的系列工作已经研究了圆柱容器曲线路径转运、轮式移动机器人速度/路径设计以及路径跟踪控制\cite{B04_Hamaguchi2002,B03_Hamaguchi2004,B02_Hamaguchi2005}；后续工作还发展出主动抑振机构和并联机构补偿路线\cite{B05_Hamaguchi2019,B06_Hamaguchi2018}。近期也出现了移动机器人液体约束离线轨迹优化\cite{B01_Lim2024}、time-optimal anti-sloshing planning and tracking\cite{B11_Viet2025} 以及特殊服务机器人上的 slosh-aware MPC tracking/control\cite{B12_Prabakaran2026}。

这些工作说明，液体防晃并不是一个空白问题；尤其是 predictive control 或 MPC 框架中引入晃液动力学也已有研究基础\cite{A12_Okatsuka2011,C05_Okatsuka2012}。因此，本文不将贡献表述为“首次将晃液状态放入 MPC”。更准确的缺口在于规划层级和部署接口：许多防晃方法是 liquid-aware 的，但面向固定路径、给定轨迹、专用转运机构、特殊移动平台、主动抑振硬件或离线轨迹优化；而普通移动机器人局部规划器具有在线性和可执行性，但通常只预测机器人、障碍物或几何路径状态，不传播被运输液体的动态记忆\cite{D02_Jian2023,D03_Zhang2025,D06_Williams2017,D13_Berscheid2021}。

这形成了本文要连接的两条研究线：一方面，anti-slosh 方法能够利用液体模型降低晃动，但往往不是导航栈中每个控制周期输出底盘命令的 online local planner；另一方面，ordinary local planners 能够在线跟踪路径、避让障碍并生成平滑控制，却通常不是 liquid-aware。本文希望在标准轮式移动底盘的局部规划层连接二者。

\subsection{关键挑战}

面向移动底盘开口液体运输的晃液感知局部规划主要面临三个挑战。

\begin{enumerate}
  \item \textbf{液体晃动具有动态记忆。} 液体响应不是当前加速度或曲率的静态函数。即使未来控制序列在速度、加速度或 jerk 意义下足够平滑，如果它与当前液体相位耦合不当，也可能放大残余晃动。因此，规划器需要在预测时域内显式传播液体状态。
  \item \textbf{普通移动机器人局部规划器通常不包含液体状态。} DWA、MPC/MPPI、trajectory optimization 或 jerk-limited trajectory generation 等方法可以在线生成可执行运动，但其状态和代价函数通常关注机器人可行性、路径误差、障碍风险、控制平滑性或时间效率，而不包含 $[\eta,\dot{\eta}]$ 这类液体模态变量。
  \item \textbf{已有防晃方法多不处在标准底盘 online local planning 层。} 固定路径设计、速度剖面、输入整形、离线防晃轨迹优化、预测/MPC 跟踪控制和主动抑振机构均可降低晃动，但它们通常不以标准轮式移动底盘的局部规划器形式，在每个控制周期根据当前状态、参考路径和液体状态求解短时域最优控制问题，并输出可执行底盘命令。
\end{enumerate}

\subsection{本文方法概述}

为解决上述问题，本文提出晃液感知模型预测轮廓控制方法（Slosh-aware Model Predictive Contouring Control, \SPMPC）。\SPMPC{} 以 \MPCC{} 为局部规划骨架，在机器人状态和路径进度状态之外引入低阶晃液模态状态。规划器在滚动时域内同时预测底盘运动和液体响应，并联合优化路径跟踪误差、路径进度、可执行底盘控制、控制平滑性以及预测晃液状态。

与仅惩罚速度变化、加速度或 jerk 的 smooth-only 方法不同，\SPMPC{} 让当前液体模态位移和速度直接影响未来运动选择。与给定轨迹后的防晃跟踪控制不同，\SPMPC{} 在局部轨迹生成阶段就把液体响应纳入优化。与离线全局防晃轨迹优化不同，\SPMPC{} 面向在线滚动执行，保留移动机器人 local planner 的接口和部署方式。

\subsection{贡献与范围}

本文的贡献限定为以下三点。

\begin{enumerate}
  \item \textbf{问题表述：} 将移动底盘开口液体运输表述为在线晃液感知局部规划问题，强调液体晃动是具有动态记忆的预测状态，而不是单纯的轨迹平滑性指标。
  \item \textbf{方法框架：} 提出包含低阶晃液模态状态传播的 \MPCC{} 局部规划框架，在同一滚动时域最优控制问题中联合优化路径跟踪、路径进度、底盘可执行控制、控制平滑性和预测晃液响应。
  \item \textbf{证据链设计：} 通过模块拆解式消融、非液体感知 local planner 对比和外部液面观测指标，验证显式晃液状态预测相对于 smooth-only 运动生成的独立价值。
\end{enumerate}

本文的第一版范围是沿给定安全参考路径的在线晃液感知局部规划。本文不将完整动态避障、homotopy/corridor 推理、随机机会约束、高保真 CFD/FEM/SPH 在线模型、CBF 形式安全证明或真实液面闭环观测器作为主贡献；内部模型预测的 slosh proxy 也不直接等同于真实液面测量。
