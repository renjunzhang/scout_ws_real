\section{引言}

移动机器人正在进入化学实验室、服务和工业转运等室内场景，其中一类具有代表性的任务是在室内环境中运输开口或半开口液体容器。与固体负载不同，液体会在加速、制动和转弯过程中产生自由液面晃动。对于液体运输任务而言，晃动不仅会降低运输效率，还可能造成样品损失、环境污染、等待时间增加甚至任务失败。因此，移动底盘在执行液体运输任务时需要的不只是几何可行、速度平滑的运动命令，还需要能够预测液体动态响应的局部运动生成方法。

本文关注的问题是：在预先给定的几何可行参考路径条件下，标准轮式移动底盘如何在线生成可执行的局部运动，同时预测并降低由底盘运动激发的开口液体晃动。本文的基本判断是：\textbf{液体晃动不是简单的轨迹平滑问题，而是具有动态记忆的状态预测问题。} 相同的速度、加速度或加加速度限制可能产生不同的液体响应，因为未来晃动不仅取决于未来激励，还取决于当前液体模态位移、速度和残余振荡相位。

已有研究分别从低阶晃液建模、输入整形、速度剖面、轨迹优化和跟踪控制等角度降低液体晃动\cite{A02_Guagliumi2021,A01_Leva2021,A07_Singer1990,A12_Okatsuka2011,C05_Okatsuka2012}；与此同时，移动机器人局部规划器已经能够在线生成满足运动约束、路径跟踪和局部避障要求的底盘命令\cite{D15_Fox1997,D16_Rosmann2017,D17_Rosmann2021,D19_Liniger2015,D20_Brito2019}。然而，这两类研究通常不在同一决策层上相交：前者多处于给定路径、给定轨迹、离线优化、特殊平台或额外机构控制层；后者虽然在线可部署，但通常不传播被运输液体的动态状态。因此，本文关注的不是“液体是否可以被建模”或“局部规划器是否可以在线运行”这两个单独问题，而是二者的交叉问题：在标准轮式移动底盘沿给定参考路径运动时，如何在局部规划层同时考虑路径推进、底盘可执行性和未来液体响应。

面向这一问题，规划器需要同时处理三点困难。第一，液体响应不是当前加速度或曲率的静态函数；即使未来控制序列在速度、加速度或加加速度意义下足够平滑，如果它与当前液体相位耦合不当，也可能放大残余晃动。第二，DWA、TEB、MPCC、MPPI 或加加速度受限轨迹生成等普通移动机器人局部规划方法可以在线生成可执行运动，但其状态和代价函数通常关注机器人可行性、路径误差、障碍风险、控制平滑性或时间效率，而不包含 $[\eta,\dot{\eta}]$ 这类液体模态变量。第三，已有防晃方法虽然能够通过固定路径设计、速度剖面、输入整形、离线防晃轨迹优化、预测控制、跟踪控制或主动抑振机构降低晃动，但通常不以标准轮式移动底盘的在线局部规划器形式，在每个控制周期根据当前状态、参考路径和液体状态求解短时域最优控制问题，并输出可执行底盘命令。

为解决上述问题，本文提出 \SPMPC{}（晃液感知模型预测轮廓控制）。\SPMPC{} 以 \MPCC{} 为局部规划骨架，在机器人状态和路径进度状态之外引入低阶晃液模态状态。规划器在滚动时域内同时预测底盘运动和液体响应，并联合优化路径跟踪误差、路径进度、可执行底盘控制、控制平滑性以及预测晃液状态。与仅惩罚速度变化、加速度或加加速度的平滑方法不同，\SPMPC{} 让当前液体模态位移和速度直接影响未来运动选择；与给定轨迹后的防晃跟踪控制不同，\SPMPC{} 在局部轨迹生成阶段就把液体响应纳入优化；与离线全局防晃轨迹优化不同，\SPMPC{} 面向在线滚动执行，保留移动机器人局部规划器的接口和部署方式。

\subsection{贡献与范围}

本文的贡献限定为以下三点。

\begin{enumerate}
  \item \textbf{液体动态记忆增强的在线 \MPCC{} 局部规划：} 提出一种面向移动底盘开口液体运输的在线晃液感知局部规划问题表述，并构建包含低阶晃液模态状态传播的 \MPCC{} 框架，在同一滚动时域最优控制问题中联合优化路径误差、路径进度、底盘控制平滑性和预测晃液响应。
  \item \textbf{有限时域预测参考适配：} 在不改变 \MPCC{} 状态维度和不直接覆盖底盘 \texttt{cmd\_vel} 的前提下，给出一种 soft Slosh-risk Reference Governor。该模块基于当前晃液状态对候选速度参考缩放因子进行有限时域预测筛选，只向 \MPCC{} 提供保守化的速度参考，用于表达“预测风险升高时降低参考速度”的软参考适配机制。
  \item \textbf{实验与验证协议：} 设计内部消融、普通局部规划器对比、移动底盘防晃近邻对比以及模型—外部液面一致性分析，用于评估显式晃液状态预测相对于仅平滑运动生成的独立作用，并防止将内部代理量误写为真实液面结论。
\end{enumerate}

本文的第一版范围是沿预先给定的几何可行参考路径进行在线晃液感知局部规划。本文不声称首次提出晃液感知 \MPC{}，也不处理完整动态避障、同伦/走廊推理、高保真流体仿真、形式化防溢出证明或真实液面闭环观测；内部模型预测的晃液代理量只用于优化和诊断，真实液面结论必须由外部视觉或液位观测支持。Slosh-risk Reference Governor 是软参考适配模块，不是硬安全锁存器；它只限制进入 \MPCC{} 的速度参考，不直接修改最终底盘命令，也不接入 RGB 真实液面反馈。
