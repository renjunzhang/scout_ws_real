## 1. 实验章节的核心目标

实验章节不能只回答“S-MPCC 是否降低了液面响应”，还需要回答：

1. S-MPCC 如何改变机器人在同一几何路径上的运动；
2. 液面改善是否只是来自普通平滑；
3. 液面改善是否只是因为机器人整体运行得更慢；
4. 液体状态和振荡相位是否真正改变了在线运动计划；
5. 方法能否在不同容器参数下继续工作；
6. 在线优化是否满足机器人控制周期的实时要求。

全文建议围绕以下核心命题建立证据：

> 在相同的给定几何路径、机器人约束和共享执行层条件下，S-MPCC 根据路径曲率和当前液体动态状态重新分配局部速度与加速度，从而降低实际测得的液面响应，同时保持路径跟踪精度、任务完成能力和实时可执行性。

实验论证顺序应保持为：

\[
\text{物理液面是否改善}
\rightarrow
\text{运动与激励为何改变}
\rightarrow
\text{是否只是更慢}
\rightarrow
\text{能否跨容器}
\rightarrow
\text{是否真正状态相关且在线}
\]

速度、角速度和加速度属于**机制证据**；真实视觉液面响应属于**效果证据**。二者需要联合出现，不能互相替代。

## 2. 任务定义与论文边界

### 2.1 当前任务定义

S-MPCC 是沿预先给定的几何可行路径运行的在线滚动时域局部运动规划与控制方法。控制器在同一预测时域内联合优化：

- 机器人运动；
- 虚拟路径进度；
- 传播的液体模态状态；
- 第一步实际执行控制。

论文应使用以下术语：

- **相同几何路径上的不同执行轨迹**；
- **prescribed-path motion planning and control**；
- **path following with optimized progress**；
- **receding-horizon motion generation along a prescribed path**。

不建议写“相同轨迹上的速度比较”。如果速度不同，时间参数化运动本身就不同；真正保持相同的是几何路径。

### 2.2 容器位置：保持安装在车体旋转中心

正式实验继续采用容器中心与车体旋转中心重合的安装方式。在当前模型下，容器受到的平面激励近似为

\[
a_x=a,\qquad a_y=v\omega.
\]

中心安装能够：

- 保证实验条件与当前模型严格对应；
- 隔离纵向加减速和路径曲率产生的主要液体激励；
- 避免容器安装位置引入额外旋转耦合；
- 将实验资源集中于液体动态记忆这一核心贡献。

当前主论文不建议增加容器偏心实验。若容器相对车体中心的位置为

\[
\mathbf r=[r_x,r_y]^\top,
\]

则还需要在 OCP 和在线液体传播中加入角加速度与向心加速度项：

\[
\begin{aligned}
a_{c,x}&=a-\alpha r_y-\omega^2r_x,\\
a_{c,y}&=v\omega+\alpha r_x-\omega^2r_y.
\end{aligned}
\]

因此，偏心安装属于模型扩展，而不是一个可以直接附加的简单鲁棒性测试。建议在局限性中明确说明：当前结果仅覆盖中心安装，偏心载荷需要扩展激励模型并进行新的系统验证。

### 2.3 不另设自由点到点模式

正式评价采用统一的给定路径任务，不将“固定路径”和“点到点”设计成两套并列模式。

如果点到点任务只提供起点和终点，并允许控制器自由选择几何路线，则还需要增加：

- 全局或局部路径几何生成；
- 障碍物和碰撞约束；
- 路线选择；
- 新的点到点规划基线；
- 路径长度、完成时间和液体响应之间的新公平性定义。

这些内容会改变当前论文的问题定义。若希望在论文视频或补充材料中展示更完整的机器人流程，可以由外部规划器根据起点和终点生成路径，再由 S-MPCC 执行；但应明确路线由外部模块产生，不把它作为 S-MPCC 的新规划能力。

### 2.4 当前主论文不声称

- 自由起终点之间的全局路径规划；
- 完整自主导航或动态避障；
- 任意容器安装位置下的通用防晃；
- 严格无溢出、稳定性或递归可行性保证；
- RGB 液面进入实时控制闭环；
- 高保真自由液面仿真；
- 优于未在统一协议下正式比较的外部规划器。

## 3. 三项论文贡献、研究问题与证据结构

### 3.1 三项论文贡献

当前 Introduction 中的三项贡献为：

1. **Online liquid-dynamic-memory MPCC formulation：** 将开放液体运输表述为沿给定路径的在线局部运动规划问题，并在 acceleration-level path-progress MPCC 中加入两个正交方向的一阶液体模态；
2. **Container-parameterized prediction and online propagation：** 建立圆柱容器几何到模态预测参数的可复现映射，并利用 odometry 激励在控制周期之间传播液体状态，使当前模态相位影响未来运动选择；
3. **Matched experimental evidence structure：** 通过 Baseline、Smooth-only、独立等完成时间比较、无权重重调的跨容器迁移、液体相位规划和视觉物理测量建立匹配证据。

三项贡献与实验之间的关系如下。

| 贡献                     | 需要验证的关键含义                                             | 直接实验或分析                                             | 证据作用                                                                   | 当前状态                   |
| ------------------------ | -------------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------- |
| C1：液体动态记忆 MPCC    | 液体状态进入在线计划；产生不同运动；物理液面受益；可实时执行   | RQ1、RQ2、RQ4 四相位、runtime                              | RQ4 证明状态相关，RQ1 证明物理效果，RQ2 排除整体减速，runtime 证明在线可行 | 设计较完整，待正式数据     |
| C2：容器参数化与在线传播 | 几何参数改变预测；实际传播状态影响优化动作；无需权重重调即可跨容器 | RQ3、RQ4 四相位、实际状态反事实 log-replay、支持性模型诊断 | RQ3 验证参数迁移，RQ4 验证相位作用，log-replay 连接正式传播状态与优化动作 | 设计已补齐，replay 工具待验收 |
| C3：匹配物理验证         | 区分液体机制、普通平滑和减速，并使用外部物理参考               | RQ1–RQ4 整体                                              | 每个对照排除一个替代解释，视觉测量避免内部模型自证                         | 与设计直接对应，待正式数据 |

需要区分三类“证明”：

- Related Work 用于说明贡献的新颖性和研究位置；
- Method 用公式、算法和实现定义说明 formulation 和 parameterization 确实被提出；
- Experiments 用于证明这些机制产生了可测量的规划、物理和实时结果。

因此，实验不能单独证明公式具有原创性，但必须证明该公式所代表的机制确实影响在线决策并产生物理效果。

贡献与证据的压缩映射为：

\[
\begin{aligned}
\mathrm{C1}&\leftarrow
\mathrm{RQ1+RQ2+RQ4+runtime},\\
\mathrm{C2}&\leftarrow
\mathrm{RQ3+RQ4+counterfactual\ log\mbox{-}replay},\\
\mathrm{C3}&\leftarrow
\mathrm{RQ1\mbox{--}RQ4\ as\ a\ matched\ whole}.
\end{aligned}
\]

第三项贡献在正式数据完成前可以暂时使用 `Matched experimental evidence structure`。投稿版本更建议改成结果导向的表述，例如：

> **Matched physical validation of state-dependent slosh-aware planning.** Through matched Baseline and Smooth-only variants, an independently tuned completion-time-matched comparison, container transfer without controller-weight retuning, and controlled liquid-phase replanning, we demonstrate that [fill only with formal supported results].

这样可以避免把“设计了一套实验”本身作为主要科学结果。方括号内容必须在正式数据完成后填写，不能预先承诺结论。

### 3.2 四个研究问题

建议用四个研究问题组织实验章节，而不是按“轨迹、速度、加速度、RGB、求解器”分别拆节。

| 研究问题                  | 核心比较                                 | 主要证据                                            | 可支持的结论                                               |
| ------------------------- | ---------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------- |
| RQ1：物理有效性与任务性能 | Baseline、Smooth-only、S-MPCC            | 实测液面、同路径运动与激励、跟踪和成功率            | S-MPCC 是否有效，以及作用过程是否符合机制                  |
| RQ2：完成时间混杂         | Smooth-match、S-MPCC                     | 等完成时间下的液面和局部运动分配                    | 收益是否不只是来自整体减速                                 |
| RQ3：跨容器迁移           | 两个容器、三种方法                       | 容器内比较、归一化液面、参数切换规划                | 几何重参数化是否无需重新调权即可保持收益                   |
| RQ4：状态相关在线规划     | 不同液体相位；实际传播状态与零状态反事实 | 不同预测计划、optimized first action、log-replay 差异、求解时间 | 液体动态记忆和实际传播状态是否真正进入在线计划且可实时求解 |

四个 RQ 分别排除不同的替代解释：

- RQ1 排除“只在内部模型中变小”；
- Smooth-only 对照排除“只要普通平滑就够了”；
- RQ2 排除“只是跑得更慢”；
- RQ3 排除“只对单一容器调参有效”；
- RQ4 排除“只是生成了一条固定速度曲线”，并通过实际状态反事实回放排除“人工相位会影响计划，但正式运行中的传播状态未实际影响优化动作”。

## 4. 对照方法与公平性

### 4.1 三种核心方法

| 论文方法         | 冻结代码映射 | 液体状态 | Slosh cost | 通用平滑                 | 作用             |
| ---------------- | ------------ | -------- | ---------- | ------------------------ | ---------------- |
| Baseline MPCC    | `B0`         | 关闭     | 关闭       | 标准设置                 | 普通 MPCC 基线   |
| Smooth-only MPCC | `B_smooth`   | 关闭     | 关闭       | 增强                     | 检验通用平滑效果 |
| S-MPCC           | `B_slosh`    | 开启     | 开启       | 与 Baseline 保持名义一致 | 提出的方法       |

对照含义为：

- Baseline 与 S-MPCC：比较加入液体状态传播和 slosh cost 后的整体效果；
- Baseline 与 Smooth-only：确认增强平滑是否确实降低控制变化；
- Smooth-only 与 S-MPCC：比较通用平滑和液体状态感知规划。

正式采集、表格和图例只允许使用以上三个映射。`B_ours` 表示 slosh 与 enhanced smoothing 的叠加开发变体，不属于当前核心方法，也不得替代 `B_slosh` 进入 88 次主矩阵。正式采集前应为三种论文方法归档独立、只读的配置快照，避免运行时误选开发变体。

### 4.2 等完成时间方法

RQ2 增加 Smooth-match。该方法使用独立 pilot 数据调节 Smooth-only 的名义参考速度，使其完成时间与 S-MPCC 接近。

建议预先规定匹配条件，例如：

\[
\frac{
|\widetilde T_{\mathrm{smooth,match}}
-\widetilde T_{\mathrm{S\text{-}MPCC}}|
}{
\widetilde T_{\mathrm{S\text{-}MPCC}}
}
\leq \delta_T,
\]

其中可将 \(\delta_T\) 预先设置为 5% 或根据独立 pilot 的可实现精度冻结。

pilot 调节时只能检查完成时间，不能查看或利用正式 RGB 液面结果。达到匹配条件后必须冻结参数，再开始正式采集。

### 4.3 所有方法必须共享的条件

- 机器人模型；
- 参考路径；
- 初始状态规则；
- 运动约束；
- 预测时域和离散步长；
- 求解器及实时迭代设置；
- 执行层速度和命令变化限制；
- 终点减速、捕获和停止逻辑；
- command gate、fallback 和安全处理；
- 相机、标定、同步和液面提取流程。

Reference governor、modal hard cap 等可选液体感知模块应在核心比较中关闭，避免无法判断收益来自哪个机制。

## 5. 平台、容器与路径设计

### 5.1 实验平台

建议在正文和补充材料中记录：

- Scout Mini 移动底盘型号和关键尺寸；
- 控制频率、里程计频率和相机帧率；
- 计算平台与 CPU；
- 软件版本和正式实验代码 revision；
- 容器安装位置及车体系坐标轴；
- 相机位置、视角、分辨率、ROI 和标定方法；
- 最终实际执行的速度、角速度和命令变化约束。

### 5.2 容器设计

- \(C_1\)：当前标称容器；
- \(C_2\)：改变半径和/或液深，使第一模态固有频率相对 \(C_1\) 改变约 15%–20% 或更多；
- 两个容器均安装在车体旋转中心；
- 使用相同液体类型和冻结的阻尼比设置；
- 跨容器时只根据几何更新物理模态参数和归一化参数，不重新调节控制器权重。

\(C_2\) 冻结前必须同时检查视觉采样能力。对每个容器计算每个第一模态周期的相机帧数

\[
N_{\mathrm{frame/cycle},c}
=\frac{f_{\mathrm{cam}}}{f_{1,c}}.
\]

当前 \(C_1\) 的第一模态约为 \(4.97\,\mathrm{Hz}\)，若相机为 \(30\,\mathrm{Hz}\)，每周期约只有 6 帧。除非提高相机帧率并重新验证提取与同步流程，否则 \(C_2\) 不宜通过显著提高 \(f_1\) 来制造参数差异；优先选择较低固有频率或在正式采集前证明当前视觉链能够可靠分辨其响应。

跨容器结果同时报告：

- 绝对液面响应，单位 mm；
- 相对于 freeboard 的归一化液面响应。

### 5.3 路径设计

建议使用两条给定路径：

#### 低风险路径

- 以直线和缓弯为主；
- 曲率变化较小；
- 用于检查方法在简单条件下是否造成不必要的时间或跟踪损失。

#### 高风险路径

应包含若干可解释且提前冻结的区段，例如：

1. \(Z_1\)：起步直线加速；
2. \(Z_2\)：进入持续曲率转弯；
3. \(Z_3\)：S 弯或曲率符号反转；
4. \(Z_4\)：退出转弯并重新加速；
5. \(Z_5\)：终点制动和到达后观察。

路径区段必须在正式结果检查前固定，不能根据结果挑选“最有利”的位置。

高风险路径的作用是提供连续且相互关联的纵向、横向激励，使液体动态记忆和相位效应有机会影响在线计划；它不应被描述成任意自然场景的完整代表。

## 6. 记录信号与信号层次

每次实验至少记录以下同步数据。

### 6.1 路径与任务状态

- 参考路径；
- 路径弧长和归一化进度 \(\sigma=s/L\)；
- 路径曲率 \(\kappa(s)\)；
- 到达判定和完成时间；
- 预先定义的路径区段标签。

### 6.2 机器人真实执行状态

- \(x,y,\theta\)；
- 线速度 \(v\)；
- 角速度 \(\omega\)；
- contour error 和必要的 lag error；
- 最终 executed velocity command；
- 安全干预、fallback 和终止状态。

### 6.3 求解器命令、执行层干预与最终命令

每个控制周期必须同时记录：

- solver 输出的原始 \(v/\omega\) 命令；
- terminal 或 safety gate 之后的命令；
- rate/rate-of-change limiter 之后实际发布的命令；
- linear limit、angular-rate limit、angular-acceleration limit、fallback 和 zero-command 标志；
- 上一周期实际发布命令和本周期实际控制间隔。

预先冻结命令差异容差 \(\epsilon_v,\epsilon_\omega\)，并定义执行层干预比例：

\[
r_{\mathrm{int}}
=\frac{1}{N_c}
\sum_{j=1}^{N_c}
\mathbb I\!\left(
|v_{\mathrm{pub},j}-v_{\mathrm{solver},j}|>\epsilon_v
\;\lor\;
|\omega_{\mathrm{pub},j}-\omega_{\mathrm{solver},j}|>\epsilon_\omega
\right).
\]

正式采集前还应根据独立部署 smoke/pilot 冻结干预准入阈值 \(r_{\mathrm{int,max}}\)，并确认三种方法在非terminal主要运动阶段均满足该阈值。正式 trial 中即使超过阈值也不得删除；应保留并报告，同时将机制解释降级为“最终执行轨迹的差异”，不能把物理结果直接归因于未执行的原始 OCP 控制。

### 6.4 OCP 预测与第一控制量

- 第一控制量 \(a_{0|j}^{\star}\)、\(\alpha_{0|j}^{\star}\)、\(v_{s,0|j}^{\star}\)；
- 预测 \(v_{k|j}\)、\(\omega_{k|j}\)、\(v_{s,k|j}\)；
- 预测模态响应；
- solver status 和 solve time。

预测量只用于解释在线计划和控制机制，不能代替实际执行运动指标。

在线 bag 至少保存第一控制量和已有诊断；RQ4 计算实验还必须由冻结的离线 replay 工具导出完整 horizon 的 \(v,\omega,v_s,\eta_x,\dot\eta_x,\eta_y,\dot\eta_y,a,\alpha\)。只保存 XY path、前三个预测点或 horizon 摘要，不足以完成 RQ4 的预注册比较。

### 6.5 液体状态与物理参考

- 传播模态状态 \((\eta_x,\dot\eta_x,\eta_y,\dot\eta_y)\)；
- 内部模型响应 \(H_{\mathrm{modal}}\)；
- 视觉标定后的物理响应 \(H_{\mathrm{vis}}\)。

必须明确区分：

- \(H_{\mathrm{modal}}\) 是控制器内部模型量；
- \(H_{\mathrm{vis}}\) 是主要物理实验证据；
- RGB/视觉测量不进入当前实时控制闭环。

## 7. 同路径运动、速度与加速度分析

### 7.1 对齐方式

运动过程曲线以归一化路径进度对齐：

\[
\sigma=\frac{s}{L}\in[0,1].
\]

不同方法完成时间不同，若主要按绝对时间对齐，会把不同几何位置错误地放在一起比较。建议：

- 路径相关运动和液面过程使用 \(\sigma\)；
- 到达后残余振荡使用 \(\tau=t-t_{\mathrm{arrival}}\)；
- RQ4 的预测时域使用相对预测时间。

### 7.2 实际激励定义

在容器位于旋转中心的前提下，实际执行激励由同步后的里程计和 executed command 计算：

\[
a_{x,\mathrm{exec}}\approx\dot v_{\mathrm{odom}},
\qquad
a_{y,\mathrm{exec}}\approx
v_{\mathrm{odom}}\omega_{\mathrm{odom}}.
\]

可进一步计算：

\[
\alpha_{\mathrm{exec}}\approx\dot\omega_{\mathrm{odom}}.
\]

数值微分和滤波流程必须在检查正式结果前冻结，并对所有方法完全相同。

### 7.3 推荐分析量

| 层次     | 信号或指标                                            | 解释目的                       |
| -------- | ----------------------------------------------------- | ------------------------------ |
| 路径输入 | \(\kappa(\sigma)\)                                    | 标记高曲率和曲率反转位置       |
| 执行运动 | \(v(\sigma)\)                                         | 检查是否局部减速或重新加速     |
| 执行运动 | \(\omega(\sigma)\)                                    | 检查转弯运动分配               |
| 纵向激励 | \(a_x(\sigma)\)、RMS                                  | 检查起步、制动和速度重分配     |
| 横向激励 | \(a_y(\sigma)\)、绝对值 p95                           | 检查曲率段液体激励             |
| 转向变化 | \(\alpha(\sigma)\) 或 \(\Delta\omega_{\mathrm{cmd}}\) | 检查旋转平滑程度               |
| 内部机制 | \(H_{\mathrm{modal}}(\sigma)\)                        | 展示模型预测或传播响应         |
| 物理结果 | \(H_{\mathrm{vis}}(\sigma)\)                          | 验证真实液面是否相应降低       |
| 任务性能 | contour error、时间、成功率                           | 检查是否以任务退化换取液面改善 |

### 7.4 不建议作为正文主要指标的量

- **最大加速度：** 三种方法具有相同硬约束时，最大值可能都接近约束上限，区分度低；
- **未经严格滤波的 jerk：** 二次数值微分容易被噪声主导；
- **单一全程平均速度：** 会掩盖局部速度和激励重新分配；
- **仅使用总加速度能量：** 无法表达液体动态状态和振荡相位；
- **仅使用预测加速度：** 不能证明机器人真正执行了相应运动。

若传感器质量足够，液体固有频率附近的加速度频带能量可以作为补充机制指标，但不能替代 \(H_{\mathrm{vis}}\) 和 RQ4 相位实验。

### 7.5 核心过程图

高风险路径建议绘制一张共享横轴 \(\sigma\) 的多面板过程图：

1. 路径曲率 \(\kappa(\sigma)\)；
2. 执行线速度 \(v(\sigma)\)；
3. 执行角速度 \(\omega(\sigma)\)；
4. 纵向加速度 \(a_x(\sigma)\)；
5. 横向加速度 \(a_y(\sigma)\)；
6. 内部液体响应 \(H_{\mathrm{modal}}(\sigma)\)；
7. 实测液面响应 \(H_{\mathrm{vis}}(\sigma)\)。

三种方法均展示重复实验的 trial-level 中位过程曲线和四分位带。不能只选择一条表现最好的“代表性轨迹”。

该图的核心解释不是“S-MPCC 平均速度最低”，而是：

> 在相同路径曲率位置，S-MPCC 是否提前减速、延后加速、改变转弯速度或改变激励时机，并且这些局部变化是否对应随后液面响应下降。

## 8. 结果指标

### 8.1 主要物理指标

正式比较保留一个明确的 primary outcome。首先用预先冻结的速度/命令阈值和最短持续时间定义首次有效运动时刻 \(t_{\mathrm{move}}\)，以统一到达判据得到 \(t_{\mathrm{arrival}}\)。主要运动窗口为

\[
\mathcal W_{\mathrm{full}}
=[t_{\mathrm{move}},t_{\mathrm{arrival}}].
\]

主要物理指标定义为：

\[
H_{\mathrm{vis,p95}}^{\mathrm{full}}
=Q_{0.95}
\left(
H_{\mathrm{vis}}(t):t\in\mathcal W_{\mathrm{full}}
\right).
\]

该窗口包括 \(Z_1\) 起步和 \(Z_5\) 制动，因为它们是开放液体运输的重要激励阶段；开始前静止等待和到达后残余振荡不混入该 primary outcome。

同时预注册 10%–90% 路径进度中段指标：

\[
H_{\mathrm{vis,p95}}^{10\text{--}90}
=Q_{0.95}
\left(
H_{\mathrm{vis}}(t):0.1\leq\sigma(t)\leq0.9
\right),
\]

用于隔离 start/terminal handling 并解释路径中段机制。它是关键敏感性指标，不替代全运动窗口 primary outcome。\(Z_1\)–\(Z_5\) 的区段结果均作为机制分析，不另行选择最有利区段。

### 8.2 关键次要指标

- 到达后固定 5 s 内的 \(H_{\mathrm{vis}}\) RMS；
- 10%–90% 路径进度内的 \(H_{\mathrm{vis}}\) p95；
- 全运动窗口内的 \(H_{\mathrm{vis}}\) RMS；
- 完成时间；
- 路径 contour error p95；
- 成功率；
- \(Z_1\)–\(Z_5\) 的预注册区段摘要。

### 8.3 机制诊断指标

- \(H_{\mathrm{modal}}\) p95；
- \(a_{x,\mathrm{exec}}\) RMS；
- \(|a_{y,\mathrm{exec}}|\) p95；
- \(\alpha\) RMS 或角速度命令变化量；
- 与 Smooth-only 权重直接对应的控制变化指标；
- 执行层干预比例 \(r_{\mathrm{int}}\) 及 \(|v_{\mathrm{pub}}-v_{\mathrm{solver}}|\)、\(|\omega_{\mathrm{pub}}-\omega_{\mathrm{solver}}|\)；
- 可选的固有频率附近加速度频带能量。

### 8.4 实时性指标

- solve-time median；
- solve-time p95；
- solve-time maximum；
- deadline-miss rate；
- solver failure；
- fallback 使用次数；
- 实际控制频率。

## 11. RQ3：跨容器迁移

### 11.1 目的

检验只根据容器几何更新模态参数、而不重新调节控制器权重时，S-MPCC 是否仍然保持相对收益。

### 11.2 保持不变的条件

- 液体类型；
- 阻尼比设置；
- 高风险路径；
- 名义速度参考；
- 运动约束；
- 预测时域和求解器；
- 控制器权重；
- 相机和分析流程。

### 11.3 只更新的参数

\[
\omega_{1,c},\qquad
c_{h,c},\qquad
\eta_{\mathrm{ref},c},\qquad
\dot\eta_{\mathrm{ref},c}.
\]

两个容器采用统一的 freeboard fraction 规则定义液面归一化参考。

### 11.4 实验与计算证据

物理实验：

- \(C_1\) 和 \(C_2\)；
- 每个容器内比较三种方法；
- 先做容器内结论，再讨论 method × container interaction；
- 同时报告 mm 和 freeboard-normalized 液面指标。

控制计算实验：

- 固定机器人状态、路径位置、归一化模态幅值和相位；
- 只切换 \(C_1/C_2\) 参数集；
- 比较预测速度、角速度、第一控制量和模态响应。

物理结果证明重参数化后的系统性能；参数切换计算实验用于更直接地解释容器参数如何改变在线计划。二者不能相互替代。

为区分“参数切换会改变计划”和“正确几何参数是否改善真实迁移效果”，建议先在计算或 log-replay 中加入 mismatch 对照：

1. 固定 \(C_2\) 的机器人状态、路径位置和归一化模态状态；
2. 使用正确的 \(C_2\) 参数运行 S-MPCC；
3. 错误地使用冻结的 \(C_1\) 参数再次运行；
4. 比较第一控制量、预测运动和预测模态响应。

该计算 mismatch 对照不增加主方案的物理实验次数，但它只能证明参数选择会改变内部预测和优化计划，不能利用同一内部模型自证“正确参数带来更好的物理液面”。只有增加 \(C_2\) 容器使用冻结 \(C_1\) 参数的物理组，并以 \(H_{\mathrm{vis}}\) 比较，才能检验参数更新对物理迁移效果是否必要。

需要控制结论强度：

- 两个容器中 S-MPCC 均有效，可以支持“几何重参数化后实现有限迁移”；
- 正确/错误参数的计算 mismatch 产生不同计划，只能支持“规划对容器参数敏感”；
- 只有可选物理 mismatch 组显示正确 \(C_2\) 参数在外部 \(H_{\mathrm{vis}}\) 上优于错误 \(C_1\) 参数，才能进一步支持“几何参数更新对物理迁移具有必要作用”；
- 完整 88 次主方案默认只主张“无权重重调的有限跨容器迁移”，不主张参数更新必要性的严格物理因果证明。

## 12. RQ4：状态相关规划、传播状态作用与实时性

### 12.1 液体相位规划实验

固定以下条件：

- 机器人位置、姿态、速度和角速度；
- 路径位置和局部参考路径；
- 容器参数；
- 模态总能量或等效归一化幅值。

只改变液体模态相位。至少冻结两个机制检查点：

- 纵向检查点：位于 \(Z_1\) 起步或 \(Z_4\) 重新加速前，使用 \(x\) 方向四相位；
- 横向检查点：位于 \(Z_2\) 入弯或 \(Z_3\) 曲率反转前，使用 \(y\) 方向四相位。

\(x\) 方向采用：

\[
\begin{aligned}
&[A,0,0,0]^\top,\qquad
[0,\omega_1A,0,0]^\top,\\
&[-A,0,0,0]^\top,\qquad
[0,-\omega_1A,0,0]^\top,
\end{aligned}
\]

\(y\) 方向相应采用：

\[
\begin{aligned}
&[0,0,A,0]^\top,\qquad
[0,0,0,\omega_1A]^\top,\\
&[0,0,-A,0]^\top,\qquad
[0,0,0,-\omega_1A]^\top.
\end{aligned}
\]

其中 \(A=0.5\eta_{\mathrm{ref}}\) 作为预先冻结的机制研究参数。两组状态在各自方向上保持相同模态能量，仅改变相位。正文可展示与主要高风险动作最相关的一组，另一组进入补充材料；不得在查看结果后选择更有利的方向或路径位置。

记录并比较：

- 预测 \(v_{k|j}\)；
- 预测 \(\omega_{k|j}\)；
- 预测 \(v_{s,k|j}\)；
- 预测 \(H_{\mathrm{modal},k|j}\)；
- 第一步 \(a_{0|j}^{\star}\)、\(\alpha_{0|j}^{\star}\)、\(v_{s,0|j}^{\star}\)；
- 可选的预测 XY 路径。

如果相同机器人状态和相同路径在不同液体相位下产生不同在线计划，才能直接支持“液体动态记忆进入决策层”的主张。

### 12.2 实际传播状态的反事实 log-replay

四相位实验使用受控构造的液体状态，能够证明 OCP 对液体相位敏感。为进一步证明正式物理运行中由 odometry 在线传播得到的状态确实影响了优化器给出的第一动作，增加反事实日志回放。

这里的“实际传播状态”是正式控制运行时记录的**内部传播模态状态**，不是由视觉或其他外部传感器测得的液体真值。该回放属于机制证据，不能代替 \(H_{\mathrm{vis}}\) 的物理效果证据。

#### 回放输入

从正式高风险路径实验中读取每个有效控制周期的：

- 实际送入 solver 的机器人状态 \(\hat{\mathbf x}_{r,j}\)，包括已启用的延迟补偿；
- 当前局部路径和路径进度；
- guarded minimum progress \(s_{\min,j}\)；
- 实际传播的液体状态 \(\hat{\mathbf x}_{\ell,j}\)；
- 本周期有效 \(v_{\mathrm{ref},j}\)；
- 上一周期接受的 OCP 控制和上一周期实际发布命令；
- pre-solve warm-start/previous-solution 状态；
- 若回放包含 \(Z_1/Z_5\)，还需保存 start-lock、terminal 和共享执行层状态；
- 当时冻结的容器参数和求解器配置。

#### 求解器快照与复现门槛

当前 solver 的连续性代价、warm start、previous solution 和进度保护都带有跨周期内部状态。actual 与 zero 分支不得在同一个可变 solver 实例上顺序求解，否则第二个分支会受到第一个分支污染。正式 replay 必须满足以下之一：

1. 从同一个 pre-solve 快照克隆两个完全一致的 solver 实例，再分别注入 actual/zero 液体状态；这是主要方案；
2. 两个分支均关闭 previous-solution warm start，并显式注入相同上一控制，作为冷启动敏感性分析。

主要 replay 工具必须支持 solver 状态的 export/import 或等价克隆，并导出完整预测 horizon。在进行反事实比较前，actual 分支必须在预先冻结的数值容差内复现在线日志中的 solver status、第一控制量和原始 solver command；不能复现的周期标记为 replay failure，不进入动作差异统计，并单独报告比例。

#### 反事实比较

对同一个控制周期固定所有非液体输入，分别求解：

\[
\begin{aligned}
\mathcal P_{\mathrm{actual},j}
&=\mathcal P(
\hat{\mathbf x}_{r,j},
\hat{\mathbf x}_{\ell,j},
\mathrm{path}_j,
\mathcal S_j),\\
\mathcal P_{\mathrm{zero},j}
&=\mathcal P(
\hat{\mathbf x}_{r,j},
\mathbf 0,
\mathrm{path}_j,
\mathcal S_j),
\end{aligned}
\]

其中 \(\mathcal S_j\) 表示两个分支完全共享的 pre-solve solver、warm-start、进度、参考速度和部署上下文。可选地增加保持模态能量但反转相位的 \(\mathcal P_{\mathrm{flip},j}\)。主要比较：

\[
\begin{aligned}
\Delta a_{0,j}
&=a_{0,j}^{\star}(\hat{\mathbf x}_{\ell,j})
-a_{0,j}^{\star}(\mathbf 0),\\
\Delta \alpha_{0,j}
&=\alpha_{0,j}^{\star}(\hat{\mathbf x}_{\ell,j})
-\alpha_{0,j}^{\star}(\mathbf 0),\\
\Delta v_{s,0,j}
&=v_{s,0,j}^{\star}(\hat{\mathbf x}_{\ell,j})
-v_{s,0,j}^{\star}(\mathbf 0).
\end{aligned}
\]

同时比较完整 horizon 内预测 \(v\)、\(\omega\)、\(v_s\)、模态状态和 \(H_{\mathrm{modal}}\) 的差异。

上述差异直接对应 optimized first action，而不是已经在机器人上执行的反事实命令。若要报告“counterfactual executed command”，必须把两个分支的 solver command 继续通过同一个 terminal、gate 和 rate limiter 快照，并比较最终发布的 \(v/\omega\)；否则正文统一使用“optimized first-action difference”。

#### 采样和报告规则

- 优先回放全部有效控制周期，或在正式结果检查前冻结 \(Z_1\)–\(Z_5\) 中的采样规则；
- 不能只挑选动作差异最大的周期；
- 按 trial 先计算摘要，再进行区组或 trial-level 汇总，避免把每个控制周期当作独立统计样本；
- 在查看正式结果前，根据重复求解数值误差冻结 \(\epsilon_a,\epsilon_\alpha,\epsilon_{v_s}\)；
- 每个 trial 至少报告 \(|\Delta a_0|\)、\(|\Delta\alpha_0|\)、\(|\Delta v_{s,0}|\) 的中位数和 p95，以及超过相应数值容差的控制周期比例；
- 正文报告实际状态与零状态下 optimized first-action difference 的 trial-level 分布和 replay reproduction/failure rate；
- 完整路径区段结果和 phase-flip 结果可放补充材料。

该分析不新增物理实验。它直接建立以下贡献二证据链：

\[
\text{odometry excitation}
\rightarrow
\text{propagated liquid state}
\rightarrow
\text{different optimized first action}.
\]

四相位实验回答“控制器原则上是否根据相位改变计划”；实际状态 log-replay 回答“正式运行中传播出来的内部状态是否实际改变优化动作”。两者作用不同，建议同时保留。该分析不证明传播状态等于真实液体状态，也不单独证明反事实命令在机器人上会产生更好的物理液面。

### 12.3 实时性分析

从全部正式物理实验中提取每个控制周期的求解数据，计算

\[
r_{\mathrm{miss}}
=\frac{1}{N_c}
\sum_{j=1}^{N_c}
\mathbb I(T_{\mathrm{solve},j}>\Delta t).
\]

同时单独报告：

- 求解失败；
- fallback；
- deadline miss；
- 实际控制频率。

推荐将 RQ4 图组织为三个紧凑部分：四相位预测计划、实际传播状态与零状态的 optimized first-action difference、solve-time ECDF。若版面不足，正文保留四相位计划和 log-replay 的核心结果，将完整 runtime 分方法统计和回放分布放入补充材料。

## 13. 正式实验矩阵

### 13.1 完整主方案

采用 \(n=8\) 个 randomized blocks：

| 实验组           | 条件                     | 方法                 |         次数 | 用途                 |
| ---------------- | ------------------------ | -------------------- | -----------: | -------------------- |
| 低风险区组       | \(C_1\) + 低风险路径     | 三种核心方法         |           24 | RQ1 双路径一致性     |
| 容器 super-block | \(C_1/C_2\) + 高风险路径 | 三种核心方法         |           48 | RQ1 高风险结果与 RQ3 |
| 等时间区组       | \(C_1\) + 高风险路径     | Smooth-match、S-MPCC |           16 | RQ2                  |
| 合计             | —                       | —                   | **88** | RQ1–RQ4 与实时性    |

高风险路径的 \(C_1\) 数据由 48 次容器 super-block 提供，同时用于 RQ1 和 RQ3，不重复采集。

RQ4 四相位实验、实际传播状态反事实 log-replay，以及 RQ3 参数切换和 mismatch 对照均属于受控计算实验，不增加主方案的物理实验次数。

### 13.2 分阶段执行方案

| 阶段       | 内容                                      | 累计次数 | 能回答的问题               |
| ---------- | ----------------------------------------- | -------: | -------------------------- |
| 核心机制包 | 高风险\(C_1\) 三方法 24 次 + 等时间 16 次 |       40 | RQ1 核心、RQ2、RQ4、实时性 |
| 双路径包   | 核心机制包 + 低风险\(C_1\) 三方法 24 次   |       64 | 增加跨路径一致性           |
| 完整主方案 | 双路径包 + 高风险\(C_2\) 三方法 24 次     |       88 | 完整 RQ1–RQ4 和跨容器迁移 |

建议优先完成 40 次核心机制包。若核心结果不能支持“真实液面改善且不只是更慢”，应先检查方法、测量和实验协议，而不是立即扩展第二容器或偏心安装。

### 13.3 样本量说明

\(n=8\) 是资源约束下的配对实验设计，不意味着达到 8 次就自动具有统计确认。应结合：

- 原始配对点；
- 效应大小；
- 95% 区间；
- 失败分布；
- pilot 方差或可用的样本量依据。

如果 pilot 显示区组内波动较大，应优先增加 block 数，而不是增加每条轨迹上的采样点。

## 14. 实验协议

### 14.1 正式采集前冻结

以下内容必须在查看正式结果前冻结并归档：

- 所有控制器权重；
- 阻尼比和容器参数；
- 运动约束和执行层设置；
- 两条路径及路径区段；
- 相机设置、ROI 和像素到毫米标定；
- 液面提取、滤波、缺帧和同步规则；
- 加速度微分和滤波规则；
- 主要结果指标和统计方法；
- 到达、成功、失败和排除标准；
- 正式软件 revision。

### 14.2 单次实验流程

1. 检查容器、液位和安装位置；
2. 机器人回到统一初始状态；
3. 等待机器人静止；
4. 仅当 \(H_{\mathrm{vis}}\) 连续至少 2 s 低于标定得到的静止阈值时开始；
5. 执行随机化顺序中指定的方法；
6. 完成路径或触发方法失败；
7. 到达后继续记录固定 \(T_{\mathrm{post}}=5\,\mathrm{s}\)；
8. 记录实验状态、异常和外部干预；
9. 按区组继续下一个方法。

### 14.3 随机化与区组

- 每个 block 包含所有待比较方法；
- block 内方法顺序随机化；
- 容器 super-block 内的容器顺序随机化或平衡；
- 同一区组尽量在相近时间和环境条件下完成；
- 不根据前一次性能结果手动改变下一次方法顺序。

### 14.4 排除和失败处理

允许排除并在同一区组重做的情况仅限于与方法无关的采集故障，例如：

- 相机或数据记录从未启动；
- 视频不可恢复损坏；
- 路径在实验开始前未正确加载。

以下情况必须保留为方法失败，不能删除或悄悄重跑：

- solver failure；
- timeout；
- 路径跟踪失败；
- 安全终止；
- fallback；
- 方法相关的执行异常。

所有有效尝试都进入成功率分母。连续指标只对已完成试验计算，并报告明确的分子和分母。

## 15. 数据处理与统计分析

### 15.1 统计样本单位

一次完整 trial 是一个统计样本。视频帧、控制周期和路径网格点不能被当作独立样本。

### 15.2 过程曲线

- 将每个 trial 插值到预先固定的公共 \(\sigma\) 网格；
- 对每种方法绘制 trial-level 中位数和四分位带；
- 到达后曲线使用公共时间 \(\tau\)；
- 过程带是描述性的 trial envelope，不是逐点推断置信区间。

### 15.3 区组配对效应

RQ1 的第一主比较预注册为：

\[
\mathrm{S\mbox{-}MPCC}
\;-\;
\mathrm{Smooth\mbox{-}only\ MPCC},
\]

因为它最直接检验“显式液体动态记忆是否优于一般增强平滑”。S-MPCC 与 Baseline 是关键次比较，Smooth-only 与 Baseline 是机制诊断比较。RQ2 的预注册主比较为 S-MPCC 与 Smooth-match。该层级不得根据结果显著性事后调整。

对方法 \(m\)、参考方法 \(m'\)、区组 \(b\) 和路径 \(p\)，定义

\[
\Delta_{b,p}^{m-m'}
=Y_{m,b,p}-Y_{m',b,p}.
\]

主要报告：

- 所有原始 trial 点；
- 区组配对线；
- 平均配对差；
- 区组内平均相对变化；
- 通过整区组重采样得到的 95% 区间；
- 配对中位差作为稳健性摘要。

由于 \(n=8\) 个 block 时普通 bootstrap 区间可能不稳定，第一主比较还必须报告：

- 对配对差进行精确 sign-flip/randomization inference；
- leave-one-block-out 敏感性，检查结论是否由单一区组驱动；
- 若对多个次要比较报告 p 值，使用预先冻结的层级解释或 Holm 校正。

不建议只报告均值 ± 标准差或单独的 p 值。混合效应模型可以作为支持分析，但不能取代直观的配对原始数据、效应大小、区间和小样本稳健性检查。

### 15.4 结果解释原则

| 观察结果                                                       | 合理解释                                                            |
| -------------------------------------------------------------- | ------------------------------------------------------------------- |
| \(H_{\mathrm{modal}}\) 下降但 \(H_{\mathrm{vis}}\) 不下降      | 只支持内部模型变化，不能声称物理防晃有效                            |
| \(H_{\mathrm{vis}}\) 下降但完成时间明显增加                    | 需要 RQ2 判断是否主要来自整体减速                                   |
| Smooth-only 与 S-MPCC 表现相当                                 | 当前证据不能说明液体状态传播优于一般平滑                            |
| S-MPCC 在等时间下仍降低液面                                    | 支持局部运动与激励重分配，而非单纯减速                              |
| 不同液体相位产生相同计划                                       | 当前 RQ4 不能支持状态相关规划主张                                   |
| 人工四相位产生不同计划，但实际传播状态与零状态产生几乎相同优化动作 | 只能证明 OCP 对构造状态敏感，尚不能充分证明正式传播状态实际影响优化决策 |
| \(C_2\) 中收益保持且无权重重调                                 | 支持几何重参数化下的有限跨容器迁移                                  |
| 正确\(C_2\) 参数与错误 \(C_1\) 参数的计算计划不同              | 只支持规划对参数敏感，不证明真实物理液面更优                         |
| 可选物理 mismatch 中正确/错误参数的 \(H_{\mathrm{vis}}\) 相当  | 不能声称几何更新对物理迁移具有必要作用                              |
| 液面改善但跟踪误差或失败率显著恶化                             | 必须作为任务性能代价共同报告                                        |

## 20. 最终建议的论文叙事

建议将实验章节收束为以下叙事：

> S-MPCC 的价值不在于单纯降低机器人平均速度，也不在于仅生成更平滑的控制命令。它通过传播液体模态状态，使当前液体位移、速度和振荡相位进入 path-progress MPCC 的在线决策。在相同给定路径上，该机制改变局部速度和纵横向激励分配，并以真实视觉液面测量验证物理效果。三种匹配内部方法、等完成时间比较、跨容器重参数化、四相位规划、实际传播状态反事实回放和实时求解统计共同构成完整证据链。

当前最稳妥的正式实验边界是：

- 容器安装在车体旋转中心；
- 使用给定几何路径，不另设自由点到点规划模式；
- 用低风险和高风险两条路径体现任务差异；
- 用 \(C_1/C_2\) 检验容器几何重参数化；
- 用 RQ1–RQ4 逐层验证物理效果、运动机制、减速混杂、迁移能力、状态相关性与实时性；
- 用实际传播状态 log-replay 补强贡献二，而不是新增偏心容器或自由点到点模式。
