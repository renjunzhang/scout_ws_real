# Scout Mini 自主导航项目结构总结

> 本文档总结 `~/scout_ws` 工作空间的整体架构、模块划分、启动流程以及核心技术要点。

---

## 一、项目概述

本项目基于 **ROS Noetic + Ubuntu 20.04**，为 **AgileX Scout Mini 差速驱动底盘** 实现完整的自主导航系统，包含：

- SICK nanoscan3 激光雷达感知
- Cartographer / Gmapping 建图
- AMCL / Cartographer 定位
- move_base / move_base_flex (MBF) / 自定义简单全局规划
- **自研 MPC 局部规划器**（集成液体晃动抑制软约束）
- 同时支持 **Gazebo 仿真** 与 **实物部署**

```
│   └── test_mpc_sim.launch     # 仿真启动
└── change.md                   # 详细技术审计文档
```

**MPC 技术要点**：
- **状态空间**：8 维 — `[e_l, e_c, e_θ, v, η_x, η̇_x, η_y, η̇_y]`
  - 前 4 维为 Frenet 误差 + 线速度
  - 后 4 维为 x/y 方向液体晃动（等效摆模型）
- **控制量**：2 维 — `[a, ω]`（加速度 + 角速度直接控制）
- **求解器**：OSQP v0.6.2（稀疏 QP，源码安装）
- **控制频率**：20 Hz
- **预测步长**：N = 20，dt = 0.1s

**话题接口**：
| 方向 | 话题 | 类型 | 说明 |
|------|------|------|------|
| 订阅 | `/scout/global_path` | `nav_msgs/Path` | 全局路径 |
| 订阅 | `/odom` | `nav_msgs/Odometry` | 里程计 |
| 发布 | `/cmd_vel` | `geometry_msgs/Twist` | 速度指令 |
| 发布 | `/local_path` | `nav_msgs/Path` | MPC 预测轨迹（可视化） |
| 发布 | `/mpc_status` | — | MPC 状态信息 |

## 九、编译注意事项

1. **白名单缓存**：使用 `catkin_make -DCATKIN_WHITELIST_PACKAGES="pkg"` 后，白名单会被缓存。清除：
   ```bash
   catkin_make -DCATKIN_WHITELIST_PACKAGES=""
   ```

   ```bash
   source ~/scout_ws/devel/setup.bash                    # 主工作空间
   source ~/scout_ws/src/.../cartographer_ws/install_isolated/setup.bash  # Cartographer
   ```

## 十、MPC 局部规划器架构详解

> 基于对 `scout_local_planner` 全部源码的逐文件审阅。

### 10.1 整体控制流水线

```
全局路径                控制循环 (10 Hz 实物 / 20 Hz 仿真)
/scout/global_path ──►┌─────────────────────────────────────────────────────┐
                      │ 1. 接收 & 缓存全局路径（map 坐标系）               │
                      │    ├─ 重采样 (resample_spacing=0.05m)              │
                      │    ├─ 可选 B-spline 平滑                           │
                      │    ├─ 全局三次样条拟合                             │
                      │    └─ 生成速度曲线 v(s)（前向/后向遍历）           │
                      │                                                     │
/odom ─────────────►  │ 2. 每控制周期：                                     │
                      │    ├─ TF 查询 map→base_link                        │
                      │    ├─ 在 map 中找最近点 → 全局弧长 s_global        │
                      │    ├─ 截取局部窗口 [idx-4, idx+N+48]              │
                      │    ├─ 窗口点变换到 base_link                       │
                      │    ├─ 可选 B-spline 平滑窗口                       │
                      │    ├─ 局部三次样条拟合                             │
                      │    ├─ 投影计算 Frenet 误差 (e_l, e_c, e_θ)        │
                      │    ├─ 沿样条采样 N 个参考点（v(s) 限速）          │
                      │    │                                               │
                      │    ├─ [可选] 起点附近原地对齐模式                  │
                      │    │                                               │
                      │    ├─ 构建 8D 增广状态 x₀                         │
                      │    ├─ 沿名义轨迹逐步线性化 A(k), B(k), c(k)      │
                      │    ├─ 组装 QP：min ½z'Hz+g'z, s.t. 动力学+约束   │
                      │    ├─ OSQP 热启动求解                              │
                      │    ├─ 提取 v_cmd = x[1].v, ω_cmd = u[0].ω        │
                      │    └─ 安全退化（求解失败时渐进制动）              │
                      └───────────┬──────────────────────────────────────────┘
                                  │
                      /cmd_vel ◄──┘  (geometry_msgs/Twist)
                      /local_path ◄── (MPC 预测轨迹，仅可视化)
```

### 10.2 各模块职责分解

#### ① PathHandler — 路径处理与参考点生成

**入口**：`updateGlobalPath()` → 每次收到新全局路径触发

**路径预处理流程**：
1. **重采样**：按固定间距（0.05m）将全局路径离散化，消除原始路径的不均匀分布
2. **全局样条拟合**：对整条路径拟合 `CubicSpline2D`（map 坐标系），用于后续速度曲线计算
3. **速度曲线 v(s) 生成**（`updateSpeedProfile`）：
   - 初始速度设为 `v_des`（通常 `0.8 × v_max`）
   - **曲率限速**：$v \leq \sqrt{a_{lat,max} / |\kappa(s)|}$
   - **前向遍历**（加速限制）：$v_i \leq \sqrt{v_{i-1}^2 + 2 \cdot a_{tan,max} \cdot \Delta s}$
   - **后向遍历**（减速限制）：$v_i \leq \sqrt{v_{i+1}^2 + 2 \cdot a_{tan,decel} \cdot \Delta s}$（保守系数 0.8）
   - 终点速度衰减到 `goal_speed`

**每控制周期**（`getReferencePoints`）：
1. **TF 变换**：查询 `map → base_link`，将全局路径窗口点变换到 base_link
2. **最近点搜索**：在全局路径（map 坐标系）中搜索离机器人最近的点
3. **全局弧长跟踪** `s_global`：用投影弧长增量平滑更新，防止前进时倒退；跳变超阈值时重置
4. **局部样条拟合**：截取 `[closest-4, closest+N+48]` 窗口的 base_link 点拟合 `CubicSpline2D`
5. **Frenet 投影**（`computeFrenetProjection`）：在局部样条上粗搜 50 + 细搜 20 采样点，计算 $(e_l, e_c, e_\theta)$
6. **参考点生成**：沿样条按 $s + k \cdot dt \cdot v_{ref}$ 采样 N 个点，每个点包含 $(x, y, \theta_{path}, \kappa, v_{ref})$

#### ② DiffDriveModel — 差速 Frenet 动力学

**连续动力学（小角度近似）**：

$$
\begin{cases}
\dot{e}_l = v - v_{path} \\
\dot{e}_c = v \cdot e_\theta \\
\dot{e}_\theta = \omega - \kappa(s) \cdot v \\
\dot{v} = a
\end{cases}
$$

**控制量** $u = [a, \omega]^T$，其中 **ω 是直接控制量**（不经积分），消除了一步延迟。

**离散化**：一阶欧拉法 $x_{k+1} = x_k + dt \cdot f(x_k, u_k)$

**线性化**（用于 QP）：$x_{k+1} \approx A_k x_k + B_k u_k + c_k$
- $A_k$：Jacobian，包含 $\partial \dot{e}_c / \partial e_\theta = v$, $\partial \dot{e}_c / \partial v = e_\theta$, $\partial \dot{e}_\theta / \partial v = -\kappa$ 等
- $B_k$：$\partial \dot{v}/\partial a = 1$, $\partial \dot{e}_\theta / \partial \omega = 1$
- $c_k$：仿射修正项，保证名义轨迹上的一致性 $c = x^{nom}_{k+1} - A x^{nom}_k - B u^{nom}_k$

**增广晃动子系统**（若启用）：
- $x_{slosh,k+1} = A_{slosh} \cdot x_{slosh,k} + B_{slosh} \cdot [a_x, a_y]^T$
- 横向加速度映射：$a_y = v \cdot \omega$（离心力）

#### ③ CostFunction — 代价函数组装

**目标函数**：$J = \sum_{k=0}^{N} J_{state}(k) + \sum_{k=0}^{N-1} \left[ J_{control}(k) + J_{rate}(k) \right]$

| 代价项 | 公式 | 说明 |
|--------|------|------|
| **状态跟踪** | $Q_{ec} e_c^2 + Q_{e\theta} e_\theta^2 + Q_v (v-v_{ref})^2 + Q_{el} e_l^2$ | contour/lag 模式可切换权重 |
| **角速度前馈** | $Q_{\omega ff} (\omega - v_{ref} \kappa)^2$ | 对控制量 ω 施加前馈参考 |
| **控制惩罚** | $R_a a^2 + R_\omega \omega^2$ | 抑制大控制量 |
| **控制变化率** | $R_{da}(a_k - a_{k-1})^2 + R_{d\omega}(\omega_k - \omega_{k-1})^2$ | **跨步耦合**二次项，保证平滑 |
| **终端权重** | $Q_{ec} \times 5, Q_{e\theta} \times 3, Q_v \times 2$ | 最后一步放大，改善终点收敛 |
| **晃动惩罚** | $Q_{slosh}(\eta_x^2 + \eta_y^2)$ | 抑制液面晃动（当前 Q=0 关闭） |

#### ④ ConstraintManager — 约束管理

| 约束类型 | 公式 | 硬/软 |
|----------|------|-------|
| **速度边界** | $v_{min} \leq v_k \leq v_{max}$ | 硬约束 |
| **控制边界** | $-a_{max} \leq a_k \leq a_{max}$, $-\omega_{max} \leq \omega_k \leq \omega_{max}$ | 硬约束 |
| **角速度变化率** | $|\omega_k - \omega_{k-1}| \leq \alpha_{max} \cdot dt$ | 硬约束（默认启用） |
| **加速度变化率** | $|a_k - a_{k-1}| \leq j_{max} \cdot dt$ | 硬约束（默认关闭） |
| **动力学等式** | $x_{k+1} = A_k x_k + B_k u_k + c_k$ | 等式约束 |
| **初始状态** | $x_0 = x_{measured}$ | 等式约束 |

#### ⑤ MPCSolver — QP 求解

**决策变量**：$z = [x_0, u_0, x_1, u_1, \ldots, x_{N-1}, u_{N-1}, x_N]$，维度 $N(n_x+n_u)+n_x = 40 \times 10 + 8 = 408$

**QP 问题**：
$$
\min_z \frac{1}{2} z^T H z + g^T z, \quad \text{s.t.} \quad l \leq A z \leq u
$$

**求解流程**：
1. 沿上一周期解的名义轨迹逐步线性化（避免固定在 $x_0$ 线性化）
2. 组装 H、g、A、l、u（Eigen 稀疏矩阵 → CSC 格式）
3. 首次调用 `osqp_setup()`，后续仅更新数值 `osqp_update_P/A/bounds()`
4. **热启动**：将上一周期解前移一步作为初始猜测
5. 提取结果：$v_{cmd} = x_{predicted}[1].v$，$\omega_{cmd} = u_{optimal}[0].\omega$

#### ⑥ LocalPlannerROS — 状态机与安全策略

**状态机**：`IDLE → TRACKING → REACHED / ERROR`

**特殊模式**：
- **原地对齐**：航向误差 > 1.2 rad 时 $v=0$ 原地转向（仅起点附近生效）
- **安全退化**：QP 不可行时以 1.0 m/s² 制动减速（非骤停）
- **路径跳变检测**：弧长突变 > 0.8m 时重置热启动

### 10.3 四轮差速底盘适配性分析

#### ✅ 适配良好的方面

| 特性 | 说明 |
|------|------|
| **ω 直接控制** | 控制量为 $[a, \omega]$，与 `cmd_vel` 的 `(linear.x, angular.z)` 完全对齐，无需轮速转换 |
| **Frenet 误差建模** | 横向/纵向/航向三维误差分离，天然适合 2D 平面底盘路径跟踪 |
| **控制变化率约束** | $\Delta\omega$ 硬约束（`alpha_max × dt`）抑制角速度突变，减少四轮打滑 |
| **曲率限速** | $v \leq \sqrt{a_{lat}/\kappa}$ 保证弯道不超侧向加速度限制 |
| **保守参数** | 实物 `v_max=1.0`, `omega_max=1.0`, `a_max=1.5` 远低于底盘极限，留有安全裕度 |
| **减速安全系数** | 反向遍历用 0.8 保守因子，实物比理论制动能力弱 |
| **禁用倒车** | `v_min=0.0`，避免四轮差速倒车时的不稳定 |

#### ⚠️ 潜在问题与改进建议

**1. 滑移转向模型简化**

Scout Mini 实际为 **四轮滑移转向（skid-steer）** 而非理想差速。当前模型 `wheelbase=0.0` 将其简化为零宽度差速，**忽略了转弯时的横向轮胎滑移**。

- **影响**：在急弯处实际转弯半径大于模型预测，导致 MPC 预测轨迹与真实轨迹偏离
- **现状缓解**：`omega_max=1.0` 和 `max_lat_accel=1.5` 的保守限制下偏差较小
- **改进方向**：可引入等效轮距系数 $L_{eff}$ 或经验滑移因子修正运动学

**2. 单轮速度约束缺失**

当前独立约束 $v$ 和 $\omega$，但未检查单轮速度：

$$v_{left} = v - \frac{\omega \cdot L}{2}, \quad v_{right} = v + \frac{\omega \cdot L}{2}$$

在 $v$ 和 $\omega$ 同时接近上限时，某侧轮可能超速。

- **影响**：$v=1.0, \omega=1.0$ 时右轮速度 = $1.0 + 1.0 \times 0.228 = 1.228$ m/s，可能接近电机饱和
- **改进方向**：添加线性耦合约束 $|v \pm \omega L/2| \leq v_{wheel,max}$

**3. 小角度近似的适用范围**

$\dot{e}_c = v \cdot e_\theta$（而非 $v \cdot \sin(e_\theta)$）在 $|e_\theta| > 30°$ 时误差显著。

- **现状缓解**：原地对齐模式在起点解决大航向偏差；正常跟踪中 $e_\theta$ 通常 < 0.3 rad
- **改进方向**：可采用 $\sin(e_\theta)$ / $\cos(e_\theta)$ 的泰勒展开到三阶

**4. Frenet 投影精度**

`computeFrenetProjection` 采用 50+20 离散采样搜索最近点，未做牛顿迭代精化。

- **影响**：在曲率变化大的段可能引入 ~1cm 级噪声
- **改进方向**：在粗搜后加 2~3 步牛顿法或黄金分割精化

**5. 控制频率偏低**

实物控制频率 10 Hz（`control_rate: 10.0`），相比通常 MPC 的 20-50 Hz 较低。

- **影响**：指令更新间隔 100ms，在 0.5 m/s 速度下约 5cm 无响应距离
- **改进方向**：若 OSQP 求解耗时 < 10ms，可提高到 20 Hz

### 10.4 轨迹平滑性保障机制总结

```
全局路径 ──► 重采样 ──► 全局样条 ──► v(s) 曲率限速 + 加减速遍历
                                         │
              ┌──────────────────────────┘
              ▼
       局部窗口 ──► [可选B-spline] ──► 局部三次样条 ──► 参考点序列
                                                          │
              ┌──────────────────────────────────────────┘
              ▼
       MPC 求解  ←── 控制变化率代价 R_da, R_domega（软约束）
                 ←── Δω 硬约束 |ω_k - ω_{k-1}| ≤ alpha_max·dt
                 ←── 角速度前馈 ω_ff = v_ref·κ（减少追踪延迟）
                 ←── 终端权重放大（改善末端收敛）
                 ←── 热启动（上一解前移，减少解突变）
                                │
              ┌────────────────┘
              ▼
       安全层  ──► 求解失败 → 渐进制动（非骤停）
              ──► 路径跳变 → 重置热启动
              ──► 大航向偏差 → 原地对齐
```

**总结**：当前 MPC 架构在四轮差速底盘上**能够正常工作且具有基本的平滑性保障**。ω 直接控制消除了角加速度积分延迟，控制变化率的软惩罚 + 硬约束双重机制有效抑制了指令抖动。主要局限在于滑移转向模型简化和控制频率偏低，在保守参数下影响可控。
