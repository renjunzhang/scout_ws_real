## 3. scout_local_planner 当前技术实现

### 3.1 模型与优化

- 状态（8 维）：`[e_l, e_c, e_theta, v, eta_x, eta_x_dot, eta_y, eta_y_dot]`
- 控制（2 维）：`[a, omega]`（角速度直接控制）
- 求解器：OSQP（稀疏 QP）
- 当前时域：`N=40, dt=0.05`，控制频率 `20 Hz`
- 主要实现文件：
  - `src/scout_apps/control/scout_local_planner/src/local_planner_ros.cpp`
  - `src/scout_apps/control/scout_local_planner/src/path_handler.cpp`
  - `src/scout_apps/control/scout_local_planner/src/mpc_solver.cpp`
  - `src/scout_apps/control/scout_local_planner/src/cost_function.cpp`
  - `src/scout_apps/control/scout_local_planner/src/constraint_manager.cpp`
  - `src/scout_apps/control/scout_local_planner/src/diff_drive_model.cpp`

### 3.2 关键约束

- 速度边界：`v_min <= v_k <= v_max`
- 控制边界：`|a_k| <= a_max`，`|omega_k| <= omega_max`
- 角速度变化率硬约束：`|omega_k - omega_{k-1}| <= alpha_max * dt`
- 加速度变化率（jerk）硬约束：`|a_k - a_{k-1}| <= j_max * dt`
- `k=0` 使用 `u_prev` 作为上一时刻输入（已实现）

### 3.3 路径处理

- 全局路径缓存 + 重采样 + 局部窗口拟合（降低 CPU）
- Frenet 投影：粗搜 + 细搜 + Newton 精化
- `time_parameterize=true` 时按 `v(s)` 生成速度剖面
- `s_global` 前进时禁止倒退（抑制参考抖动）

## 4. 近期已完成的核心改造（已落地）

以下功能在当前代码中已存在：

1. 约束维度修复（`numConstraints` 与实际约束行一致）
2. `Δomega` / `Δa` 硬约束接入 ConstraintManager
3. 全时域名义轨迹线性化（不再只用 k=0）
4. 线性化仿射项 `c = predict - A*x - B*u`（一致性修复）
5. `predict()` 去掉 `v` 硬裁剪（由约束统一处理）
6. 终点停车速度策略（`goal_speed`、`remain` 减速）
7. 渐进式 terminal weights（最后若干步线性抬权）
8. `omega_ff` 二次项补全（`(omega-omega_ref)^2` 二次+线性项）
9. 路径相似性检测（相似路径不触发无条件 warm-start 重置）
10. 输出时间对齐（`v_cmd` 半步外推，`omega_cmd` 前两步均值）
11. `cmd_vel` EMA 滤波（含曲率自适应 `alpha_omega`）

## 7. 当前已知风险（建议重点关注）

1. **仍是“路径跟踪 MPC”而非完整 MPCC**  
   进度 `s` 不是优化变量；道路走廊/障碍物半空间约束尚未接入。

2. **四轮差速实物的滑移/侧偏未显式建模**  
   低速可用，高速急弯仍依赖误差反馈修正。

3. **全局路径质量强依赖上游**  
   当上游路径点过少或频繁重发时，虽然已做相似性抑抖，但跟踪质量仍受影响。

4. **`/local_path` 是可视化轨迹，不等于真实底盘轨迹**  
   其主要用于调试 MPC 预测趋势。

## 8. 推荐回归测试（5 步）

1. 直线到终点：检查平滑减速与停车稳定
2. 终点对齐：检查 yaw 收敛与无抖动
3. 连续弯道：观察 `e_c` 峰值和 `omega_cmd` 是否锯齿
4. 中途重规划：确认相似路径不触发明显突跳
5. 急弯贴障：验证是否需要上游更强膨胀/走廊约束

---

## 9. 现阶段结论

- 当前 `scout_local_planner` 已具备实物部署能力，低速/中速跟踪可用。  
- 若目标是“复杂环境下长期稳定且贴边安全”，下一阶段建议补上：
  - 道路走廊与障碍约束（至少软约束）
  - 更贴近四轮差速实物的滑移补偿模型

## 10. 实物调参速查表

> 适用对象：Scout Mini 四轮差速实物，当前 MPC 架构（Frenet 跟踪 + OSQP）  
> 建议原则：一次只改 1~2 组参数，每次改动后固定路线回归 3 次。

### 10.1 调参顺序（推荐）

1. **先限幅**：`v_max / omega_max / a_max / alpha_max`
2. **再贴合**：`Q_ec / Q_etheta / Q_contour`
3. **再平滑**：`R_domega / R_da` + `filter.alpha_*`
4. **最后收尾**：`goal_tolerance / yaw_tolerance / goal_speed`

### 10.2 现象 -> 参数 -> 调整方向

| 现场现象 | 先看参数 | 调整方向 |
|---|---|---|
| 弯道切内弯、撞墙风险 | `lookahead_distance`, `Q_ec`, `Q_etheta` | `lookahead_distance` ↓；`Q_ec/Q_etheta` ↑ |
| 弯道跟不上、外飘 | `Q_omega_ff`, `R_omega`, `R_domega`, `filter.kappa_boost` | `Q_omega_ff` ↑；`R_omega/R_domega` 适度 ↓；`kappa_boost` ↑ |
| 方向盘感“抖”/角速度锯齿 | `R_domega`, `alpha_max`, `filter.alpha_omega` | `R_domega` ↑；`alpha_max` ↓；`alpha_omega` ↓ |
| 直线速度忽快忽慢 | `R_da`, `j_max`, `filter.alpha_v` | `R_da` ↑；`j_max` ↓；`alpha_v` ↓ |
| 提前减速、跑不满速度 | `max_tan_decel`, `Q_v`, `goal_tolerance` | `max_tan_decel` ↑（不超过实物能力）；`Q_v` ↓；`goal_tolerance` ↓ |
| 到点后停不稳/来回挪 | `goal_speed`, `goal_tolerance`, `yaw_tolerance` | `goal_speed=0`；适度放宽容差；必要时提高终端权重 |
| 路径频繁更新导致状态抖动 | `path_change_threshold` | 阈值适度 ↑（如 0.3 -> 0.4） |

### 10.3 常用参数建议区间（实物）

| 参数 | 建议区间 | 备注 |
|---|---|---|
| `vehicle.v_max` | 0.6 ~ 1.0 | 先低速稳定，再提速 |
| `vehicle.omega_max` | 0.8 ~ 1.2 | 实物定位噪声大时取低值 |
| `vehicle.a_max` | 0.8 ~ 1.5 | 太大易打滑 |
| `vehicle.alpha_max` | 1.5 ~ 3.0 | 太大易急转抖动 |
| `vehicle.j_max` | 2.0 ~ 4.0 | 与 `R_da` 联调 |
| `mpc.Q_ec` | 20 ~ 50 | 越大越贴路径 |
| `mpc.Q_etheta` | 8 ~ 20 | 越大越重航向 |
| `mpc.R_domega` | 2 ~ 6 | 越大越平滑但转向更慢 |
| `mpc.R_da` | 0.3 ~ 1.0 | 越大越平滑但加减速更慢 |
| `path_handler.lookahead_distance` | 0.35 ~ 0.60 | 小更贴合，大更稳但切弯 |
| `path_handler.max_lat_accel` | 1.0 ~ 1.8 | 实物安全优先 |
| `filter.alpha_v` | 0.2 ~ 0.4 | 小更稳，大更快 |
| `filter.alpha_omega` | 0.3 ~ 0.6 | 小更稳，大更灵敏 |
| `filter.kappa_boost` | 0.3 ~ 0.8 | 弯道滞后时提高 |
