# 论文主线与现有证据

更新：2026-09-19，核对至 `ab424cd8`。[返回总览](./README.md) · [当前方法框架](./01_当前方法框架.md)

## 1. 论文围绕什么问题展开

建议以以下问题组织论文：

> 在运动空间和运输时间受限时，全程几何与速度规划，加上基于当前液体状态的在线 MPCC，能否减小连续转弯与停车过程中的晃动？各部分贡献是什么，效果能否进入实物？

可暂用“面向移动机器人液体运输的两层防晃规划与模型预测轮廓控制”作为工作题名。叙述顺序是：**液体响应具有记忆 → 全程安排运动 → 在线修正执行 → 分辨收益来源 → 用真实液面验证。**

当前最清楚的方法基础是共同车辆—执行器—液体预测模型、全程规划和在线局部调整。两层结构、液体代价以及采用某个求解器各有已有研究基础；贡献需要结合具体机制、相关工作和验证结果确定。

## 2. 已经有哪些证据

### 整套方法：已有模型内正向结果

三次新 Full 对照三次归档 B0 的均值如下：

| 指标 | 原始路线 B0 | 完整方法 Full |
| --- | ---: | ---: |
| 运输峰值 / mm | 0.977478 | 0.505408 |
| 运输 P95 / mm | 0.480923 | 0.223075 |
| 运输 RMS / mm | 0.202898 | 0.111543 |
| 到点时间 / s | 31.445667 | 28.282333 |

三次 Full 均通过执行与窗口检查，三项模型指标分别降低约 48.29%、53.62%、45.03%。但 B0 使用原始 S 路线，Full 使用上层优化后的几何与速度，两组还有参考模式和代价差异。因此，该结果支持给定任务下整套方案的开发效果，不能把降幅全部归因于下层液体项。

来源：[防晃优先三次复核](../实现与修复/20260919_防晃优先与可选时间优化.md)。

### 下层液体代价：已有一次受控消融

新增一次关闭下层液体代价的运行，与归档 Full 共用同一上层计划、模型和其他全部运行参数，仅将液体权重从 5 改为 0。预先指定的 `full_01` 相对关闭组：

- P95 降低 18.43%，RMS 降低 10.41%。
- 峰值略升 0.30%，到点慢 0.360 秒。

它提供了下层代价对 P95/RMS 的初步正向证据，尚未证明三指标稳定全改善。新增关闭组只有一次，三次归档 Full 均值不能替代重复配对。双方共用的是参考计划，实际轨迹和速度仍会随在线决策变化。

来源：[同计划单次消融](../仿真实验分析/01_对比结果/20260919_同计划下层液体代价单次消融.md)。

### 运行基础与尚缺的效果证据

执行链修复后的固定批次六次运行均无异常；这是当前闭环能够运行的依据。上述液面指标均为模型响应，本版实物/RGB 效果尚未验证。离线缩时开关已验证超时回退，但尚未得到更短计划带来的闭环收益。

来源：[执行链验证](../实现与修复/20260919_执行链稳定性修复与三组B0_Full验证.md)、[时间开关验证](../实现与修复/20260919_时间优化开关单候选验证.md)。全部属于开发验证，`formal=false`。

## 3. 不同对照分别回答什么

| 对照 | 回答的问题 | 当前进度 |
| --- | --- | --- |
| 原始路线 B0 与 Full | 在共同任务与区域中，整套方案表现如何？ | 已有结果，包含几何、速度和控制的共同变化 |
| 同一计划，仅切换下层液体代价 | 在线液体代价是否提供额外收益？ | 已做一次关闭组，P95/RMS 改善，峰值未逐次全改善 |
| 匹配下层，切换上层液体目标并重新规划 | 上层考虑液体响应是否有额外价值？ | 待验证 |
| 双方固定原始 S 几何 | 收益在固定该路径时是否仍存在？ | 待验证 |
| 相近实际耗时下的 RGB 对照 | 模型内收益能否转化为真实液面收益？ | 本版待验证 |

这些对照支持不同层次的主张，论文应显式说明各组拥有的几何和速度自由度。相同到达期限也需要配合实际耗时报告。若要进一步主张“两层有协同增益”，需补齐上层/下层液体机制组合对照，检验各层增量及其交互。

现有 `planned_mpcc` 与 Full 的非液体权重尚未对齐，不能直接充当单项消融。已完成的下层消融是在 `planned_slosh` 内只改液体权重。

## 4. 当前适合怎样安排正文

| 正文部分 | 重点内容 |
| --- | --- |
| 问题与相关工作 | 连续转弯、执行滞后和停车残振为何需要全程安排与在线调整；与已有防晃规划/控制逐项比较 |
| 模型与任务 | 区分命令和实际运动；定义液体估计、可行区域、运输期限及评价窗口 |
| 全程规划 | 几何与速度的联合决策、液体目标、终点及停车要求 |
| 在线 MPCC 与两层接口 | 当前状态构造、进度参考、局部决策、执行检查；说明全程时序保持的现有限制 |
| 实验与讨论 | 整套效果、机制消融、实际耗时、模型与 RGB 的差异，以及失败和适用范围 |

工程修复用于说明实现可信度和可复现性。候选研究贡献应集中在：全程安排如何影响液体响应、在线状态调整增加了什么、两者在实际执行下如何共同起作用。具体贡献强度由消融与实物结果决定。

当前尚无在线剩余任务反馈、全程性能保持证明或递归可行性证明；论文若涉及这些内容，应作为待研究问题。有限时长搜索也不足以支持“时间最优”的题名或结论。

已有[方法与试验写作思路](../验证与论文/20260916_双层防晃MPCC方法与试验章节书写思路.md)可用于展开数学定义；其中 9 月 16 日的实现状态按历史记录理解。相关文献入口见[协同框架](../思路与方案/20260915_轨迹层与MPCC协同框架思路.md)。

## 5. 后续主线怎样延伸

近期继续围绕现有无障碍框架：明确比较条件，检查有实测依据的执行器与状态估计差异，稳定后立即开展低速功能检查和小规模 RGB 实物对照。结果不明确时，沿计划、命令、实际运动和液体响应定位原因。

取得正向实物证据后，再研究**防晃接续**：减速、停等或偏离名义计划后，如何从当前车辆、执行器及液体状态重新安排剩余运动。现有离线后缀诊断可作为起点；随后再扩展单障碍下的减速、等待、绕行与恢复。

论文定位据此分阶段判断：现阶段先验证并写清两层方法及各层贡献；接续机制实现并验证后，再考虑将“执行偏差下的全程防晃协调”提升为核心主线。详细推进依据见[后续节奏](../思路与方案/20260919_后续主线与推进节奏.md)，最新实验事实以[当前状态](../当前实验状态与文档索引.md)为准。
