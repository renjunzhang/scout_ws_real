# 论文主线与现有证据

更新：2026-09-19，实验依据核对至 `2d2697b7`。[返回总览](./README.md) · [方法框架](./01_当前方法框架.md) · [阶段收尾与下一步](./03_阶段收尾与下一步选择.md)

## 1. 当前可以围绕什么写

> 在给定运输区域和运动限制下，全程几何与速度规划结合在线液体感知 MPCC，改善运输晃动；需要更快运输时，通过可选离线时间搜索，在防晃门槛内调整时间与晃动的折中。

可暂用“面向移动机器人液体运输的两层防晃规划与模型预测轮廓控制”作为工作题名。方法顺序为：液体响应具有记忆 → 上层安排整趟运动 → 下层根据当前状态调整 → 消融分析额外贡献 → 可选缩时 → 实物核验。

当前代码与最小仿真验证已完成，可以整理论文。按用户确认，报告样本量、均值和波动范围即可，不要求每次 Full 都低于所有对照；历史严格判定作为开发诊断保留，不再据此反复补跑。以下三类比较回答不同问题，同一组三次默认 Full 被多次复用，不能当成互相独立的新批次累加样本量。

## 2. 三类实验分别说明什么

### 整套方法：共同运输任务下的效果

| 指标 | 原始 S 路线 B0，n=3 | 防晃优先 Full，n=3 | Full 均值降低 |
| --- | ---: | ---: | ---: |
| 运输峰值 / mm | 0.977478 | 0.505408 | 48.29% |
| 运输 P95 / mm | 0.480923 | 0.223075 | 53.62% |
| 运输 RMS / mm | 0.202898 | 0.111543 | 45.03% |
| 到点 / s | 31.445667 | 28.282333 | 10.06% |

Full 使用上层重新优化的几何和速度，B0 跟踪原始 S 路线，两组还有参考模式和代价差异。这组结果说明给定任务下整套方案的观测收益，包含路径、速度和控制的共同变化。

来源：[防晃优先三次复核](../实现与修复/20260919_防晃优先与可选时间优化.md)。原始 B0 为三次归档记录；不是本轮新跑的三组配对。

### 同计划下层消融：液体代价的额外贡献

双方共用同一蓝色上层路径与 progress 速度参考，保留相同的 28 维模型、控制运行物和其余运行参数，只将下层液体权重由 5 改为 0。关闭组为原一次加两次补测，Full 复用上述三次。

| 指标 | 关闭下层液体代价，n=3 | Full，n=3 | Full 均值变化 |
| --- | ---: | ---: | ---: |
| 运输峰值 / mm | 0.591896 | 0.505408 | −14.61% |
| 运输 P95 / mm | 0.296655 | 0.223075 | −24.80% |
| 运输 RMS / mm | 0.128735 | 0.111543 | −13.35% |
| 到点 / s | 28.041333 | 28.282333 | +0.241 s |

六次均无异常。P95/RMS 的两组逐次范围完全分离；峰值范围分别为 0.524110～0.712339 mm 和 0.477365～0.540832 mm，存在重叠。论文可表述为“本工况下，下层液体代价进一步降低三项模型晃动指标的均值，时间代价较小”，同时展示逐次点或范围。

这组关闭项基线称为 `cost0`，不是原始 `raw_mpcc` B0；它保留了上层防晃计划。共享参考也不意味着实际速度和实际轨迹完全相同。

来源：[同计划三次对照](../仿真实验分析/01_对比结果/20260919_同计划下层液体代价三次对照.md)。

### 可选时间优化：门槛内的时间与晃动折中

| 指标 | 开关关闭，名义 40 s，n=3 均值 | 开关开启，名义 38 s，n=1 |
| --- | ---: | ---: |
| 到点 / s | 28.282333 | 24.256000 |
| 运输峰值 / mm | 0.505408 | 0.671215 |
| 运输 P95 / mm | 0.223075 | 0.277627 |
| 运输 RMS / mm | 0.111543 | 0.140270 |

38 s 候选求解一次、闭环一次，实际缩短 **4.026 s（14.24%）**，运行无异常。三项晃动指标比默认模式增加约 25%～33%，但均满足原定防晃门槛和运输/停车液面上限。默认继续关闭时间优化。

论文可将其作为“限晃条件下缩时”的单次示例，明确样本量；不能写成时间最优，也不写成开启后晃动继续降低。缩时重新联合优化几何与速度，因此不是固定几何的时间律消融。此前 36 s 超时回退的失败记录照实保留。

来源：[38 s 单次闭环验证](../实现与修复/20260919_时间优化38秒单候选闭环验证.md)、[36 s 超时回退](../实现与修复/20260919_时间优化开关单候选验证.md)。

## 3. 评价与表述统一

三项运输指标统一统计 `[0,t_stop)`，停车后另观察 5 s；报告实际到点、停稳时间和名义时长，离线计算耗时单列。当前液面均为 odom 驱动模型输出，本版实物 RGB 效果尚未验证；全部现有结果标记 `formal=false`，是开发仿真证据。

论文图表可直接使用报告的同名 JSON：展示均值、逐次样本或范围，保留失败尝试及其原因。三次重复不支持统计显著性的主张，峰值范围重叠也不妨碍如实报告平均收益。论文呈现采用此口径，原有计划资格、液面上限和执行检查不放宽。

## 4. 下一步验证按论文主张选择

| 想进一步说明什么 | 需要的工作 | 本阶段是否必须补做 |
| --- | --- | --- |
| 当前工况下整套方法、下层代价及时间折中 | 整理已有三类结果与方法说明 | 数据已具备，进入写作整理 |
| 模型内收益能转化为真实液面改善 | 对齐部署和观测链，做小规模 RGB 实物对照 | 下一阶段的重要验证，尚未执行 |
| 固定原始 S 几何也有效 | 双方固定该几何，比较速度规划与液体控制 | 仅在论文需要该结论时做 |
| 上层液体目标本身有贡献 | 匹配下层，切换上层液体目标并重新规划 | 仅在需要独立上层归因时做 |
| 两层之间存在额外协同增益 | 冻结公共条件后做相应机制组合对照 | 仅在需要交互作用结论时做 |
| 偏离原计划后仍能恢复全程防晃 | 实现并验证防晃接续，之后再扩展避障 | 后续研究，不属于当前已完成方案 |

现有 `planned_mpcc` 的非液体权重与 Full 不同，不能直接用于单项消融；已完成的下层对照是在 `planned_slosh` 内只改液体权重。额外对照由论文需要决定，不自动把所有选项变成本阶段待办。
