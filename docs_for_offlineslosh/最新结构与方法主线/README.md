## 主线概括

**面向移动机器人液体运输，用上层规划整趟路径、速度与停车，用下层液体感知 MPCC 根据实际状态调整运动，在给定空间和时间要求下减小晃动。**

上层考虑连续转弯和制动之间的长期影响；下层处理当前运动、液体状态和执行偏差。当前两层通过共同预测模型、名义计划和进度参考连接。

## 当前判断

- **框架已具备仿真运行基础。** 全程规划、在线控制和停车已接通，执行链修复已有固定批次验证。
- **整套方法已有模型内正向结果。** 最新 Full 的三项晃动指标和耗时均优于归档 B0，但包含路径与速度改变的作用。
- **两层各自的贡献仍需进一步分辨。** 已完成一次同计划下层代价消融，P95/RMS 改善，峰值尚未逐次全改善；真实液面收益尚待本版实物验证。

当前推进节奏是：**明确比较条件、核对关键实物差异 → 稳定后立即做小规模实物验证 → 正向后研究防晃接续与避障。**
