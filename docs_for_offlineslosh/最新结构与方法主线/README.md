# 最新结构与方法主线

更新：2026-09-19。分支：`feat/spmpc-liquid-control`；实验依据核对至 `2d2697b7`。

**“防晃优先＋可选时间优化”的代码和最小仿真验证已完成，本阶段收尾。** 当前默认仍使用防晃优先模式；下一步由论文需要和实物准备情况决定，本次只整理记录。

## 主线概括

面向移动机器人液体运输，上层规划整趟路径、速度与停车，下层液体感知 MPCC 根据实际状态调整运动，在给定空间和时间要求下减小晃动。时间优化是可选的离线搜索：在防晃门槛内寻找更短的计划。

两层通过共同预测模型、名义计划和进度参考连接。当前反馈进入下层，在线剩余任务重规划、接续和避障仍是后续研究。

## 当前结论

| 内容 | 已有证据 | 当前处理 |
| --- | --- | --- |
| 整套方法 | 原始路线 B0 与 Full 各三次，Full 晃动和耗时均值均改善；包含路径、速度和控制的共同作用 | 保留作为整套方法仿真结果 |
| 下层液体代价 | 同一计划、其他参数一致，两组各三次；峰值/P95/RMS 均值降低 14.61%/24.80%/13.35%，平均慢 0.241 s | 按均值和波动范围整理，不因峰值范围重叠继续补跑 |
| 可选时间优化 | 40→38 s 求解一次、闭环一次；实际 28.282→24.256 s，快 14.24%，晃动增加但仍满足既定门槛 | 单次缩时收益已验证，默认仍关闭 |
| 实物与后续研究 | 本版尚无 RGB 液面验收；在线接续和避障未接入 | 等待下一步选择，不作为本阶段未完成代码 |

**论文口径与运行门槛分别记录。** 论文报告样本量、均值和波动，不要求每个 Full 样本都低于所有对照；离线选计划与运行检查仍沿用原防晃、运动和停车门槛。当前结果来自液体模型，实物效果需独立测量。
