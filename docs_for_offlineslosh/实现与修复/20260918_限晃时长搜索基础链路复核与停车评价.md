## 4. 历史 9 次运行的统一窗口复算

停车候选为以下持续满足时刻的最大值：目标位姿误差 ≤ 0.05 m / 0.1 rad、实际速度 ≤ 0.01 m/s / 0.02 rad/s、首次持续零发布命令加冻结的最大执行延迟。命令阈值为 `1e-6`，使用 `control_cycle_audit.command_publish_stamp`；从首次持续零命令起计时，不能从此前最后非零命令起计时。最大延迟取归档 `execution_model` 参数。

raw pose 的参考系由生产者代码、归档 live 参数及 audit/path frame 一致性相互核对；raw pose 自身没有 header，仍使用 bag 接收时间。FIFO 清退由发布时间和延迟推断，没有直接测得队列内部状态。因此这些数值称**开发级停车候选**，不是形式化证明的实际 t_stop。物理模型的 ROS 接收调度偏差仍在。
