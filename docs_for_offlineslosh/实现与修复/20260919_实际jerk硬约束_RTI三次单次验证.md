# 实际 jerk 硬约束：RTI 3 次单次验证

2026-09-19。**只把本次模型试验的 RTI 从 1 次改成 3 次，S 路径成功完成；30 Hz 实时门槛尚未通过。** 在线液面仍为软代价，实际纵向 jerk 上限保持 1 m/s³。

| 指标 | 原 RTI 1 次 | 本次 RTI 3 次 |
| --- | ---: | ---: |

| 实际模型 jerk 峰值 | 1.000 m/s³ | **1.000 m/s³，未超限** |

| 求解调用总耗时最大值 | 26.472 ms | **34.170 ms** |

本次 1195 拍正常求解、10 拍正常停车、296 拍完成状态，没有求解失败、恢复停车或控制异常；记录到任务时刻 50 s，覆盖完成后的 5 s。最终位置误差 2.85 cm、朝向误差 0.0507 rad，满足原容差。

**结论：** 单次结果支持“增加 RTI 迭代能够解决这条路径此前的数值问题”，但计算开销增加。30 Hz 一拍只有 33.333 ms，本次最大求解调用耗时超出约 0.836 ms；计入原有 3 ms 发布预留，预算更紧。本试验未启用在线墙钟截止控制，也不包含 ROS 状态对齐和发布开销，不能写成“实时部署通过”。不追加试验，不修改生产默认迭代配置，不启动 Gazebo 或实车。

液面峰值 0.463383 mm 是本次完整模型试验的节点输出；原 RTI 1 次运行未完成，且归档 Gazebo 的采样及执行环境不同，不作液面收益对比，更不代表真实液面改善。
