# 时间优化：38 秒单候选闭环验证

2026-09-19。按用户确认的最小方案，仅尝试名义时长 **40→38 s**，新候选求解一次、闭环一次；40 s 直接复用已验证计划及三次 Full 记录。没有修改控制代码、权重、物理设置或防晃门槛，没有重试或追加候选。

**本次初步验证了实际缩时效果：到点由关闭开关时平均 28.282 s 降至 24.256 s，缩短 4.026 s（14.24%）；全程无异常，三项防晃门槛及绝对液面上限均通过。** 晃动高于默认防晃优先模式，体现的是在既定门槛内用部分防晃余量换取时间。默认仍关闭时间优化，没有替换现用 40 s 计划。
