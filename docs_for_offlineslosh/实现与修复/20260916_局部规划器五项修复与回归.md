## 停车合同和状态含义

区域启用时必须保留terminal、MPC停车交接、jerk及有效尾段参数，配置不完整会明确拒绝。`complete_stop.enable=false`关闭的是完整液体稳定等待，不关闭区域停车尾段检查。raw不读取液体观测，共享传播器内部的中性液体状态不冒充实测；无液体时的零高度诊断也不表示真实液面为零。

尾段固定当前进度对应的凸cell，复用footprint与margin。每步从起点预留实际速度/延迟目标速度上界对应的扫掠距离；命令、FIFO和加速度记忆全部归零后，仍预留 `tau_v * abs(v_actual)` 的衰减残余位移。它可能拒绝本可跨cell制动的情况，这是当前保守策略的边界，不是所有控制都不可行的证明。

| 状态 | 含义和运行行为 |
| --- | --- |
| `STOP_FIFO_REGION_VIOLATION` | 模型预测不可被新命令改变的FIFO前缀节点已越界；返回失败，不能声称此时发零能消除越界 |
| `STOP_REGION_UNSAFE` | 本制动策略的扫掠/残余位移余量或尾段位置不通过；不等于已证明不可避免碰撞 |
| `STOP_TAIL_TIMEOUT` | 给定尾段预测预算内未到quiet，明确失败，不把截断尾段算安全 |
| `REGION_STOPPING_TO_PRESERVE_MARGIN: ...` | 当前停车可行，但候选命令后的停车尾段未通过；发已核验的制动首命令，保持停车接管至任务重置；不是任务完成 |
| `TERMINAL_DRAINING` / `TERMINAL_SETTLING` | 释放执行器命令/队列，或等待完整停车的稳定条件；GOAL_REACHED仍需当前观测满足完成条件 |

替换候选命令时保留被拒绝的first-shot审计，但将其预测horizon标为无效并清空轨迹，避免当作已接纳命令的未来。`terminal`数组末尾追加 `stop_region_checked`、`stop_minimum_region_clearance_m`、`stop_fifo_prefix_violation`，旧字段位置不变；typed消息schema未改变。

## 连续进度与无输出回放

首次或显式新任务允许全局定位；后续仅在从已接受进度到lookahead上界之间搜索，平台距离一起处理，避免waiting样本卡住起步。它保留计划原有progress坐标，不按几何弧长重新标定，也不以横向跟踪误差或v×dt限制正常切角。重复发布同路线不重置；`configure()`视为显式新任务，需重新设置路线。首次定位在自交处的歧义、较大定位跳变后的恢复仍应按任务重置处理。

ROS中不消费液体时选本拍复制的odom时间，消费液体时选共同液体时间。指定时刻TF、odom frame、child frame和位姿有限性均需有效，不能在对齐失败时退回Time(0)。静态TF的零stamp允许使用，非零TF stamp须匹配目标epoch。

无输出回放使用独立输入topic接原audit，要求本节点 `publish_cmd_vel=false`、完整历史门开启、正cmd_timeout；禁止把本节点audit输出接回自身。完全相同的重复记录幂等处理；来源切换、时钟/cycle/发布时间倒序或冲突要求重启。空历史、断流及历史watchdog间隙仍会失败，不用虚构的零命令绕过。只有无时间戳 `/cmd_vel` 的旧bag不满足本入口合同。

具体ROS1独立master、`/use_sim_time`、播放topic限制和remap步骤只维护在[脚本README：无运动回放](../../src/scout_apps/control/spmpc_local_planner/scripts/README.md#无运动回放)。回放重算命令不改变bag后续状态，不能据此认定新策略闭环改善。

## 参数归属

通过现有 `planner_overlay_file` 暴露实验配置，不再复制一套停车预算或控制参数。四组对比应保持共同参数一致。

| 参数 | 默认 / 作用 |
| --- | --- |
| `planning/projection/lookahead` | 2.0个路线progress单位，连续分支搜索前向窗口；过小会落后，过大需复核近邻路线形状 |
| `terminal/complete_stop/max_tail_prediction_sec` | 8 s，普通区域制动与完整停车共享尾段预算 |
| `terminal/complete_stop/quiet_v`、`quiet_omega` | 0.001 m/s、0.001 rad/s，尾段quiet阈值；不能替代真实噪声标定 |
| `terminal/complete_stop/command_zero_tolerance` | 1e-6，完成队列门容差；尾段quiet另外要求命令/FIFO/记忆已精确归零 |
| `command_history/source` | `published`或`external_audit`；launch对应 `command_history_source` |
| `command_history/external_audit_topic` | 默认 `/spmpc/replay/control_cycle_audit`；launch对应 `external_audit_topic` |

基础参数见[common.yaml](../../src/scout_apps/control/spmpc_local_planner/config/planner/common.yaml)，共同实验合同见[四组配置README](../../src/scout_apps/control/spmpc_local_planner/config/experiments/trajectory_mpcc/README.md)。

## 验证结果与身份

| 验证层 | 本轮结果 |
| --- | --- |
| Native stub | 17/17个CTest程序通过，包含三项核心反例及记录命令合同 |
| Native真实acados | 18个CTest程序各通过；初跑replay diagnostics有两个旧假设失败，修正为显式新任务和configure后重新设置路线后，该程序19个内部用例重跑通过 |
| Python定向检查 | 49项通过；另2个roslaunch参数展开用例因本机缺ROS1环境未运行，不计通过 |
| 完整模型闭环 | 三种路线 × 四组 × 执行器时间常数倍率1.0/1.15，共24次，22次完成 |
| ROS与实物 | 未完成ROS1整节点编译、TF/bag联调；未启动底盘或执行实物实验 |

模型闭环两次失败仍是 `corner + geometry + tau1/tau1.15`，状态 `ACADOS_SOLVE_FAILED_4`；保留失败行，没有用调参掩盖它们。原始跟踪组和两种planned组均完成本轮三场景测试，但这不能推广到所有路线。最长控制周期82.212311 ms，各试验P95最大59.621152 ms，均不能支持30 Hz实时性验收；跨轮计时变化受负载与新增检查影响，不作为速度优化结论。

较小曲率依然不等于降晃：例如nominal单弯raw/planned_slosh的正则曲率积分约5.457/1.573，而模型液面峰值约0.893/1.194 mm。该曲率指标包含0.05 m/s低速正则，计算定义见[再次复盘](20260916_当前主线复盘与剩余缺口.md)。液体来自理想plant状态，峰值按30 Hz节点采样，没有独立实测或连续峰值认证。

本轮仿真初态改为计划中声明的 `task.start_state`，校验28维有限且与优化首样本误差不超过2e-6。此前直接把优化首样本约1e-10量级的负命令残差当作真实历史，会被正确的历史门拒绝；此次修正仿真输入，不放宽生产历史门，也不清零真实非零初态。三份计划重新生成并独立验证为 `SOFTWARE_VERIFIED`，计划ID与原验证一致，文件hash按本次生成保存。
