# Phase-Rejoining Residual S-MPCC 实物实验方案

> 更新日期：2026-08-21
> 本文档回答“仿真通过以后，实物上具体做什么、每项实验为什么做、什么结果才算通过”。它是待执行方案，不是已有实验结果。

## 0. 一眼看懂：现在不能直接开始正式实物实验

- 当前代码基线：`552259c8`。
- 当前状态：考虑执行延迟的独立求解器骨架已经建立，但还没有接入在线控制；正式液体目标、恢复判断、执行状态匹配条件和独立仿真对象也没有完成。
- 当前结论：**仿真尚未通过，实物正式运行仍是 NO-GO。**
- 当前该做的事：先完成控制器和独立仿真，再完成 C0–C4 仿真对比。

进入实物线路前，仿真至少要同时满足：

1. 独立仿真液面中，C4 相对 C0 正向；
2. C4 相对完成时间和平滑程度相近的 C1 仍正向；
3. 安全受控偏离中，C4 相对 C3 能减少错误修正或恢复失败；
4. 延迟、液体频率和阻尼扰动下结论不过分脆弱；
5. 控制器能稳定按 30 Hz 运行，正式仿真版本已经冻结。

仿真通过以后，实物按下面顺序做，不能跳步：

```text
仿真通过
   ↓
第1阶段  标定Scout执行响应和所有时间戳
   ↓
第2阶段  用独立RGB验证液体模型是否足以支撑控制决策
   ↓
第3阶段  生成实物专用轨迹和恢复规则，并先旁路检查
   ↓
第4阶段  小规模预实验，确认流程和可测性
   ↓
第5阶段  正式名义实验：C0/C1/C2/C4
   ↓
第6阶段  正式安全偏离实验：C3/C4
   ↓
核心结论通过后，再考虑input shaping实物对照或第二条路径
```

各阶段在论文中的作用不同：

| 阶段 | 真正回答的问题 | 是否用于最终效果结论 |
| --- | --- | --- |
| 标定 | Scout 和传感器到底有多大延迟、惯性和时间偏差 | 否，只证明实验链可信 |
| 模型保真度过渡 | 低阶液体模型对真实液体是否保留控制所需的幅值、相位和动作排序 | 是，但只作模型支撑证据 |
| 小规模预实验 | RGB 能否看出差异，四种控制器和实验流程是否可审计 | 否，不与正式结果混用 |
| 正式名义实验 | 完整方法是否真的降低真实液面，而且不是只靠变慢、变平滑 | 是，论文主结果 |
| 正式安全偏离实验 | 尾段接回判断是否能减少有害在线修正 | 是，核心机制结果 |

## 1. 所有实物实验共用的规则

### 1.1 五种控制条件

| 条件 | 人话解释 | 它负责回答什么 |
| --- | --- | --- |
| **C0 普通 MPCC** | 只跟路径，不知道液体状态，也没有离线防晃尾段 | 完整方法相对普通 MPC 是否有总体收益 |
| **C1 平滑公平对照** | 仍是普通控制器，但在独立开发数据上调到与 C4 完成时间和平滑程度接近 | C4 的收益是否只是因为更慢、更平滑 |
| **C2 离线轨迹回放** | 回放与 C4 相同的完整离线防晃轨迹，不允许在线修正 | 完整离线防晃序列本身表现如何 |
| **C3 在线修正但不检查尾段** | 与 C4 使用相同在线修正和底盘模型，但不判断修正后能否接回防晃尾段 | 没有恢复判断时会发生什么 |
| **C4 完整方法** | 离线防晃轨迹、双通道执行预测、有界在线修正和尾段接回判断全部启用 | 本文最终系统的表现 |

C3 关闭的只是本文的尾段接回判断。速度限制、碰撞停止、求解失败处理和平台硬安全必须与 C4 一样保留，不能为了制造差异而关闭安全保护。

### 1.2 真实液面只由独立 RGB 负责判定

实物防晃的唯一主指标建议冻结为：

$$
Y_{\mathrm{RGB}}=
Q_{0.95}\!\left(
\left\{
\mathrm{max\mbox{-}LCR}_{\mathrm{RGB}}(t)
\mid t\in\mathcal W_{\mathrm{motion+tail}}
\right\}
\right),
$$

即：对每次完整运行，从开始运动到固定静置尾段结束，取 RGB 测得液面最大抬升量的 95% 分位数。每次运行只得到一个主统计值。

还要从 RGB 得到一个带正负号的液面量，例如左右液面高度差

$$
y_{\mathrm{signed}}=h_{\mathrm{right}}-h_{\mathrm{left}},
$$

它只用于模型保真度实验中的过零、主频、相位和衰减比较。非负的 `max-LCR` 适合评价晃动幅值，但不能独自说明正负相位。

控制器内部 `/slosh/height`、内部 observer 和其他 slosh monitor 只能解释“为什么可能改善”，不能替代 RGB，也不能在 RGB 负向时用内部结果宣称实物防晃成功。RGB 当前是独立评价传感器，不应写成液面反馈闭环。

### 1.3 固定实验范围

首轮实物只使用：

- 一种冻结容器、装液量、安装位置和载荷；
- 一条静态净空的冻结核心路径；
- 相同起始位姿、速度上限、底盘控制器和安全限制；
- 每次运行前相同的液体静置准入条件；
- 预先审核过的小幅、可重复偏离。

首轮不做：动态障碍、人工推车、突然撞击、近溢出危险边界、在线绕障、第二容器和强非线性破波工况。不可恢复边界的大规模扫描留在仿真和录包回放中。

## 2. 第1阶段：标定 Scout 执行响应和测量时间轴

### 要回答的问题

控制器发布的命令何时真正作用到 Scout？线速度和角速度的延迟、惯性是否不同？Nokov、odom、IMU 和 RGB 的物理时间能否对齐？

### 对照

- 最终实际发布命令与 Nokov/odom 实际运动；
- 线、角使用同一个延迟的简单模型，与线、角分开建模的模型；
- 只用计划命令回放，与使用最终实际发布命令回放；
- 模型拟合数据与完全独立的测试运行。

### 怎么做

1. 使用正式实验相同的容器、装液量、安装方式和载荷。
2. 执行安全的小幅线速度阶跃、加减速、左右转动和线角组合命令，覆盖计划使用的速度范围与正负方向。
3. 同时记录状态采样、优化结果、最终发布命令、Nokov、odom、IMU 和 RGB 的源时间戳，并用统一运行编号贯通整条记录。
4. 分别辨识线速度和角速度的纯延迟、响应快慢、增益、死区、饱和及必要的方向差异。
5. 单独标定 RGB 时间延迟；不能简单按 bag 中最近帧代替真实物理时刻。
6. 使用未参与拟合的完整运行验证模型，并检查电量、日期和地面条件改变后参数是否仍在冻结范围内。

### 主指标

- 线速度和角速度在完整预测时间内的 held-out 预测误差及区间；
- 两路延迟和响应时间的跨 trial 分布；
- ROS、Nokov、odom、IMU、RGB 的时间偏差及不确定度；
- 使用最终发布命令回放相对计划命令回放的误差改善；
- 第一拍候选动作造成的实际运动差异，相对 Scout 执行噪声的大小。

### 通过标准

在查看独立测试结果前，依据控制裕量和 RGB 时间分辨率冻结数值门槛。至少还必须同时满足：

1. 双通道模型在独立数据上明显优于单一共同延迟和命令持值基线；
2. 从状态采样、预计发布、两路命令生效到联合预测终点的时间定义闭合；
3. 使用最终发布命令回放明显优于只用求解器计划命令；
4. 第一拍动作差异高于执行噪声，否则在线修正在实车上不可辨识；
5. 时间偏差和参数漂移小于后续模型保真度与恢复判断预留的容差。

任一项失败，都不能进入正式控制，应先降低控制链延迟、修正时间同步或缩小使用范围。

### 能支持和不能支持的结论

- **能支持：**Scout 双通道执行模型和证据时间轴在冻结工况内可信。
- **不能支持：**液体模型准确、恢复判断有效或真实液面已经降低。

## 3. 第2阶段：模型保真度过渡实验

这一步连接“仿真中模型有效”和“实物中真实液面降低”，不能省略。它分为两项：先验证液体响应，再验证模型能否支持控制决策。

### 3.1 液体响应保真度

#### 要回答的问题

使用真实 Scout 运动作为输入时，控制器的低阶液体模型是否至少保留观察平面内的主频、相位、幅值和衰减？

#### 对照

- 模型预测的液面状态与独立 RGB 的 `max-LCR`、左右液面高度差；
- 用最终实际运动驱动模型，与用计划命令驱动模型；
- 参与模型拟合的激励，与完全独立的验证激励。

#### 怎么做

1. 在安全幅值内执行标准直线加减速、左右转弯和线角组合激励。
2. 模型拟合只使用一组完整运行；验证使用另一组完整运行，不能把同一次运行的相邻帧随机拆分。
3. 模型输入优先使用离线平滑后的 Nokov/odom 运动学，并用 IMU 交叉检查；不能只使用 processed IMU，把滤波相位误差误认为液体模型误差。
4. 比较运动结束后的自由衰减，使固有频率、阻尼和 RGB 时间偏差可以分别判断。
5. 所有验证只覆盖正式实验计划使用的小幅主模态范围；出现破波、撞壁或明显高阶模态的 trial 作为越界记录，不能拿来回调后仍算独立验证。

#### 主指标

- RGB signed-state 的主频、过零时刻和相位误差；
- `max-LCR` 的峰值、P95、RMS 和衰减时间误差；
- 实际运动回放相对计划命令回放的改善；
- 不同直线、左右转弯和组合激励下的最差误差。

#### 通过标准

- 主频和衰减误差落在正式控制预先允许的范围；
- 观察平面相位误差小于候选动作排序与尾段重接所需的容差；
- 幅值误差不会把明确越界状态误判为安全状态；
- 使用实际运动回放的预测在独立运行上优于命令回放和简单持值预测；
- 最差方向和最差激励仍在冻结适用范围内。

数值门槛必须在独立验证数据解盲前冻结。如果验证后修改液体参数或 RGB 延迟，原验证数据立即降级为开发数据，必须重新采集独立验证运行。

#### 能支持和不能支持的结论

- **能支持：**低阶模型在冻结容器、液位和小幅运动范围内，保留了观察平面中与控制有关的液面动态。
- **不能支持：**模型还原了完整二维/三维流场、所有内部液体状态都被 RGB 直接测量，或模型在近溢出工况仍准确。

### 3.2 完整预测时间和候选动作排序

#### 要回答的问题

从读取状态到新命令发布、再到两路命令生效和短液体窗口结束，模型是否仍能预测真实结果？它能否判断两个安全候选动作中哪个会产生更小的真实晃动？

#### 对照

- 完整双通道预测，与命令持值、单一延迟和只预测 100 ms 的简单方法；
- 候选动作 A 和 B 加各自后续尾段；
- 模型给出的动作排序与重复实物运行的 RGB 排序。

#### 怎么做

1. 每个预测目标都绑定真实物理时刻，不能按 bag 索引取最近帧。
2. 使用同一套安全预激励脚本，重复构造近似相同的初始 RGB signed-state。
3. 分别执行候选 A 和 B 及其后续尾段；两个候选的实际线、角运动差异必须高于执行噪声。
4. 只有初始 RGB signed-state 在预先冻结容差内的 A/B 才组成有效配对；无效配对按预注册规则记录，不能看完结果后选择性删除。
5. 排序数据与后续恢复规则的拟合、调参和测试严格分开。

#### 主指标

- 从状态采样时刻到联合终点的 RGB 预测误差；
- 候选动作 pairwise ranking accuracy 及区间；
- 相对持值、单延迟等简单基线的改善；
- 初始状态匹配率、有效配对率和第一拍动作可分辨率。

#### 通过标准

- 完整预测在独立测试运行上优于所有预注册简单基线；
- 动作排序准确率及其区间超过预先冻结的最低有用水平；
- 最差相位区间没有完全缺少样本；
- 不能通过只挑动作差异最大或初始状态最有利的配对获得正向结果。

#### 能支持和不能支持的结论

- **能支持：**模型在完整控制 lead 内具有控制相关的预测和候选排序能力。
- **不能支持：**模型对任意未来时长准确，或一次候选排序正确等于恢复安全保证。

## 4. 第3阶段：生成实物专用版本并做旁路检查

这一步是准备，不是正式效果实验。

### 要回答的问题

按实车参数重新生成的离线轨迹、执行状态匹配条件和恢复规则是否彼此一致？控制器在真正接管车辆前，能否正确记录它本来会作出的选择？

### 对照

- 使用实车参数后的独立仿真 C0–C4，与此前冻结的仿真结论；
- 旁路记录的相位、动作和恢复判断，与离线重放得到的预期结果；
- 恢复规则拟合数据，与完全独立的测试数据。

### 怎么做

完成标定和模型验证后，需要重新生成：

- 实物专用离线防晃轨迹及完整减速—消余晃—静置尾段；
- 当前命令队列和 Scout 响应能否接回离线轨迹的匹配条件；
- 使用独立数据建立和测试的恢复判断规则；
- 固定代码、参数、轨迹、RGB 标定、分析脚本和停止规则的实物版本。

然后必须做两项检查：

1. **用实车参数重跑独立仿真。**控制器使用实车辨识参数，但外部仿真 Scout 和液体仍保留独立偏差；C0–C4 结论必须继续正向。
2. **实车旁路观察。**控制器只记录“本周期会选择什么动作、是否允许接回”，不实际接管车辆，检查时间索引、最终命令、恢复判断和后备动作是否一致。

恢复规则的拟合数据和独立测试数据按完整 trial 分开。独立测试至少报告覆盖率、错误放行、错误拒绝、最差相位和真实接回结果。若规则改动，必须产生新版本和新独立测试集。

### 主指标

- 实车专用轨迹、模型、恢复规则和运行配置的合同及 hash 一致性；
- 实车参数独立仿真中的 RGB 主指标、tracking、失败和实时性；
- 旁路检查中的时间索引错误、命令记录缺失和预期/实际判断不一致次数；
- 恢复规则在独立数据上的覆盖率、错误放行、错误拒绝和最差相位样本量。

### 通过标准

- 使用实车参数重跑独立仿真后，C4/C0、C4/C1 和 C4/C3 的预注册方向仍然通过；
- 所有实物专用资产能追溯到同一个冻结版本，合同和 hash 无冲突；
- 旁路检查没有未解释的相位跳变、时间错位、命令缺失或后备动作不一致；
- 恢复规则在独立数据上达到预先冻结的覆盖率和误判门槛。

### 能支持和不能支持的结论

- **能支持：**实物专用版本可以进入小规模实车控制，经验恢复规则已经由独立数据检查。
- **不能支持：**防晃已经成功或恢复具有安全保证。恢复规则仍只能称为经验判断，不能称为安全证书。

## 5. 第4阶段：小规模预实验

### 要回答的问题

RGB 是否能稳定看到控制条件的差异？C0、C1、C2、C4 是否真正发出了不同且可追溯的命令？正式随机配对实验能否安全执行？

### 对照

- 名义路径上少量 C0、C1、C2、C4 配对 block；
- 必要时用极少量、最保守的 C3/C4 安全偏离检查分支是否真的触发；
- C1 与 C4 的完成时间、速度、加速度和 jerk 包络。

### 怎么做

1. 先用开发数据调整 C1、C4、RGB 流程和安全范围，然后冻结一个候选版本。
2. 再采集全新的 pilot 数据；pilot 期间不再改控制器参数。
3. 每个 block 内各条件各运行一次，使用预先生成的平衡随机顺序。
4. 每次 trial 开始前，RGB 幅值和 signed-state 必须满足冻结的静置条件。
5. pilot 用于估计 block 内配对方差、RGB 最小可检测差异和正式样本量，不进入正式效果统计。

### 主指标

- RGB 有效帧率、时间戳完整率、噪声和最小可检测差异；
- 每种条件的实际命令分离度；
- C1 与 C4 的完成时间及运动平滑匹配误差；
- 路径跟踪、停车、求解失败、30 Hz 超时和安全改写；
- block 内 RGB 主指标的配对方向和方差。

### 通过标准

- RGB、命令链、实验配置和分析结果能从每个图追溯到原始 trial；
- C1 的完成时间及运动包络进入预先冻结的匹配容差；
- 各条件实际动作差异高于执行噪声；
- 正式效果大小和所需样本量在可执行范围内，没有明显负向或无法测量的问题；
- 无未解释的安全事件、系统性超时或条件特有的数据缺失。

若 pilot 后修改参数，该 pilot 只能作为开发数据，必须重新冻结版本并采集新的 pilot。

### 能支持和不能支持的结论

- **能支持：**实验流程、测量分辨率和预计样本量足以开始正式确认。
- **不能支持：**C4 已经显著优于任何基线。pilot 结果不能与正式数据合并“凑样本”。

## 6. 第5阶段：正式名义效果实验

### 要回答的问题

C4 是否相对普通 MPCC 真正降低真实液面？这种降低是否仍然存在于与 C4 同样慢、同样平滑的普通控制器对照中？

### 对照

正式主矩阵只包含：

- C0 普通 MPCC；
- C1 平滑公平对照；
- C2 离线防晃轨迹回放；
- C4 完整方法。

主检验顺序固定为：先比较 C4 与 C0；只有这一项通过，才检验 C4 与 C1。C2 用于展示完整离线序列的实际表现，但 C2/C4 之间同时包含在线修正等差别，不能把它当成单一模块消融。

### 怎么做

1. 只使用冻结核心路径、容器、液位、起点、速度限制和安全规则。
2. 每个 block 内 C0、C1、C2、C4 各运行一次，使用预先生成的平衡随机顺序。
3. 运行前满足同一液体静置条件；运行中保留所有求解失败、停车、安全改写和 RGB 故障标签。
4. pilot 根据物理意义、freeboard 风险、RGB 最小可检测差异和配对方差确定正式重复次数；不直接沿用旧的 40/64/88 次矩阵。
5. 正式数据开始后不再调权重、选择指标、改变 tail 窗口或扩缩恢复规则。

### 主指标

- **唯一物理主指标：**每个 trial 的 RGB motion＋fixed-tail `max-LCR` P95；
- **公平性指标：**完成时间、路径和航向误差、速度、加速度、角加速度及 jerk；
- **失败指标：**未到达、求解失败、安全停车、超时和传感器无效；
- **解释指标：**RGB RMS/peak/settling time、内部液体状态、相位、residual 和恢复判断分支。

### 通过标准

只有同时满足以下条件，才能写“C4 相对普通 MPCC 改善了防晃性能”：

1. C4 相对 C0 的 RGB 配对改善及区间达到预先冻结的最小有意义效应；
2. 若进一步声称收益不是减速和平滑造成，C4 相对 C1 的第二顺序检验也必须通过；
3. 完成时间和 tracking 落在预注册的非劣容差内；
4. C4 的失败、停车、超时和安全事件不比基线恶化；
5. 多数 block 的方向一致，效果不是由单个异常 block 驱动。

如果 RGB 降低但车辆明显更慢、跟踪更差或失败更多，只能报告防晃—任务折中，不能写总体优于普通 MPC。内部 slosh 正向而 RGB 不正向，实物主结论仍为未通过。

### 能支持和不能支持的结论

- **C4 优于 C0：**支持完整系统相对普通 MPCC 的端到端实物收益。
- **C4 同时优于 C1：**进一步支持收益不是单纯减速或平滑造成。
- **C2 的结果：**说明纯离线回放的能力和局限，但不单独证明 residual 或恢复判断的贡献。
- **不能支持：**尾段接回机制具有独立价值；这个问题必须由下一阶段 C3/C4 回答。

## 7. 第6阶段：正式安全偏离和恢复实验

### 要回答的问题

当实车出现小幅、可重复的执行偏离时，不加判断的在线修正是否可能破坏后续防晃尾段？C4 的尾段接回判断能否减少这种有害修正，同时保留足够的正常放行？

### 对照

- C3：允许在线修正，但不检查修正后能否接回尾段；
- C4：相同在线修正，加尾段接回判断、保存的恢复动作和失败后备。

两者必须保留相同的平台限速、硬安全、求解失败处理和最终命令出口。

### 怎么做

只从下面选择经过仿真和安全审查、幅值预先冻结的偏离：

1. 软件附加一小段已知命令延迟；
2. 对短时间段施加已知的安全限幅；
3. 使用预先编排的短速度门；
4. 使用小幅、可重复的初始位姿偏差。

每个 C3/C4 配对应使用相同预激励和静置规则，尽量匹配初始 RGB signed-state。初始状态不满足冻结容差的配对按预注册规则标为无效，同时保留原始 attempt 和原因。禁止用动态障碍、人工推车或不可重复碰撞作为正式扰动。

### 主指标

- trial 级实际接回成功率和失败率；
- RGB motion＋tail P95、tail RMS 和静置时间；
- C4 的放行覆盖率、错误放行和错误拒绝；
- 从偏离到重接所需时间；
- 保存恢复动作被提出、通过安全链并真正发布的比例；
- 停车、求解失败、任务完成和 tracking。

同一个 trial 中的几百个恢复判断高度相关，不能把每个控制周期当作独立样本。周期级 coverage 只能描述行为；错误放行和恢复成功必须以完整 trial 或 block 统计。

### 通过标准

- C4 相对 C3 减少预注册定义的有害修正、恢复失败或异常停车；
- C4 的真实 RGB 结果改善或至少不恶化；
- C4 不能靠拒绝全部动作获得零错误放行，正常放行覆盖率必须达到预先冻结的最低水平；
- 独立测试中的错误放行及其上置信界处于预注册可接受范围；
- 最差相位有数据，失败后实际发布的命令符合后备合同。

### 能支持和不能支持的结论

- **能支持：**在冻结路径和安全偏离范围内，经验尾段接回判断能减少无约束 residual 的错误修正。
- **不能支持：**递归可行性、一般安全保证、动态障碍恢复或所有未知扰动下均可恢复。论文仍应使用“经验恢复放行判断”，不能升级为安全证书。

## 8. 两项建议增强实验

这两项只在核心路径 C0–C4 全部通过后开展，不阻塞首轮实物闭环。

### 8.1 Input-shaping 实物对照：建议优先加入

输入整形是审稿人熟悉的传统外部防晃方法，比内部旧版 S-MPCC 更能说明本文相对已有防晃方法的位置。若能可靠实现，应在独立开发数据上冻结其液体频率、整形参数、任务时间和输入约束，再作为次要实物对照运行。

它必须与 C4 使用同一路径、速度/加速度上限和相近完成时间。它不能替代 C1：C1 排除“只是更平滑”，input shaping 回答“相对成熟防晃前馈方法是否还有收益”。

- **目的：**回答完整方法相对审稿人熟悉的传统防晃前馈是否仍有竞争力。
- **主指标：**仍使用相同的 trial 级 RGB motion＋tail P95，并同时报告完成时间、tracking 和失败。
- **通过标准：**C4 的配对效应达到预先冻结的最小有意义改善，且任务指标不恶化；若只持平，应如实写成性能相当而功能不同。

- **通过后能说：**C4 在当前路径和容器上相对可信传统防晃基线仍有竞争力。
- **不能说：**本文在所有容器和重复任务上全面优于 input shaping。

### 8.2 第二条冻结路径：可选泛化证据

可由 MBF 在静态地图中预先生成第二条不同曲率路径，随后冻结路径点列，并为它重新生成自己的离线防晃轨迹和恢复规则。建议只做小规模 C0/C1/C4 确认；若资源允许再加入 C2。

- **目的：**检查正向方向是否只依赖一条经过反复调试的核心路径。
- **主指标：**相同 RGB 主指标、任务公平性和失败统计，不为第二路径更换评价口径。
- **通过标准：**C4/C0 以及需要作平滑归因时的 C4/C1 均保持预注册正向，且使用第二路径自己的冻结资产。

- **通过后能说：**方法不是只在一条路径上出现正向方向。
- **不能说：**具有在线避障、动态重规划或任意路径泛化能力。

如果时间只能选一项：核心创新容易被质疑为只针对一条路径调参时，优先第二路径；缺少审稿人熟悉的外部防晃对照时，优先 input shaping。

## 9. 随机化、样本量和数据隔离

### 9.1 统计单位

- 一个 **trial** 是从静置准入、开始运动到固定 tail 结束的一次完整运行。
- 一个 **block** 包含同一实验问题下各条件各一次，例如主实验的 C0/C1/C2/C4 各一次。
- 正式统计单位是 trial 和 block；RGB 帧、IMU 样本、路径点和 MPC 周期都不是独立样本。

### 9.2 随机配对

- 同一 block 内使用预先生成的平衡随机顺序，使每个条件出现在各顺序位置的次数接近。
- 同一 block 尽量在相近电量、温度、装液和地面条件下完成。
- 日期、电量、液温、装液质量、相机设置和地面状态作为 block 元数据保留。
- 主分析报告每个 block 的原始配对差、总体效应和区间，并检查移除任一 block 后结论是否翻转。

### 9.3 样本量

先根据 freeboard 风险、RGB 最小可检测差异和物理意义冻结“最小值得关心的改善”，再用独立 pilot 估计 block 内差值方差和正式样本量。不能看到正式结果方向后临时扩样，也不能因为结果正向提前停止。

### 9.4 数据隔离

至少分开保存：

| 数据 | 用途 | 不能做什么 |
| --- | --- | --- |
| 执行/液体模型拟合数据 | 辨识参数 | 不能再次充当独立模型验证 |
| 模型保真度独立数据 | 验证完整 lead、相位和排序 | 看到结果后改模型则立即降级为开发数据 |
| 恢复规则拟合数据 | 建立恢复判断 | 不能进入错误放行统计 |
| 恢复规则独立测试数据 | 判断覆盖率和误判 | 不能调恢复阈值 |
| 控制器开发数据 | 调 C1/C4 和流程 | 不能进入论文正式效果统计 |
| pilot 数据 | 检查流程、估计方差和样本量 | 不能和正式结果合并 |
| 正式名义/恢复数据 | 给出论文结论 | 不能反过来修改同一实验版本 |

所有失败、求解失败、安全停车和超时都是结果。只有预先定义的外部采集故障可以补做，而且原始 attempt 和排除原因仍需保留。

## 10. 为什么这样设计：与领域论文梳理的关系

本方案参考了[液体防晃方法分类与领域分析](../防晃领域论文梳理/液体防晃方法分类与领域分析.md)，但没有机械照搬某一篇论文：

| 实验设计 | 文献给出的原因 | 本方案怎样落实 |
| --- | --- | --- |
| 设置 C1 平滑公平对照 | C11 表明相同 jerk 代价下，有无液体模型仍可能产生很大晃动差异；“平滑”不能自动等于“防晃” | 匹配 C4 完成时间和运动包络，再比较独立 RGB |
| 建议 input shaping 外部对照 | A07、B02–B04 和 C03 等固定整形/剖面方法已有较成熟实水证据 | 将其作为可信传统防晃次要基线，而不是用内部旧版本自比 |
| 增加模型保真度过渡 | A01/A02 等低阶模型只在标定范围可靠；A12/C05 也提示长时间内部传播会积累误差，AR16–AR22 说明强非线性时机制会改变 | 用 actual-motion replay、独立 RGB signed-state 和完整 lead 排序验证，明确小幅适用范围 |
| 显式标定双通道执行模型 | 领域梳理指出多数工作把命令近似为容器实际运动，真实底盘延迟、限幅和低层改写是实物缺口 | 从最终发布命令追到 Nokov/odom/IMU/RGB，验证线、角不同延迟和惯性 |
| RGB 与内部模型分开 | 许多论文中的相机或超声只用于评价；模型内部有液体状态不等于测到了真实液面 | RGB 决定实物主结论，内部 slosh 只作机制解释 |
| C3/C4 安全偏离比较 | 单纯“离线轨迹＋在线 MPC”已有相关工作；本文真正需要证明的是在线修正是否会破坏后续相位抵消，以及恢复判断是否有独立价值 | 用已知延迟、限幅或短速度门做可重复反事实比较，不引入动态障碍 |
| trial/block 级重复统计 | 现有防晃论文常缺少重复次数、完整时延尾部和失败统计 | 使用随机配对 block、失败保留和区间报告，禁止把帧或控制周期当独立样本 |

因此，每项实物实验都只回答一个明确问题：

```text
标定：命令到真实运动是否可信？
模型过渡：低阶模型对真实液体是否有控制价值？
名义主实验：真实液面是否降低，而且不是靠变慢？
安全偏离实验：尾段接回判断是否真的减少错误修正？
增强实验：结果是否能跨传统基线或第二条路径保持？
```

## 11. 最终执行清单

- [ ] 独立仿真 C0–C4、鲁棒性和 30 Hz 全部通过并冻结；
- [ ] Scout 线/角执行参数和全部时间偏差在独立数据上通过；
- [ ] 液体模型的真实 RGB 幅值、相位、完整 lead 和候选排序通过；
- [ ] 实物专用离线轨迹、执行匹配条件和恢复规则重新生成；
- [ ] 用实车参数重跑独立仿真仍然正向；
- [ ] 实车旁路检查通过；
- [ ] 新 pilot 通过，正式样本量、随机表和停止规则冻结；
- [ ] 名义 C0/C1/C2/C4 正式随机配对完成；
- [ ] 安全偏离 C3/C4 正式随机配对完成；
- [ ] 所有结论以独立 RGB、任务公平性和失败统计共同判断；
- [ ] 核心结果通过后，再决定 input shaping 或第二条路径增强实验。

当前只需记住一句话：

> **先用仿真把方法机制做通，再用标定和 RGB 模型保真度实验建立过渡，最后才用 C0/C1/C2/C4 和 C3/C4 的随机配对实物实验回答“真实液面是否降低、尾段接回是否有用”。**
