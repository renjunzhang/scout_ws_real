# Full 与 FP-AS：方法及结果对比

2026-09-20。供梳理方法、与 GPT Pro 讨论；复用已有实现与归档结果。

**两者都在全局层考虑液体模型并优化全程运动节奏。Full 还允许改变路径；两者的优化目标和下层执行方式也不同。** 因此，现有结果不能直接解释为“全局层有没有采用防晃速度规划”的区别。

**方法对比**

| 对比项 | 我们的 Full | 当前 FP-AS 适配 |
| --- | --- | --- |
| 全局层优化什么 | 联合优化路径几何、速度和命令序列，预测液体响应 | 固定几何，优化沿路径的时间律及对应命令序列，预测液体响应 |
| 路径如何处理 | 原始路线作为引导，允许在给定可行区域内改路 | 冻结原始路线平滑后的曲线，不使用 Full 优化路径 |
| 全局层主要目标 | 液体位移及变化率、末端残振，加上路径引导、曲率、控制量与 jerk 等加权项 | 主要最小化沿路径进度 jerk 的平方积分，曲线另加小的角命令平滑项 |
| 全局层液面处理 | 液体状态软代价，同时保留运输和停车液面限制 | 液面作为运输和停车约束，不使用 Full 的液体状态运行代价 |
| jerk 的区别 | 原纵向命令 jerk 有硬限制并进入平滑代价 | 保留原命令 jerk 硬限制，另约束并优化沿路径进度 jerk；进度 jerk 不等于执行器响应后的实际 jerk |
| 时长如何确定 | 默认固定名义时长；另有可选有限时长搜索。下面共同档使用名义 44 s | 当前成功 S 计划固定 40 s；28 s 候选离线超时，没有闭环结果 |
| 下层如何取参考 | 按路径进度取位置和速度参考（`progress`），允许重新调整局部路径与速度 | 按任务时间取位置和速度参考（`time_tracking`），反馈修正跟踪误差 |
| 下层是否优化液体 | 是，液体软代价权重 5；在线液面硬约束关闭 | 否，使用不含液体优化的常规跟踪控制；液体模型用于离线规划和运行评价 |
| 下层关键权重 | 速度跟踪 `w_v=1`；共同档进度奖励为 0，默认快速档为 0.2；几何目标权重 0，保留曲率项 | 速度跟踪 `w_v=10`；进度奖励 0；几何目标权重 2，曲率项关闭 |
| 全程计划如何保留 | 在线改速、改路后，未自动重规划剩余全程；按进度取参考不会自动保持原消晃时序 | 目标是执行原时间计划，但仍存在跟踪误差，不能认为完全复现离线运动 |
| 执行与实物适配 | 保留执行器延迟、响应、命令 FIFO、状态时间对齐和故障停车 | 同样保留这些共同执行环节 |

Full 保留路径优化，是为了同时改善转弯和路线长度；这项自由度能否带来最终收益，需要看闭环结果。Ferrari 原文也包含路径与时间联合优化，不能把这项设计本身作为已经证明的优势。

**已有 S 路径约40秒共同档结果**

以下使用已核对运行物的旧稳定版本，两组各一次。完成时间按持续到位、低速和命令延迟清空统一计算；运输统计窗口为运动开始至停稳。**所有液面高度均为模型输出，没有独立真实液面测量。**

| 指标 | Full 较慢档 | FP-AS |
| --- | ---: | ---: |
| 名义规划时长 / s | 44.000 | 40.000 |
| 统一任务完成时间 / s | 41.021 | 40.432 |
| 名义路径长度 / m | 5.112 | 5.813 |
| 实际起步时刻 / s | 4.337 | 1.073 |
| 起步至统一完成 / s | 36.684 | 39.359 |
| 各自离线计划预测的运输模型峰值 / mm | 0.098782 | 0.262409 |
| Gazebo 运输模型峰值 / mm | 0.486963 | 0.269344 |
| Gazebo 运输模型 P95 / mm | 0.193539 | 0.149733 |
| Gazebo 运输模型 RMS / mm | 0.083174 | 0.078542 |
| 停车评价窗内模型峰值 / mm | 0.000050 | 0.015029 |

任务完成时间相差 1.44%，但起步、实际运动时长和路径不同。FP-AS 本次运输三项指标更低。Full 的停车模型数值更低，但它平移停下到统一完成有 6.044 s，FP-AS 为 1.259 s；Full 在停车评价窗前已有更长衰减时间，不能将尾振差全部归于控制效果。

**目前能确定什么、还不能确定什么**

- **已确定：** Full 已有全程防晃规划；其执行运动偏离名义计划，闭环模型峰值高于离线预测。上表离线和执行指标来自各自轨迹与窗口，不能直接视为同一输入下的模型预测误差。
- **待验证的解释：** 下层重新安排速度可能削弱上层防晃节奏；不同目标、权重、路径以及执行时序失配也可能影响结果。尚未证明速度跟踪就是主要原因，也不能据此认定在线液体代价无效。
- **值得讨论的最小对照：** 复用同一份 Full 计划，保留液体代价和执行适配，只改变明确的一项速度参考执行机制，检查计划保留程度与模型晃动。不能直接切换整个 `external_timed` 配置来归因，因为它还会关闭在线液体优化并改变多项权重。此对照尚未实施。

新增“执行器响应后的实际 jerk ≤ 1 m/s³”实验约束已暂缓，原命令 jerk 限制继续保留。上表不属于该新增约束版本的结果，关闭当前源码开关也不等于新运行物已通过旧稳定版验证。正式重复、实际执行时序与模型失配核验、独立实物液面收益仍有缺口。

论文依据：Ferrari 等，[*Time-Optimal Anti-Sloshing Trajectory Planning for Multiple Liquid-Filled Containers Subject to SCARA Motion*](https://doi.org/10.1109/LRA.2025.3643281)，IEEE RA-L，2026。FP-AS 参考第 III-A 节、式 (19) 的固定路径分支；原文第 III-B 节另有路径与时间联合优化。当前 FP-AS 是固定时长 Scout 适配，没有完整复现原文时间最优算法。
