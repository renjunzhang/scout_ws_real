## 2. C06 的 LMPC 缩写需要区分

C06 的正式摘要写的是 **Lyapunov-based model predictive control**，并与线性扩张状态观测器 LESO 结合；它采用质量–弹簧–阻尼模型、平坦性时间最优轨迹和仿真验证。以上仅依据本次取得的正式摘要，全文细节仍待核对。

2026-09-12 已将 C06 列为[主方案第 6.3 节](../../思路/20260911_面向受扰恢复的防晃规划与在线MPCC协同思路.md)的 E 组优先外部复现计划。重试用户提供的 Wiley 全文入口仍为 HTTP 403，本机全文状态不变。接下来先核对原输入、观测量、目标与 Lyapunov 约束并复现原数值结果，再判断 Scout 非完整运动及执行器适配能否保持核心机制。用户材料中的“平面两个方向加速度输入”暂记为待公式核验信息；必要适配不能自动继承原理论保证。

R19、R20、R21、R22、R28、R29 所属谱系中的 LMPC 是 **Learning Model Predictive Control**。两者使用相同缩写，机制和理论条件不同。文献比较时应写出全称，不把 C06 描述成基于历史任务数据学习终端集合的算法。

可以把另一台电脑的 PDF 和原索引直接复制进用户指定的 `arxiv/` 目录。现有已登记文件位于 `pdf/`，旧文件不必预先改名或自行归类。

合并时按以下顺序核对：

1. **文件哈希**：相同 SHA-256 表示文件完全相同，只补来源关联。
2. **DOI／arXiv ID**：判断是否同一工作；版本号不同、机构库封面不同或排版不同，哈希可能不同。
3. **题名＋作者＋年份**：没有 DOI 时再核对，不能只按文件名或标题近似自动合并。
4. **版本与谱系**：作者稿和期刊稿可以关联；会议前作、期刊扩展和后续研究不因作者相同而删除。
5. **稳定编号与分类**：保持现有 R01–R66，确认后的新工作顺延编号；补充旧库编号映射，继续按原文 4.1–4.9 与基础材料角色分类。
