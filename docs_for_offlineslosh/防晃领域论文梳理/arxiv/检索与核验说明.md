## 1. 检索性质与范围

这是**定向筛选的公开论文集**，不是穷尽检索、系统综述或期刊质量排名。优先选择强相关且有可靠发表记录的论文，同时保留少量与本题直接有关的其他刊会和新预印本。

首批使用 arXiv Atom API 发现与获取作者稿，使用 Crossref 的题名／DOI 查询匹配正式发表信息。追加批次还沿论文参考文献，通过 OpenAlex 和机构库页面定位公开全文，从 UNIMORE、Bologna 机构库及 J-STAGE 获取文件。arXiv 版本号、作者、摘要、更新时间、作者填写的 DOI、journal reference 和 comment 均予以保留。

首批共记录 15 次 arXiv 检索／ID 查询：14 次成功，累计返回 164 条记录，按带版本的 arXiv ID 合并后 157 条候选，选取 30 篇。此数字仅表示该批实际返回结果，不表示各检索式在 arXiv 中的全部命中数。结果按相关性截取，部分词义不相关的 liquid 论文被排除。追加批次另有 5 组 arXiv 检索／ID 查询，以及 Crossref／OpenAlex 和原文参考文献追溯，最终新增 7 篇不同工作。

## 3. 选择与排除规则

- 纳入能直接帮助防晃基线、液体建模／相位验证、受约束重定时、反馈能力或实时 MPC 设计的论文。
- 非液体论文被明确标为可迁移方法，不能算作已有机器人防晃实验。
- 排除液态神经网络、液晶、天体物理等仅因关键词命中的工作；不为增加数量收录缺乏方法联系的论文。
- 同一工作的会议前稿／期刊稿优先选择更完整的一份；例如 FaSTrack 选择 TAC 版本，没有再把 CDC 版本算一篇独立方法。
- 同一谱系但解决不同子问题的论文仍可保留，例如 R04／R05 的状态反馈与输出反馈；不得将其理论或数值结果当作多次机器人复现。
- 3 篇预印本 R03、R21、R30 分别服务于在线急停近邻、鲁棒终端学习和机械等价模型核查，均显式标注正式发表未核实。

## 4. 发表元数据怎么确认

首批 27 篇、追加 7 篇，合计 34 篇的题名、作者及出版 DOI 在 Crossref 中匹配到正式记录；不是仅依据 arXiv 的 “submitted to” 判断刊会。每篇保留 `Rxx_publication_evidence.json`，含查询来源、检索日期和匹配后的记录。

匹配时特别处理以下边界：

- R18 正式题名含 “Funnel-Based”，与 arXiv 题名不同；作者与 arXiv 提供的 DOI 对应，保留不同题名与版本说明。
- R21 的查询返回过 R20 的近似题名，但作者及题名不完全相同，**没有**把 R20 的 DOI 填给 R21。
- R07 卷期和上线日期顺序异常、R18 会议年与论文集年不同、R19／R24 早期发表年与卷期年不同，均保留原始日期并说明。
- R34 的 Crossref 日期为 2015，机构库作者稿封面明确列 TCST 24(2), 609–622 (2016)，因此按 2016 卷期引用，单独说明日期来源。R33 是 RAAD 2024 章节，但 arXiv 上传于 2025。
- R32 的机构库机器版本标签与 PDF 的期刊版式不一致，记录实际来源和可见首页信息，不根据单一标签宣布文件版本完全等同于出版网站副本。
- 出版元数据匹配只能确认这份作者稿所对应的出版工作；尚未逐节比较 arXiv 与出版终稿。本文献库没有把所有作者稿称为出版最终版。

未匹配到正式记录的论文按预印本使用；不能据此断言不存在后续发表。正式引用前仍应精读全文，并视需要复查出版页、更正和版本变化。

## 5. 文件验证与可复查数据

2026-09-11 批次的 37 个文件保存到 `pdf/`。其中 32 个使用带版本号的 `https://arxiv.org/pdf/<id>v<version>` URL；另外 4 个来自机构库，1 个来自 J-STAGE 期刊公开全文。每个文件检查 `%PDF-` 文件头、`pdfinfo` 页数和 `pdftotext` 可读性，筛读首页（机构库封面后继续检查论文首页）确认题名／作者，并计算 SHA-256。

机构库可能在同一作者稿上添加本次下载日期封面，因此再次获取或从另一台电脑复制的同篇论文可能有不同哈希。SHA-256 用于检查文件字节；论文身份去重还须依据 DOI、arXiv ID、题名、作者和版本。

- [manifest.json](metadata/manifest.json)：完整文件路径、版本 URL、下载时间、大小、页数、哈希、分组、阅读状态和方法借鉴备注。
- [selected_arxiv_records.json](metadata/selected_arxiv_records.json)：首批冻结的 30 篇 arXiv 源元数据；追加 2 篇的 arXiv 元数据已写入总清单，原始查询保存在追加批次目录。
- [candidates.json](metadata/candidates.json)：首批未筛选前的候选集合，含无关命中；不要把它当作推荐清单。
- `metadata/followup_20260911/`：追加批次的 arXiv 查询、Crossref／OpenAlex 记录、公开文件地址与成功／失败获取日志。
- [taxonomy_mapping.json](metadata/taxonomy_mapping.json)：当前 66 篇按原文 4.1–4.9 或第 3 章基础材料的定位，保留直接液体方法与通用基础的区别。
- [references.bib](references.bib)：正式出版条目与预印本分开编码，保留 arXiv 版本入口。

可在本目录运行以下只读检查，重新验证文件未缺失或变化：

```bash
python3 - <<'PY'
import hashlib, json
from pathlib import Path
root = Path('.')
papers = json.loads((root / 'metadata/manifest.json').read_text())['papers']
for item in papers:
    data = (root / item['file']).read_bytes()
    assert data.startswith(b'%PDF-'), item['code']
    assert hashlib.sha256(data).hexdigest() == item['sha256'], item['code']
print(f'{len(papers)} PDFs verified')
PY
```

本次阅读深度为摘要、首页及部分结果／参考文献段落筛读，全文文本已在临时工作目录提取但未宣称逐篇精读。清单中的 `human_read=false` 表示本次未取得用户已读确认，不是在断言用户从未读过这些论文。
