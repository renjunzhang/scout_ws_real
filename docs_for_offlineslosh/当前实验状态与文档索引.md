本阶段固定 30 Hz、0.90/0.08 mm 运输/停车限值、5 s 停车窗口，复用原下层控制。实现、所有成功与失败及最终闭环记录见[限晃时长搜索实现与验证](./实现与修复/20260918_限晃时长搜索实现与验证.md)。此前两次基线超时保留在[基础链路复核](./实现与修复/20260918_限晃时长搜索基础链路复核与停车评价.md)；不能再将其当作当前仍无新计划。

此前[旧种子单次复核与曲线](./仿真实验分析/01_对比结果/20260918_B0与Full单次复核.md)：B0/Full 各一次均无控制异常，到点 31.527/41.530 s，模型运输峰值 0.969/0.685 mm。Full 峰值低 29.3%，耗时长 31.7%；停车窗峰值为约 0/0.0547 mm，Full 仍使用旧种子。这组单次结果不并入下列历史筛选均值。

## 4. 仍需收敛的事项

1. **运行稳定性**：定位完整尝试中仍出现的状态对齐拒绝与预算停车，以全量结果核对修复效果，保留每次失败。
2. **上下层一致性与重复性**：纳入末端包络后单次达标，仍需后续有限同条件复核；时间过程及预测/实际响应仍非完全一致，不宣称已稳定解决。
3. **比较条件**：实际耗时不同，`planned_mpcc` 与当前 Full 的非液体权重也未完全对齐；单独归因 slosh 前须对齐对照条件。
4. **评价与部署**：odom 模型高度不等于独立液面真值；实物、RGB 和全场景实时性尚未验收。先收敛无障碍版本，再评估避障接入。

新液面阈值、归一化约束、固定清单搜索及新 Full 单次闭环均已完成；随后按用户要求完成 fixed_time 单次负例及上层末端包络单次通过，结果见最新验证记录。此前确认的实物部署记录对应 `7d17f6c`（`diag/lt-dwa-collision-tracking` 路线），不能用其运行正常替代当前 feat 的实物验收。

### 2.1 底盘与延迟

- 底盘能连续执行平滑速度命令，先前的“一卡一卡”不能简单归因于硬件速度不连续。
- 实车存在命令起效延迟和渐进建立过程，尤其角速度建立较慢；单一纯延迟不能完整描述执行器。
- 持续有效线加速度能力约为 `3.0 m/s²`，不是当前低速 C02 试验的主要限制。
- 当前 legacy `fixed_closed_loop` 使用历史命令作理想前推，没有显式区分 command 与 actual。

### 2026-09-16 时的机制判断

当前证据将问题分为三个层次：

1. **运行时与状态结构：** I0、command/actual 分离和 L22 关闭已经用于有效 V2 配对，运行时故障计数为零。因此不能继续把这次负结果简单归因于仍在使用 L22 或故障性硬停车。
2. **连续性修改已进入实物验证：** full-da 软惩罚 smoke 未达当次改善门，后续硬 jerk 约束已实现并在 C03 三个硬约束组中通过核验。该约束限制预测网格的命令加速度变化，不等于真实杯体 jerk 已受控；完整时域 `Delta alpha_cmd` 仍未加入。
3. **预测与真实液体：** 同包幅相、激励和 NOKOV 分析已有后续证据，但结构、驱动及测量链各自的作用仍需核实。C03 内部高度尚无一致收益；命令平滑与软件/运行时通过均不能单独证明 RGB 改善。

6 月仿真有正向模型证据：六组各 9 次，B0/Bslosh 的模型高度 P95 组均值为 `0.594/0.496 mm`。但评价量是 model proxy，不能据此认定当前执行器、I0 与真实液体之间的相位关系已准确。参见 [仿真结果](../docs/实物实验注意事项/对比试验/仿真对比试验/20260627_SPMPC内部消融N9复跑_1mm结果.md) 与 [评价口径](../src/scout_apps/control/spmpc_experiments/config/benchmark/external_slosh_observer_policy.yaml)。
