# 曲线载液运输：10天最终推进思路

**当日最小验证已收尾：** [RTI质量退出与旧稳定基线回归](../实现与修复/20260919_RTI质量退出与旧稳定基线回归.md)中模型通过，但更正配置后的Gazebo仍失败。用户确认新增实际jerk约束不属必须物理要求，已暂缓；按本十天主线复用旧稳定Full／FP-AS共同档，仅补齐同版本B0的S记录缺口，不继续扩展jerk修复或重复扫参。当前无新增实物收益证据。

更新：2026-09-19。本版取代之前包含直线/ZVD扩展的推进安排。已同步FP-AS 28秒超时及[约40秒共同档单次结果](../实现与修复/20260919_S路径约40秒共同档最小验证.md)：Full／FP-AS统一完成41.021／40.432 s，差1.44%；FP-AS运输模型指标更低，Full停车模型残振更低。正式重复、半圆与实物尚待执行；最小阶段见[执行清单](20260919_外部防晃基线与今日最小仿真验证方案.md)。

**目标：在10天内完成关键对比、必要实物验证和完整论文稿。实验范围固定为S形连续转弯与水平半圆；S路线优先，半圆保留为第二仿真场景。**

## 1. 固定研究范围与论文主线

论文主线：

> 面向曲线与连续转弯载液运输，上层安排全程路径和速度，下层MPCC根据当前状态调整运动；通过外部方法比较、同计划消融和独立实物测量，评价整体性能及下层防晃的增量。

- **主场景：现有S路线。** 优先解决公平比较，随后完成主实物实验。
- **第二场景：水平半圆/U形转弯。** 复用同一规划、控制和评价流程，验证另一类转弯任务；各方法使用共同起终点、终点朝向、可行区域及必要途经顺序，保证完成同一个转弯任务。
- 半圆对应Scout可执行的平面运输，不照搬Ferrari机械臂的空间半圆及独立托盘旋转。
- 不新增直线/ZVD实验、避障、曲线输入整形、在线全程重规划、新模型或额外算法。已有直线及失败记录保留，结论限定为实际验证的任务。
- 两条路线的配置在正式评价前固定，不依据哪条路线有利于Full来删换场景。

**当前待验证的主假说：相近实际完成时间下，Full能否在曲线任务上取得更小的运输晃动或停车残振。** 已有下层消融是正向证据，但外部性能优势尚未成立。

## 2. 第一优先级：S路线FP-AS与Full的相近耗时对比

### 已知起点

- Full已有S路线实际到点时间均值约28.282秒；FP-AS现有一次约40.399秒。
- FP-AS固定28秒已尝试一次，600.033秒离线超时，未生成合格计划、未进入Gazebo；[日志及停止记录](../实现与修复/20260919_FP_AS_S路径28秒对比尝试.md)保留。此后只新增一个Full较慢候选、一次Gazebo，复用FP-AS得到约40秒共同档，不重试28秒。
- FP-AS在当前40秒名义规划下的运输模型指标更低，Full到点更快。不能据此断言同耗时下谁更优。
- 上述液面全部来自odom驱动模型；不是独立实测液面。
- 当前FP-AS是Ferrari固定路径分支的Scout固定时长适配，不是原文时间最优算法的完整复现。

### 最小执行顺序

1. 约28秒首选档已按原运动、液体、起终和停车要求重新优化时间律，但达到600秒上限仍未通过；本步骤按失败记录收尾，不无依据重跑。
2. 先从旧日志核对统一的任务完成口径及版本可复用性。后续新计划须通过离线核验与执行检查，才进入闭环预试，核对实际时间、参考时钟、跟踪误差及停车过程。禁止直接压缩播放原40秒轨迹。
3. 唯一后备档已执行：Full名义44秒、现有进度奖励设为0，重新规划并通过资格及单次执行；保留进度模式、共同物理限制和液体代价。实际完成41.021秒，与FP-AS 40.432秒满足5%规则；两组起步与运动阶段时长不同，结果仅支持该口径的单次比较。
4. 共同档按可执行性和预先规定的耗时规则选择，不按液面结果选择。约28秒档失败和原40秒结果均保留。两档之外不展开时间扫描。
5. 首选档尝试已有结果，第2天内确定可用共同档或明确剩余缺口。单次离线求解上限600秒，超时不自动重试；有明确实现/配置错误才限时修复受影响案例。求解失败、超时或跟踪失败只说明当前实现未找到/执行出合格方案，不证明该方法理论上做不到。

### 耗时和公平条件

- **现有28.3秒、40.4秒是到点时间，正式比较必须同时核对停车。** 优先采用“进入统一终点容差并满足已有车辆停稳判据”的时刻作为任务完成时刻；到点时刻另报。液体完全静止不作为新的任务完成条件。
- 先从现有日志重算该口径；约28秒仅是初始参考，不把旧到点时间直接当成新的停稳时间。
- 预试阶段固定匹配规则：本轮采用两组平均实际完成时间差不超过Full平均时间的5%，同时报告每次耗时和真实差值。5%是本轮预设的实用容差，不是通用论文标准。
- 正式重复超出匹配范围时，保留数据，按实际时间—晃动折中解释，不事后放宽容差或只挑匹配的运行。
- 两组共用容器/液量、初始液体状态、起终条件、可行区域、运动限制、液体/停车要求及45秒任务期限。使用各方法合理的参考执行方式：FP-AS按时间，Full按其既定进度模式。
- 主对比允许几何不同，报告路径与长度；结果代表整体方案的差异，不能全部归于下层MPCC。
- 水平半圆单独确定自己的共同耗时，不能直接照搬S路线的28秒目标。沿用同一匹配规则与有限预试预算。

## 3. 最终实验安排

| 层级/任务 | 比较方法 | 预算与处理 | 回答的问题 |
|---|---|---|---|
| S路线仿真，优先 | B0、FP-AS、Full | 每组3次可比较记录；先审查旧记录，缺多少补多少 | 主任务整体效果及外部方法差异 |
| 水平半圆仿真，第二场景 | B0、FP-AS、Full | 每组3次；复用同一实现与评价流程 | 优势或代价能否延续到另一类曲线 |
| 同计划下层消融 | cost0、Full | 复用已有S路线两组各3次成对条件数据，不扩展到全部场景 | 下层液体代价的作用 |
| S路线实物，主实物 | B0、FP-AS、Full | 各3次正式尝试，共9次 | 独立实测液面、实际耗时、停车效果 |
| 水平半圆实物，可选 | B0、FP-AS、Full | 仅在主任务与写作均按期完成且时间足够时，同条件各3次 | 补充实物场景；不挤占S路线9次主预算 |

两条仿真路线的主比较共18条记录目标，包含可复用记录；现有同计划消融另列，不强制重新做一整套消融。每组3次是小样本重复预算，不是显著性或鲁棒性的保证。

**复用原则：**

- 核对代码版本、配置、场景、初态、模型、时间戳、原始日志和统计窗口。旧记录具备可比性且可重算才进入对应比较。
- 共享执行/估计/统计组件统一版本，各算法保留合理的参数和时间/进度模式。当前旧B0/Full与新FP-AS存在版本差异，不能直接拼成同版本正式对照。
- 已有消融若只能证明旧冻结版本下的效果，可作为独立标明版本的消融保留；不能与调整后的Full结果混算。
- 现有数据属于开发验证，不能仅更改formal标签就称为新正式实验。
- 全部正式尝试登记成功、失败和超限；液面统计注明有效记录数，失败运行不静默删除，不通过不断重跑凑出3次成功。
- 确定性仿真重复若完全一致，只说明可重复执行，不能据此宣称抗扰动或参数鲁棒性。

## 4. 实物测量与写作从第1天并行

### 实物预试：第2天形成可执行、可测量的判断

- 用当前完整两层方案检查起步、转弯、到点、停车、控制节拍及命令出口，不能默认加入全局层就解决了上次失败。
- 液面测量确认像素到毫米标定、静水噪声、可见方向和与机器人日志的同步；统一各方法的提取流程。
- 同步记录名义计划、最终命令、odom/可用IMU、独立液面视频。当前控制可以继续使用已有状态估计，不要求把视频新接入实时控制。
- 若只有单视角，指标按实际可见液面定义，不能称已测得整个杯沿最大高度。
- 对实车与仿真差异，先定位执行响应还是液体预测偏差，只修有数据依据的问题。旧记录约5 Hz车体振动的影响需要实测对齐判断，不预先认定因果。
- 若测量无法分辨方法差异，就不能支持“实物更稳”；模型结果只能单独报告。

### 正式实物

通过预试后固定实物版本、参数和数据处理。使用相同初始液面稳定规则，B0/FP-AS/Full轮换运行，三组均保留其上层规划与对应执行机制。仿真中匹配的耗时要在实车预试重新核对，不能假定自动成立。

不为实物另加cost0完整矩阵。下层消融留在仿真，实物优先证明整套方法与外部基线的效果。

### 同步写作

第1天建立论文骨架并写问题定义；实验期间完成方法、FP-AS适配说明、平台、测量和评价设置；每天处理当天数据，结果段随图表更新。

Ferrari已经同时研究固定路径时间律与路径—时间联合优化。本文应如实说明Scout运动约束、全程计划与在线执行接口及实验证实的增量。FP-AS比较只覆盖所选适配分支；“有上下两层”本身不构成已经证明协同优势的证据。

## 6. 结果怎样决定论文表述

| 观察结果 | 可以支持的表述与下一步 |
|---|---|
| 相近实际完成时间下，Full的运输指标改善，停车也合格 | 支持所测曲线任务下的整体性能优势；用实物检验是否延续 |
| 运输指标接近，但停车残振或完成时间存在差异 | 如实表述具体指标上的优势/代价；保留全部指标，不能事后更换唯一胜负标准 |
| Full在外部对照下仍更差 | 承认该工作点未证实外部优势，收窄贡献与投稿预期，继续整理已获证据而不新增模块 |
| FP-AS未找到合格解或实际未完成 | 报告实现、求解预算与失败位置；不证明理论不可行，也不替代合格对手下的防晃比较 |
| 仿真改善，实物不改善 | 分析执行/测量/模型差异；不能将模型收益写成真实收益 |
| 整体实物效果可辨，下层小增量不可辨 | 整体结论来自实物，下层作用限定为现有仿真消融 |

第2天判断共同工作点与测量链是否可用；第4天判断主实物能否进入正式重复。发现明确错误可限时修复并重做受影响数据，不增加方法或场景来寻找获胜结果。D8之后只处理必要的数据、图表和文字问题。
