# 后续主线与推进节奏

2026-09-19，后续研究思路。

**现有框架稳定后，立即开展实物验证；取得正向证据后，再推进防晃接续与避障。**

近期先验证现有两层方法能否在实车上平稳、高效地完成运输。后续研究的问题是：机器人因执行偏差或障碍改变原计划后，如何结合当前车辆、执行器和液体状态，调整剩余路径与速度，让整趟运输仍保持防晃收益？

目前已完成执行链修复后的六次稳定性验证，以及防晃优先方案的三次新 Full 复核；三项模型指标均优于冻结 B0，但 Full 使用重新优化的路径。当前主要缺口是同路径公平对照和真实液面收益，不能把现有降幅全部归因于防晃控制。最新事实见[当前实验状态](../当前实验状态与文档索引.md)。

| 阶段 | 主要工作 | 推进依据 |
| --- | --- | --- |
| 1. 稳定框架并明确对照 | 固定批次的启动/对齐/预算修复及重复验证已完成；先定义同路径、参数对齐的对照，再检查关键仿真实物差异 | 运行与评价可信，能够区分路径改变与防晃控制的贡献 |
| 2. 立即实物验证 | 先做低速功能检查，再做 B0/Full 小规模配对；记录 IMU/odom，并用 RGB 核验真实液面收益 | 运行稳定，少量重复中出现一致的防晃与效率收益 |
| 3. 防晃接续 | 在减速或短暂停等后，从当前状态调整剩余运动 | 相比现有恢复方式，新机制改善整趟运输的晃动与耗时 |
| 4. 单障碍扩展 | 先验证静态障碍通行，再引入按脚本出现的单障碍，研究减速、等待、绕行及恢复 | 相同碰撞约束下，液体感知决策带来可重复收益 |
| 5. 完整实验 | 补齐相关防晃对手、机制开关对照、重复 RGB 实物试验和失败分析 | 实验能够解释收益来源，并支持论文贡献 |

“正向”应体现在相近耗时下真实晃动降低，或相同液面限制下运输更快，并兼顾停车残振。若效果不明确或变差，先沿命令、运动和液体响应定位原因，修正现有框架；后续接续与避障研究暂缓。

实物正向后，接续研究可从“弯前停一下，再继续走”开始，比较新增机制开关前后的恢复过程。已有离线剩余计划检查可帮助探索；在线实现再考虑局部修正或低频重规划。避障时允许更新路线和时间安排，碰撞安全优先。

**仿真与实物的差异从第一阶段就开始检查：**

- 仿真对象单独设置执行器参数，覆盖实测的低速响应变化；上、下层预测模型保持一致。
- 增加与实物相同的 IMU 处理链，检查滤波、时间戳，以及 odom 与真实车体运动的差异。
- 依据实测证据检查车体振动、液体参数和初始残振的影响；被控对象与控制器估计分开。
- 按真实节拍检查整个控制周期、最终发布命令和停车后响应。

优先用已有实物包对照三条曲线：原计划预测、实际命令重放、IMU 实测激励，选择最关键的差异先检查。达到稳定条件后立即转入实物，更全面的失配测试随实物反馈补充。

**近期先完成三件事：**

1. 保留当前 T=40 s、RMS 尺度归一化、1.80 m 上层包络的三次 Full 结果及全部历史尝试；时间优化默认关闭，不继续为扩大差距扫参。
2. 先明确同路径对照：复用蓝色计划及速度、对齐非液体代价，只切换液体项可检查下层贡献；双方固定原 S 路径则用于检查该路径下的防晃能力。当前两类均未完成，现有 planned_mpcc 配置也不能直接当作只差液体项的对照。
3. 核对关键仿真实物差异，对齐部署参数、录包评价与公平比较条件，准备稳定后的实物对照；本次更新未启动新实验。

论文希望回答：在相近运输效率下能否更平稳，或在相同液面限制下能否更快；新增机制关闭后，收益是否减少。具体创新点根据验证结果与相关工作对照进一步明确。
