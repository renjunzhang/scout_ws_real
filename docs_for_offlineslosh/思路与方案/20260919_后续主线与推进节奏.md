# 后续主线与推进节奏

更新：2026-09-19，按 `2d2697b7` 实验快照完成阶段收尾。详细交接见[阶段收尾与下一步选择](../最新结构与方法主线/03_阶段收尾与下一步选择.md)。

**现有防晃优先与可选时间优化的代码、最小仿真验证已完成。下一步选择论文整理或小规模实物验证；实物正向后，再推进防晃接续与避障。** 本文描述可选推进方向，不自动启动新实验。

近期已得到三类证据：原始路线 B0/Full 的整套比较、同计划下层液体代价两组各三次消融、38 s 计划单次实际缩时。后两类分别显示三项晃动指标均值改善、以及防晃门槛内 14.24% 的实际时间收益。原始 B0/Full 路径不同，贡献归因与样本量按[论文主线](../最新结构与方法主线/02_论文主线与现有证据.md)区分。

按用户确认，论文报告均值和波动范围，不为峰值范围重叠或所有样本未完全分离继续补跑。原计划资格、液面限制和执行检查保持不变。固定原始 S 几何、独立上层液体目标及组合消融，仅在对应论文主张需要时再做。

## 阶段状态

| 阶段 | 当前状态及工作 | 推进依据 |
| --- | --- | --- |
| 1. 现有框架与最小仿真 | 已收尾：执行链修复、默认 Full、下层消融、时间开关及回退均有记录 | 保留当前基线，不重复实现或自动扫参 |
| 2. 论文整理与实物准备 | 可直接整理现有图表和方法；选择实物时先核对部署及观测链，再安排低速检查和小规模 RGB 比较 | 论文叙述与已有证据一致，实物使用明确配置和统一口径 |
| 3. 防晃接续 | 实物正向后，研究减速或短暂停等后的剩余运动调整 | 相比现有恢复方式，新增机制改善整趟运输的晃动与耗时 |
| 4. 单障碍扩展 | 接续机制具备基础后，再研究减速、等待、绕行及恢复 | 相同碰撞约束下比较液体感知决策 |
| 5. 按论文补充验证 | 按最终主张选择相关方法、机制对照和必要实物重复 | 足以解释主张，不默认扩大成完整消融矩阵 |

“实物正向”可以是相近耗时下真实晃动降低，也可以是相同液面限制下运输更快，并兼顾停车残振。若结果不明确，先用已有记录沿计划、命令、实际运动和液面响应定位问题，再决定最小改动。

## 实物前优先核对什么

当前仿真用 odom 驱动液体模型，真实液面收益尚未验证。实车既有部署记录来自 `diag/lt-dwa-collision-tracking`，不能视为 feat 两层框架已部署或验收。

优先利用已有实物包，对照原计划预测、实际命令重放、IMU 实测激励，选择最关键的差异：

- 执行器的实际延迟、低速响应与模型是否相符。
- IMU/odom 处理、滤波和时间戳是否支持当前状态构造，RGB 能否提供独立液面评价。
- 命令发布节拍、停车后响应和有实测依据的振动/初始残振影响。

达到运行条件后做小规模实物比较；更全面的失配测试随实物反馈补充，不为穷举差异先扩展仿真。

## 暂时保留什么，下一步决定什么

保留默认 T=40 s、RMS 归一化尺度和 1.80 m 上层减速包络；38 s 计划作为可选缩时结果，时间开关默认关闭。全部历史失败和原始数据继续保留。

下一步只需决定优先整理论文还是准备实物，以及论文是否需要固定原 S 路径或独立上层归因。具体实验数量和配置在任务选定后再明确。新机制可从“弯前停一下，再继续走”开始，使用已有离线剩余计划诊断作为入口；在线反馈和避障仍属于后续阶段。
