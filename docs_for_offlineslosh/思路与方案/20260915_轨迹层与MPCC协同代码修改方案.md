### 2.2 首版上层问题合同

以下是区域内几何与时序联合规划的候选定义；先经 P1 验证下层自主选路，再在 P2 实现上层问题。固定几何是对照模式，以下数值和参数化尚未冻结。

| 项目 | 首版建议 |
|---|---|
| 已知量 | 导航引导曲线及路线进度定义、有序可行区域、完整初态、待执行命令、运动/液体参数、目标位姿、共同到达期限、停车窗口 |
| 动力学 | 用当前共源核传播 command/actual、FIFO、加速度记忆和液体状态；几何与 Scout 非完整运动相容 |
| 决策 | 包含转向的全程命令及由其得到的区域内实际轨迹、速度和路线进度；参数化必须能同时改变几何与时序 |
| 目标 | 曲率幅值/变化、全程液体响应、停车残余和运动消耗，保留弱路线正则；普通缓弯计划共享非液体目标，仅关闭明确列出的液体项 |
| 约束 | 完整动力学、真实初态、速度/角速度/加速度/jerk、区域内车体占用与通行顺序、真实终点、共同期限；引导曲线不作逐点贴合等式 |
| 终点 | 几何到达、车体停稳、命令/FIFO/加速度记忆释放和液体稳定分别检查；不能只以 `s` 到终点或液体位移过零作为完成 |
| 评价 | 实际曲率、转向变化、路径长度、全程晃动、耗时、停车残余与所有失败；跟踪误差只作诊断，独立对象/液面数据另列 |

用 `z` 表示完整增广状态、`c` 表示可执行控制参数，首版按固定执行网格建立 `z[k+1] = F(z[k], c[k], dt)`。沿用 30 Hz 时，改变名义运输时长应通过规划步数或外层候选处理，不能随意缩放 `dt` 而保留原 FIFO 拍数，导致物理延迟同时改变。离线优化的网格、执行网格和积分子步分别记录。

候选目标可写成 `w_K * J_geometry + w_H * J_full_liquid + w_R * J_stop_residual + w_U * J_motion + w_C * J_route`。`J_geometry` 表达实际路径曲率偏好；液体两项覆盖完整响应及停车残余；运动项采用明确归一化的命令/变化量或路径长度；`J_route` 为弱横向正则，进度关联另外处理。各项形式、归一化、权重和液体边界开关需在相应阶段比较前写入配置。加权目标是否产生预期缓弯偏好须由动作对照确认，不能仅凭命名宣称优先级。该目标是我们的适配，不冒称 R32 原式或严格时间最优。

先找得到可执行、按时完成的区域内普通缓弯计划，再评估防晃增量。可比较完整命令序列与几何节点加时间律；固定路径上的速度节点单独用于对照。不得通过理想平面加速度、瞬时切换车速、重置状态或事后限幅生成看似可行的计划。R32 的进度 jerk 与当前命令加速度变化上限不是同一个量。

### 2.3 下层目标与剩余任务的责任

- **几何决策**：利用已有位姿/actual 运动状态及 `a_cmd, alpha_cmd, v_s` 控制，在区域内优化实际轨迹。无需先增加一个独立“选路器”，但现有状态自由度必须配上区域约束、合适目标和行为验证。
- **参考**：原导航曲线负责路线/进度关联，上层名义轨迹供热启动、速度安排或可关闭的弱偏好；不施加强制追踪中间名义点的要求。上层液体序列仅用于名义诊断。
- **目标**：contour 作为弱横向正则，lag 维护实际位置与进度对应；曲率与液体目标直接参与动作选择。速度/anti-creep 使用一致有效参考，进度与共同期限共同核对；区域边界和运动上限单独约束。
- **进度连续性**：当前 `v_s` 是控制，`w_du_vs` 只对首阶段前次控制做平滑；R08 的进度加速度方案需单独评估。若增加进度记忆/变化率约束或改变状态布局，应作为独立行为改动，不能在接参考时隐式引入。
- **剩余任务**：首阶段只评价预测末端接候选后缀的结果；只有其进入目标、约束或明确的候选选择后，才可能影响动作。单个巡航参考、progress 奖励和当前真实终点停车模块不能替代这部分。

### 2.4 曲率目标与几何自由度的最小定义

正常移动且近似无侧滑时，用 `kappa = omega_actual / v_actual` 描述实际路径曲率；`v_s` 是导航进度速度，不能替代车速。`J_geometry` 可研究按实际行驶弧长累计的归一化曲率平方及曲率变化，具体形式在 P1 选择。以时间累计时须解释其速度依赖，不能把更慢行驶自动解释成几何更缓。

低速/停车/原地转向阶段不直接计算 `omega/v`。在 P0–P1 明确正常移动适用域、可微表达、角速度/角加速度代价与约束、阶段转换；不得通过低速正则化让急转被记作零曲率，或让优化器靠进入未计分阶段逃避缓弯要求。对应事件及角运动单列，具体阈值与允许策略尚未冻结。曲率峰值/弧长加权 RMS、变化和液体指标分别报告。

首版区域采用显式给定的静态区域及通行顺序，约束覆盖车体和节点间运动；区域来自任务配置，不用现有 `corridor_width` 冒充。模型运动权限、区域、真实终点及共同耗时/运动消耗要求构成选路边界，不靠强 contour 防止无意义绕行。可行范围和曲率权重应对 Full/Smooth 一致。

## 4. 两层接口与参考语义

建议首版计划由 JSON 元数据和逐样本表组成，字段至少包含：

- 导航引导曲线与名义轨迹各自的身份、坐标系、模型/参数/计划版本、进度关联、任务时间起点。
- 名义 `t,s,x,y,yaw`、实际行驶弧长及曲率适用状态，预测实际 `v,omega`、名义发布命令及初始待执行历史；路线进度、行驶距离与命令/actual 分列。
- 名义液体预测、速度/加速度/jerk 等运动限制，到达要求和固定停车评价窗口。
- 区域边界、通行顺序与车体余量的关联，几何自由度/曲率目标开关，计划适用范围及可行性结果。
- 规划目标/归一化、参考模式、任务与停车事件定义、移动/停等/停车阶段身份；固定时序和在线进度对照使用同一计划身份。

完整 rollout 状态和配置作为复现产物保存。计划中的液体序列只作参考和机制诊断，在线初态仍取当前估计与真实命令历史。

**建议用原导航曲线的弧长定义唯一 `s,v_s` 路线进度。** 上层名义几何与速度按该进度关联，下层在区域内重新选择几何与时序，同时记录剩余期限。实际车速不必等于路线进度速度；实际行驶距离用于曲率统计，不增加第二套独立控制进度。名义几何作为参考不会重置进度坐标、隐式收紧活动区域或强迫回到原曲线。

阶段参考应随预测进度变化。首版可围绕热启动进度构造局部速度剖面表达式，作为阶段参数传入，并保留对优化变量 `s` 的依赖；不能把整窗都取成当前点速度。插值、进度映射有效域及越区间后的重新装配须测试。有效参考同时用于速度、低速惩罚和诊断。现有曲率限速取自参考曲线，在允许改道后需区分引导曲率、名义曲率和实际曲率；实际角速度/加速度约束仍保留，避免参考曲率限速抵消缓弯路线的速度余量，也避免重复组合终点减速。

弧长查询只负责移动段。停等时同一个 `s` 对应多个时间，液体仍继续演化，因此计划还要保存阶段身份和阶段内时间，不能用任意一次相同进度样本恢复液体状态。任务时钟在跨周期查询时持续推进，不因落后或重新装配而重置到名义时刻。

参考模式与几何配置分开：无上层的巡航参考也可使用 P1 的自主几何配置；关闭轨迹层不自动恢复原跟踪目标。回归旧 feat 时需同时选择原几何/目标配置。

| 模式 | 查询及控制语义 | 用途 |
|---|---|---|
| 原巡航参考 | 当前巡航值及相应几何配置下的限速/停车处理 | 为 P1 无上层方法供速；与原几何/目标配置组合时做 feat 回归 |
| 固定时序参考 | 按共同任务起点后的实际经过时间读取完整参考，不随误差平移/拉伸时钟 | 同计划时序对照；不称 C06 直接复现 |
| 在线进度参考 | 根据当前/预测唯一进度关联名义运动，并重新预测实际运动与液体 | 两层协同候选；保留期限和阶段处理 |

固定时序与在线进度的参考/进度项差异属于被比较机制，应逐项记录；其余模型、预测时域、信息来源、液体设置、运动边界及停车窗口保持一致。固定时序版不另加一套暗中追赶或重置时钟的恢复逻辑。

原有巡航参考模式（含已有曲率限速与停车处理）继续显式保留作对照；请求轨迹模式后，计划缺失或身份不符应明确报错，不能悄悄退回原模式并仍记为轨迹层运行。

### 4.1 候选剩余段评价接口

首版为纯数值接口，先不接入命令发布或 ROS 循环。建议输入/输出合同如下：

| 输入或输出 | 必需内容 |
|---|---|
| 预测末端 | solver 返回的完整状态、预测有效时刻、来源周期、模型/参数身份；包括位姿、actual/command、两通道 FIFO、加速度记忆、液体位移/速度、进度 |
| 候选后缀 | 同一计划的阶段/样本身份、接续规则、名义后续命令；任何过渡/跟踪控制都显式记录 |
| 任务合同 | 共同起点事件和到达期限、路径/区域、运动/液体边界、停车策略与固定评价窗口 |
| 报告 | 候选是否通过、违反的边界和位置、预计到达/停稳/稳定时刻、实际曲率及低速角运动、液体峰值/残余、检查耗时、模型与候选身份 |
| 状态语义 | `CANDIDATE_PASS`、`CANDIDATE_FAIL`、`NOT_EVALUATED`；失败不提升为全局无解，未算完不能算通过 |

从预测末端直接重放候选命令，保留衔接误差并核验运动、几何、FIFO 与 jerk；不能把位姿投影到计划、重置液体或清零待执行命令。若直接后缀无法接上，可另外生成可执行的过渡候选，仍从同一完整状态验证。

候选通过仅说明该模型下存在这一条经检查的后续运动；节点检查需另做细化传播核验，实物与鲁棒效果仍需独立证据。所有候选失败只说明本次搜索没有找到后续。首版报告保持诊断身份；检查预算不足返回未评价，不追加隐藏的速度改写。

如果后续要加入 `J_tail` 或终端可接续约束，需另外设计其关于优化变量的表达、导数/近似及有效域，接入共源代价/约束生成和 solver 核验，并验证最优动作确实变化。离线后缀检查器不能未经开销与执行契约验证直接塞进 30 Hz 发布链。

## 5. 分阶段实施与验收

### P0：确认开发基础与最小问题

先明确自主选路的静态区域、目标位姿、曲率/低速定义、路线进度与任务时钟、耗时和停车事件，形成第 2 节配置草案。核对生成 solver 与源码身份，复用 V1/V2–V4 的检查。针对微负实际速度分别复现噪声、偏置与真实回退，设计实际状态允许域和命令约束；保留真实 x0，不靠裁零掩盖不可行。

低速执行器与静止阈值用现有数据核对；统一模型重放 Smooth-only，按同有效时刻比较实际/预测容器激励。杯沿余量、液量/安装与恢复预算单独校准。离线规划设计可先推进，ROS1 构建、配置/无速度发布检查和执行链验收须在新实车前完成。

输出：可复现的小问题、基本运动/停车行为及已知限制。ROS1 集成前先做不依赖 ROS 的数值检查；不把 ROS2 环境当作 ROS1 构建环境。

### P1：先验证 MPCC 能自主选择缓弯路径

先在无上层、明确区域的单弯与连续弯数值问题中修改现有 MPCC：接入区域/车体约束，弱化 contour，保留 lag 的进度关联，单独加入可关闭的实际曲率偏好。同步符号参数、生成 C、C++ 索引及诊断，重新生成 solver；新增目标经共源分项与 solver 总价核验。复用实际运动与液体传播，不通过求解后的几何平滑或命令改写制造轨迹变化。

按第 2.4 节处理曲率正常移动域、低速角运动和区域节点间占用。原巡航回归模式保持显式；区域模式与曲率目标分别有开关，区域启用后不设置中间参考点必须回线的终端要求。执行器、液体权重及停车策略不与首个几何变更一起调整。

同初态/命令历史/区域下，依次比较跟踪正则变化、同一弱正则下曲率偏好开/关；Full/Smooth 共享每组非液体条件。记录速度，必要时增加同速度条件的几何诊断以分离改速作用；同时检查可行初值和约束接近情况。若只改变曲率权重却未改变实际路径，保留该结果并定位目标、可行空间或求解因素，不直接扩大实车扫参。

输出：可以在允许区域中主动改变转弯半径、位置及转向时机的证据；比较实际曲率、速度、液体响应、任务完成与代价变化。更大偏离本身不算通过。曲率下降与液体目标额外降低晃动分开验收，模型内选路证据不等同实物收益。

### P2：上层联合安排全程几何与速度

实现完整 `trajectory_rollout.py` 和第 2.2 节优化，复用 P1 已定义的区域、曲率和路线进度语义。选择能改变几何及时序的参数化，保留固定几何的速度优化作对照；调用共源执行链传播实际轨迹、待执行历史及液体，覆盖完整制动与停车尾段。

在相同区域、初态、运动限制和运输时间要求下比较普通缓弯与模型防晃计划，几何偏好对两者相同。名义规划可使用完整未来动作，不得使用未知未来扰动。输出计划文件、曲率/速度/液体曲线及完整可行性和时间报告；未完成任务的低 RMS 不算收益。

验收包含共源传播一致性、积分细化边界核验、目标位姿与停车尾段，以及同任务下固定几何/自主几何和普通/防晃的分因素对照。高精度重放只验证数值可行性，独立效果留给 P5。

### P3：接入全时域参考并保留自主几何

实现 `TrajectoryReference`、`HorizonReferenceBuilder`，扩展 `SolverInput`；保存原导航曲线、名义轨迹、区域和唯一进度映射，在 acados 包装层装配全窗口参考。同步参数、生成物、索引与消息版本，重新生成 solver。

先接普通缓弯计划，再接防晃计划；使用已验收的 P1 几何配置，接参考时不同时改区域、曲率/液体权重和停车策略。核对名义路径作为热启动/弱偏好与速度安排的角色，接入后仍能在同一区域内自主改变轨迹。按第 4 节分别实现固定时序和在线进度模式，改变实际动作后重新传播液体；全时域进度平滑另作独立变更。

输出：前方安排进入全预测窗口且不会强制回线的证据；名义命令、返回预测与最终发布命令逐拍可追溯。关闭轨迹层回到 P1 同配置无上层行为；同时关闭新几何模式时回到本轮前的 feat 基线。

### P4：从预测末端检查候选剩余运动

实现第 4.1 节离线评价，复用 P2 rollout，输入来自 P3 的真实 solver 预测末端。尤其保留在线改道后的位姿、液体相位及命令/FIFO，不投影回名义轨迹。候选后缀无法直接接上时，过渡候选须从这个状态生成并检查。

构造位置/速度相近但液体速度方向或 FIFO 不同的候选，核对剩余晃动、曲率、耗时与可行性判断；加入改道衔接失败、期限不足、低速停等、无候选及计算未完成等情况。输出可追溯的末端、候选和检查报告。全部检查只诊断时，不报告控制收益。

若证据支持，再单独定义进入在线目标/约束的版本：明确近似误差、代码生成、开销和失败语义，做同初态有/无该项的动作对照。终端代价需通过 solver 总价核验；接续约束需验证与真正可执行后缀的关系。未经这一步，不声称解决在线剩余可行性问题。

### P5：独立闭环与实物

主比较按框架第 5.1 节定义为 **原始路径＋普通 MPCC vs 完整协同方法**。主基线不经过新增几何/防晃优化或全程重定时，仅保留共同的必要插值/投影及普通 MPCC 的正常决策能力。液体代价、液面约束、液体恢复和液体后缀指导关闭；同一路线、区域、车体/执行器模型、求解配置、运动限制与耗时要求在两组中保持一致。新增曲率偏好、跟踪正则及上层处理列为整套方法的差异，不把组合收益全部归给液体项。

主基线的液体监视器只用于评价。需检查当前 `TaskStopManager` 的液体依赖：关闭 solver 液体项后若仍依液体残余调整命令、延迟停车完成或进入恢复，该 profile 不能称为无液体优化。复用共同的车体制动/停稳判定与固定停车观察窗口，将液体稳定评价和控制决策分开；具体模式接线须在实车前核验。

先确认 P1 几何选路能力在独立对象上成立，再按框架第 5.2 节用匹配的新几何配置执行“普通缓弯/防晃计划 × 在线液体目标开/关”四组。这些消融共用区域、曲率偏好、参考正则和进度模式；另保留同配置无上层及固定几何对照。普通缓弯上层组不等于主基线。profile 列清上层处理、几何自由度、曲率、液体代价/边界、恢复、停车和后缀指导开关。

固定时序/在线进度用同一计划比较；若 P4 信息进入控制，再增加有/无剩余段指导对照。几何放宽带来的共同收益、上层液体规划增量和在线液体目标增量分别报告。旧论文笔记 B/D 编号不直接沿用。

独立仿真覆盖名义执行、短时限速、初始位姿偏差和模型失配；主实验只给控制器实际可获得的信息。未知液体初态/直接液体扰动与可从实际运动更新的激励误差分开评价；真值状态只能用于标明身份的上限研究或独立评价。用于规划的同一模型只能先做流程回归，效果确认另用独立对象。

适配 diag 最近的预测/命令/观测诊断和实验入口，核对新模型与消息身份。完成 ROS1 整链验证后，选定候选做短实车检查及新的配对复验。记录实际路径曲率/变化、低速停转、区域占用、路径长度、全程晃动、耗时、到达、残余和全部失败；跟踪误差仅作诊断，固定停车窗口，以独立液面数据确认防晃效果。

R36 风格整形/滤波参照先限于经过可执行性验证的任务，计入延迟与全部实际耗时。受扰恢复能力优化、高维终端集合、额外监督器及动态避障，在基本两层收益明确后再研究；论文的存在不替代这些机制的本项目验证。

## 7. 必须覆盖的验证与待定项

| 验证对象 | 要区分的行为 |
|---|---|
| 原始路径主基线 | 无新增几何/防晃规划及全程重定时；液体不经代价、约束、恢复、后缀或停车逻辑影响决策；保留正常 MPCC 能力 |
| 主比较与消融 | 主比较报告整套方法差异；贡献消融匹配非被比较设置，普通缓弯上层组与原始路径基线身份分开 |
| 自主几何 | 同初态下区域/目标变化能改变实际转弯半径和时机；接入上层后仍保留选路权限；偏离增大不等于曲率降低 |
| 曲率与低速 | 使用 actual 运动及实际弧长；低速/原地转向不除零、不填零逃避代价；曲率改善与减速、液体收益分开 |
| 区域及进度 | 约束覆盖车体和节点间运动；原路线、名义几何和实际轨迹身份清楚，进度映射越域/跳变显式失败 |
| 计划与任务身份 | 错模型、单位、路径、阶段或过期计划明确失败；请求轨迹模式后不静默退回巡航 |
| 完整 rollout | 同初态/历史/命令下共享传播一致；缩放运输时长不改变物理延迟；包含制动和停车尾段 |
| 全时域参考 | 前方减速进入 N+1 参考；改变优化进度确实改变参考；局部表达式越区间、端点和停等被明确处理 |
| 两种时序模式 | 固定时序时钟不被重置；在线模式只有一个进度；改变时序后液体重新传播 |
| 目标/约束 | contour 弱正则与 lag 关联分开；引导/名义/实际曲率区分；速度与 anti-creep 参考一致；新增代价与 solver 总价一致 |
| 剩余段检查 | 不投影末端、不清历史；液体相位/FIFO 差异能改变结果；候选失败与未评价不误报全局无解或通过 |
| 剩余段进入控制 | 独立开关、优化表达与适用域明确；观察动作和结果变化，计入完整运行耗时 |
| 回归与独立评价 | 轨迹层关闭回到 P1 同配置；新几何模式也关闭才回到旧 feat；真实终点停车、模型内检查与独立效果分开 |

下次复盘优先确定：自主几何的区域、曲率/低速定义与弱参考关系，再确定上层几何和时序的参数化、共同期限、停车事件及参考接口。几何节点/命令参数化、阈值、后缀候选和检查预算在相应阶段冻结；首先用 P1 的明确转弯问题检验自主选路能力。
