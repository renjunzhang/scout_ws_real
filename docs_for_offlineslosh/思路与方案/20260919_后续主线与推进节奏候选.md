# 后续主线与推进节奏：10天收尾安排

更新：2026-09-19。修订重点：补入有文献依据的外部防晃方法对照，区分方法比较与内部消融。当前方法与已有结果依据 `2d2697b7` 对应文档；新增基线尚待实现、验证，本安排没有执行新实验。

**目标：10天内完成现有方法收敛、必要仿真与实物对照、完整论文和投稿材料。按9月19日为第1天，9月28日为第10天；实际启动日不同则整体平移。**

执行前提是第1–2天能接触实车和液面测量设备，并能集中投入。设备窗口和导师反馈时间在第1天明确，不把这些问题留到最后。

## 1. 核心调整：实物前置、写作并行、方法限时冻结

原来的“完善完方法→做完仿真→最后实物→开始写作”风险太大。

改为：**第1天启动写作与实物排查，第2天取得可评估的实车记录，第4天冻结正式配置，第5–7天完成必要重复，第8天形成完整稿，第9–10天修改和投稿准备。**

你已有全程规划、在线MPCC、停车、同计划液体代价消融及时间搜索结果。现在最容易拖延的是开放式改算法和过晚发现实物问题。上次无全局层实物失败，不能直接推出“加入全局层就一定解决”。

本轮优先级：系统能执行且能可靠测量 → 至少一个真实外部防晃方法通过验证 → 与完整方法公平比较 → 用内部消融解释增量 → 完成边界清楚的文章。

上一版只列B0、cost0、Full，缺少有代表性的已有防晃方法，不能充分回答“相比已有方法有什么优势”。本版将外部对照纳入主实验，时间通过取消新功能和次要消融腾出，不能用重命名cost0来替代文献方法。

## 2. 锁定论文范围

保留主线：

> 面向给定区域内的移动机器人液体运输，利用全程几何与速度规划引导在线液体模型MPCC，并通过仿真和实物对照评价运输晃动、耗时及停车残振。

证据围绕四件事组织：

1. **外部防晃方法与Full：**相比经典输入整形、模型防晃规划与跟踪，有什么性能及适用性差异。
2. **B0与Full：**相比普通MPCC的整套系统收益，包含路径、速度和控制变化。
3. **同计划cost0与Full：**下层液体代价在模型仿真中的额外作用，单独列为消融。
4. **实物包含外部方法：**至少一种已通过验证的外部防晃方法与Full在共同任务下比较，不能只验证B0/Full。

**本轮不开发**在线剩余任务重规划、防晃接续、避障、学习安全集、QOPP替代求解器或多模态在线控制。历史PR-RMPC/Tail-Commit失败记录保留，接续方向移出这10天。

38 s缩时单次结果放可选附录或简短讨论，不再继续搜索更短时间。独立上层液体项消融、完整组合矩阵不作为必做；固定路径外部基线按第4节实施，与“给Full额外补一套固定几何消融”分开。

不主张全局最优、时间最优、任意扰动恢复、递归可行性或已经证明两层交互增益。题目与摘要围绕实际验证的能力写。

## 3. 方法只修有明确原因的问题

- **D1冻结我方架构与论文范围，同时确定外部方法定义。** 保留现有上下层结构；新增工作限定为基线实现和核验。
- **D1–D2并行定位实物问题、验证外部方法。** 不继续为提高我方仿真百分比扫参。
- **D3–D4完成必要修复，冻结版本、配置、模型和统计脚本。** 优先只改一至两个有日志依据的问题。
- **D4后不新增机制。** 若发现影响有效性的错误，修复并重做受影响数据，不能混合新旧配置。

| 修复优先级 | 具体问题 | 完成依据 |
|---|---|---|
| 1 | 部署版本、命令出口、限幅、控制节拍、停车或明显超时异常 | 实际执行可解释，任务可完成 |
| 2 | 时间戳、坐标系、单位、重力处理、明显执行延迟或低速响应偏差 | 命令与实测运动主要变化能对上 |
| 3 | 液体频率、阻尼或高度换算的明显错误 | 实测运动重放后，预测与独立液面的主要差异得到解释 |

以现有T=40 s、RMS归一化尺度和1.80 m上层减速包络为起点，只有明确证据才调整。模型修复影响预测时，上下层同步核对。odom或处理后IMU选哪条估计链，在正式实验前按可用性确定并固定；不并行研发两套估计器，不强行将RGB接入实时控制。

## 4. 方法比较与消融：修订后的实验矩阵

### 4.1 五类方法，分清身份

| 组别 | 方法 | 身份 | 主要回答什么 |
|---|---|---|---|
| B0 | 原始路线＋普通MPCC，无液体决策机制 | 工程基线 | 普通运输控制做到什么程度 |
| IS-ZVD | 经典ZVD输入整形＋保持时序的常规执行/跟踪 | 外部经典防晃方法 | 与低计算量前馈防晃方法相比如何 |
| FP-AS | 参考Ferrari固定路径分支的液体约束轨迹规划＋按时间跟踪 | 外部优化方法的Scout适配实现，待验证 | 与已有模型防晃规划路线相比如何 |
| cost0 | Full同一上层计划、同一progress模式，仅关闭下层液体代价 | 内部消融 | 下层液体代价的额外作用 |
| Full | 当前全程联合规划＋在线液体模型MPCC | 本文方法 | 整套方法的效果 |

B0与cost0都不能顶替有代表性的外部防晃方法。**cost0不能换个名字就算FP-AS。** 本表是待实施方案，不代表外部基线现已可运行。

### 4.2 外部方法一：经典ZVD输入整形

文献依据为Guagliumi等2022对输入整形/滤波类防晃方法的研究，§3.1包含ZVD，§4讨论指定总时长。[作者接受稿](https://cris.unibo.it/bitstream/11585/889873/5/antisloshing%20trajectories%20post%20print.pdf)，[正式DOI](https://doi.org/10.1115/1.4054224)。

实施范围先限定为**直线起步—运输—停车**：根据共同标定的液体主频和阻尼构造ZVD，对预定义运动参考整形，再通过常规执行/轨迹跟踪完成。整形脉冲及其时间应依据原文公式核验；写为“ZVD基线”，不声称复现原文所有滤波方法和工业装置。

必须满足：

- 先在其适用的理想直线模型上验证预期残振抑制，再接入Scout执行模型；不能把错误实现当成弱对手。
- 整形延迟及尾段全部计入总耗时。若要匹配总时长，应先重新设计基础轨迹再整形，检查压缩后的加速度/jerk；不能整形后随意整体缩时。
- 参考执行保持所设计的时序；自由progress改速可能破坏整形效果。
- 原文重点是直线起停。连续S路径中的横向激励、转动及车辆约束不同，不能独立滤`v、ω`或`x、y`就宣称完成曲线版复现。

**十天内默认只把ZVD放进直线工况，不新增曲线整形研发。** 若已有可靠的曲线实现，可经验证后加入，但不得因为只适合直线就强行将其在S弯上的失败解释为方法劣势。

### 4.3 外部方法二：固定路径防晃规划＋按时间跟踪

参考Ferrari等2026 §III-A、式(19)的固定路径分支，在给定几何上优化运动时间规律，显式考虑液体响应、运动限制和停车残振，再使用常规时间轨迹跟踪。[论文](https://doi.org/10.1109/LRA.2025.3643281)

这里选择固定路径分支便于控制适配规模；原文§III-B另有几何与时间联合优化，必须在相关工作中说明。**结果只能针对本次复现/适配的分支，不得据此声称全面优于Ferrari全部方法。**

可以复用Scout动力学、液体传播、CasADi和已有轨迹跟踪基础设施，但必须逐项列清：

| 项目 | 保留的算法核心或需要说明的适配 |
|---|---|
| 几何 | 使用预先给定、平滑且Scout可执行的固定路线 |
| 规划 | 独立求解该路径的时间律；保留原文时间/jerk目标、液体限制、起终与残振处理的核心含义 |
| 平台适配 | 机械臂约束换成Scout运动与执行条件，航向按车辆可执行性处理 |
| 执行 | 按真实任务时钟取参考，使用不含在线液体优化的常规轨迹跟踪；不每拍重置参考时钟 |
| 复现报告 | 列明原文与实际实现的模型、决策、目标、约束、离散及求解差异 |

如果为了共同预算改成固定时长，明确写成固定时长适配实验，不说保留了时间最优求解。若只是将我方规划器固定几何、保留我方软代价和progress执行，应标为**本文固定路径变体**，不计入外部方法名额。

D1先确认现有代码是否已具备合适的时间参考跟踪接口；资料中没有足够代码信息，不能承诺该基线两天必然完成。D2检查原文算法要素和简例表现，D3完成公平预试；届时未通过则按第7节调整，不能拿未调通版本进行正式比较。

### 4.4 工况与次数：不把所有方法硬塞进同一场景

| 层级/工况 | 方法 | 预定次数 | 目的 |
|---|---|---:|---|
| 仿真A：直线起停 | B0、IS-ZVD、FP-AS、Full | 各3次，共12次 | 在ZVD适用场景比较经典与优化防晃方法；各组使用同一直线几何 |
| 仿真B：已有S路线/连续转弯任务 | B0、FP-AS、Full，另列cost0消融 | 各3次，共12次 | 主任务的外部方法比较与内部机制解释 |
| 实物主任务：优先S运输 | B0、已验证的FP-AS、Full | 各3次，共9次正式尝试 | 包含外部防晃方法的真实液面对照 |
| 可选实物直线 | IS-ZVD、Full；需要时加入B0 | 每组3次 | 增强经典方法的实物比较，时间不足可取消 |

目标为24次仿真、9次主实物尝试。S任务原有B0/cost0/Full共9次若配置及记录适用可复用，因此目标新增为15次仿真；配置修复影响行为时，重做受影响组，不能混用。

若FP-AS在D2–D3无法形成可信实现，优先保留已验证的ZVD，在**共同直线任务**上安排B0/ZVD/Full实物各3次；S任务保留系统效果及消融。此时论文对外部方法的结论限定为直线运输，并明确缺少复杂路径近邻对照。不得静默改回只有B0/cost0；复杂路径外部对照是导师要求的硬条件时，需承认十天内该项尚未完成，而不是换标签掩盖。

### 4.5 公平比较与实现验收

- 所有组共用平台、容器/液量、初始液体条件、起终条件、物理限制和测量方式；基线获得合理调参机会和相同可用信息。
- 整形、轨迹规划和MPCC分别采用适合自身算法的执行接口；不能用我方自由改速接口破坏其他方法的时序。记录实际跟踪误差及限幅触发情况。
- 共同45 s期限不是同耗时。正式比较前选取预声明的相近实际耗时工作点，或少量时间—晃动折中点；调参数据和评价数据分开，不只挑Full有利的点。
- 固定路径FP-AS与区域内Full的比较说明整套策略取舍，不能将全部差异归于在线液体代价。直线工况限制相同几何，有助于减少这一影响。
- 统一从实际运动和独立评价流程计算结果；实物以真实液面为准，不能各自报告控制器内部预测代价。仿真评估模型与规划模型共源时明说其局限。
- 每个外部方法留一页实现说明：来源、原文要素、平台适配、参数、原理验收和可执行性。只实现思想时如实命名，不写“完整复现”。

已有仿真均为`formal=false`，B0是归档三次。先核对版本、配置、原始日志与统计窗口，确认可追溯、可重算后使用；不只改标签就称正式新实验。

正式次数预先固定，报告逐次点、均值和范围；任务失败、超限均保留。仅采集损坏等明确数据问题按事先规则补跑。不因Full没获胜就删样本或追加调参；同一组三次Full用于多个比较仍只有三次样本。

## 5. 仿真到实物：最短诊断链

### 5.1 先分类上次失败

| 失败表现 | 先查什么 | 不能直接推出 |
|---|---|---|
| 异常退出、走不完或停不住 | 版本、控制节拍、命令和停车链 | 因为缺少全局层 |
| 实际运动偏离预期 | 延迟、限幅、低速及制动模型 | 液体优化本身无效 |
| 运动执行正常，但液面未改善 | 液体模型/估计、激励和方法作用 | 加全局层后必然有效 |
| 液面数据不能分辨差异 | 标定、视角、同步、静水噪声 | 模型指标可替代真实收益 |

旧包能回答的先用旧包，缺什么才补短实验，不开展全面系统辨识。

### 5.2 四类对齐记录

| 记录 | 回答的问题 | 最小动作 |
|---|---|---|
| 名义计划与最终命令 | 下层改了什么？限幅/停车是否改变动作？ | 标记参考模式、有效节拍、关键事件 |
| 命令与odom/处理后IMU | 底盘是否按假设起步、转弯、制动？ | 核对主要延迟、响应和实际激励 |
| 实际运动重放的液体模型与RGB | 已知实际激励后，模型是否仍错？ | 比幅值、相位、停车衰减；先排单位和同步 |
| 公平任务的外部方法、B0与Full | 是否真实降晃？花多少时间？ | 独立测量、统一窗口、冻结配置后重复 |

哪一段先出现明显偏差，就先处理哪一段，不同时换模型、控制器和规划器。当前progress模式可改变名义时序，40 s计划约28 s到点本身不能判错。名义时间、实际到点、停稳分别报告，名义液体序列不能冒充实物状态。

### 5.3 测量先验收

静水片段先确认像素到毫米标定、边缘波动、视角覆盖及同步。用固定规则提取真实液面，模型输出与真实测量分别定义。

当前cost0与Full模型峰值均值差约0.086 mm、RMS差约0.017 mm。真实差值未必相同，但不能预设RGB能分辨这些数值。若下层增量不可分辨，实物验证外部方法、B0与Full的整套效果，下层增量限定为仿真结论。

若视频只见某方向液面，就按该定义报告，不能称测得整个杯沿最大高度；更详细模型的交叉检查也不能替代真实测量。

## 7. 两道门槛和止损规则

### D2：验收实车记录与外部基线

当前版本可低速完成短任务并停车，命令/运动/液面记录能对应，测量有基本标定与噪声记录。**此时不要求防晃已经变好。**

未通过实车项：暂停扩大实验，只修最明确的部署、执行或量测问题。外部方法另行验收其原理、时序接口与可执行性；未调通的算法不能充当弱基线。FP-AS进度不满足时，按第4.4节预定方案缩小工况，保留真实外部比较。

### D4：确定最终可验证的论文主张

至少已有B0、外部防晃方法和Full在共同适用任务上的可评价预试，能够检查真实液面、耗时及停车残振。外部实现说明与简例验收同时完成。预试用于排错与定范围，不充当有效性的最终证明。

| 发现 | 后续处理 |
|---|---|
| 可执行、可测量，预试支持值得正式验证 | 冻结配置，按预定重复做，不继续扫参 |
| 仅差一个明确实现/同步错误 | 最多半天至一天针对性修复，重做受影响预试，取消可选实验 |
| Full降晃主要依赖明显更慢 | 如实报告时间—晃动折中；若需相近耗时结论，补匹配耗时对照，替换其他可选项 |
| 整套实物有效，下层增量无法分辨 | 保留外部方法实物比较，下层增量限定仿真 |
| 真实收益仍不成立或量测不可用 | 保留负结果、缩减主张；10天完成诚实稿件和缺口说明，能否直接投稿由实际证据与目标期刊决定，必要时延后 |

D4正向预试不保证正式重复仍有收益，最终表述服从全部正式数据。不换路线或删样本追求好结果；确需改变任务定义时，标记探索过程并重新冻结。

**D8之后只修数据错误、图表和文字，不新增贡献点、算法和可选实验。**

## 8. 公平条件、指标、图表

共同起终条件、容器/液量、安装、区域、物理限制、期限和评价规则。每次按相同规则等待初始液面稳定，三组实物采用轮换顺序，尽量减小电量和时间漂移。外部方法保留其合理执行方式，不能强制用会破坏其时序的progress参考接口。

主对比允许实际路径不同，但报告路径长度与实际时间。共同45 s期限不等于同耗时，不把整套收益归给单项代价。

保留指标：

- 任务完成/失败、区域或运动超限、控制异常。
- 运输窗口`[0,t_stop)`的真实液面峰值/P95/RMS，模型指标另标。
- 停稳后固定5 s残振；到点与停稳时间分别记录。
- 实际路径、速度和长度，必要曲率统计用于解释。
- 离线规划耗时与在线求解/控制节拍分别报告。

优先复用已有脚本。实测量与模型高度定义不同，先统一物理含义；无法统一则分开报告。

主要图表控制在六组：

1. 框架与两层接口。
2. 实验平台、容器、液面测量和标定。
3. 仿真外部方法比较的轨迹/速度和指标；cost0/Full消融单独成小图，均展示逐次点。
4. 命令—实际运动—液面的对齐记录，解释仿真与实物差异。
5. 实物B0、外部方法、Full的液面时序与重复汇总，明确停车段。
6. 实际耗时、长度、残振和计算开销汇总表。

代表性时序图采用一致选择规则，例如各组最接近RMS中位数的一次，同时展示全部逐次汇总；不只挑最好的一次。
