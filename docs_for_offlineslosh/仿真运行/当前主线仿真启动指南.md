## 复现当前 Full

以下仅为新建单次运行的模板。`NEW_FULL_CASE` 必须换成未使用的目录；端口应为空，使用 Bash 加载入口。

```bash
cd /home/a/scout_ws
source /tmp/scout_tf_epoch_overlay_20260919/setup.bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
python3 scripts/run_trajectory_gazebo_smoke.py \
  --setup /tmp/scout_tf_epoch_overlay_20260919/setup.bash \
  --output /data/a/scout_sim_replacement/results/NEW_FULL_CASE \
  --profile planned_slosh --identified-actuator \
  --task /data/a/scout_sim_replacement/results/20260919_slosh_early_brake_120624/task.json \
  --plan /data/a/scout_sim_replacement/results/20260919_slosh_early_brake_120624/plan.json
```

历史 B0 框架通过 `--profile raw_mpcc`、去掉 `--plan` 运行，共用任务和物理设置。**这仍是原始路径的 B0，不构成与 Full 相同路径的消融。** 同路径对照要先定义共同几何、速度参考和非液体代价；现有 `planned_mpcc` 的相关权重与 Full 不同，不能直接替换 profile 后宣称公平对照已完成。

后续[同计划单次下层消融](../仿真实验分析/01_对比结果/20260919_同计划下层液体代价单次消融.md)已完成：使用上面的 `planned_slosh` 模板，追加 `--slosh-weight 0`，仅覆盖本次下层液体代价，其他参数不变。该对照保留相同的 28 维模型和上层计划；它不是原始 `raw_mpcc` B0，峰值收益尚未逐次通过。

runner 的 `passed` 不代替完整验收：仍须检查 45 s 内到点/持续停车、三指标与绝对液面上限、停车窗覆盖、全程异常及运行物身份。最终三次检查与冻结门槛分别保存在 `full_01..03/assessment.json`、`slosh_limits.json`；离线 `qualification` 仅代表预测检查，闭环资格另存。
