# 仿真对比试验分析索引

更新：2026-09-19。先看最新结果与比较边界，再按需追溯修复和单次验证；历史报告保留原日期。

代码与最小仿真验证已[阶段收尾](../最新结构与方法主线/03_阶段收尾与下一步选择.md)，当前结果分为三类：

[同计划下层液体代价三次对照](./01_对比结果/20260919_同计划下层液体代价三次对照.md)：两组各三次，Full 平均峰值/P95/RMS 降低 14.61%/24.80%/13.35%，平均慢 0.241 s。峰值范围有重叠，按用户口径报告均值与波动，不再为样本完全分离补跑。

[可选时间优化的 38 s 单次闭环](../实现与修复/20260919_时间优化38秒单候选闭环验证.md)：实际 28.282→24.256 s，快 14.24%，晃动增加但仍满足既定门槛，运行无异常，默认开关继续关闭。

此前[防晃优先三次复核](../实现与修复/20260919_防晃优先与可选时间优化.md)：三次新 Full 对照三次冻结 B0，平均峰值/P95/RMS 为 0.505408/0.223075/0.111543 mm，降幅 48.29%/53.62%/45.03%，平均到点 28.282 s，三次均零异常。**Full 改变了路径和速度参考；这是整套方法对比，该批没有同路径公平对照。** 液面仍为 odom 驱动模型估算。

[最新录像（35.4 秒原速）](/data/a/scout_sim_replacement/results/20260919_slosh_priority_video_01/full_slosh_priority.mp4)：绿色是 B0 使用的原始参考，蓝色是 Full 上层优化路径，橙色是定位轨迹。录屏单次正常到点，不并入三次统计。

[执行链修复后的六次验证](../实现与修复/20260919_执行链稳定性修复与三组B0_Full验证.md)先于防晃优先批次，已消除该固定批次的启动、对齐及预算异常；其中旧快速 Full 的 P95/RMS 略高于 B0。09-18 的旧种子筛选结果、缩时超限与单次尝试都是历史数据，不代表最新配置。

启动方式见[当前主线仿真启动指南](../仿真运行/当前主线仿真启动指南.md)；项目总入口见[主线文档](../README.md)。
